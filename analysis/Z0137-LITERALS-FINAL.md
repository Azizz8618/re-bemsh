## 2. УГОЛ 1: БАЙТЫ KOI-7 И ГОСТ

Точная формула forced-листинга. Слово 48 бит = 6 байт
b0..b5 (big-endian). Две короткие команды дают два
16-битных поля операнда:

  поле 1 = биты[8:24]  = байты b1,b2
  поле 2 = биты[32:48] = байты b4,b5

Проверка на известных артефактах (все сошлись):
  0057 70040, 0072 44101, 0073 2015,
  0102 64440, 0110 32460, 0117 1700.

Для 35 KOI-7 слов получено 67 уник. значений полей.
Пересечение с 57: пусто. Расширенный тест, все 16-битные
окна при любом сдвиге 0..47 внутри каждого KOI-7 слова,
тоже дал 0. ГОСТ-таблица к байтам 0137 неприменима
(Z0137-LITERAL-MEANING.md §0.4): коды читаются KOI-7.
Обратная подстановка не изменила байты 38 27 значения
34047, значит совпад не имеет отношения к таблице.

Вывод: ни один из 57 не есть байт-пара имени мнемоники.
