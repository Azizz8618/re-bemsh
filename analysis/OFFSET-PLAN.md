## 0. ОПРЕДЕЛЕНИЕ ОПЕРАТОРА И ОБЛАСТЬ

Правило оператора (обязательное):
«Смещение» включает случай, когда литерал указывает на
ПРОЦЕДУРНУЮ МЕТКУ в том же или внешнем модуле.

Поэтому область работ трёхчастная:

1. числовые смещения внутри зоны (слово, индекс,
   константа, смещение от страницы);
2. адреса меток (A#####, D#####, I####, X#####,
   G#####, системные SUBnnn_...);
3. межмодульные ссылки на метки (B, B2, Монитор,
   другой том).

Не путать со смещением на диске. Дисковый байт =
зона × 8256 + 64 (MM-030000-SOURCE.md §1), а не
адрес в ОП. Модули: B = 0137-0177, B2 = 0540-0577.
B2-зоны 06/78 занимают те же страницы, байты-двойники.

## 1. АРИФМЕТИКА (общая для всех классов)

[ФАКТ] Штамп: адрес в ОП = база + номер слова зоны
(ZONE-BASE-MAP.md §1). Контроль: 0154.0751 -> 02751,
0170.0216 -> 02216.

[ФАКТ] База страницы ОП = страница × 02000₈
(dispak/extra.c:1914-1916, disk_readi в core+page×02000).

[ФАКТ] Окно зоны = [база, база + 02000₈), 1024 слова.
Внутренний адрес: база <= адрес <= база + 01777₈.
Для базы 76000 окно обрезано 15-битным 077777.

[ФАКТ] `-З` вычитает базу наложения: метка минус база =
голый индекс слова 0..01777 (LABELS-ALL-RESTORATION.md
§2, BE-LISTING-MECHANICS.md §5-6).

Правила счёта (OPERAND-CATALOG.md §4):

- кавычные значения восьмеричные;
- голые числа в выражении десятичные;
- D00100+40 -> 00150₈ (база 0100 + 40₁₀);
- `'103'+48-∧N` -> 115₁₀ = 0163₈, затем минус ∧N.

База 030000: [ФАКТ] том 2099, зона 0076, физ. 0102,
байт 544960, 1024/1024 по преобразованию T. Загрузка
uil=10/0/1400, (01400 & 03700)<<4 = 030000, pc=03100,
event n=84646 (MM-030000-SOURCE.md §4, §8). В карту
баз следует добавить запись ФАКТ (в ZBM её пока нет).

## 2. ТАКСОНОМИЯ: ШЕСТЬ КЛАССОВ

### Класс A. Локальное смещение внутри зоны

Примеры: 0154:0751 -> 02751 (штамп), 0147:01315 ->
01315; `Э70 -15` (ASM-Z0057.be:1328), `ЦИКЛ -1`.
Счёт: absolute = base(zone) + word. База из ZBM §3,
ширина слова 6 байт в gold-дампе.
Формы F01, F03, F04, F17 (OPERAND-FORMS-INVENTORY).
Особый случай 0147: база ОП 00000, база сборки 1.
Проверка: absolute - base = word.
Статус баз: ФАКТ 14 зон, ГИПОТЕЗА 3, НЕ ИЗВЕСТНО 52.

### Класс B. Локальная процедурная метка

Примеры: MBE-Z0137.be:693 `ЗП A01036-З+10(М2)`,
MBE-Z0137.be:711 `ПБ A01036-З-38(М6)`,
MBE-Z0137.be:1119 `ПВ A01036-З(М16)`.
Счёт: absolute = base(zone) + word(label) + off₁₀.
При `-З`: результат = word + off, то есть индекс без
базы. Мнемоники: пв CALL; пб, по, пе, цикл, выпр
ветвление; это ядро правила оператора.
Индекс: PROC-LABEL-INVENTORY.md, 2676 меток.
Роль: A##### код, D##### данные (F07, F08).
Уверенность: 1089 статических CALL, из них 926 только
из dis-forced; 1 ФАКТ (0147:1322, 31 vjm).

### Класс C. Межзоновая цель в модуле B или B2

Примеры: литерал 70000 в 0137 -> страница 34 -> 0150;
2001 -> страница 01 -> 0154; `ВНЕШН Z0155.Z0155A`
(F12, F35) -> зона 0155.
Счёт: absolute = страница × 02000₈ + смещение.
page = absolute >> 11; зона по карте страниц ZBM §4.
Граница: цель попадает в окно ДРУГОЙ зоны того же
модуля B (0137-0177) или B2 (0540-0577).
Статистика 0137: 186/273 литералов имеют file:line
в другой зоне, 129/177 привязаны к странице.
B2-двойники 06/78 не различаются по содержимому.

### Класс D. Внешняя цель: Монитор, другой том

Примеры: 64xxx (стр.32, Монитор, 4 литерала),
72554 и 66151 (стр.35/65, ГИПОТЕЗА), поле 16-25
CALL загрузчика (73 литерала), база 030000.
Счёт: страница × 02000₈ + off для стр.16-25 и 32;
030000 по формуле uil; для стр.35/65 зоны нет.
target_zone пусто, scope=external.
Статус: 4 монитор-адреса ФАКТ, 73 поля задачи
НЕ ИЗВЕСТНО (Z0137-XREF-FORCED.md §3(d), §6).

### Класс E. База-относительная форма `-З`

Примеры: D00003-З (MBE-Z0137.be:523), D00720-З+1
(ASM-Z0060.be:729), `З ЭКВ Z0137` (MBE-Z0137.be:177).
Счёт: value = base_symbol - З ± off₁₀, где base_symbol
из ЭКВ `З ЭКВ Znzzz` (24 определения).
876 вычитаний базы (OPERAND-FORMS-INVENTORY.md §5).
`МЕТКА-З±k(Mn)` (F21): 398 с индексом, 342 без,
136 просто `МЕТКА-З`. Для 0147 `-З` не нужен.
Проверка: без `-З` в CALL 01036 стало бы 11036.

### Класс F. Адрес текстового или табличного слова

Примеры: KOI-7 таблица 0137:0057-0121; GOST 0144;
0141 полная копия 1612-1654; 0166:0646-0710.
Счёт: absolute = base(zone) + word, word из каталога
650 слов (V78-TEXT-LITERALS-CATALOG.md §2).
GOST 379, KOI-7 105, TEXT 166, ITM 0.
Адресуется метками D00077, D00100 внутри зоны, не
абсолютными литералами (Z0137-XREF §3(a): 0 лит.).
Проверка: v78_word_inspect.py --zone Z --word W.

## 3. СХЕМЫ ДАННЫХ ДЛЯ ДВУХ НОВЫХ ИНСТРУМЕНТОВ

Инструменты строятся параллельно, но не в этом
write set. Порядок и имена полей фиксированы.

### 3.1 Индекс меток: label index record

Ровно восемь полей:

    {label, zone, base, offset, absolute,
     kind, file, line}

Пример:

    {
      "label": "A01036",
      "zone": "0137",
      "base": "-",
      "offset": "01036",
      "absolute": "",
      "kind": "code",
      "file": "dis-forced/Z0137.asm",
      "line": 693
    }

Правила:

- label: A#####, D#####, I####, X#####, G##### или
  системное SUBnnn_... из инвентаря;
- zone: 4 восьмеричные цифры из имени файла;
- base: из ZBM Приложение A, '-' если НЕ ИЗВЕСТНО,
  '72000?' если ГИПОТЕЗА;
- offset: номер слова зоны, восьмеричный;
- absolute: base + offset, пусто при неизвестной базе;
- kind: code для A, I, X и CALL; data для D и таблиц;
- file, line: первичное вхождение в dis-forced/*.asm.

Источники: 2676 меток PROC-LABEL-INVENTORY, 2197
восстановленных в .be (LABELS-ALL-RESTORATION),
Gnnnnn из смежных .be (0 в 69 .be).
Дедупликация по (label, zone). Мощность >=2676.

### 3.2 Запись смещения: offset record

Ровно двенадцать полей:

    {file, line, mnemonic, operand_raw,
     base_symbol, offset_value, offset_radix,
     absolute, target_label, scope,
     target_zone, status}

Пример:

    {
      "file": "bemsh/MBE-Z0137.be",
      "line": 693,
      "mnemonic": "ЗП",
      "operand_raw": "A01036-З+10(М2)",
      "base_symbol": "A01036",
      "offset_value": 10,
      "offset_radix": "decimal",
      "absolute": "",
      "target_label": "A01036",
      "scope": "local",
      "target_zone": "0137",
      "status": "НЕ ИЗВЕСТНО"
    }

Правила:

- file, line, mnemonic, operand_raw дословно: ЗП в .be,
  зп в dis-forced, источник виден по имени файла;
- base_symbol: З, Dnnnnn, Annnnn, 'nnnnn' или page;
- offset_value знаковый; offset_radix = octal для
  кавычных, decimal для голых, symbolic для ЭКВ;
- absolute восьмеричный, пусто при неизвестной базе;
- target_label из индекса §3.1 или пусто;
- scope: local | interzone | external (классы B, C, D);
- target_zone: 4 цифры или пусто;
- status: ФАКТ | ГИПОТЕЗА | НЕ ИЗВЕСТНО; в JSON
  инструмента приняты короткие коды Ф, Г, Н.

Совместимость: file, line, mnemonic, operand_raw уже
есть в v78_operand_probe.py; его value.radix даёт
offset_radix. v78_word_inspect.py даёт байты слова.
