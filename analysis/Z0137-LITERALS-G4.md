## 2. ОБОЗНАЧЕНИЯ

ЗНАЧЕНИЕ: восьмеричное/десятичное.
ГДЕ: адрес слова в зоне 0137 ( dis_word - 1,
восьмеричное ) и мнемоника из bemsh-строки.
"+" = последующие адреса по порядку применений,
"xN" = число повторов мнемоники.
CONST = простая константа/заполнитель.
EXTERN = кандидат внешнего смещения (база,
адрес в другом модуле/странице).
[Д] = вердикт прямо назван в документе.
[Г] = вердикт сам помечен как гипотеза.

## 6. ОГРАНИЧЕНИЯ

Роль ни одного из 25 литералов не доказана
исходником транслятора. Класс CONSTANT [Д]
опирается на явную формулировку аудита, но это
всего лишь техническая заглушка. Возможное
чтение малых литералов как ячеек зоны
(AM10 = ячейка 010) остаётся ГИПОТЕЗОЙ:
LABELS-KEY-BE.md:204 отрицает адресную роль
этих чисел в 0137. Для AM1700/B22015/B24102
комментарий bemsh:539-540 называет "база" и
"адреса", что противоречит EOC:45,60,64
(PLAIN_CONSTANT). Расхождение не разрешено.
