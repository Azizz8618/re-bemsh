## 1. Что делает зонд

Вход: один или несколько файлов .be и/или листинг
dispak. Позиционные аргументы, ключи:

  --format json|text   формат вывода (по умолчанию text)
  --check              проверить инварианты

Зонд извлекает:

  072000  база пула, страница 035
  06402   указатель, младшие 11 бит дают r[16]
  06445   счётчик длины, НЕ смещение пула
  2010    48-битное слово дескриптора

Символы ищутся по границе восьмеричной цифры, поэтому
76445 и 26445 не дают ложного срабатывания. Строки
с ЭКВ помечаются define, с atx/ЗП/store - write,
с СЧ/xta/arx/read - read, остальные - mention.

Дескриптор читается как четыре поля по 12 бит:

  [ 2010 | N | 0005 | 200K ](8)
  биты 47..36  флаг 2010 = 2000 OR 0010
  биты 35..24  N, номер исходной строки
  биты 23..12  константа 0005
  биты 11..0   поле 2000 + K

K = младшая цифра поля 200K, число слов записи.
Слова с префиксом 2000 (после MEND) попадают в
отдельный счётчик prefix2000 и в проверку НЕ идут.

## 2. Проверяемые инварианты

  flag_2010    поле флага равно 2010 (восьм.)
  tag_0005     константное поле равно 0005
  K_2_5        число слов записи в диапазоне 2..5
  N_monotonic  N не убывает внутри одного файла

Монотонность проверяется отдельно для каждого файла:
N это номер строки одного потока, не общий id.
Константа 0005 названа в задании "field2", а в
PDF §1 это биты 23..12, то есть третье поле слова.
При --check пустой результат считается нарушением
descriptor_present. Код возврата: 0 чисто, 1 нарушение,
2 ошибка чтения файла.

## 4. ФАКТ

  дескриптор = 4 поля по 12 бит, 48 бит всего;
  флаг 2010 получается OR бита 0010 с базой 2000;
  маска 01762 = 0000000000052000 воспроизведена;
  константа 0005 постоянна во всех наблюдаемых словах;
  K принимал значения 2, 3, 4, 5 в отчётах;
  N в отчётах не убывает внутри одной последовательности;
  пул начинается с 072000, индекс из младших 11 бит 06402;
  06445 не равно смещению пула;
  зонд прочитал реальный MBE-Z0154.be без записи;
  все 31 новых теста прошли.

## 5. ГИПОТЕЗА

  2010 против 2000 разделяет строки внутри макроса
    и после MEND (D05 §1, TPL §4);
  0005 это код формата "исходная строка" (D05 §5);
  развёртка макроса читает дескрипторы при вызове,
    в опытах макрос не вызывался (TPL §5).

## 6. НЕ ИЗВЕСТНО

  почему константа равна именно 5;
  точный смысл префиксов 002 и 247;
  что делает обработчик 06051-06056 на границе;
  поведение пула при заполнении всех 1024 слов;
  причина расчёта базовой цифры 450 (см. §8).
