Дата: 23.11.2026. Write set: только новый файл,
`tools/rebuild-matrix.sh` и его тест. Ни один существующий
файл, Makefile или `.be` не менялся. Коммитов нет.

Статусы: [ФАКТ] наблюдение, [ГИПОТЕЗА] догадка,
[НЕ ИЗВЕСТНО] ответа нет. Восьмеричные адреса.
Степень: `↑`. Тире не используется.

## 0. Зачем

Оператор попросил "попробовать разные режимы".
`tools/rebuild-zone.sh` жёстко задаёт: карту `0-0`,
карту `ЗОНМОД433900  0001`, `лент 43(2248-ЗП)`,
вызов `dispak -l`. Нужно знать, какие из этих
параметров действительно влияют на побайтовую
сборку, а какие можно менять.

Различены пять осей "режима":

1. карта вывода задания: `0-0` или `1-1`;
2. карта `ЗОНМОД`: есть или нет;
3. получатель ленты 43: `2248`, `2249`, `2099`,
   без `-ЗП`;
4. флаги `dispak`: `-l`, пусто, `-tt`, `-s`,
   `--no-insn-check`, `-b`;
5. guard `BESM6_PATH`: strict против default.

Ось `disbesm6` base против forced W_CODE отделена:
это вариант дизассемблирования, не режим сборки.

## 3. ФАКТ

F1. Карта `ЗОНМОД` пишет в ленту 43 и в режиме
`0-0`. В A0 md5 копии `2248` изменился. Комментарий
в `rebuild-zone.sh`: "листинг (0-0) не пишет в
образы", неверен при наличии `ЗОНМОД`. Пишет
именно карта, а не `0-0`: в A2 без карты образ
не меняется.

F2. Все ячейки `0-0` дают 1024/1024 и `Δb=0`
независимо от `ЗОНМОД`, кодировки, `-tt`, `-s`,
`--no-insn-check`, номера ленты и `-ЗП`.

F3. Режим `1-1` (A1, A3) печатает таблицу символов,
а не объектные слова: листинг 7,4-7,5 КБ,
0/1024 слов. Текущий разборщик слов здесь не
работает. Режим не пригоден для сборки из листинга.

F4. `1-1` сам по себе не пишет образ: в A3 нет
изменения md5 и нет сообщения `ЗАПИСАН`. Строка
`МОДУЛЬ Z0137 ЗАПИСАН В ЗОНЫ С 433100 ПО 433101`
появляется в A0, A1, C1, C2, C3, то есть там,
где есть `ЗОНМОД`. Это подтверждает вывод
`docs/MACRO-TABLE-FORMAT-VERIFIED.md` §10.

F5. `-b` не батчевый режим: листинг 114 байт,
вывод отладчика и `неверный ключ`, слов нет.
`rc=0`, но результат не usable.

F6. Имя `2248b` отвергается: `ЧУЖОЙ СИМВОЛ`
(буква `b` не восьмеричная). Числовое имя `2249`
работает и даёт 1024/1024.

F7. `лент 43(2248)` без `-ЗП`: в листинге
`disk_writei: disk 2248 is read only` и
`ОШИБКА МД ЭВМ`, но слова 1024/1024, `Δb=0`.
Ошибка записи на ленту не портит набор слов.

F8. `-tt` дал 26 407 169 строк трассы и не изменил
набор слов: 1024/1024.

F9. Тест `tools/tests/test_rebuild_matrix.py`:
9 тестов, все прошли без `dispak` (0,23 с).

F10. Кросс-проверка зоны `0147`: ячейки A0, A2, B1
тоже дали 1024/1024 и `Δb=0`.

## 4. ГИПОТЕЗА

H1. В `1-1` записанный модуль содержит слова
перемещений, поэтому дамп записанной зоны не совпал
бы с gold побайтово. Согласуется с
`docs/REBUILD-0137.md` §3, но здесь не измерялось:
записанный модуль не выгружался.

H2. Печать слов и запись по `ЗОНМОД` идут по
независимым путям. Основание: отказ записи в C3
не изменил слова.

H3. Разница `0-0` против `1-1` это переключатель
формата печати в МАКРО-БЕМШ. Исходника
транслятора нет, доказать из кода нельзя.

## 6. Ось disbesm6: base против forced

[ФАКТ] `dis/MBE-Z0137-L1.asm`: 1038 строк,
`dis-forced/Z0137.asm`: 2041 строка, различаются

есть против сырого бинарника, а не против `.asm`.
Ось ортогональна режимам `dispak`.

## 7. Итог: валидные режимы

VALID для побайтовой сборки:

```
карта 0-0; ЗОНМОД любая; -l или кириллица;
-tt; -s; --no-insn-check;
лента 2248, 2249 или 2099;
с -ЗП или без -ЗП (в последнем случае шум в логе).
```

INVALID:

```
карта 1-1 (нет объектных слов в листинге);
флаг -b (не батч).
```

Осторожно: при `ЗОНМОД` образ копии меняется,
поэтому прогон только на копиях обязателен.

## 8. Вызов скрипта

```
bash tools/rebuild-matrix.sh --help
bash tools/rebuild-matrix.sh --dry-run 0137
env -u BESM6_PATH bash tools/rebuild-matrix.sh 0137
REBUILD_MATRIX_CELLS="A0-base C2-tape2099" \
  env -u BESM6_PATH bash tools/rebuild-matrix.sh 0137
REBUILD_MATRIX_WORK=/dev/shm/rebuild-matrix \
  env -u BESM6_PATH bash tools/rebuild-matrix.sh 0137
```

Guard: отказ с кодом 3, если `WORK` или входящий
`BESM6_PATH` указывает на `/usr/local/share`,
`~/.besm6` или `EC5061`. `--help` guard минует.
Артефакты ячейки: `job.b6`, `listing.out`,
`silver.bin`, `meta.txt`. Копии образов удаляются
после ячейки.
