## 1. Структурная карта зоны 0172

База 02000. Абсолютный адрес = 02000 + offset слова.
Диапазоны ниже наблюдённые, границы приблизительные там,
где стоит знак ≈. Роль блоков вне ядра это [ГИПОТЕЗА]
(статика без динамического доказательства).

Формат блока:
  <offset слова> (абс <адреса>) / роль
    вход/выход: ...
    читает/пишет: ...
    источник: <файл:строки>

  0000-0100 (абс 02000-02100) / резервуар нулей, D00100
    вход/выход: нет
    читает/пишет: зп START
    источник:Z0172.asm:6-149

  0100-0241 (абс 02100-02241) / данные, D00200
    вход/выход: нет
    читает/пишет: зп D00200
    источник:Z0172.asm:149-343

  ≈0242-0377 (абс 02242-02377) / старт, флаги
    вход/выход: из монитора [Г]
    читает/пишет: уиа, сч, пб; 02173, 02177
    источник:Z0172.asm:344-530

  ≈0400-0520 (абс 02400-02520) / разбор операндов
    вход/выход: пб/пе
    читает/пишет: счи, и, нтж; 02005, 02167
    источник:Z0172.asm:529-773

  ≈0520-0777 (абс 02520-02777) / подпрограммы
    вход/выход: пб/пе
    читает/пишет: сда, или, зп; 02006, 02007
    источник:Z0172.asm:773-1017

  ≈1000-1122 (абс 03000-03122) / управляющие слова
    вход/выход: нет
    читает/пишет: зп D00377, конк
    источник:Z0172.asm:1017-1180

  ≈1123-1400 (абс 03123-03400) / константы, сообщения
    вход/выход: нет
    читает/пишет: конк, зпм, вчаб
    источник:Z0172.asm:1180-1521

  ≈1400-1447 (абс 03400-03447) / дескрипторы [Г]
    вход/выход: нет
    читает/пишет: зп '44xx'

    читает/пишет: -
    источник:Z0172.asm:1900-2012

    вход/выход: нет

## 2. Побайтовое доказательство (сжато)

[ФАКТ] Слово = 6 байт. Первые 3 байта это L-половина,
  последние 3 байта это R-половина (cu.c:199-201 чередует
  L и R полукоманды при одном PC). offset = PC - 02000.

  PC 03453, offset 01453:
    0172: 3e 07 33 | 10 80 00
      L: struct=1, op1 014 → 114, reg 3, addr 3463
         = пио '3463'(М3)  [трасса: vzm 3463(3)]
      R: op 010, reg 1, addr 0
         = сч (М1)         [трасса: xta (1)]
    0170: f0 d0 02 | 0c 05 2a
      L: op 015, reg 17, addr 2  = или 2(М17)
      R: op 110, reg 0, addr 2452 = пб '2452'
      Совпадения НЕТ.

  PC 03515, offset 01515:
    0172: 5a 7f fe | 09 00 00
      L: struct=1, op1 004 → 104, reg 5, addr 77776
         = уиа -2(М5)  [трасса n=421272, 569201]
    0170: 09 00 00 | ec 88 58  даёт utc/другое, не vtm.

[ФАКТ] 27 полукоманд подряд (03451-03465 плюс 03515)
  совпали по тройке (код, адрес, регистр). Случайность
  исключена. Ни одна не совпала со словом 0170.

[ФАКТ] Дополнительное подтверждение: статические слова
  зоны 0172 совпадают с трассой и вне ядра:
    offset 1573 = сч D01777+3 / или D01777+5
                 трасса 03573: xta 2002 / aox 2003
    offset 1574 = или D01777+5   трасса 03574: aox 2004
    offset 1607 = ржа '3'        трасса 03607: ntr 3

    offset 1611 = пб (М4)       трасса 03611: uj (4)
  Это путь ЭКВ из BEMSH-MACROMACHINE-MECH.md §4.2.
  Все пять точек совпали (оптимально для зоны 0172).

## 4. Цикл макромашины в мнемониках БЭСМ

[ФАКТ] Ниже кадр из MM-STATIC-DYN-MAP.md §4 и
  BEMSH-MACROMACHINE-MECH.md §2.1. Все адреса это
  абсолютные PC, зона 0172, база 02000. Слева мнемоника
  БЭСМ, в скобках динамический смысл из трассы.

Пролог (вход в тело):
  03451 сч '3415'      загрузить операнд
        зп D01777+7    положить в ячейку 02006
  03452 сч             взять ноль
        зп D01777+8    положить в ячейку 02007
  03453 пио '3463'(М3) читать поле ∧-параметра, индекс М3
        сч (М1)         база текста по М1

Тело (.СЛ):
  03454 сбр D01777+7   сложить с 02006
        сда 64+40      сдвиг/маска константы
  03455 уи  М6          установить М6
        мода '70146'   модификация адреса
  03456 сч  (М6)       читать по М6
        сбр '3415'(М4)  сложить с константой по М4
  03457 рзб D01777+7   вычесть 02006
        или D01777+8    ИЛИ с 02007
  03460 зп  D01777+8   результат в 02007
        слиа -1(М3)    декремент счётчика ∧N в М3

Ветвление назад:
  03461 сч  D01777+7   взять 02006
        сда 64+8       сдвиг
  03462 зп  D01777+7   записать 02006
        пе  '3453'     перейти на 03453, если М3 != 0

Выход (при М3 = 0):
  03463 сч  D01777+8   взять 02007
        зп  (М2)       записать по М2
  03464 слиа 1(М1)     сдвинуть М1
        слиа 1(М2)     сдвинуть М2
  03465 пино '3451'(М3) переход по М3 к 03451
        пб  (М5)       переход по М5 (выход из макроса)

### 4.1 Счётчик 48 → 1

[ФАКТ] Два связанных счётчика идут в обеих половинах:
  М3 на 03460 (слиа -1(М3)) принимает значения
    00061 → 00060 → 00057 → ... → 00001 → 00000
  (это восьмеричные 49, 48, 47, ..., 1, 0).
  Аккумулятор на 03515 (уиа -2(М5)) принимает
    0060 → 0057 → ... → 0001 (ровно 48 значений),
  нуля в уиа нет: ноль только закрывает цикл.
[ФАКТ] Первое значение М3 = 00061 (49), а не 00060,
  зафиксировано в трассе (MACRO-OPS-LOOP-DYN.md:57-83).
  Причина сдвига на 1 [НЕ ИЗВЕСТНО].
[ФАКТ] Значения М3 и acc совпадают со значениями ∧N
  в макросах Е, ЕЕ, ОПРЕ, ЕВНЕШ (§5 старого отчёта).
[ГИПОТЕЗА] 03460 реализует обе строки SЕТА: начальную
  SET 48 и декремент SET ∧N-1. Прямого доказательства
  обеих строк в одном слове нет.

### 4.2 Подстановка ∧-параметров

[ФАКТ] На 03453 пио '3463'(М3) читает слово по адресу
  03463 с индексом М3. Это выбор текущего ∧N из таблицы
  параметров. Адрес 03463 сам лежит в зоне 0172
  (offset 01463). В трассе это vzm 3463(3).
[ФАКТ] xta (1) на той же строке берёт базу текста по М1
  (MM-STATIC-DYN-MAP.md §4, L-половина).
[ФАКТ] Пул исходных текстов макроопределений физически
  по 072000 (BEMSH-MACROMACHINE-MECH.md §4.1), запись
  06061 atx 72000(16), дескриптор [2010|N|0005|200K].
[НЕ ИЗВЕСТНО] Кто именно читает записи пула 072000 при
  развёртке. Опыты P0-P2 макрос не вызывали.

### 4.3 Ветвление AIF

[ФАКТ] Адрес 03462 пе '3453' есть динамическая форма
  AIF (∧N NЕ 0).СЛ: переход берётся, пока М3 не нуль.
  При нуле управление идёт на 03463 и 03465, цикл
  закрывается (MACRO-OPS-LOOP-DYN.md:146-149).
[ФАКТ] Условный AIF из §3 старого отчёта идёт по цепочке
  04160 → 03342 → 03343 → 03433/03434 → 77000.
[НЕ ИЗВЕСТНО] Статическое прочтение 03342/03343 в зоне
  0172 даёт мода '44400'(М4)/зп '4541' и сл/зп '4541'
  (Z0172.asm:1462,1464), то есть НЕ aex/u1a из трассы.
  Сам старый отчёт (§3) уже отметил, что содержание этих
  адресов зависит от оверлея. Побайтового доказательства
  AIF-сайта в настоящем отчёте НЕТ.

### 4.4 Куда идёт результат

[ФАКТ] ЭКВ считается на 03573/03574/03610:
  сч 2002 / или 2003 / или 2004 (операнды),
  и 3724, зп 2001 (результат). Статика зоны 0172
  совпала с трассой (§2 выше, 5 точек).
[ФАКТ] Из 02001 строится запись таблицы *MET*:
  04146 aox 2001, 04147 atx (7), ячейки 73266/73267.
  В макросе Е за 48 проходов порождается 48 символов
  E1..E48 с адресами 00103..00162.
[ФАКТ] При ЕВНЕШ результат это 46 внешних символов
  E1..E48 и 48 строк OПEPAЦИИ HET в листинге.
[НЕ ИЗВЕСТНО] Попадает ли значение ЭКВ в объектное слово
  при другой конфигурации задания: в опытах оно шло
  в *MET*, а не в объектный модуль.

## 6. Роль зон 0170 и 0154, механизм оверлея

[ФАКТ] Зона 0170 исполнялась ТОЛЬКО на входе:
  01314 uj 2000 → 02000 ntr 3 → uj 2214 → 02214.
  Штамп 0170.0216 «МАКРОМАШИНА ОТ 1.11.78» найден в ОП
  по 02216, база 02216 - 0216 = 02000
  (BEMSH-MACROMACHINE-MECH.md §1, PASSES-CODE-LOCATION.md).
[ФАКТ] Зона 0154 это редактор (проход 1), загружается
  первой по той же базе 02000. Слово 02000 в ней это
  xta 6065. PC 03453 в редакторе даёт уиа -5(М12)

## 7. ВЕРДИКТ

[ФАКТ] 1. Зона 0172 с базой 02000 это РЕАЛЬНЫЙ интерпретатор
  макромашины 06/78. Ядро занимает offset 01450-01467
  (PC 03450-03467) плюс счётчик на offset 01515 (PC 03515).
[ФАКТ] 2. Все 27 полукоманд PC 03451-03465 и 03515 побайтово
  совпали с трассой по (код, адрес, регистр). Ни одна
  не совпала со словом 0170 в том же offset.
[ФАКТ] 3. Статика 0172 дополнительно совпала с трассой
  на 03573/03574/03607/03610/03611 (путь ЭКВ), 5 точек.
[ФАКТ] 4. Зона 0170 исполнялась только на входе
  (ntr 3, uj 2214, штамп по 02216). Это НЕ ядро.
[ФАКТ] 5. Зона 0154 это оверлей редактора,
  та же база 02000.
  Смена оверлея идёт через Э70: 0154 → 0170 → 0172.
[ФАКТ] 6. Счётчик живёт в М3 ( слиа -1(М3), 00061 → 0)
  и в acc на 03515 (уиа -2(М5), 0060 → 0001, 48 шагов).
  Возврат AIF это пе '3453' на 03462, пока М3 != 0.
  Результат ЭКВ идёт 02002/3/4 → 02001 → 73266 → *MET*.

[ГИПОТЕЗА] 1. 03460 реализует и SET 48, и SET ∧N-1;
  сдвиг 00061 против 00060 не объяснён.
[ГИПОТЕЗА] 2. 03453 это точка .СЛ, 03462 это AIF.
[ГИПОТЕЗА] 3. Блоки 0242-1447 и 1470-1776 это
  подпрограммы интерпретатора, их роль не доказана.
[ГИПОТЕЗА] 4. 0170 и 0172 это два куска одной программы.

[НЕ ИЗВЕСТНО] 1. Кто инициирует загрузку 0172.
