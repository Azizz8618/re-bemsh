# РВС 01/78: разрешение внешнего символа 50321255

## 0. Первичные источники

1. w2.err, полная трасса -tt + WATCH.
   Фрагмент: строки 519347-519689.
2. dump5.out, дамп 72470-72520 на PC 72361.
3. dump.out / dbg2.out, 185 слов РВС начиная с 72200.
4. Исходники: bemsh/MBE-Z0154.be:194, :889;
   bemsh/MBE2-Z0554.be:223, :833;
   c0154.b6:20; link.b6:28.
5. analysis/OFFSET-FINAL.md §12-14.

Все числа восьмеричные. acc - 48 бит, в трассе 16 цифр.
`wtc` - точка WATCH, не код РВС. Мнемоники как в трассе:
`aax` = И, `aex` = XOR, `aox` = ИЛИ, `asn` = сдвиг,
`utc` = сброс acc, `vjm`/`uj`/`uza`/`u1a` = переходы.

## 2. Шаг 72301-72305: расщепление 50321255

```
72301 atx 72504   acc 50321255 -> 72504
72302 xta 72504
72303 aax 72437   & 0000000077770000 = 50320000
72304 atx 72501   база = 050320, в 72501
      aex 72504   50320000 XOR 50321255 = 00001255
72305 atx 72504   смещение = 001255, в 72504
```

Маска 72437 держит средние 16 разрядов слова внешнего
имени. `aex` (XOR) снимает уже выделенную базу и оставляет
младшие 16 разрядов. Это и есть "голое" 001255.

Какая из полей дальше используется:
- 72501 (база 50320): только тест флага на 72306 и
  печать диагностики на 72357-72360. В арифметике
  коррекции не участвует.
- 72504 (смещение 1255): главное значение. Оно идёт в
  `a-x 72500` на 72247, в `aax 72444` на 72274 и
  заменяется результатом на 72257 и 72264.

То есть вопрос "почему 50321255 стало 001255" решается
одной командой 72304: база уходит в 72501, а в acc
остаётся только младшее поле.

## 3. Шаг 72316-72317: 040100, 066231 -> 026331

040100 не константа РВС. Это младшие 16 разрядов второго
полуслова объектного слова:

```
519476 72157 apx 72506  (=0000000077777777)
              acc=5032125561040100
519478 72160 atx 72514  acc=0000000061040100
519498 72227 atx 72500  acc=0000000000040100
```

То есть `61040100 & 077777 = 040100`, записано в 72500.

066231 - константа по адресу 72477, дубль по 72516:
dump5.out: `C 0000 0000 0006 6231` (72477 и 72516).
В 72316 читается именно 72477:

```
519542 72316 xta 72500   (=0000000000040100)
519543 72316 a+x 72477   (=0000000000066231)
                              -> 0000000000126331
519544 72317 aax 72445   (=0000000000077777)
                              -> 0000000000026331
519545 72317 atx 72500   store 0000000000026331
```

`126331 & 077777 = 026331`. Маска 077777 (15 бит)
сбрасывает переполнение старшего разряда. Дамп на 72361
подтверждает: 72500 = 0000000000026331.

## 4. Инвариант и нарушитель

Формула коррекции (путь вычитания, флаги 72502 = 4):

```
delta = (72504 - 72500) по модулю 2^15
      = (001255 - 026331) = -010796
      15-разрядное дополнение: 052724
72445: delta & 077777 = 052724
72264: 72504 := 052724
```

Трасса: w2.err:519554, 519563, 519566.

Инвариант успеха: `0 <= delta <= 07777`.
Причина нижней границы: 026331 > 001255, разность
отрицательная и превращается в большое положительное
число. Причина верхней границы: 72274 маскирует
`0007777`, то есть в поле адреса команды влезает только
12 разрядов. 052724 = 21972 > 07777 = 4095.

Нарушение зафиксировано в итоговой строке w2.out:

```
НЕВЕРНЫЙ АДРЕС В КОР КОМ  АДРЕС СЛОВА 42122
ИКОП 12 032  АДРЕС 52724
```

`52724` в сообщении - это ровно содержимое 72504
(dump5.out: `C 0000 0005 2724`). Слово заплатки всё же
собирается: 72274-72265 дают 51322724 (w2.err:519605,
519610), но диагностика уже выдана.

Какие значения обязаны выполняться: смещение символа
должно быть не меньше базы 72500, и разность должна
влезать в 12 разрядов. Здесь 001255 < 026331, условие
нарушено. Это не перезапись tables и не раскладка
объектов: OFFSET-FINAL.md §14 снял гипотезу наложений.

## 5. Ответственный модуль и минимальная правка

Символ: BR0321 ЭКВ '50320'.
Определён: bemsh/MBE-Z0154.be:194 и
bemsh/MBE2-Z0554.be:223.
Использование: `ПЕ BR0321(М12)`,
MBE-Z0154.be:889 и MBE2-Z0554.be:833.

Link-задание link.b6 содержит Z0137-Z0177, но НЕ Z0554.
Поэтому в этой сборке работает BR0321 из MBE-Z0154.be.
Модуль Z0154: link.b6:28 `мдл Z0154 434032`,
`наз 002000`; c0154.b6:20 `Z0154 СТАРТ '2000'`.
Смещение 1255 совпадает с литералом
MB1255 ЭКВ '1255' (MBE-Z0152.be:269).

Структурная причина: BR0321 задан абсолютным ЭКВ
'50320', а модуль грузится по другой базе. Внешнее
имя несёт абсолют 50320 и малое смещение 1255, тогда
как вычисленная база 026331 много больше смещения.

Минимальная правка (НЕ применять): в bemsh/MBE-Z0154.be
заменить абсолютный `BR0321 ЭКВ '50320'` на
перемещаемый символ (внешний/локальный) и пересобрать
объект Z0154. Альтернатива, менее надёжная: добиться,
чтобы смещение в слове внешнего имени превышало 026331,
то есть перегенерировать второе полуслово 61040100.
Правка только `наз` недостаточна: три варианта
(START, измеренная база, база из слова 2) уже дали
одинаковый НЕВЕРНЫЙ АДРЕС.

## 6. ВЕРДИКТ

ФАКТ (с цитатами):

1. Расщепление 50321255 на 50320000 и 00001255:
   PC 72301-72305, w2.err:519448-519459 и
   w2.err:519516-519527. В 72501 база 50320, в 72504
   смещение 1255.
2. 040100 получено из 61040100 маской 077777:
   PC 72226-72227, w2.err:519498.
3. 066231 - константа 72477, дубль 72516: dump5.out;
   чтение на PC 72316: w2.err:519543.
4. 72500 = (040100 + 066231) & 077777 = 026331:
   PC 72316-72317, w2.err:519542-519545.
5. Разность 1255 - 26331 = -10796, дополнение 052724:
   PC 72247, 72262, 72264; w2.err:519554, 519563,
   519566. Дамп 72504 = 52724: dump5.out.
6. Базовое поле 50320 в арифметике не участвует:
   PC 72306 (тест), 72357-72360 (печать).
7. Маска 0007777 на PC 72274: w2.err:519605.
   Заплатка 51322724: w2.err:519610.
8. Текст ошибки с АДРЕС 52724: w2.out.
9. BR0321 = 50320 в MBE-Z0154.be:194, вызов на :889;
   Z0154 в link.b6:28; START '2000' в c0154.b6:20.
10. Три варианта `наз` не меняют ошибку (условие задачи).

ГИПОТЕЗА:

1. Инвариант `0 <= delta <= 07777` выведен из маски
   72274 и факта отрицательной разности; прямой
   проверки границы в коде РВС не найдено.
2. Нарушитель - BR0321 из MBE-Z0154.be, а не
   MBE2-Z0554.be: вывод по составу link.b6 (Z0554
   отсутствует). В самой трассе имени модуля нет.
3. Роль 066231 как константы расчёта базы раздела;
   семантика числа в исходниках 01/78 не описана.
4. Минимальная правка - перевод BR0321 в
   перемещаемый символ с пересборкой Z0154.

НЕ ИЗВЕСТНО:

1. Почему 066231 имеет именно такое значение и как
   оно связано с адресом загрузки раздела.
2. Почему база 050320 представлена в слове как 5032
   (граница восьмеричного поля 16 бит).
3. Где именно РВС проверяет 052724 на допустимость:
   PC 72364 `*64 72367` печать, PC 72365 вызов
   71153 только инкрементирует счётчик 70544;
   саму проверку в дизассемблированных 185 словах
   однозначно идентифицировать не удалось.
4. Причина, по которой поле 61040100 даёт
   базу 026331, а не значение не больше 001255.
