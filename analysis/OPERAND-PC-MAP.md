## 1. Метод

1) Из листинга берем слово/эффект: значение символа,
   число SETA, упакованную строку, адрес метки.
2) В потоке ищем это слово в acc exec или operand store.
3) PC найденного exec и есть писатель выхода.
4) PC минус база зоны даёт смещение в Z*.asm.
   Для 02000: off = PC - 02000 (0154/0170/0172).
   Для 04000: off = PC - 04000 (0155/0171/0173).
   Для 26000: off = PC - 26000 (0162).
   Для 00000: off = PC (0147, только dis/).
5) БЭСМ имя берём из той половины слова Z*.asm,
   которая совпадает с mn трассы.
   atx = зп, aax = и, aox = или, utc = мода,
   wtc = мод, asn = сда, xta = сч, uj = пб.
