## 3. Новые файлы

- `tools/loader_reloc_probe.py`: read-only CLI. Guard
  `guard_output()` отказывает (код 3, `REFUSE`) любой путь
  записи внутри `--root` и внутри `/usr/local/share`;
  чтение образов разрешено. `--root` задаёт каталог образов,
  `--dry-run` печатает план без запуска `besmtool`,
  `--format json|text` выбирает формат, `--output` задаёт
  файл отчёта вне каталога образов. Дампы идут только в
  уникальный `tempfile.TemporaryDirectory` с cleanup.
  Зоны задаются восьмеричными строками (`0137`, `0143`).
- `tools/tests/test_loader_reloc.py`: 33 теста.
  23 юнит/CLI-теста на синтетических байтах и путях, без
  эмулятора; 10 интеграционных тестов с skip, если нет
  `besmtool` или томов. Интеграция сама зовёт
  `besmtool dump --to-file` во temp-каталог, проверяет оба
  md5, отличия загрузчика, 0 отличий 2148/2248 и зону
  `0154`. Guard и dry-run тестуются отдельно.
- `analysis/LOADER-RELOC-TESTS.md`: этот отчёт.
