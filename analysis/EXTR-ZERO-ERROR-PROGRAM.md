# Рабочая программа с КОП 020/021: 0 ошибок транслятора

Дата: 21.11.2026. Прогон на копиях томов в
  /tmp/.private/azizz/extr20-21-final/.
Воспроизведение: python3 /tmp/.private/azizz/start-probe/
  final_program.py

## 1. ПРОГРАММА (диалект inp$$$/eoi$$$)

    ТЕСТ  СТАРТ 1
      сч '1'
      сбр '1000'       -> 00 020 1000  (КОП 020)
      сч '2'
    L21  мода
      Э21 '1000'     -> 00 21 01000 (КОП 021, 2-я структура)
      ФИНИШ

## 2. РЕЗУЛЬТАТ [Д]

    ЧИCЛO OШИБOK=0000. MAKC CEPЬEЗH=0.
    ДЛИHA ПPOГ=00003
    BXOДH=00001  BHEШH=00000

Листинг:
    00 020 1000   0003 0003  CБР '1000'
    00 21 01000   0006 0006  Э21 '1000'

## 3. КЛЮЧ: КАК ПИСАТЬ Э21

`Э21` ставится только в правую половину
  (ADDREX/IMMEX). Надо писать
  её второй строкой после `мода` с меткой:
    L21  мода
         Э21 '1000'
Прямая форма `Э21 '1000'` без предшествующей `мода`
  даёт `OПEPAЦИИ HET` на авто-вставленной моде.

## 4. Э20 (КОП 020) — ДРУГАЯ СТРУКТУРА

`Э20` прямой формой во всех опытах даёт 1 ошибку:
  транслятор трактует его как 1-ю структуру (где
  020 = СБР). Рабочая форма — `сбр '1000'` или
  `кк 16,'1000'` (оба дают 00 020 1000, 0 ошибок).

## 5. ИТОГ ПО СПОРУ

- `сбр/рзб` = КОП 020/021 1-й структуры (сборка/разборка);
- `Э21` = КОП 021 2-й структуры (экстракод, вектор
  0562 в simh); собирается через `мода` + `Э21`;
- `кк N` = КОП 020+N 1-й структуры, не системный ЭN;
- оба кода уживаются в одной пользовательской
  программе с 0 ошибок (этот опыт).
