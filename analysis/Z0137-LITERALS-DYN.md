## 5. ЧТО ОСТАЁТСЯ НЕ ИЗВЕСТНО И ПОЧЕМУ

1. Роль любого из 323 литералов ВНУТРИ зоны 0137.
   Причина: зона не загружена (ZONE-BASE-MAP §3:70).
   Ни одна её команда не исполнялась в трассе.
2. Различие "база таблицы" против "ячейка данных"
   для 177 значений памяти. Причина: многие из них
   пишутся загрузчиком PC 64077, это не семантика.
3. Печатаемый символ. Причина: нет мнемоники вывода
   в трассе, байт передаётся через регистр.
4. Причина отсутствия 35 значений. Причина: одна
   трасса, одна фаза загрузки, без строк DD pc=.
5. Подлинность small-совпадений (42+16). Причина:
   value-level grep не различает ЭКВ-имя и бытовой
   операнд с тем же числом.

## 6. ЧТО ДОКАЗАНО [ФАКТ]

1. Литерал есть АБСОЛЮТНЫЙ адрес (на 818339
   переходов, 0 PC-относительных). См. §3.1.
2. 12 уникальных значений - живые цели перехода
   других зон; 177 - живые адреса памяти; 35 -
   не посещались в этом прогоне.
3. Запись по адресу печатается отдельной строкой
   "NNNNN: store V", где N - адрес, V - данные
   (cu.c:242). Это исправляет начальный разбор, где
   V ошибочно принимался за адрес.
4. Зона 0137 не исполнялась, поэтому динамический
   verdict о СМЫСЛЕ литерала невозможен в принципе.

НЕ утверждаю полного понимания: 0 из 323 ролей внутри
0137 доказаны динамикой. Статические [Д] из G4/G5/G6
остаются гипотезами по природе (исходник транслятора
на диске отсутствует).
