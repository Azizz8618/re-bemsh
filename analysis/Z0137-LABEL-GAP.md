## 0. ВЕРДИКТ

ФАКТ: в dis-forced 27 меток: 1 кодовая `A`, 26 данных `D`.
ФАКТ: в .be ровно 2 настоящие метки первого поля:
  `A01036` (слово 1036, точное имя) и `I3`

ФАКТ: все 27 адресов-якорей лежат внутри модуля

ГИПОТЕЗА: вывод «метки первого поля невозможны в 0137»
  относился к 40 ВНЕШНИМ целям CALL (4231, 70000 и т.п.),
  которых среди этих 27 меток НЕТ. Для данных 27
  меток метка первого поля возможна с вычитанием базы `-З`.
НЕ ИЗВЕСТНО: сохранится ли 0 отличий при вставке
  метки на каждое слово, особенно на строки КОНД
  и на слова 1241/1242 без ссылок. Нужна проба.

## 3. ОСОБЫЕ СЛУЧАИ

### 3.1 Слово 01036, метка A01036

ФАКТ: в .be метка FIRST-FIELD `A01036` на строке 1630
  (`A01036 ВЧАБ`), ссылка строка 1119
  (`ПВ A01036-З(М16)`). Имя метки точное,
  совпадает с dis-forced.
ФАКТ: механика (LABEL-MODE-EXPERIMENT.md §0):
  значение метки первого поля = база + индекс.
  При базе `10000` метка слова 1036 = `11036`.
  Эталону нужно `01036`, поэтому `-З` обязательно.
ФАКТ: прямая ссылка `ПВ A01036(М16)` даёт FAIL:
  11036 вместо 01036 (LABEL-MODE-EXPERIMENT.md:177-189).
ФАКТ: `ВНЕШН` ломает байты (бит CA),
  `ВХОДН` байтобезопасен но меняет метаданные
  (REAL-LABELS-0137.md:84-86).
ГИПОТЕЗА: 3 остальные ссылки на A01036 всё ещё
  идут через ЭКВ, а не через метку:
    +10 -> 1050 -> MB1050 (строка 693),
    +2  -> 1040 -> MB1040 (строки 706, 708),
    -38 -> 0770 -> C770   (строка 711).
  Проба: заменить на `A01036-З+12(М2)`,
  `A01036-З+2(М7)`, `A01036-З-46(М6)`
  (смещения переведены в восьмеричную систему).
  Если формула верна, 0 отличий сохранится.

### 3.2 Область D00100

ФАКТ: D00100 на слове 100, самый частый якорь:
  337 ссылок, 38 различных десятичных смещений
  (от -0 до +43). Первое поле в .be отсутствует.
ФАКТ: все эффективные адреса имеют имена ЭКВ:
  MB100='100', MB101..MB111, B2112..B2117,
  B2120, MB121, BR122, MB132..MB137,
  B2140..B2144, MB145, AM147, BR150,
  B2151, MB152, MB153 (строки 341-410, 220).
ФАКТ: пример перевода: `D00100+40` -> 0150 -> BR150;
  `D00100+12` -> 0114 -> MB114.
ГИПОТЕЗА: рецепт первого поля для этой области:
  поставить `D00100` на слово 100 и писать
  `D00100-З+<восьмеричное смещение>`.
  ОПАСНОСТЬ: смещения в dis-forced десятичные,
  а литералы в .be восьмеричные. `+40` нужно
  писать как `+50`, иначе получится 0140, не 0150.
  Требуется побайтовая проба до внесения.

### 3.3 Крайние якоря D01237 / D01254

ФАКТ: D01237-24 -> 01207 -> MB1207 (строка 355).
ФАКТ: D01254+28 -> 01310 -> MB1310 (строка 359).
ГИПОТЕЗА: первое поле возможно как
  `D01237-З-30(М...)` и `D01254-З+34(М...)`
  (30 и 34, восьмеричные эквиваленты 24 и 28).
НЕ ИЗВЕСТНО: слова 1237 и 1254, КОНД или код;
  вставка метки может сдвинуть сборку.

## 5. ФОРМЫ ДЛЯ ПРОБЫ (без правки репозитория)

1. БАЗОВАЯ (проверено, 0 отличий):
     метка `D#####` в первом поле на слове N,
     ссылка `D#####-З` (или `-З+oct`, `-З-oct`).
   Проверена на A01036 и I3.
2. ЭКВ-ЛИТЕРАЛ (проверено, 0 отличий):
     `D##### ЭКВ '<слово>'`, ссылка без `-З`.
   Даёт 21 метку, но НЕ является меткой первого поля.
   Способ LABEL-BASE-EXPERIMENT.md, откатан в файле.
3. ВНЕШН: FAIL, добавляет бит CA релокации.
4. ВХОДН: 0 отличий, но меняет счётчик входов.
5. Прямая ссылка без `-З`: FAIL, даёт база+N.

Порядок проб (минимальный набор):
  шаг 1: D00001 (простая ссылка, 1 слово),
  шаг 2: D00100+40 (смещение, дес. в восьм.),
  шаг 3: D01237 (конец модуля, КОНД-риск),
  шаг 4: D01241/1242 (метки без ссылок).
Каждый шаг: `bash tools/rebuild-zone.sh 0137 B`,
ожидается HAM=10000, 1024/1024, 0 отличий.
