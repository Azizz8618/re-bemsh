# РОЛЬ ЗОНЫ 0565 В ТРАНСЛЯТОРЕ B2 (ВАР.12/77)

Дата: 22.11.2026. Write set: только analysis/Z0565-ROLE.md.
Коммитов и push нет. Эталонные образы не менялись.
Адреса восьмеричные. Разделитель карт в тексте: ↑.
Статусы: [ФАКТ], [ГИПОТЕЗА], [НЕ ИЗВЕСТНО].

## 0. Краткий ответ

[ФАКТ] 0565 это НЕ мусор и НЕ только таблица. Это код
  макрокомпилятора B2. В зоне 151 вызов `пв XXXX(М16)`,
  69 дескрипторов и код во всей зоне (998 сильных слов).
[ФАКТ] Зона загружается оверлеем только по ветке загрузчика
  0547.01305. Ветка зависит от флага D01167. Во всех
  наблюдаемых прогонах флаг равен нулю, поэтому грузится
  другая пара, 0570/0571 (макромашина). Пара 0565/0566
  (макрокомпилятор) ни разу не загружалась.
[ФАКТ] Надёжного динамического подтверждения исполнения
  0565 нет. Статический контракт зоны восстановлен.
[НЕ ИЗВЕСТНО] Что делает флаг D01167 отрицательным и при
  каком задании ветка 0565/0566 выбирается.

## 1. СТАТИКА: КОНТРАКТ ЗОНЫ

### 1.1. Первые 20 слов (forced-листинг Z0565.asm)

```

 0001  счи ; зп (М17)              счётчик/сохранение

 0004  зп (М1) ; зп                данные

 0006  конк 12000000 ; зп          константа
```

### 1.3. 151 CALL: кому и куда

[ФАКТ] Все 151 обращение это `пв XXXX(М16)` (4 из них
  `пв (М16)` через поле без адреса). `вжм` нет.
  Гистограмма целей (адрес: число):

```
  4147:34  5013:31  4363:16  5003:14  4762:12
  3711:12  4772:7   3232:6   4240:5   4341:4
  3633:2   5056:1   4576:1   4056:1   3667:1
```
[ФАКТ] Все адреса лежат на странице 02 (04000-05777).
  При загрузке пары 0565 (page 01) и 0566 (page 02) это
  смещения внутри 0566: 0147, 1013, 0363, 1003, 0762 и др.
[ФАКТ] Цели это настоящие подпрограммы, а не текст:
  0566.0147 = `зп 6(М17); слиа 7(М17); счи М16;
  зп (М17); сч -2(М17)`; 0566.1013 = `счим М1;
  пв '4747'(М1)`; 0566.0363 = `зп 5(М17); ...`.
  Возврат идёт по link-регистру М16 (`пб (М16)`).
[ФАКТ] В самой 0565 семь `пб ...(М16)`, из них четыре
  `пб (М16)`. Один `пб '2140'`.

### 1.4. Кто «вызывает» 0565

[ФАКТ] Прямого CALL в 0565 нет. Зона это оверлей и
  загружается таблицей зон в 0547 (в B это 0147, байты
  те же). Таблица 0547.1130-1153, разбор forced:

```
 1130 сч '3400'; счрж '1750'   -> 0550
 ...
 1142 сч '0100'; счрж '1765'   -> 0565, page 01
 1143 сч '0200'; счрж '1766'   -> 0566, page 02
 1144 сч '0100'; счрж '1770'   -> 0570, page 01
 1145 сч '0200'; счрж '1771'   -> 0571, page 02
```
[ФАКТ] Число 1765 это логический номер. Смещение карты
  лент 6600 переводит его в физическую зону 0565.
[ФАКТ] Загрузка идёт экстракодом Э70 из 0547:

```
 01304 сч D01167 ; по A01213   проверка флага
 01305 Э70 D01142              грузит 1765 (0565)
 01306 Э70 D01143              грузит 1766 (0566)
 01310 пб A01777+1             вход в 02000 = 0565.0
 01311 Э70 D01144              грузит 1770 (0570)
 01312 Э70 D01145              грузит 1771 (0571)
 01314 пб A01777+1             вход в 02000 = 0570.0
```
[ФАКТ] Флаг D01167 (физический адрес 01167, страница 00)
  в образе 0547 равен нулю. Во всех разобранных
  dis-forced нет глобальной ссылки `'01167'` с записью.
[ФАКТ] По коду эмулятора (simh/BESM6/besm6_cpu.c:1574):
  `по` в арифметическом режиме при ACC >= 0 ПЕРЕХОДИТ.
  Ноль флага значит переход на A01213, то есть 01311,
  то есть пара 0570/0571. Ветка 0565/0566 требует
  отрицательного значения D01167.

## 3. ПОЧЕМУ 0565 НЕ ЗАГРУЖАЛСЯ

[ФАКТ] Причина механическая: ветка 0547.01304 читает
  D01167=0 и уходит на 01311 (0570/0571). Ветка 01305
  с Э70 D01142 (0565) не достигается.
[ФАКТ] Таблица 1765/1766 в 0547 НЕ удалена. Код загрузки
  0565 НЕ удалён. Это не «вырезанная» зона, а
  невыбираемая альтернатива.
[ГИПОТЕЗА] 0565/0566 это более старый макрокомпилятор
  (штамп 12.2.76), а 0570/0571 более новая макромашина
  (штамп 15.12.76). Задание без ЧТКОМП выбирает вторую.
[ГИПОТЕЗА] Отрицательное значение D01167 может быть
  выставлено специальным заданием/картой, которого в
  доступных колодах нет.
[НЕ ИЗВЕСТНО] Кто и когда пишет D01167. Ответа в
  прочитанных листингах нет.

## 4. ЧТО СКАЗАНО О 0165 В B

[ФАКТ] Таблица 0547.1142 байтово равна 0147.1142. В B
  та же проверка D01167. В прогоне B (offset 6200) по DD
  грузятся 0070-0076, а не 0065/0066.
[ФАКТ] Значит «0565 не грузится» это не баг B2, а
  общее свойство каркаса заданий 0-0.
