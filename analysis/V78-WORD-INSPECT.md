# Инспектор 48-битных слов v78_word_inspect

Дата: 24.11.2026. Read-only инструмент для 1978-й версии.

## Назначение

По 48-битному слову (или по слову в gold-дампе зоны)
показать: восьмеричное и hex представление, шесть байт
с формулой `TAB[GOST&077]`, все четыре декодирования
из `tools/text_decode_all.py` с оценкой качества и,
опционально, поиск того же байтового шаблона по четырём
эталонным томам.

## Запуск

```
python3 tools/v78_word_inspect.py 01400744203630417
python3 tools/v78_word_inspect.py 0x1400744203630417
python3 tools/v78_word_inspect.py --zone 0144 --word 0571
python3 tools/v78_word_inspect.py --zone 0152 --word 0317 \
    --search --format json
python3 tools/v78_word_inspect.py --check
```

Входное слово задаётся восьмеричным (до 16 цифр)
или `0x`-шестнадцатеричным. `--zone` и `--word` восьмеричные.

## Выходные поля

| Поле | Смысл |
|---|---|
| oct/hex | представление слова |
| bytes | 6 строк: индекс, hex, oct, формула TAB |
| decode | GOST/KOI7/TEXT/ITM: текст, вердикт, hit-ы, диграфы |
| search | по томам 2048/2148/2248/2348: зона, слово, порядок байт |

Вердикты декодирования: ВЕРОЯТНО, ВОЗМОЖНО, СЛАБО,
НЕТ_ГЛИФА. Это оценка, а не доказательство смысла.

## Важная оговорка поиска

Тома хранят слова в побайтовом порядке, отличном от
gold-дампов, поэтому ищутся оба порядка: прямой и обратный.
Номера зон в выводе ФИЗИЧЕСКИЕ (позиция в файле), а не
каталожные. Для каталожной адресации использовать
`besmtool search`/`dump`. Результат search — кандидаты
для ручной проверки, не доказательство.

## Проверки

`python3 tools/v78_word_inspect.py --check` проверяет четыре
константы (0x40, 0x01, 0xbe, 0xbf), TEXT-кодировку и слово
`gold/MBE-Z0152-L1.bin:0317`.

`python3 -m unittest tools/tests/test_v78_word_inspect.py`
— 24 теста OK.
