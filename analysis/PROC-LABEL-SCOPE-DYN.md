## 6. ГИПОТЕЗЫ И НЕ ИЗВЕСТНОЕ

[ГИПОТЕЗА] Метки OV01/OV02/OV36/OV37 объединяют
  оверлейные зоны одной страницы. Это НЕ требуем
  точную зону в момент перехода: страница в данный
  момент содержит ровно одну из зон списка.

[ГИПОТЕЗА] Смена 0154 -> 0170 -> 0172 и 0151 -> 0153
  идёт по PASSES-OVERLAY-MECH.md. Без DD pc= в этой
  трассе момент смены для конкретной строки не
  восстанавливается.

[НЕ ИЗВЕСТНО] Зона страницы 14 (030000-031777).
  5233 события оттуда помечены UNKNOWN.

[НЕ ИЗВЕСТНО] Точная зона для 7 vjm-целей, попавших
  в страницу 14 или иную неотображённую область.

[НЕ ИЗВЕСТНО] В B-explore.err нет строк DD pc=.
  Привязка "страница -> зона в момент vjm"
  заимствована из снимков и отдельных DD-прогонов,
  а не измерена в этом же прогоне.
