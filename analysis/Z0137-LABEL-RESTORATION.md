## 1. ИНСТРУМЕНТ И МЕТОДИКА

Карта слово -> строка .be взята из листинга
`/tmp/.private/azizz/rebuild-all/0137/listing.out`:
второй 4-значный десятичный столбец (колонка 55)
есть номер некомментарной строки .be. Слово N имеет
адрес `010000+N`; метка первого поля ставится на
строке первой половины слова.

Правки внесены тремя проверенными пакетами:
  A - 26 меток первого поля + 4 ссылки I3;
  B - 4 операнда A01036 (MB1050, MB1040 x2, C770);
  C - 409 операндов через 66 ЭКВ-имён.
После каждого пакета: `bash tools/rebuild-zone.sh 0137`.
Итог после каждого: 1024/1024, 0 отличий.

## 2. УТОЧНЕНИЕ: СИСТЕМА СЧИСЛЕНИЯ

ФАКТ: кавычные значения ЭКВ восьмеричные
  (`BR150 ЭКВ '150'` = 0150 = 104 десятич.).
ФАКТ: голые числа в выражении МАКРО-БЭСМ десятичные.
  Прямая проба: `A01036-З+12` дала 01052 вместо
  01050, а `A01036-З+10` дала 01050. Также
  `A01036-З-46` дала неверно, а `A01036-З-38`
  дала 0770.
ФАКТ: предупреждение Z0137-LABEL-GAP.md §3.2
  («+40 писать как +50») неверно для голых чисел:
  верно `+40`. Проверено на 409 операндах.
Смещение = `dec(ЭКВ) - dec(слово метки)`.

## 4. ОСОБЫЕ СЛУЧАИ

Слово 2/3 (D00002, D00003). Было: I3 на слове 2,
ссылки `I3-З+1` давали слово 3. Стало: I3 переименован
в D00002 (слово 2), на слове 3 поставлен D00003,
четыре ссылки переписаны в `D00003-З`. Значение то же
(2+1 = 3), 0 отличий.

Четыре «отсутствовавшие» метки. Все поставлены в первое
поле без изменения байтов:
  D01237: `СЧ (М13)`, ссылка -З-24 (19 раз);
  D01241: `ПО BR6727(М7)`, ссылок нет;
  D01242: `И MB114(М7)`, ссылок нет;
  D01254: `УИ М14`, ссылка -З+28.
Гипотеза GAP «нужна КОНД/зп строка» не подтвердилась:
достаточно любой строки слова, байты не меняются.

A01036: три уцелевших операнда переведены с ЭКВ на метку:
  MB1050 -> A01036-З+10, MB1040 -> A01036-З+2 (x2),
  C770 -> A01036-З-38. Все 0 отличий.

D00100: 337 ссылок с 33 ЭКВ-имён переведены на
  `D00100-З+N` (N = 0..43). D00656: 7 ссылок на
  `D00656-З±N`. D01237: 19, D01254: 1.
