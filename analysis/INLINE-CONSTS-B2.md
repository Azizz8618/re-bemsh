## 2. МЕТОД

1. Из 16 файлов `bemsh/MBE-Z0NNN.be` (NNN = 150..167)
   взяты все machine-строки `КОНД В'<16 окт>'` с
   номерами строк. [Д]
2. Сырое окт. слово каждого КОНД сопоставлено с
   6-байтовым словом `gold/MBE-Z0NNN-L1.bin`.
   Сопоставление монотонно; 100% слов получили
   уникальный адрес во всех 16 зонах. [Д]
3. Контекст команд - из `dis-forced/Z0NNN.asm`
   (все 1024 слова декодированы, адреса явные). [Д]
4. Границы: CALL/RET (ПВ/ПБ/ПВО/ВЖМ/ВЖ) и
   ветвления (ПО/ПЕ/ЦИКЛ/ПИО/КОНК/СТОП). [Д]
5. Кластер = подряд идущие адреса КОНД. INLINE,
   если размер 1..6 слов; команды-соседи с обеих
   сторон в пределах ±4 слов; соседние команды
   (d=1) не CALL/RET/ветвление. Иначе FILL/TABLE. [Г]

Ограничение: адреса КОНД получены сопоставлением с
эталоном, а не из меток в .be (их на строках нет).
Монотонность 100% делает привязку однозначной. [Г]
