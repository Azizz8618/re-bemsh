## 3. Методика сравнения

1. `tools/bin_to_octal.py` превращает каждый DAT в 16 восьм. цифр:
   `python3 tools/bin_to_octal.py <bin> > /tmp/new.oct` (33792 строки),
   то же для OLD (32768 строк).
2. `tools/compare_shifted.py 0400 /tmp/new.oct /tmp/old.oct`.
   ⚠ Пример из PLAN.md передаёт скрипту `.bin` напрямую — это
   ошибка: скрипт читает **текст** строк вида `^ *[0-7]{16}$` и на
   бинарнике даёт ошибку чтения (`utf-8` decode /
   `No octal block found`). Первый аргумент —
   восьмеричный `base_offset`, который **прибавляется** к найденному
   сдвигу в словах; он не задаёт номер зоны.
3. FFT-ветка в `compare_shifted.py` нерабоча (`random`/`math`
   закомментированы), поэтому всегда используется brute force;
   `python3 -S` даёт тот же результат.
4. Независимый разбор в Python: разбиение на зоны по 6144 байт,
   число ненулевых байт и md5 каждой зоны, перебор сдвига зон
   `k = OLD_idx − NEW_idx` и перебор сдвига внутри пары зон
   `s` (OLD-слово `j` = NEW-слово `j−s`).

## 4. Результат сдвига

Сырой вывод (полностью — `analysis/mbe_diff.txt`):

```
/tmp/old.oct 02400 : 42.04% of 100000/64274/26010
```

`02400₈ − 0400₈ = 01000₈` = 1024 слова = **одна зона**.
Это независимо подтверждает соответствие:
`OLD 0540+j ↔ NEW 0140+j`, `j = 0…31`.
NEW `0137` остаётся без пары (логически это `0537`, пустая зона).

Поразовый перебор даёт при `k=−1` 122406 совпавших байт из
196608 (62,26%) и 9 побайтово идентичных зон; у всех других
`k` — не более 24,2%. На уровне слов: 17228 равных из 32768
(52,57%), 15540 различных; 5956 нулевых слов OLD исключены
из процента `compare_shifted.py` (11272/26812 = 42,04%).

## 6. Классификация отличий

**L — зоны загрузки/установки.** 0140–0143 ↔ 0540–0543:
1017–1024 различных слов на зону, лучший сдвиг почти не
помогает. Это не «реальная правка транслятора», а другая
настройка загрузчика/паспорта тома; ср. VERSIONS-SCAN.md §7
для 2148/2248 (там тоже отличаются только зоны 0137–0143).

**S — сдвиг текста/кода внутри зоны.** 0145, 0152, 0153, 0165,
0166, 0170, 0171, 0173, 0176, 0177: при `s ≠ 0` число
совпавших слов заметно растёт (например 0176: 11 → 548,
0177: 633 → 804, 0152: 462 → 675). Правдоподобно вставка/
удаление слов в начале зоны (новые тексты/константы),
а не изменение самих команд. Это гипотеза по бинарнику.

**C — подлинная правка кода и таблиц.** 0147, 0151, 0154,
0157, 0161, 0172: лучший сдвиг `s = 0`, значит слова
изменены на своих местах. Примеры:
- `0147.1317` NEW `п'МШ ВЕР'` / `01320 п'.06/78'`,
  OLD `0547.1317 п'МШ ВАР'` / `0552 п'.12/77'`;
- `0151` — адресные константы сдвинуты на `+7…+10₈`
  (`сч '76313'` → `сч '76322'`, `зп '77132'` → `зп '77142'`);
- `0161` — всего 11 слов, в основном константы:
  `конд п'20-/6Н'` → `конд п'20-/6Э'`, `п'/6.900'` →
  `п'/6,900'` (изменение чисел/текста сообщений).

**M** 0155/0555 — 1018 различных слов, слабый сдвиг `+42`;
классификация неоднозначна (код + таблица).

`disbesm6 -a0 -e0` по одной зоне (файлы в `/tmp/p6-*.asm`).

  Э50 '105'            зп (М1)

То есть NEW содержит **вставку** `Э50 '105'`, `пе`, `сч`,

изменение кода, а не только переименование меток. Адреса выше
— локальные внутри зоны (`-a0`), не физические.

## 8. Оговорки и неопределённости

1. На диске `ВАР.12/77`; написание `ВЕР.12/77` нигде не найдено.
2. Зона `0537` пуста во всех копиях; OLD начинается с `0540`.
   NEW `0137` не имеет пары: лучшее совпадение с любой зоной
   OLD — около 18% байт. Не следует утверждать, что она
   «просто сдвинута»: это отдельная зона установки.
3. `МВЕ60` в листингах — тестовая программа ДКС, пример
   работы транслятора, **не его исходник** (`ANCHORS.md`).
   Поиск её слов в зонах даёт 0 совпадений.
4. Запись `1000–1037` (`МБ 2.0 ДЛЯ М3/М1`, `.02.87`) —
   отдельная программа, в сравнение не включена.
5. Класс `S` — рабочая гипотеза о вставке/удалении слов;
   исходный текст транслятора отсутствует, доказать её
   побайтово нельзя.
6. Метки `A#####`/`D#####` и адреса в листинге `disbesm6`
   локальны для `-a0`; физические адреса зон указаны отдельно.
7. Сравнение выполнено только по 32 общим зонам; даты взяты
   из текстовых штампов, а не из каталога (каталог OLD даёт
   только `.78`).
