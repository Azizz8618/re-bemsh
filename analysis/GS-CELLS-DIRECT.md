Предыдущий отрицательный результат объяснён: фильтр

[ФАКТ] Таблица состоит из пар 48-битных слов:
  07776+N = значение, 07777+N = тег (N чётно).
Индекс N хранится в регистре r[4] и равен счётчику
КОЛИЧ ЯЧ ГС. Пишущая команда находится в коде
макроредактора: 077427 atx 7777(4) и 077430 atx
7776(4). Базовый адрес 07776 для значения, 07777
для тега. Физические адреса из трассы.

## 2. Как найдены ячейки

[ФАКТ] В трассе Z1 вокруг записи счётчика (строка
816215) идут команды:

  77425: asn 47            acc=0000000000001122
  77426: atx 7777(17)      → 11021: store ...
  77427: xta 6601          acc=0020000000000000
  77427: atx 7777(4)       r[4]=01122
         11121: store 0020000000000000
  77430: xta 6452          acc=0000000064130245
  77430: atx 7776(4)       r[4]=01122
         11120: store 0000000064130245
  77431: utm 2(4)          r[4]=01122
  77432: a-x 6371          acc=0000000000001124

Эффективный адрес: 07777+r[4] (тег) и 07776+r[4]
(значение). 07777+01122 = 11121, 07776+01122 = 11120.
После записи счётчик в r[4] становится 01124, что
совпадает с финальной записью в 01201.

[ФАКТ] Та же пара команд 77427/77430 появляется в
трассе многократно с r[4] = 00010, 00012, ..., 01122.
Это весь массив ГС. Шаг r[4] = 2, то есть каждая
запись занимает ровно 2 ячейки по 48 бит.

[ФАКТ] Диапазон адресов массива в опытах:
  значение 011000..011120, тег 011001..011121.
Последняя пара до макроса: 11114/11115 (Z0).
Пара нового макроса: 11120/11121 (Z1/Z2/Z3).

## 4. Доказательство связи со счётчиком

[ФАКТ] Счётчик 01201 = 001122 (Z0) и 001124 (Z1-Z3).
[ФАКТ] r[4] в момент записи пары = 01122 во всех
трёх опытах с макросом. Это в точности финальный
счётчик Z0. После записи r[4] = 01124.
[ФАКТ] дельта +2 ячейки = +1 пара слов = +1 макрос.
Это совпадает с MACRO-TABLE-FORMAT-VERIFIED.md §4.1.

## 5. Попытка декодирования полей

[ФАКТ] Слово значения строится побайтово в буфере
06452 сдвигом влево на 8 бит с прибавлением байта:

  Z1: 000...320 → 000...150260 → 0000064130245
      байты d0, затем b0, затем a5
  Z2: 000...242 → 0000000121257
      байты a2, затем af
  Z3: 000...307 → ...143641 → ...61720655 →
      ...30750326655 → 0014364153326641
      байты c7, a1, ad, ad, a1

[ФАКТ] Число байт равно числу букв имени:
  ПРЕ = 3, ВО = 2, ГАММА = 5.
Следовательно младшие байты слова @11120 содержат
имя макроса в кодировке транслятора.

[ФАКТ] Сравнение с GOST-10859 (П=2f, Р=30, Е=25,
В=22, О=2e, Г=23, А=20, М=2c):
  d0 b0 a5  против 2f 30 25
  a2 af     против 22 2e
  c7 a1 ad ad a1 против 23 20 2c 2c 20
Все байты кроме первого равны коду GOST с
установленным старшим битом (80/81). Первый байт
имеет дополнительные биты (d0, a2, c7).

[ФАКТ] Теговое слово @11121 одинаково во всех трёх
опытах: 0020000000002041. Первичная запись
0020000000000000 заменяется позже, на строке
820378 (Z1), 820602 (Z2), 821090 (Z3).
Сравнение с тегами остальных ячеек массива:
  2470000000000000 (чаще всего), 3170000000000001,
  3330000000000001, 3770000000000000, 0020000000002023.
Тег макроса начинается с 002, а не с 247.

[ГИПОТЕЗА] Тег = [тип|указатель]. Код 002 может
означать 'макрос', младшее поле 2041 может быть
указателем в текстовый пул. Прямого доказательства нет.

[ГИПОТЕЗА] Первый байт имени несёт длину или маркер
начала поля; остальные байты это GOST с битом 80.
Точная формула не выведена.

[НЕ ИЗВЕСТНО] Точное преобразование GOST-кода в
байт ячейки (почему первый байт d0/c7, а не af/a3).
[НЕ ИЗВЕСТНО] Смысл поля 2041 в теге макроса.
[НЕ ИЗВЕСТНО] Где хранится тело макроса и как оно
связано с этой парой ячеек. Схема [TAG(24)|VAL(24)]
из MACRO-TABLE-FORMAT.md §6 не подтверждена:
в ячейке два отдельных 48-битных слова, а не одно
слово с двумя 24-битными полями.

## 7. ФАКТ / ГИПОТЕЗА / НЕ ИЗВЕСТНО (сводка)

ФАКТ:
  адрес таблицы 07776+r4 (значение), 07777+r4 (тег);
  команды 077427 и 077430 пишут пару слов;
  r4 = счётчик КОЛИЧ ЯЧ ГС, шаг 2;
  Z0: 11120/11121 не пишутся, ГС=001122;
  Z1/Z2/Z3: пишутся 11120/11121, ГС=001124;
  значение @11120 зависит от имени, 3/2/5 байт;
  тег @11121 = 0020000000002041 во всех опытах.

ГИПОТЕЗА:
  тег [тип|указатель], код 002 = макрос;
  первый байт имени содержит маркер или длину.

НЕ ИЗВЕСТНО:
  точная кодировка первого байта имени;
  смысл поля 2041 в теге;
  связь пары с телом макроса;
  схема [TAG(24)|VAL(24)] как формат одного слова.
