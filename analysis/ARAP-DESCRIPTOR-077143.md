## 0. Главный результат

[ФАКТ] Таблица дескрипторов по 077143 НЕ является таблицей
"карта -> PC обработчика". Это ОДИН 6-словный буфер, который
перезаписывается перед каждым переходом
(цикл 014350-014354).

[ФАКТ] PC перехода берётся ПОЛНОСТЬЮ из одного слова 077144:

    074532: xta 77144   ; acc = word[077144]
    074532: ati 12      ; r[12] = acc
    075651: uj (12)     ; PC = r[12]

Ни половинного слова, ни модификации регистра, ни индекса
здесь НЕТ. r[12] есть точная копия word[077144].

[ФАКТ] В полной трассе word[077144] принимает ПЯТЬ значений.
Но на пути карт 075650 -> 075651 их всего ДВА: 074022 и
075655. Остальные три значения принадлежат второму
вызывающему 074515 -> 074516 (см. §1.1).
Поэтому один PC соответствует многим картам.

## 4. Почему разные карты дают одинаковый r[12]

[ФАКТ] 077144 - НЕ ключ карты, а двухзначный селектор.
Наблюдается ровно два класса:

    класс A, PC 074022: ВВД, ТРН, КНЦ в конце колоды;
    класс B, PC 075655: ЧТКОМП, ЗОНМОД, БТМАЛФ,
                        ЗПКОМП, КОНЕЦ, КНЦ как действие.

[ФАКТ] Оба PC суть ПЕРЕДНИЕ распознаватели, а не конечные
обработчики команд. По трассе:

    074022: xta 76336 / arx 74040 / atx 74040 / utc
             xta 76505 / aax 76337 / aex 76340 ...
             сравнение текста карты с эталонами
             076336-076342
             и поиск по словарю 076722/076664

    075655: utc / vjm 75033(12)
      075033: xta 76505 / aax 76431 / aex 76432 ...
      075660: xta 76505 / aax 76461 / aex 76462 ...
             сравнение с эталонами 076431/076432 и
             076461/076462, затем общий поиск 074251

[ФАКТ] Оба потока сходятся на подпрограмме поиска 074251,
которая работает с r[13]/r[14] как с указателями словаря.
То есть выбор конкретной карты происходит ПОСЛЕ 075651,
внутри 074022 или 075655, сравнением текста буфера 076505
с эталонами. Один и тот же r[12] у разных карт - следствие
того, что эти карты идут через ОДИН И ТОТ ЖЕ распознаватель.

[ФАКТ] Карта КНЦ может дать оба значения: 075655, когда она
есть действие, и 074022, когда она закрывает колоду
(вывод out-d-knc.txt, строки 88 и 212). Значит r[12]
определяется РОЛЬЮ карты в потоке, а не её текстом.

[ГИПОТЕЗА] Класс A - карты ввода/перевода и завершения
блока, класс B - карты-директивы, writable/executable
действия. Прямого именного списка классов в тексте нет.

## 5. Что НЕ является PC из дескриптора

[ФАКТ] Поля 077143, 077150, 077145, 077146, 077147 не
являются PC перехода. По 074530-074535 они идут в r[10],
r[11], r[13], r[14], r[15]. Команда 075651 использует
только r[12].

[ФАКТ] 06452 здесь не участвует. Это отдельный буфер
ключа, использованный в 077414-077432 (см.
ARAP-DISPATCH-06452.md).
