# ЗОНА 0172: СТРУКТУРА МАССИВА 0260-1740

Статус: [Д] = факт побайтового чтения; [Г] = гипотеза.
Адреса восьмеричные. Исследование read-only, 21.11.2026.
Метод: gold/MBE-Z0172-L1.bin, слово = 6 байт big-endian,
  расщепление на 2 полуслова по 24 бита, разбор полей
  по re-siprod/tools/siprod_asm.py:100-131 (decode).

## 1. ОБЪЁМ

[Д] Диапазон 0260-1740 включительно = 817 слов, а не 812
  (docs/SEMANTIC/Z0172.md:11,
   analysis/NUMERIC-ARRAYS-B2.md:113
  указывают 812; расхождение 5 слов не объяснено).
[Д] Плотные ненулевые слова 0260-1737; 1740 =
  `0000000000003160` (хвост, не конд).
[Д] Гистограмма кодов операций полуслов (817x2):
  слева зп 166, сч 123, уиа 119, пб 56, или 35, мода 27;
  справа зп 269, пб 93, мода 72, сч 49, пв 40.
[Д] Нет доминирующего кода => НЕ однородная таблица.

## 2. НАЙДЕННЫЙ ФОРМАТ ЗАПИСИ F

[Д] Повторяющийся шаблон: `2240 I I I I | 0300 T T T T`,
  где L = уиа r4 с 12-битным полем ID (младшие 4 цифры
  полуслова), R = пб r0 с 12-битным TARGET.
[Д] Группы по константе TARGET:

  TARGET a3010: 0774-1001, 1004-1005 (8 записей)
    ID: 0012 0014 0030 0016 0020 0022 0026 0136
  TARGET a3656: 1642-1655 (12 записей)
    ID: 0116 0144 0070 0072 0074 0076 0100 0102
        0104 0106 0112 0114
  TARGET a3676: 1660-1675 (14 записей)
    ID: 0122 0110 0034 0036 0040 0042 0044 0046
        0050 0052 0054 0056 0060 0062
  Одиночные: 0736, 1277 (TARGET 3162, ID 3173 оба),
    1223 (TARGET 4253, ID 0066).

[Д] Байтовая проверка: 0172.1642 `4a004e0c07ae` vs
  1645 `4a003a0c07ae`: отличается ТОЛЬКО байт 2 (ID);
  байты 3-5 (`0c07ae` = 03003656) постоянны.
  0172.1660 `4a00520c07be` vs 1663 `4a001e0c07be`:
  снова только байт 2; `0c07be` = 03003676.
[Г] F = таблица соответствия ID -> адрес обработчика
  (классификация/диспетчеризация): ID растут с шагом 2,
  несколько ID отображаются в один TARGET.

## 3. СРАВНЕНИЕ С 0165 / 0170 (побайтово)

[Д] 0165.0367 `0900000c0591` (02200000|03002621),
  0370 `0900000c067c`: отличаются байты 4-5.
[Д] 0170.0003 `5c84380c062d` (27102070|03003055),
  0006 `5c84380c056c`: отличаются байты 4-5.
  docs/MACRO-TABLE-FORMAT.md:89-128 называет это
  [константная метка | указатель].
[Д] 0172 (формат F), ЗЕРКАЛО: постоянна правая половина,
  меняется байт 2 левой. Это НЕ тот же формат.
[Г] Оба относятся к семейству [поле | указатель], но
  0172 инвертировано: [переменный ID | константный адрес].

## 4. ОСТАЛЬНАЯ ЧАСТЬ МАССИВА

[Д] 0260-1000: 25 раз встречается левый тег `02200000`
  (тот же, что в 0165), но разбросанно, без сплошного ряда.
  Правые половины часто `пв rN aNNNN` (40 всего).
[Д] ~1022-1400: «рыхлые» пары [тег | aNNNN], где R =
  голый адрес `0000NNNN`, L = повторяющиеся теги
  000377, 000000, 21643400, 22044000, 22445000,
  50157000, 55132000, 64150000, 61142000.
  504 правые половины лежат в a2000-a4777.
[Д] Фиксированного шага, 2-/4-словных записей,
  tag|value с константным тегом здесь НЕ найдено.
[Г] Пул шаблонов/атрибутов макромашины; поиск
  читателя не дал результата (CROSSREF: CALL=0).

## 5. ДЕКОДИРОВАНИЕ ТЕКСТОВ (dtran.cc:167,182)

[Д] GOST-8: 153/817 слов имеют >=0.84 печатных символов,
  но примеры, смешанный мусор: `RR005Ф` (1060),
  `00006М` (1105), `V062А4` (1623).
[Д] 6-бит TEXT: 734/817 «печатных», артефакт таблицы
  (все 64 кода отображаются в печатные знаки);
  примеры `6З .,(2Ю`, `ЧЗ2RБ0`, нечитаемо.
[Д] KOI-7: 451/817, примеры `Z..l.?`, `MM...o`.
[Д] Читаемых фраз/имен/штампов НЕТ (согл. Z0172.md §3.9).

## 6. ВЕРДИКТЫ

1. Группы F (0774-1005, 1642-1655, 1660-1675):
   [Д] формат ID->TARGET, 3 группы по 8/12/14 записей.
   [Г] таблица диспетчеризации/классификации.
2. 0260-1000: [Д] данные с тегом 02200000 и пв-адресами;
   [Г] дескрипторы того же семейства, что 0165/0170.
3. 1022-1400: [Д] пары [тег|адрес] без фиксированного
   шага; смысл НЕ ОПРЕДЕЛЁН.
4. Вся зона: [Д] нерезидентна, CALL=0, штампа нет.
   [Г] назначение остаётся ОТКРЫТЫМ.
