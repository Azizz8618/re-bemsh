# Каталог: синтаксис операнда → PC → выходное слово

Дата: 24.11.2026. Объект: ВЕР.06/78.
Три исходных отчёта:
  OPERAND-FORMS-INVENTORY.md  (39 форм F01-F39)
  OPERAND-DECKS.md            (22 контрольные колоды OP01-OP22)
  OPERAND-PC-MAP.md           (PC и выходные слова)
Инструмент: tools/v78_operand_probe.py, 44 теста OK.

## 1. Метод

1. Инвентарь форм составлен по 69 `.be` и `macros.be`:
   39 форм в 8 классах.
2. Для каждой формы построены изолирующие колоды
   (SIPROD GATE для макросов, MONITOR-80 для прямых
   констант). Манифест 79 → 101, 29 прогонов rc=0,
   md5 эталонов сохранён.
3. По выходному слову из листинга находилось событие
   `store`/`exec` с совпадающим `acc`; PC события
   объявляется писателем. Всего 111 фикстур,
   около 59,9 млн событий.
4. PC сверен с dis-forced/*.asm для БЭСМ-мнемоники.

29 из 39 форм имеют приписанный PC, 30 — выходное
слово или эффект. 17 форм подтверждены мнемоникой
в dis-forced. Исключения: формы зоны 0147 (только
`dis/`) и читатели флагов с базой 030000.

## 4. Правила, проверенные пробой

- `D00100+40` → `00150₈` (база `0100₈` + `40₁₀`), 104₁₀.
- `'103'+48-∧N` → 115₁₀ = `0163₈`, затем минус `∧N`.
- `-З` вычитает базу оверлея, численно не вычисляется.
- Кавычные значения восьмеричные, голые в выражении
  десятичные.

## 5. Ограничения

1. F05, F09, F10, F18, F20, F25, F26 — формы из
   1978-исходника или смежных `.be`, в доступных
   колодах событий нет. F26 `К'...'` не имеет ни
   одного вхождения.
2. F13, F30, F34 — директивы, не порождающие слова;
   для них PC не определен по построению.
3. F31: только store по `05651`, нет MACHINE-exec.
4. Читатели `030000` не имеют байтовой дизассемблировки
   в authoritative листингах; база измерена, источник
   найден (том 2099 зона 0076), но мнемоника не
   подтверждена байтом.
