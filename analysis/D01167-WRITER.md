# КТО ПИШЕТ ФЛАГ D01167 (B2, ВЕТКА 0565/0566)

Дата: 22.11.2026.
Write set: только analysis/D01167-WRITER.md.
Коммитов и push нет. Эталонные образы не менялись.
Адреса восьмеричные. Разделитель карт в тексте: ↑.
Статусы: [ФАКТ], [ГИПОТЕЗА], [НЕ ИЗВЕСТНО].

## 0. КРАТКИЙ ОТВЕТ

[ФАКТ] В зонах B и B2 ровно ОДНА команда записи в ячейку
  01167: `зп D01167` (R-полуword 0551.1674 / 0151.1675).
[ФАКТ] Ни в одном из 6 проверенных заданий эта команда не
  исполнялась. Все доступные трассы показывают только ЧТЕНИЕ
  01167. Значение ячейки равно нулю.
[ФАКТ] Ветка 0547.01304 читает 01167 = 0 и уходит на 01311,
  то есть грузит 0570/0571. Пара 0565/0566 не выбирается.
[НЕ ИЗВЕСТНО] Какое задание делает 01167 отрицательным.
  Достоверного ответа в доступных материалах нет.

### 1.2. Единственная команда записи в B/B2

[ФАКТ] Все вхождения D01167 в forced-листингах:
  (формат: адрес: операция)

  зона 0147/0547: 1304 сч D01167   чтение флага
  зона 0151/0551: 1674 зп D01167   ЗАПИСЬ
  зона 0154/0554: 1402,1705 сч     чтение
  зона 0155:      0134 сч          чтение
  зона 0165/0565: 0050,1103 сч     чтение

[ФАКТ] Код записи (сырое слово 0036013600001167):

  0551.1674 L сда 64+30      FORM
  0551.1674 R зп D01167      <-- единственная ЗП в 01167
  0151.1675 L сда 64+30
  0151.1675 R зп D01167      <-- то же в B

[ФАКТ] Это хвост подпрограммы АРАП. Перед записью читаются
  ячейки верхней памяти 076476 и 076357:

  0551.1673 L сч  '76476'
  0551.1673 R сбр '76357'
  0551.1674 L сда 64+30
  0551.1674 R зп D01167
  0551.1675 L пб '75653'

[ФАКТ] Рядом идёт такой же блок для D01101 (0551.1676/1677).
  То есть D01167 это один из набора флагов, копируемых
  из верхней памяти в локальные ячейки D011xx.

### 1.3. Кто читает флаг

[ФАКТ] Слово 0547.1304 = 0010116702601213:

  1304 L сч D01167    чтение
  1304 R по A01213    переход при ACC >= 0

[ФАКТ] По коду эмулятора (cu.c, opcode uza) при нуле ACC
  переход СОВЕРШАЕТСЯ: 01213 → 01311 → Э70 D01144/D01145.
  Отрицательное значение нужно для ветки 01305 (0565/0566).

### 1.4. Монитор (вне зон B/B2)

[ФАКТ] re-dispak/base.txt, зона 0401:

  0401.0062 зп 1171(10); зп 1161(10)
  0401.0063 зп 1165(10); зп 1163(10)
  0401.0064 зп 1167(10); сч 600
  0401.1117 сч 1161(10); зп 1163(10)
  0401.1120 сч 1165(10); зп 1167(10)
  0401.1123 счи 2; зп 1161(10)
  0401.1124 счи 4; зп 1165(10)

[ФАКТ] Здесь D01167 это копия D01165. Но зона 0401 НЕ
  исполнялась ни в одной доступной трассе (PCs 04xxx в
  baseline.tt.err отсутствуют).

### 2.1. Условия опыта

[ФАКТ] Инструмент: dispak builds/dispak/dispak с включённым

  BESM6_WATCH_RW=0 ловит все обращения по исполнительному
  адресу EA=01167, включая записи (WR).

### 2.2. Результат WATCH: записей НЕТ

[ФАКТ] Сводка по 4 заданиям (все RD, ни одного WR):

  B2-2048-6600  1 обращение  PC 14163L utm 1(13) EA=01167
  B2-2348-6600  1 обращение  тот же PC 14163L
  B2-2348-nochk 5 обращений  + 01304L xta 1167
  baseline-2348 5 обращений  + 01304L xta 1167

[ФАКТ] Типовые строки:

  WATCH 01304L xta 1167(0) EA=01167 RD AU=00323500003237
  WATCH 14163L utm 1(13) EA=01167 RD AU=10000067000124

[ФАКТ] PC 14163 это не проверка ветки, а копирование
  дескрипторного блока: 14162 xta 20000(13) читает левую
  половину, 14163 utm 1(13) читает правую по EA=01167.

### 2.3. -tt трасса: ветка 0547.01304

[ФАКТ] baseline.tt.err, первое попадание в 01304:

  01212 uj 1304
  01304 xta 1167 (=0000000000000000)  <-- флаг = 0
  01304 uza 1213                       <-- переход
  01213 uj 1311
  01311 *70 1144   грузит 1770 (0570)
  01312 *70 1145   грузит 1771 (0571)
  01314 uj 2000    вход в 0570

[ФАКТ] Значение 01167 в момент ветки равно НУЛЮ.
  Фактически загружается пара 0570/0571 (макромашина).
  Слов 0565/0566 в ОП не появляется.

[ФАКТ] В задании B2-2048-6600 PC 01304 не достигается
  вообще; флаг читает только блок 14162/14163.

### 2.4. Статический writer не исполнялся

[ФАКТ] Б2-зона 0551 грузится по адресу 074000 (PC 75676
  равен 0551.1676). Команда 0551.1674 была бы по PC 075674.
  В -tt трассе PC 075674 отсутствует, а PC 075676/075677
  исполняются и пишут D01101:

  75676 xta 76476 ; apx 76357
  75677 asn 136 ; atx 1101   → store 01101

[ФАКТ] Значит подпрограмма, содержащая `зп D01167`, в
  наблюдаемых прогонах НЕ вызывается. Вызывается только
  соседний блок для D01101.

## 4. ИТОГ ПО СТАТУСАМ

[ФАКТ] Единственный статический writer в B/B2 это
  `зп D01167` в 0551.1674R (B2) / 0151.1675R (B).
[ФАКТ] Ни в одном доступном задании он не исполнялся.
[ФАКТ] Записей в 01167 в 4 трассах с WATCH нет.
[ФАКТ] При ветке 0547.01304 флаг = 0, выбирается 0570/0571.
[ГИПОТЕЗА] D01167 это копия системного флага D01165,
  которую монитор (0401.1120) или АРАП (0551.1674)
  выставляет в зависимости от режима задания.
[НЕ ИЗВЕСТНО] Кто и при каком задании делает флаг
  отрицательным; исполнялась ли ветка 0565/0566 когда-либо.

## 6. ОГОВОРКИ

1. WATCH ловит записи только из цикла исполнения команд
   dispak. Прямая запись приёмником колоды не ловится.
2. -tt трасса B2-2048-6600 взята из /tmp/.private/azizz/
   b2-dyn/; -tt трасса baseline-2348 построена заново.
3. forced-листинг 0551 помечает все слова как W_CODE.
   Для raw-слова 0036013600001167 разбор подтверждён
   исполнением соседнего блока 1676/1677 в трассе.
4. Проверено 6 колод. Другие колоды и реальные архивные
   задания 1970-х годов не доступны.
