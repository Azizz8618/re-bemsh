## 3. ИНВЕНТАРЬ ФОРМ

Апостроф в .be это ASCII ' (0x27). В macros.be это
типографский ’ (U+2019). В 1978-исходнике знак
параметра это &, в macros.be это ∧.

    macros.be:73  Е∧N ВНЕШН ∧А..Е∧N
    macros.be:105 Е∧N ЭКВ ’103’+48-∧N
    macros.be:116 Е∧N.Д ЭКВ ’103’+48-∧N
Фаза: ММ. Выход: 49 имён Е0..Е48 в таблице символов.
1978, ФАКТ. Суффикс ".Д" создаёт второе семейство.

F33. ∧М..∧А(N’∧А) - диапазон имён
Примеры:
    macros.be:3  ∧А(1) ВНЕШН ∧М..∧А(N’∧А)
    macros.be:73 Е∧N ВНЕШН ∧А..Е∧N
Фаза: ММ. Выход: N объявлений ВНЕШН, затем АР
пишет N записей символов.
1978, ФАКТ. ".." это оператор диапазона macros.be.

F34. ∧А(1) - параметр с индексом
Примеры:
    macros.be:3  ∧А(1) ВНЕШН ...
    macros.be:63 ∧А(1) ЭКВ ∧А(2)
Фаза: ММ. Выход: выбор позиции из списка фактичес-
ких аргументов, слово не порождает.
1978, ФАКТ.

### 3.7 ДИРЕКТИВЫ, СПИСКИ, МНЕМОНИКИ

F35. ВНЕШН owner.symbol - директива связи
Примеры:
    MBE-Z0137.be:174  ВНЕШН Z0155.Z0155A
    MBE-Z0144.be:222  ВНЕШН Z0156.Z0156A
    MBE-Z0154.be:72   ВНЕШН Z0157.Z0157A
Фаза: ММ разворачивает, АР регистрирует.
Выход: +1 к ВНЕШН, запись СА в *МЕТ*, PC без изм.
1978, ФАКТ. 668 вхождений в MBE-Z01*.be.

F36. ВХОДН name - директива входа
Примеры:
    MBE-Z0150.be:172  ВХОДН Z0150A
    MBE-Z0154.be:75   ВХОДН Z0154A
    MBE-Z0154.be:110  ВХОДН ENT154
Фаза: АР. Выход: +1 к ВХОДН, запись с пометкой В
в *МЕТ*, PC без изм. 1978, ФАКТ. 10 вхождений.

F37. мнемоника в поле операции
Примеры:
    MBE-Z0154.be:648  СЧ C6065
    MBE-Z0154.be:649  Э50 '103'
    macros.be:207     ПВ ∧ВХОД.(13)
Фаза: АР, ММ если внутри макроса.
Выход: машинное слово, PC+1.
1978, ФАКТ.
[ФАКТ] Проверка всех 151242 строк: ни одна мнемоника
(ПВ, УИА, КОНД, ЭКВ, ПБ) не стоит в поле операнда
отдельным токеном. 0 вхождений. Поэтому "мнемоника
как операнд" не отдельная форма каталога, а свойство
поля операции.

F38. оп1,оп2 - список операндов
Примеры:
    mbe60_bemsh.txt:44   кк 26,'74000'
    mbe60_bemsh.txt:106  кк 26,'70000'(М11)
    macros.be:2          ВНЕШ ∧А,∧Б,...,∧Р
Фаза: АР для команд, ММ для директив.
Выход: одно слово с двумя полями или список записей.
1978, ФАКТ. По автокоду 1967 операнды в поле
отделяются запятыми (BEMSH-SYNTAX-SOURCES.md §2.2).

F39. (М1,1) - пара в директиве ЭКВИВ
Примеры:
    macros.be:80  ЭКВИВ (М1,1),(М2,2),(М3,3),...
    macros.be:81  ЭКВИВ (М10,8),(М11,9),...
    macros.be:82  ЭКВИВ (М16,14),(М17,15),...
Фаза: ММ. Выход: последовательность приравниваний
имен М1..М35 к числам 1..27, PC не меняется.
1978, ФАКТ.

## 6. СХЕМА СТРОКИ КАТАЛОГА

Точная схема из задания:

    form | example | file:line | phase |
    expected output | PC | status

Колонки:
    form             код формы F01..F39
    example          один реальный операнд
    file:line        источник написания
    phase            МР / ММ / АР
    expected output  слово / символ / счётчик / состояние
    PC               заполняют другие агенты
    status           ФАКТ / ГИПОТЕЗА / НЕ ИЗВЕСТНО

Примеры строк:

    F01 | '51' | MBE-Z0140:370 | АР | слово | | ФАКТ
    F07 | D00003-З | MBE-Z0137:523 | АР | слово | | ФАКТ
    F12 | Z0155.Z0155A | MBE-Z0137:174 | ММ | симв | | ФАКТ
    F14 | (М3) | ASM-Z0055:890 | АР | слово | | ФАКТ
    F22 | В'02000000' | ASM-Z0055:882 | АР | слово | | ФАКТ
    F23 | П'ОШИБКА' | ASM-Z0056:1473 | АР | слово | | ФАКТ
    F28 | ’103’+48-∧N | macros.be:105 | ММ | симв | | ФАКТ
    F36 | Z0154A | MBE-Z0154:75 | АР | счётчик | | ФАКТ

[ФАКТ] Для ЭКВ, ВНЕШН, ВХОДН и SЕТА адреса слова
нет. Для них PC оставляем пустым.
Для F13 и F21 PC относится к следующей строке слова.
