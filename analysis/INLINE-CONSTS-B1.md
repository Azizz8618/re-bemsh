## 1. ЗАДАЧА И МЕТОД

[Д] Искать слова `КОНД В'...'` внутри пробегов команд
(УИА/ЗП/СЧ/МОДА/Э66/Э67/...) без ПВ/ПБ/ПВО/ВЖМ на границах
кластера. Образец: `0137:0057-0076` (`MBE-Z0137.be:508-545`,
`analysis/SIMILAR-BLOCKS-B1.md`).

Метод:

1. Строки 8 `.be` делятся на CMD / CALL / DATA.
2. Адрес слова найден побайтовым совпадением 6 байт `КОНД`
   с эталоном `gold/MBE-Z<зона>-L1.bin` (1024 x 6 байт).
3. Окружение ±4 слова из `dis-forced/Z*.asm` (halves),
   для 0146/0147 (нет forced) - из `.be`.
4. Границы пробега: ПВ/ПБ/ПВО/ВЖМ = CALL; цикл/по/пе/пио =
   BR; конец/начало зоны = END/FILL.

[Д] - подтверждено байтами gold + листингом; [Г] - гипотеза.
