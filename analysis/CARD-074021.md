## 4. Ответ на вопрос задачи

[ФАКТ] 074021 есть МАРКЕР КАРТЫ-ОБРАМЛЕНИЯ.
  В job-B его дали первая карта ВВД и карта ТРН.
  В job-all ещё и ЕКОНЕЦ.
  Дальше flag 074544 = 0, `u1a (12)` не переходит,
  и writer пишет вторую запись 074022.

[ФАКТ] 075654 есть МАРКЕР КАРТЫ-ДЕЙСТВИЯ.
  Его дали все 9 карт-действий из §3. Дальше flag тоже 0,
  writer пишет вторую запись 075655.

[ФАКТ] 074770 есть МАРКЕР СТРОКИ ПРОГРАММЫ.
  Для него flag 074544 = 0000000100000000 (ставит 074765),
  `u1a (12)` переходит сразу на 074771, минуя перезапись.
