## 0. Главный результат: гипотеза НЕ подтвердилась

[ФАКТ] Память 06452 НЕ является таблицей переходов.
Это ОДНО слово-буфер, в которое PC 03024 (`atx 6452`)
пишет поочередно разные 6-байтовые слова. В трассе B
такая запись встречается 1401 раз, со 1401 разным
значением. Ячеек 06453..06477 дамп показывает
нули в каждой точке останова.

[ФАКТ] Подпрограмма 077414-077432 НЕ диспетчит карты.
Она вызывается из 03030 командой `vjm 77414(16)`;
r[16] = 03031 есть АДРЕС ВОЗВРАТА. Команда
`u1a (16)` по 077432 возвращает управление на 03031,
а не передаёт его обработчику 03040/07056.

[ФАКТ] Таблица, которую ищет 077414, лежит по 07776 и
07777 с индексом r[17]. Ключ поиска: слово в 06452.

[ФАКТ] Настоящее сравнение ключевого слова карты идёт
в 014335-014336 (`aex (2)` + `uza (14)`), а настоящий
переход к коду обработки: через 014171, 075650 и
074530 с таблицей дескрипторов по 077143.

Вывод: запрос "таблица по 06452 + индекс r[13]/r[6]" в
виде dispatch table НЕ существует. Ниже даны факты,
которые её заменяют.

[ФАКТ] PC 014335-014336 суть ДВЕ полукоманды одного

[ФАКТ] В точке совпадения r[3] = 076712 для всех
