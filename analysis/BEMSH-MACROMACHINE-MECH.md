# Как макромашина (зона 0170) исполняет макропрограммы

Дата: 23.11.2026. Write set: только настоящий новый файл.
Коммитов, push и правок в другие файлы НЕТ.
Объект: МАКРОМАШИНА 06/78, проход 2 конвейера
  МАКРОРЕДАКТОР (0154) -> МАКРОМАШИНА (0170) -> АРАП (0152).

## 0. Условности и источники

[ФАКТ] прочитано в исходнике, дампе, листинге или трассе
  с точной ссылкой (файл:строка либо линия .trace/.err).
[ГИПОТЕЗА] вывод без прямого свидетельства.
[НЕ ИЗВЕСТНО] ответа в прочитанных данных нет.

Обозначения: `&` в задании dispak = `∧` в OCR-макросе.
Все адреса восьмеричные, это 15-битные адреса ОП,
НЕ адреса зон диска. Степень пишем стрелкой вверх (↑),
каретку не используем. Строки ≤60 колонок, тире не пишем.

## 3. Ветвление AIF: адреса 04160, 03342, 03343

[ФАКТ] MACRO-VS-FLAG.md:186-208, два задания, разные
  одним символом (`тф 1` против `тф 0`). Номера
  строк = позиции в `.stderr.txt`:

  линия   GATE_1 (1)          GATE_0 (0)
  199305  05651 store ...0121  ...0120
  199311  04160 aex 5542       acc=0121  acc=0120
  199351  03342 aex 5640       acc=1     acc=0
  199352  03343 u1a 3434       не взят   взят
  199354  03433 xta 5441 (=1)     -
  199353  -                       03434 xta 5447 (=0)
  199359  77000 store ...0001     -
  199358  -                       77000 store ...0000

[ФАКТ] 05651 несёт код аргумента `&v`: 0121 это `1`,
  0120 это `0` в печати GOST. 04160 сравнивает с
  константой 0120. 03342 превращает результат в
  логический 1/0. 03343 ветвит:
  при 0 идём на 03434 (константа 0), иначе на 03433
  (константа 1). Результат пишется в 77000 командой
  02452 `atx (17)` с r[17]=77000
  (MACRO-VS-FLAG.md:201-208).

[ФАКТ] AIF переходит на метку при ИСТИНЕ условия
  (docs/MACRO-COMMANDS.md §1 п.10,
  MACRO-OPS-MISC-DYN.md:206-215).
  В шести макросах из macros.be:16-59 метка `.К`
  всегда ведёт к `АНОП/АNОР`, то есть к пропуску
  генерации (VS-FLAG-CELL.md:142-175).

[ФАКТ] Глобальная переменная `∧ВS` лежит в ОП по
  адресу 011273 (VS-FLAG-CELL.md:61-104). Запись
  идёт только при вызове макроса `б`:
  30624: xta 1772(3)   acc=...0001 r[3]=30000
  30624: wtc 1130(1)   (=1400240000011273)
  30625: atx 11273
        11273: store 0000000000000001
  Инициализация (обе трассы, линия 191375):
  03426: xta / atx 7777(4) -> 11273: store 0
  Эффективный адрес 01274 + 07777 = 011273.

[ФАКТ] Все семь сайтов чтения `∧ВS` используют один
  проводник `wtc 1130(1)` и `xta 11273`
  (VS-FLAG-CELL.md:104-132): ВНЕШБ 30201, ВНЕШС 30233,
  ВХОДБ 30147, ВХОДС 30115, КОНДБ 30265, КОНДС 30277,
  AIF в `б` 30700.

[НЕ ИЗВЕСТНО] Точная семантика `wtc 1130(1)` и таблицы,
  на которую указывает r[1]=07777
  (VS-FLAG-CELL.md:225-233).

[ФАКТ] B-explore.err:1874107-1874111 показывает те же
  адреса 03342/03343 с ДРУГИМИ мнемониками
  (`xta 6571`, `aox 6154`, `atx 6571`, `vjm 77605(15)`).
  Это подтверждает: конкретное содержание слова по
  адресу 03342 зависит от текущего прогона/оверлея.
  Отождествлять 03342 с одной командой без трассы
  нельзя.

Итог по §3:
  ФАКТ: 04160 + 03342 + 03343 есть динамический сайт
        вычисления условия AIF и ветвления.
  ФАКТ: 0121/0120 это аргумент &v, НЕ флаг ∧ВS.
  ФАКТ: сам флаг живёт в 011273, читается по
        `xta 11273`, пишется на 30625.
  НЕ ИЗВЕСТНО: статическое прочтение зоны 0170.

## 4. Подстановка ∧-параметров и команда ЭКВ

### 4.1 Что читает интерпретатор

[ФАКТ] Пул исходных текстов макроопределений физически
  начинается по 072000₈ (страница 035) и занимает
  одну страницу 072000-073777₈
  (TEXT-POOL-06445.md:7-24,
  POOL-DESCRIPTOR-FIELDS.md:119-144).
  Запись идёт командой зоны 0156:
  06057: xta 6402
  06057: aax 6165   маска 0o1777
  06060: ati 16     r[16] = смещение
  06060: xta 6404   дескриптор
  06061: atx 72000(16)
  B-explore.err:1481767 подтверждает:
  06061: atx 72000(16) (=2000000200052002) r[16]=00005.

[ФАКТ] Строка пула = дескриптор + текстовые слова
  + терминатор, обычно 3 слова
  (TEXT-POOL-06445.md:119-136). Дескриптор читается
  как 4 поля по 12 бит:
  [ 2010 | N | 0005 | 200K ] (8)
  N = номер исходной строки, K = число слов записи
  (POOL-DESCRIPTOR-FIELDS.md:9-21). Поле 0005 есть
  фиксированная константа из маски 01762
  (DESCRIPTOR-0005.md:60-92).

[ФАКТ] В зоне 0170 есть своя дескрипторная таблица
  0170.0003-0067: 53 подряд слова с префиксом
  `2710 2070 0300` и меняющимся 4-значным полем
  (docs/SEMANTIC/Z0170.md:59-73). Код читается как
  пары полукоманд `пв '2070'(М5) | пб '3055'` и т.п.

[ГИПОТЕЗА] Именно пул 072000 и/или таблица 0170.0003-0067
  служит интерпретатору источником текста макроса
  при подстановке. Прямого доказательства чтения
  этих структур в проходе 2 НЕТ. В опытах P0-P2 макрос
  не вызывался, и вопрос «кто читает записи пула при
  развёртке» прямо помечен как открытый
  (TEXT-POOL-06445.md:180-187,
  POOL-DESCRIPTOR-FIELDS.md:166-173).

[НЕ ИЗВЕСТНО] Где физически лежит таблица `*MET*` в момент
  работы макромашины и какова её ёмкость
  (MACRO-OPS-EQU-DYN.md:224-225).

  `ntr 3` (MACRO-OPS-EQU-DYN.md:214-220).

[НЕ ИЗВЕСТНО] Попадает ли значение ЭКВ в объектное

  значение шло в `*MET*`, а не в объектный модуль.

## 6. ЕВНЕШ: 46 внешних символов E1..E48

[ФАКТ] Макрос ЕВНЕШ (macros.be:68-76) строит имена
  подстановкой числа в позицию `∧N`:
  `Е∧N ВНЕШН ∧А..E∧N`.
  Это НЕ арифметика кодов, в отличие от макроса Е,
  где `Е∧N ЭКВ '103'+48-∧N`
  (MACRO-DK-EVNESH.md:198-205).

[ФАКТ] Управляемые прогоны (MACRO-DK-EVNESH.md:283-307):

  вариант       ГС      ДЛИHA  BHEШH  METOK
  V00 (база)    001332  00203  00003  00104
  EV1_MACRO     001336  00203  00061  00162
  EV2_NOPARAM   001336  00203  00061  00162
  EV3_RANGE     001332  00203  00003  00104

  Δ BHEШH = 00061 - 00003 = 00056 (8) = 46 (10)
  Δ METOK = 00162 - 00104 = 00056 (8) = 46 (10)
  `ДЛИHA ПРОГ` не изменилась: ни одного слова.

[ФАКТ] В `*MET*` EV1 появились E1..E48 с метками CA:
  E1 00061CA, E2 00060CA, ..., E48 00004CA.
  Номера CA идут в ОБРАТНОМ порядке: E1 получает
  старший номер 0o61, E48 младший 0o4.
  E11 и E46 уже были определены в базе (00115, 00116),
  поэтому новых CA 48 - 2 = 46
  (MACRO-DK-EVNESH.md:296-302).

[ФАКТ] Ошибки EV1: 2 x `METK YЖE OПP`
  (0301 +0008+E46 и 0371 +0008+E11)
  плюс 48 строк `OПEPAЦИИ HET`. Итого 50 = err=0050.
  EV2 (вызов без параметра) дал тот же результат:
  параметр ∧А на число символов не повлиял.
  EV3 (`внешн e1..e48` в теле, без макроса) дал
  err=0001 и неизменные счётчики: обёртка
  МАСRО/AIF/SЕТА необходима

[ФАКТ] В режиме 1-1 EV_1_1 дал 50 ошибок и

[ФАКТ] В базе mbe60 `ВНЕШН=3` это три объявления в

## 8. Сводка по уровням достоверности

ФАКТ:
  1. Вход машины: 01314 uj 2000 -> 02000 ntr 3 ->
     uj 2214 -> 02214. Оверлей страницы 01, база 02000.
  2. Штамп 0170 найден в RAM по 02216, код после
     штампа начинается на 02222 (utc).
  3. Ядро цикла: 03460 utm -1(3), 03462 u1a 3453,
     03453 vzm 3463(3), 03465 v1m 3451(3) с r[3]=0.
     Счётчик 48 раз принимает 0060..0001 на 03515.
  4. Сайт AIF: 05651 -> 04160 -> 03342 -> 03343 ->
     03433/03434 -> 77000. Флаг ∧ВS в 011273.
  5. Пул текста по 072000, запись 06061 atx 72000(16),
     дескриптор [2010|N|0005|200K].
  6. ЭКВ: 02002/3/4 -> acc (03573/03610) -> 02001 ->
     73266 -> `*MET*`. Формула 0o103+48-&a,
     5/5 совпадений.
  7. Четыре цикла 48↑0 (Е, ЕЕ, ОПРЕ, ЕВНЕШ)
     в macros.be и один общий код интерпретатора.
  8. ЕВНЕШ даёт 46 новых externals E1..E48,
     имена строятся подстановкой Е∧N.

ГИПОТЕЗА:
  1. 03460 реализует обе строки SЕТА (начало и
     декремент), сдвиг 00061 не объяснён.
  2. 03462 `u1a 3453` есть `АIF (∧N NЕ 0).СЛ`.
  3. 03453 есть точка `.СЛ`.
  4. Тег 0010 означает арифметический операнд,
     нормализация идёт через `ntr 3`.
  5. Пул 072000 и таблица 0170.0003-0067
     используются макромашиной при подстановке.
  6. Расхождение статики и трассы вызвано
     подменой оверлея в странице 01.

НЕ ИЗВЕСТНО:
  1. Статическое соответствие «слово зоны 0170 ↔
     команда интерпретатора». disbesm6 печатает
     03450..03520 как данные, принудительный
     дизассембль даёт другие мнемоники.
  2. Динамический адрес END/МЕND и переход
     машина -> АРАП.
  3. Кто именно читает пул 072000 при развёртке.
  4. Где лежит `*MET*` в момент работы машины.
  5. Причина шести повторов цикла с r[3]=00060.
  6. Причина 48 `OПEPAЦИИ HET` и 50 ошибок ЕВНЕШ.
  7. Поведение всех этих механизмов в B2 (0554/0570).
