## 1. МЕТОДИКА

Метки извлекались из колонки меток dis-forced/Z<зона>.asm:
в строке с адресом слова второе табулированное поле
содержит A##### или D#####. Адрес слова брался из первого
поля (восьмеричное, с двоеточием или без).

Карта слово -> строка .be взята из listing.out после
rebuild-zone.sh: второй 4-значный десятичный столбец
есть номер некомментарной строки .be. Базы по СТАРТ:
  0170 = 02000, 0171 = 04000, 0172 = 010000,
  0173 = 010000, 0176 = 1.

Метка ставилась в первое поле свободной строки слова,
которая имеет адрес в листинге (левая половина слова).
Замена 8 пробелов на имя (6 символов) плюс 2 пробела
не меняет длину строки и не порождает слов.

ВАЖНО: добавление метки в строку правой половины слова
(без адреса в листинге) сдвигает границы слов. Проба на
0171 дала 4105 различий. Все метки поэтому ставятся
только на строки с адресом.

Две коллизии (0171 D00007 и D00011):
основная строка слова уже несла другое имя. Метка
ставилась на ближайшую свободную строку с адресом.
Байты не менялись.
