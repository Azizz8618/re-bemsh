# Перемещения и установка: 2048 ↔ 2148 / 2248

Источник: `docs/VERSIONS-SCAN.md` §7 (побайтовая сверка) и §1
(md5 образов). Дополнительно проверено md5 самих файлов в
`/usr/local/share/besm6`. Образы не изменялись.

## 1. Суть

На всех трёх томах лежит **одна и та же редакция**
`МАКРО-БЕМШ ВЕР.06/78` (штамп `0147.1315`). Но на 2148 и
2248 иной **загрузчик**: зоны `0137–0143` (5 зон) не совпадают
с 2048. Ядро `0144–0177` в основном побайтовно совпадает;
исключения — три зоны текстовых таблиц (см. §3).

Это **не третья версия транслятора**, а другая установка той же
редакции (другой паспорт тома / настройка загрузки). При
сравнении версий 06/78 ↔ 12/77 (`analysis/versions.md`) зоны
`0137–0143` следует исключать из «ядра».

## 2. md5

Образы целиком:

| Диск | md5 | Размер, байт |
|---|---|---|
| 2048 | `4b94cc188969c110dcc78d1958b80fe0` | 33024000 |
| 2148 | `55d2f8223952f75ca92f984c98f52c61` | 8379840 |
| 2248 | `c11067b35e2b85a51433e7d7b5efdd19` | 33024000 |

Склейка ровно 33 зон `0137–0177` (202752 байт):

| Диск | md5 склейки |
|---|---|
| 2048 | `2f503f5b8f8fb6ad12632fed6f8cf17f` |
| 2148 | `90434226c98df1c40bbb8d76e1560613` |
| 2248 | `90434226c98df1c40bbb8d76e1560613` |

2148 и 2248 идентичны друг другу, но не совпадают с 2048.
md5 склейки 2048 совпадает с эталоном `v2048.bin`
(см. `analysis/versions.md` §1).

## 3. Поразовая разница (VERSIONS-SCAN.md §7)

| Зоны | Отличий | Что это |
|---|---|---|
| `0137–0143` (5 зон) | ~5300 байт/зона | загрузчик/настройка адресов |
| `0144–0146`, `0150`, `0152–0157`, `0160–0175`, `0177` | 0 | код совпадает |
| `0147` | 1977 байт | тексты сообщений: в 2148/2248 нет префикса `ИПМ` |
| `0151` | 3 байт | мелкая правка |
| `0176` | 1 байт | мелкая правка |

По данным того же раздела, `disbesm6` для зоны `0137` даёт
на 2148/2248 `зп '3407' / Э60 '73407'`, а на 2048 —
`зп '70000' / сбр`. Непосредственная проверка дампа зоны
`0137` (6144 байт) подтверждает разные первые слова:

```
2048: 00 00 00 04 00 00 ...   (зп '70000')
2148: 00 07 07 07 07 07 ...   (зп '3407')
```

## 4. Почему это важно для Phase 6

1. Сравнивать редакции `ВЕР.06/78` и `ВАР.12/77` нужно по
   зонам `0144–0177` (ядро), а не по `0137–0143`: последние
   меняются при установке на другой том.
2. На 2048 обе версии лежат в `0137–0177` и `0540–0577`;
   на 2148/2248 второй редакции нет (`0547` отсутствует).
3. Зона `0537` пуста во всех копиях; на 2048 старая редакция
   начинается с `0540`, что создаёт сдвиг на одну зону
   относительно логической нумерации (`+0400₈`).
4. md5 `904342…` для 2148/2248 нельзя смешивать с `2f503f…`
   2048: это разные установки одной редакции.

## 5. Оговорки

- Каталог зоны 0 на 2148/2248 нечитаем как KOI-7; наличие
  транслятора подтверждено только штампами в самих зонах.
- На 2248 зона `0115` содержит сохранённый **листинг**
  программы, оттранслированной транслятором, — это не исходник
  и не объектный код транслятора (`ANCHORS.md`).
- Запись `*S 100-177` на 2248 — независимое подтверждение
  диапазона `0137–0177₈`.
- Числа «~5300 байт/зона» и мнемоники выше процитированы из
  `VERSIONS-SCAN.md` §7; собственная проверка выполнялась только
  для md5 файлов и первых байт зоны `0137`.
