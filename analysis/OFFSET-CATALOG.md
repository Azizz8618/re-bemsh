## 4. Метод замены (проверен на копии)

```
было:  ЦИКЛ 29(М7)
стало: ЦИКЛ A00035-З(М7)
+ после строки «Z0055 СТАРТ '10000'» вставить
  «З ЭКВ Z0055»
```

Проверка: `rebuild-zone 0055 ASM` → ✓ 2000 слов, 0 отличий.
Если `З ЭКВ` поставить ДО `СТАРТ` — `НЕОП MET`, FAIL.

## 5. Ограничения

1. Внешняя метка через `ВНЕШН` меняет байты
   (OFFSET-EXTERNAL-LABEL-BLOCK.md), поэтому не применяется.
2. 2229 кодовых межзонных совпадений часто ложные:
   маленькие константы попадают в окно 0147 с базой 00000.
3. 57 литералов 0137 не имеют роли; зона не загружалась.
