(2000 слов). 1024/1024 PASS.

[Д] Аудит (difflib, before/after): 59 строк
"метка A/D -> роль", остаток строки побайтово
одинаков; удалены только 59 строк ЭКВ;
insert/прочих правок = 0. Обратная замена
ролей на A/D и возврат 59 ЭКВ дают исходный
текст без других изменений.

[Д] Длина строк: до 2688 строк, после 2629.

## 2. Зона 0547, режим MBE2: ЗАБЛОКИРОВАНО

[Д] До запуска создан .bak:
bemsh/MBE2-Z0547.be.bak.20261122_000741.

[Д] tool: зона 0547, переименовано 63, удалено ЭКВ 63.
Примеры: A00003 -> INIT03, A00467 -> EPI467,
A00472 -> OUT472, A00506 -> UTL506.

[Д] make rebuild-zone Z=0547 MODE=MBE2 на результате
tool: FAIL, ЧИCЛO OШИБOK=0242, МАКС CEPЬEЗH=4.
Контроль: тот же rebuild на .bak (исходник до tool)
даёт 1024/1024 PASS. Значит ошибки внесены tool,
а не унаследованы от исходника.

[Д] В листинге (rebuild-all/0547/listing.out)
строки с HEKOPPEKTHA для INIT03:
ПБ INIT03 и СЧ INIT03(М1). Было INIT03 ЭКВ '3'
(литеральная константа 3), метка A00003 стоит
по адресу 10002 (база СТАРТ '10000').

[Г] Причина: предпосылка tool ("слово по адресу N
совпадает со словом, на которое указывало ЭКВ 'N'")
верна только для зон с базой 1 (0147). В 0547 база
10000: метка A##### имеет физический адрес
10000+N-1, а ЭКВ даёт литерал N; после переименования
ссылки INIT03(M1) и ПБ INIT03 резолвятся в адрес
вместо литерала. Отсюда 242 ошибки.

[Д] По правилу FAIL пользователя: файл восстановлен
из .bak, sha256 совпал с исходником до tool:
5c7d3c69...5728 (0547-before.be). Ручных правок нет.
