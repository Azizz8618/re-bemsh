# Встроенные константы в линейном коде B2 (0540-0557)

Дата: 21.11.2026. Образ 2348, старая версия 12/77 (B2).
Только чтение `gold/*.bin`, `bemsh/*.be`,
`dis-forced/*.asm`.
[Д] = факт из файла с `file:line`; [Г] = наш вывод/гипотеза.

## 1. Задача и определения

Искали слова ДАННЫХ/констант (КОНД В'...', нуль-забел, ПАМ,
литералы), вставленные в середину ЛИНЕЙНОГО ПРОГОНА.

Линейный прогон = подряд идущие декодированные команды без
входа CALL и без RET/ветвления на границах. Границы:
ПВ/ПБ/ПВО/ВЖМ; в B2 реально встречаются ПВ, ПБ, а также
ветвления ПИО/ПИНО/ЦИКЛ (`bemsh/MBE2-Z0540.be:913`). [Д]

Встроенный кластер (по заданию):
* 2+ слов КОНД/ПАМ/нуль/данных, у которых есть команды-
  соседи в пределах +-4 слов, а на краях прогона нет ПВ/ПБ;
* либо одиночный КОНД, окружённый командами в таком прогоне.

Слово = 48 бит = 2 полуслова (левая/правая команда).
В `.be` одно слово занимает 2 строки, кроме полного КОНД,
которое даёт одну строку `КОНД В'<16 цифр>'`. Проверка:
`bemsh/MBE2-Z0540.be:941-942` = слово 0424 (ПБ+МОДА),
`:1019` = слово 0467 (полный КОНД).
Адрес = индекс слова. [Д]

Метод:
1. Разбор 16 `.be` на 1024 слова (проверено: 1024). [Д]
2. Классификация каждого полуслова: код / КОНД / нуль /
   `из КОНД`; граница = ПВ/ПБ/ПИО/ПИНО/ЦИКЛ. [Д]
3. Поиск DATA-кластеров с командами в пределах +-4 и
   без границы в +-4 (прогон без ПВ/ПБ на краях). [Г]
4. Отсев таблиц, FILL и блока KOI7 0540:0465-0527. [Д]

## 5. Категория D: нуль-забел внутри кода

Небольшие кластеры нулевых слов (2-3 слова) с командами по
краям и без ПВ/ПБ: [Д][Г]

* 0554:1135-1137 (3 слова), `.be:1667-1671`. [Д]
* 0550:1126-1136 (9 слов), `.be:1597-1613` - пограничный
  случай, ближе к таблице. [Г]

Классификация: **INLINE-CONSTS-IN-LINEAR** (0554),
TABLE/FILL (0550, 9 слов). [Г]

## 6. Исключено

* 0546 - весь FILL (`bemsh/MBE2-Z0546.be:22-`, 2048
  нуль/данных строк, 0 границ). По заданию исключён. [Д]
* KOI7-блок 0540:0465-0527 (`SIMILAR-BLOCKS-B2A.md`):
  КОНД-группы 0470-0474, 0476-0477, 0504-0506 и слово
  0527 попадают в исключённый блок. [Д]
* Большие таблицы КОНД: 0553:0055-0074 (16 слов),
  0553:0271-0301 (9), 0554:0147-0155 (7, KOI7-строки),
  0552:0714-1124 (~30 KOI7-строк "константа+нуль").
  Это STANDALONE-TABLE, не встроенные константы. [Д][Г]
* Большие нулевые забелы: 0550:0346-0405 (32),
  0550:0505-0545 (33), 0552:0632-0661 (24). FILL. [Д]
* Слова `из КОНД` с левой ПБ (всего 893 слова): в
  принудительном листинге это ПБ/ПВ-границы, поэтому не
  подходят под признак "прогон без ПВ/ПБ на краях". [Д][Г]
  По зонам: 0540:154, 0541:49, 0542:56, 0543:56, 0544:46,
  0545:37, 0547:96, 0550:36, 0551:121, 0552:13, 0554:52,
  0555:80, 0556:9, 0557:88. [Д]
