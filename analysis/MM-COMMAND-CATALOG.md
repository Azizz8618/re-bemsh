## 1. Природа четырёх фикстур (ФАКТ)

Колоды P1a/P1b/P2a/P2b отличаются лишь видом метки
в теле (`ZLBL1` против `ZLBL1:`), см. deck_copy в manifest.
Каждая колода определяет ОДИН макрос `ZMAC01` и НИКОГДА его
не вызывает. Листинг P1a.job/listing.txt:20-33 показывает:
  0001 0001 MACRO /
  0003 0002 ∧M ZMAC01 ∧ZP ∧ZQ   (TEPM HE OПP)
  0008 0005 MEND /
  0010 0006 ФИHИШ
  ДЛИHA ПPOГ=00000, BXOДH=00000, BHEШH=00000,
  ЧИCЛO METOK=00001, ЧИCЛO OШИБOK=0006.
Развёртки макроса в этих четырёх прогонах НЕТ.
Поэтому все PC ниже - это исполнение САМОГО интерпретатора,
а не развёртка конкретной макрокоманды из macros.be.

Фазы P1a (номера событий): INPUT 39271-39291,
EDITOR 39292-159330, MACHINE 159331-200086,
LISTING 200087-233400. В MACHINE 34229 exec-событий.
Остальные три фикстуры имеют те же границы сдвинутыми
на десятки событий; подписи PC в MACHINE совпадают.

## 5. Команды без динамического свидетельства

Все 33 позиции, помеченные в таблице §2 как `нет`,
не имеют исполнения в MACHINE фикстур. Причины:

1. Колоды не вызывают макрос (основная причина).
   Заданы только `MACRO / ... MEND /` и `ФИНИШ`.

## 6. Сверка с docs/MACRO-COMMANDS.md

Перечисление §2 совпадает с MC:16-70 и с выводом
`python3 tools/macro_decode.py --catalog` 37/37,
по numbering, написанию и примеру из macros.be.
Совпадает также ST:85-124 (37 позиций, проходы).
Расхождения, которые нужно помнить:

1. MC:49 пишет `DК` (лат. D), а mb:198 - `ДК`
   (кир. Д). Это РАЗНЫЕ байты: 0o77 0o52 против
   0o44 0o52 (DK:96-117). Декодер их не различает.
2. MC:49 и динамические задания используют ASCII
   апостроф `'36'`, в mb:198 типографский `’36’`
   (U+2019) (DK:119-120).
3. MC:38-39,43-44,46-47 утверждают: Б-вариант при
   VS==1, С-вариант при VS==0. Динамика VS:153-175
   даёт ОБРАТНОЕ: АIF переходит при ИСТИНЕ на `.К`,
   а `.К` есть АНОП, то есть пропуск. Значит код Б
   появляется при VS==0, код С при VS==1.
   Ячейка 011273 = 0 без вызова `б`, = 1 после `б`.
   Это противоречие MC и динамики, а не опечатка.
4. MC:24,28 называют ∧ВS булевой, а mb:17 и mb:122
   объявляют её в GВLА (арифметическая), запись идёт
   через SЕТА (mb:130). Противоречие источника
   зафиксировано в MACRO-VS-FLAG.md:68-71.
5. Позиции 29 (`АНОП / АNОР`) и 36 (`ТЕКСТ / П'`)
   объединяют по два написания. 37 позиций дают
   39 различных токенов. Позиция 14 `.МЕТКА` -
   класс меток, не одна команда.
6. MC:45 помечает семантику КОНД как гипотетическую.
   ST:212-215 относит КОНД, DК, МNОТЕ, ПВ, ЭКВ
   к ГИПОТЕЗЕ, а Х' - к НЕ ИЗВЕСТНО. Настоящий
   каталог сохраняет те же границы.
