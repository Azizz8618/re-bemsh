# Восстановление меток A#####/D##### (группа 1)

[Д] - факт из gold/дампа или файла с file:line;
[Г] - наш вывод/гипотеза.

## 1. Задача

Перенести метки A#####/D##### из dis/*.asm в bemsh/*.be
для 14 зон группы 1 (2 зоны ASM, 12 зон B).
Инструмент: tools/restore_dis_labels.py (пилот на 0147:
1024/1024 PASS, 173 метки).

## 2. Методика (все шаги [Д])

1. cp файла в *.bak.<timestamp> перед изменением.
2. python3 tools/restore_dis_labels.py <ЗОНА> <MODE>.
3. make rebuild-zone Z=<ЗОНА> MODE=<MODE>:
   требуется WORDS совпало=1024 и RESULT: PASS.
4. При FAIL - немедленный откат из .bak (не сделано:
   все зоны дали PASS).
5. awk length: длина строк вставленных меток <=60.

## 3. Окружение [Д]

Каталог gold/ в worktree отсутствует (gitignored,
.gitignore:7). Дампы скопированы read-only из главного
дерева: cp /home/azizz/Yandex.Disk/re-bemsh/gold/*.bin
в gold/ worktree. Эталонные образы не изменялись.
Первый прогон до копирования дал "Нет файла gold/..." -
все 14 зон были откатаны из .bak, затем переделаны.
