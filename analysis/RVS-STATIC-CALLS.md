## 1. Методика и воспроизводимость

Каталог: z0001.txt, 146 записей `МДЛ`, из них 87 с
чистым `НАЗ`. Зоны каталога ВОСЬМЕРИЧНЫЕ, besmtool
принимает ДЕСЯТИЧНЫЕ. Пример: 421260 -> зона 1260₈
= 688₁₀.

Извлечение (все копии):
  besmtool dump 2113 --start=<dec> --last=<dec> \
    --to-file=/var/tmp/rvs-static/raw/<name>.bin

Дизассемблирование:
  disbesm6 -a<НАЗ> -e<entry> <zone.bin>
  BOM (EF BB BF) и ANSI из вывода убраны.

Для РВС-образа вход найден перебором: код начинается
со слова 0024₈ = адрес 070024. Для остальных модулей
вход найден перебором по числу команд `пв`.

## 6. МАШИНЕРИЯ ЛИНКОВКИ

### 6.1. Поиск по внешним символам

[ФАКТ] A71115 - табличный диспетчер. Он сравнивает
значение из М1 с константами D72502-D72520 и ветвится
на A70114, A70116, A70151, A70143, A72263.
Константы в ГОСТ (070502-070520):

  ИПЗ РМБ ПВА ПВО ТЕР
Это имена команд сервисного монитора, а не
имена внешних символов МАКРО-БЕМШ.

### 6.2. Коррекция адресов команд

[ФАКТ] По адресу ядра 070427-070543 лежит таблица
из 115₈ = 77 слов. Каждое слово: левые 24 бита
код операции + R, правые 24 бита = 0.
Примеры (декодер siprod_asm.OPS):
  070427  зп  / зп     R=1 / R=0
  070430  сбр / зп     R=1 / R=0
  070431  уи  / зп     R=1 / R=0
  070500  уиа / зп     R=3 / R=0
  070543  уиа / зп     R=2 / R=0

[ГИПОТЕЗА] Это таблица шаблонов команд для
классификации поля адреса при коррекции.
Косвенное подтверждение: рядом константы
D70420 (маска 7777777777700000),
D70422 (0o125), D70423 (771777).

[НЕ ИЗВЕСТНО] Прямой переход по этой таблице в
статическом листинге не найден. Возможен доступ
через регистр со смещением.

   внешних адресов.
