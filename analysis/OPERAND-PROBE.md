## 1. ПРИМЕНЕНИЕ

    python3 tools/v78_operand_probe.py FILE...
    python3 tools/v78_operand_probe.py --catalog \
        /home/azizz/Yandex.Disk/re-dispak/macros.be
    python3 tools/v78_operand_probe.py FILE \
        --check --summary
    python3 tools/v78_operand_probe.py FILE \
        --format json --form cell_ref
    python3 tools/v78_operand_probe.py --help

Ключи: `--format json|text` (по умолчанию text),
`--check` (проверка инвариантов, код 1 при нарушении),
`--summary` (счётчики по формам и классам),
`--form ФОРМА` (только одна форма),
`--catalog ПУТЬ` (добавить каталог к входам).
Коды: 0 успех, 1 нарушение проверки, 2 ошибка ввода
или CLI. Оба входа можно задать вместе.

Поле записи JSON: `file`, `line`, `mnemonic`,
`operand`, `form`, `value`, `symbol`, `register`,
`output_class`. В `value` есть `radix`, `decimal`,
`octal`, `raw` и `detail`.

## 2. ТАКСОНОМИЯ ФОРМ

| форма | пример | radix |
|---|---|---|
| none | `Е`, `М` | - |
| bare_number | `64`, `-1` | decimal |
| quoted_number | `'1173'`, `'10'` | octal |
| cell_ref | `D00100+40`, `A01036-З+10` | octal |
| register | `(М4)`, `(13)` | - |
| register_pair | `(М1,1),(М2,2)` | - |
| string_constant | `В'7600...'`, `П'ШИФР'` | octal/text |
| equiv_expr | `'103'+48-∧N`, `64-5` | octal/decimal |
| macro_param | `∧А`, `∧М..∧А(N’∧А)` | symbolic |
| label | `Z0155.Z0155A`, `E70000` | - |
| external | `ВНЕШН Z0155.Z0155A` | - |
| mnemonic_operand | `КО`, `ДАЙКОТ(13) КО` | - |
| unknown | `$$$` | - |

Суффикс регистра `(Мn)` или `(13)` отщепляется от
любой формы и уходит в поле `register`. Латинская
`M` нормализуется в кириллическую `М`.

## 3. СИСТЕМА СЧИСЛЕНИЯ

[ФАКТ] Голое число в выражении .be десятичное:
`64` = 64(10) = 0100(8), `СДА 64-5` = 59(10).

[ФАКТ] Число в кавычках восьмеричное:
`'103'` = 67(10), `'1173'` = 0o1173 = 635(10).

[ФАКТ] В `D00100+40` база восьмеричная, смещение
десятичное. 0100(8) + 40(10) = 0100(8) + 050(8) =
0150(8) = 104(10). Проба печатает `octal=00150`.

[ФАКТ] `-З` вычитает базу наложения. Поле
`minus_overlay_base` фиксирует этот факт, но число
без значения `З` не вычисляется.

[ФАКТ] `'103'+48-∧N`: константа 0o103 + 48 =
115(10) = 0163(8), затем вычитается параметр `∧N`.
