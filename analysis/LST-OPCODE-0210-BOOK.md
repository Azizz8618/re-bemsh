- Книга:843-848: структуру задаёт разряд 20 (0=1-я, 1=2-я);
  Ф и У - поля кода операции 1-й и 2-й структур.
- simh besm6_cpu.c:1037-1045: reg=RK>>20; при бите 20
  opcode=(RK>>12)&0370.

## 2. Что показывают официальные .lst [Д]
- apunkt.be.lst:15 - шапка: "... КОМАНДА A ИСП N ГЕН N ...".
  Числа 0210/0200 в .lst - это ИСП N (номер строки),
  НЕ опкод: apunkt.be.lst:159 "... 0210 0136 СЧ E42".

- Э202/Э210 в ek6.lst:20,174 - МЕТКИ, не опкоды.

## 5. Вердикт [Д]/[Г]
[Д] Слово: 2-я структура, КОП2=021, reg=4.
[Д] Книга: КОП 21 = Э21 экстракод. simh печатает "э21".
[Д] .lst/disbesm6: отдельного мнемонима нет (КОНК/КОНД).
[Г] Возражение "нет такой команды, смотри сбр/рзб" -
    подмена структур: СБР/РЗБ суть КОП1 020/021.
    "э21" не выдумка: это имя экстракода по книге и simh.
Расхождение книга<->simh есть лишь для 22/23 (МОД/МОДА),
на 20/21 все согласны.

## 6. Рекомендация по комментарию [Г]
Оставить "э21", но явно зафиксировать структуру:
    L=э21 КОП2 021 (Э21 экстракод по книге);R=ПБ
Если нужен нейтральный тон (по .lst/disbesm6):
    L=КОП2 021 (экстракод, мнём. в .lst нет);R=ПБ
НЕ писать L=сбр / L=рзб - это 1-я структура.
