## 1. Метод изоляции

Для каждой из пяти команд построена пара колод.
Колода (a) вызывает только эту команду. Колода (b)
заменяет её командой из той же группы общего PC.
Всё остальное байт-идентично: `diff` показывает
ровно одну изменённую строку на пару.

Пример, пара GВLА/LСLА:
  < gbla &vs
  > lcla &vs

Сравниваются множества событий фазы MACHINE
(kind=exec/store, pc, mn, operand, acc). Если PC
присутствует только в (a), он и есть писатель.
Если множества равны, команды неразделимы.

Guard отказывает для каталога /usr/local/share/besm6
(RUN:158-178). Тома копируются в scratch, md5 до и
после каждого прогона совпал 16/16. Трасса только
потоком, полный лог не сохраняется (RUN:354-370).
