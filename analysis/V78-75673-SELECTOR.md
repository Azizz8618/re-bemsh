## 0. КРАТКИЙ ОТВЕТ

[ФАКТ] Единственный путь, который может передать управление
  на PC 075673, это словарный поиск 074251 в B2. Вызов
  идёт из 0551.1662-1664 (dis-forced/Z0551.asm:1865-1873),
  база словаря r14=077027, ключ берётся из M[076475].
  В словаре запись ключа "ЗПКОМП" по 077061 указывает
  на обработчик 077062 = 075673. Ключ "ЧТКОМП" по
  077063 указывает на 075676. То есть 75673 выбирает
  директива ЗПКОМП, но только в версии B2.

[ФАКТ] Ни в одном доступном задании этот обработчик не
  выбран. Прямой опыт с брейкпоинтом 75673 на колоде
  macros.b6 (в ней есть ЗПКОМП430070) не дал ни одного
  останова. Трассы TP1/TP2 и P1-P4, указанные в задании,
  к моменту работы отсутствовали (каталоги /var/tmp
  очищены), поэтому все оценки ниже даны по новым прогонам.

[ФАКТ] Три перехода на BR5673 в зоне 0137 остаются
  статическими ссылками: зона 0137 ни в одном прогоне
  не загружалась.

[НЕ ИЗВЕСТНО] Какое реальное задание 1978 года вырабатывает
  ключ, выбирающий 075673. Все доступные колоды и 7
  вариантов карт из D01167-NEGATIVE.md не активируют его.

### 2.3. Содержимое словаря

[ФАКТ] Ключи словаря закодированы таблицей
  gold/MBE-Z0147-L1.bin, слово 0561 (GOST-байт ->
  внутренний байт, см. analysis/GOST-BYTE-FORMULA.md §3).
Раскодированные пары B2 (зона 0552, база 076000):

    077061 "ЗПКОМП" -> 077062 = 075673  <-- D01167
    077063 "ЧТКОМП" -> 077064 = 075676      D01101

    077121 "?СОМР " -> 077122 = 075673  <-- ещё одна

Байты ключа 077061: da d0 ab af ad d0.
Байты ключа 077063: de b4 ab af ad d0.
Оба decoding проверены по таблице 0147.0561:
  da=З d0=П ab=К af=О ad=М d0=П;
  de=Ч b4=Т ab=К af=О ad=М d0=П.

[ФАКТ] В B (зона 0152):
    077071 "ЗПКОМП" -> 077072 = 075674

То есть 075673 это обработчик ТОЛЬКО версии B2.
Это объясняет, почему поиск в B не даёт 75673.

## 4. СВОДКА СТАТУСОВ

ФАКТ:
  - 9 текстовых вхождений 75673: 3 в 0137, 6 в 0151;
  - 0137 - внешние переходы BR5673, зона не грузится;
  - 0151 - данные/садомодификация, не переходы;
  - value 075673 в gold есть только в B2-зоне 0552;
  - словарь 077061 "ЗПКОМП" -> 075673 существует;
  - в B тот же ключ даёт 075674, не 075673;
  - dispatch 0551.1662-1666 готов передать управление;
  - прямой опыт: PC 75673 НЕ достигнут ни в одной колоде;
  - 77144 пишется только дескриптором 74522;
  - 075673 только читается загрузчиком, WR нет.

ГИПОТЕЗА:
  - 75673 задуман как обработчик директивы ЗПКОМП
    в версии B2, ключом служит "ЗПКОМП";
  - ключ 077121 ("?СОМР ") - второй, уточнённый доступ;
  - невыбор вызван тем, что проверка 1660 требует
    первый байт 0x50, а ключ ЗПКОМП имеет da.

НЕ ИЗВЕСТНО:

    ключ, который доходит до 1662 и выбирает 075673;
  - исполнялась ли ветка 0565/0566 в 1978 году;
  - точный смысл второго ключа 077121;
