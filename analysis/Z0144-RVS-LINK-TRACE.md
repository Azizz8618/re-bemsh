## 3. ЧТО НАЙДЕНО

[ФАКТ] В link-dd.err 4058804 строк, 241 событие
`DD pc=`, 156 различных значений `z`. Событий с
`z=0144` ровно 2:

  DD pc=70142L r016=71706 u=43 z=0144 RD
  DD pc=72102L r016=72474 u=43 z=0144 RD

[ФАКТ] Это НЕ исполнение кода зоны 0144. В формате DD
`z` это зона ДИСКА, `u=43` лента ПЕРСО. Трасса показывает
команду `70141: *70 71706` с операндом `43/0/144`, то есть
Э70 читает дискозону 0144 в ОП по адресу 71706. Проверка
`besmtool dump 2222 --start=144` показывает там объектный
модуль (`зп`, `слц 311(15)`), а не транслятор. Ловушка
`z=0144` в трассе НЕ НАДО путать с зоной 0144 образа 2348.

[ФАКТ] В дампе ядра на PC 70142 НЕТ полного образа зоны
0144: 0 совпадений 1024 слов подряд, лучшее 79/1024
на базе 70001. Код 0000-0274 не найден совсем.

[ФАКТ] Но нашёлся блок из 115 слов: зона 0144 адреса
0426-0542 побайтно равна ядру 070427-070543.
Начало:

  0144.0426 500000000000  ядро.070427 500000000000
  0144.0427 510000000000  ядро.070430 510000000000
  0144.0430 520000000000  ядро.070431 520000000000

По всем gold-образам этот блок найден только в
MBE-Z0144-L1.bin, MBE2-Z0544-L1.bin и MBE-full.bin
(слово 012426). Это общая таблица редактора связей.

[ФАКТ] Версии не совпадают: штамп зоны 0144
`Р В С :10/75` (0144.0571), а баннер этого прогона
`Р В С :01/78`. Код 0144, значит, НЕ является кодом
загруженного линковщика.
