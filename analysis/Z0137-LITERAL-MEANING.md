а не число. Разбивка по классам: BASE 24, CELL 4,
CONST 3, DATA 3, EXTERNAL 2, RETURN 1.

## 3. ЧТО НЕ СПЕЦИФИЧНО ДЛЯ ЗОНЫ 0137

1. KOI-7 артефакты (37 имён): их "значения"
   2015, 44101, 70040, 64440, 72554, 32460,
   10014, 47544 и др. суть биты строк "ИЛИ",
   "ЗНАК", "ЗП", "УИ", "ДЕЛ", "Э50", "МОДА".
   Это не константы зоны 0137 вообще.
2. Малые операнды <02000к8 с (М7) или (М17):
   и 1..77(М7), нтж 3(М7), сч 8(М7), зп 5(М17).
   Это смещения массива D00100+N и счётчики
   циклов. Повседневные индексы, не роли.
3. сда 64±N (строки 268,357,380,574,...):
   стандартный приём выделения поля БЭСМ,
   не константа транслятора.
4. Малые адреса зп D000NN (010, 011, 013, 021,
   040 и др.): ячейки данных этой же зоны.
   Их роль - "память", а не Named constant.
5. Маска 7777 - типичная 12-битная константа,
   встречается вне 0137.

Итого: большинство "литералов" это либо текст,
либо индексы, либо адреса ячеек, либо внешние цели.
Осмысленных именных ролей в зоне нет, что совпадает
с analysis/Z0137-EQU-AUDIT.md:59-61.

## 4. ПОЧЕМУ ДИНАМИКА ДАЛА 0 РОЛЕЙ ВНУТРИ ЗОНЫ

analysis/Z0137-LITERALS-DYN.md:11-20 и
analysis/Z0137-BASE-FINAL.md:121-148 фиксируют:
зона 0137 не загружена в наблюдаемых прогонах
(ZONE-BASE-MAP.md §3:70, база "-").

Следствия:
1. Ни одна команда 0137 не исполнялась.
   Значит трасса не показывает, как зона
   ПОТРЕБЛЯЕТ литерал.
2. Трасса показывает только судьбу ЧИСЛА в других
   зонах (монитор 64xxx, загрузчик оверлеев).
   Совпадение числа с живым адресом не есть
   атрибуция зоне 0137.
3. 37 KOI-7 артефактов в трассе ведут себя как
   адреса просто потому, что биты KOI-7 дают
   числа 7xxxx. Отсюда ложные "роли".
4. Проверка PC 00100/00107/00110/64000/64063
   и PC 03610 не нашла KOI-7 отпечатка; гипотеза
   "загружена и стёрта" не подтверждена.

Вывод: 0 ролей внутри зоны - корректный результат
метода, а не доказательство отсутствия смысла.

## 6. ЧТО ОСТАЛОСЬ НЕИЗВЕСТНЫМ И ПОЧЕМУ

1. Роль KOI-7 таблицы мнемоник при сборке.
   Причина: исходника МАКРО-БЕМШ 06/78 нет.
2. Какие модули находятся на страницах 16/17/20-25.
   Причина: карта ОП для них пуста в снимках.
3. Смысл immed CON355=3554, '4656', '4114',
   '36266'. Причина: не KOI-7, не адрес,
   трасса зоны отсутствует.
4. Почему зона 0137 не грузилась в тестовых заданиях.
   Причина: вне WRITE SET и вне доступных трасс.
5. Точное назначение ячеек 0140-0153
   (таблица указателей/продолжений). Причина:
   видна только запись адресов, нет чтения
   с именованной ролью.
