# Рабочая программа пользователя с Э20/Э21/сбр/рзб

Дата: 21.11.2026. Прогон на копиях томов, каталог
  /tmp/.private/azizz/extr20-21-3/. Воспроизведение:
  python3 /tmp/.private/azizz/start-probe/experiment3.py

## 1. РАБОЧАЯ ПРОГРАММА (диалект inp$$$/eoi$$$)

    ТЕСТ  СТАРТ 1
    Е
    М
      сбр '1000'       -> листинг: 00 020 1000  (КОП 020)
      рзб '1000'       -> листинг: 00 021 1000  (КОП 021)
      ФИНИШ

Результат: `ДЛИHA ПPOГ=00001`, 2 машинных слова,
  `OПEPAЦИИ HET` только на служебных строках E/M
  (артефакт нашего шаблона: в эталонных заданиях
  E/M идут без табуляции; на сборку слов не влияет).

## 2. ЧТО ДАЁТ "кк"

    кк 16,'1000'  -> 00 020 1000   (= сбр)
    кк 17,'1000'  -> 00 021 1000   (= рзб)
    кк 20,'1000'  -> 00 024 1000
    кк 21,'1000'  -> 00 025 1000
    кк 26,'0'     -> 00 032 0000   (= УВВ / Э32)

Правило [Д]: `кк N` собирает 1-ю структуру с КОП
  `020+N`. Это НЕ системный экстракод Э20/Э21
  (2-я структура), а команда 1-й структуры.

## 3. Э20/Э21 ПРЯМОЙ ФОРМОЙ

    сч '1'
    Э20 '1000'   -> OПEPAЦИИ HET на второй половине
    сч '2'
    Э21 '1000'   -> листинг 00 21 01000, но +1 ошибка

Транслятор ЗНАЕТ мнемоники Э20/Э21 (печатает их как
  ОПЕРАЦИЮ), но простая форма `Э20 '...'` собирается
  с ошибкой на авто-вставленной моде: эти команды
  ставятся только в правую половину (ADDREX/IMMEX),
  как и Э50..Э77.

## 4. ВЫВОД

Рабочая пользовательская программа с «этими экстракодами»
  в 1-й структуре — это `сбр`/`рзб` (или `кк 16/17`).
Прямые Э20/Э21 (2-я структура) требуют другой формы
  записи и в нашем шаблоне не собираются без ошибок.
  simh/книга называют их экстракодами; транслятор
  печатает их мнемоникой, но не собирает простым写法.
  Все пометки [Д] основаны на листингах прогона.
