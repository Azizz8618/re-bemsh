## 1. Как найдено

[ФАКТ] Трасса Stream-сканировалась дважды:

  - поиск `r[N]` в интервале 076643-076777
    дал 742 727 совпадений, почти все это
    отрицательные константы (077777 = -1);
  - вычисление ЭФФЕКТИВНОГО адреса
    `(операнд + r[N]) mod 0100000` для каждой
    команды с индексом дало 445 474 перехода
    в область. После фильтра по адресам
    076643-076655 остался чёткий результат.

[ФАКТ] Исходники RLE-записей (строки `store`
после `76622: atx 76642(5)`) дают ровно 11
адресов: 076643, 076644, ..., 076655.

[ФАКТ] Единственная программа, читающая все
эти 11 адресов подряд, - `01412: xta N(5)`
с R5 = 076642. Совпадений по каждому индексу
N=1..13: по 103, ровно числу вызовов цикла
076600 (103 входа, 103 выхода `76610: uj (12)`).

## 4. Перекрёстная проверка "запись -> чтение"

[ФАКТ] В RLE-потоке есть записи со счётчиком
повторов в байте:

    1044778: 76643: store 0020000000000000
    1044823: 76643: store 0032640100000000
    1044847: 76643: store 0032640200000000
    1044921: 76643: store 0032640500000000

Значение `0020..` есть счётчик 0x01,
`..05..` - счётчик 0x05 (см. CODE-01-EXACT.md).

[ФАКТ] После этой серии первое чтение
076643 - тот же `01412: xta 1(5)`
в строке 1046438. Между ними повторного
чтения 076643 нет.

[ФАКТ] Итого: сначала RLE пишет байт-счётчик
в 076643+, затем 01412 читает готовое слово
целиком и переносит его в 012000+.

## 6. Что делает потребитель с байтами

[ФАКТ] Копирует 16 слов из 076642-076657
в 012000-012017 без изменений. Слово 076642 -
заголовок со счётчиком, 076643-076655 -
RLE-сжатые данные, 076656-076657 -
хвост (076657 = `2500000000000000`).

[ГИПОТЕЗА] Буфер 012000+ является дескриптором
каталога, который затем передаётся дальше
(через R13 = 012000, см. `01400: m+j 11(13)`
и REG-DYN-MBE60.md). RLE-представление
передаётся "как есть", обратного разворачивания
счётчиков в пробелы в этой трассе не видно.

[НЕ ИЗВЕСТНО] Кто именно читает 012000+ после
копирования. В трассе после строки 1043607
зафиксированы только записи в 012000+
(`01413`, `01675`), явного чтения готового
буфера не найдено. Возможно, он считывается
другим процессом или уходит на печать через
канал, не попавший в трассу.
