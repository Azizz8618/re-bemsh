# Фокус: ИПМ МАКРО-БЕМШ ВЕР.06/78

Дата: 23.11.2026. Только версия 06/78, зоны 0137-0177 тома 2348.
B2 12/77, автокод 1967 и РВС как отдельная тема ВЫНЕСЕНЫ.
Три версионных вопроса уточняются агентами в отдельных отчётах.
Адреса восьмеричные, степень ↑, тире НЕ используется.

## 1. Идентичность

ФАКТ. Основной штамп: `ИПМ МАКРО-БЕМШ ВЕР.06/78`
по адресу 0147.1315. Присутствует на томах 2048, 2148,
2248, 2348. Каталог тома 2048, запись 0000.0445:

  0137-0177 ТРАНСЛЯТОР С М/К Б Е М Ш ... 20.06.78

ФАКТ. Версия занимает 33 зоны по 1024 слова, итого
33792 слова = 202752 байта. Все 33 зоны реконструированы
с 0 байтовых отличий от gold.

## 4. Что доказано именно для 06/78

1. Оверлей 0154 и 0170 грузится по 02000 (page 01),
   совпадение 1024/1024, breakpoint сработал, первая
   команда `xta 6065` = `сч '6065'`.
2. Пул текста 072000: писатель `06061: atx 72000(16)`,
   r[16] = M[06402] & 0o1777; дескриптор
   `[2010|N|0005|200K]`; читатель `01534: xta (6)`.
3. Последовательность загрузки: RLOAD 064063 → Э60 →
   АРАП 076000 → редактор 02000 → макромашина 02000.
   481 вызов архива до входа в макромашину, после 0.
4. 37 макрокоманд каталога, омоглиф-толерантный декодер.
5. Ячейки ГС: +2 за простой макрос, +4 при LСLА/SЕТА/АIF
   и у authentic Е.

## 4b. Граница с 12/77

ФАКТ (`analysis/V78-COMPARE-77.md`, проверка md5): из 32
сравнимых зон идентичны только 9: 0144, 0146, 0150, 0160,
0162, 0163, 0164, 0167, 0175. Остальные 23 отличаются,
всего 15540 различных слов. Утверждение
«ядро 0144-0177 полностью идентично 12/77» НЕВЕРНО.
Зона 0137 пары не имеет: зона 0537 пуста.

ФАКТ. Реальная правка кода, а не только сдвиг текста:
- 0147 вставлены две полукоманды и переадресован пб;
- 0172 добавлена 6-словная запись и 193 правки адресных
  полей;
- штампы заменены: ВАР.12/77 → ВЕР.06/78,
  АРАП 10/75 → 04/78, редактор 10.04.76 → 20.06.78,
  машина 15.12.76 → 1.11.78.

ФАКТ. «Старшая редакция» 12/77 датирована РАНЬШЕ 06/78.
Высокие номера зон 0540-0577 суть физическое размещение
со сдвигом +0400 восьм., переключаемое смещением лент
6200 → 6600, а не признак более новой версии.

## 4c. Распределение по томам

ФАКТ (`analysis/V78-MEDIA.md`, 260 извлечённых зон, проверка md5):
из 33 зон 06/78 между томами различаются только 8:
0137, 0140, 0141, 0142, 0143, 0147, 0151, 0176.
Остальные 25 зон равны на 2048, 2148, 2248, 2348.
Пример: 0154 md5 `256a7bc6` на всех четырёх;
0147 `14a3e2bf` на 2048/2348 и `c414762c` на 2148/2248.

ФАКТ. md5 склейки 0137-0177: 2048/2348 `2f503f5b...`,
2148/2248 `90434226...`. Зоны 0140-0143 на 2148/2248
побайтно равны зонам 0540-0543 на 2048/2348.
В 0147 у 2148/2248 обнулены первые 3456 байт и убран
префикс `ИПМ`.

ФАКТ. Авторитетный источник 06/78: 2048 (каталог с датой
20.06.78) и побайтово равный ему 2348. Все 8 отличающихся
зон и комплект 0540-0577 берутся из этой пары.
На 2148/2248 второй копии нет, попадания 0115 суть листинг.
ГИПОТЕЗА: загрузчик 2148/2248 заимствован из области B2.
НЕ ИЗВЕСТНО смысл правок 0151/0176 и причина обнуления 0147.

## 4d. Синтаксис и цепочка строки (23.11.2026)

ФАКТ. Гипотеза «сбр/рзб делят строку на поля» снята
(356 forced-хитов, 72 динамических адреса, ни одного
разбиения). Уточнение: сбр/рзб нормализуют текст
`0x40 → 0x01` в цикле 076600.

ФАКТ. Контрольные колоды: ведущий пробел гасит METKA,
`:` объединяет метку и операцию, давая −2 ячейки ГС,
`;` против `,` не меняет PC,
7-значная метка принимается.

ФАКТ. Проверка маркеров 075353-075357: `aex` есть XOR
(dispak/arith.c:131), `076315 = be` ловит конец строки,
`076316 = bf` подчёркивание. `aex 76316` использует bf,
`aex 76315` использует be. Это НЕ классификатор
символов: буквы, цифры и разделители дают одинаковый
результат (`analysis/V78-MASK-BE-BF.md`).
Решение по METKA: 075377 utm 1(6), ветка 075357:
P1a ветку НЕ берёт, P1b уходит в 075364.

ФАКТ. Разрыв с писателем текста пула ЗАКРЫТ: Э70
`05755: *70 6612`, адрес `(uil.i_addr & 03700)<<4 =
072000` (extra.c:3577, memcpy 4076). `-tt` печатает
только store, поэтому Э70 в трассе не виден как запись.
Мост ДОКАЗАН: 012000 → барабан (u=12, z=0) → 072000,
данные 24/24 (`analysis/V78-POOL-TEXT-WRITER.md`,
`analysis/V78-RLE-DRUM-BRIDGE.md`). Оговорка: в 072000
доходит вывод канала 01675, а не 01413, чей вывод был
затёрт в буфере 012000. Цепочка: Э70 → 072000 → 06427
→ 06405 → 077320 → 06451 → 075353 → 06404 → 06061.
Автомат S0-S17 VERIFIED в `analysis/V78-TOKENIZER-FSM.md`,
сверен в `analysis/V78-FSM-VALIDATION.md`.

НЕ ИЗВЕСТНО: статического кода для 01675, 01433, 01715,
05756, 06007, 01574 в gold НЕТ (вне зон 0137-0177);
точная роль `0xbf`; причина затирания 01413 каналом 01675.

ВЕРДИКТ. Разбиения строки на 4 поля (МЕТКА / ОПЕРАЦИЯ /
ОПЕРАНД / КОММЕНТАРИЙ) НЕ НАЙДЕНО. Автомат S0-S17
описывает нормализацию и транспорт строки, а не её
лексический разбор. Критерий и активный план:
`docs/V78-SYNTAX-NEXT-PLAN.md`,
`analysis/V78-SYNTAX-FINAL-VERDICT.md` (вердикт НЕТ).
