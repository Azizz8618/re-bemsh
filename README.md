# re-bemsh

Реверс-инжиниринг транслятора языка ассемблера БЭСМ-6 (Монитор-80,
магнитный том 2348) и транслятора макроопределений МАКРО-БЕМШ / МВЕ60.

Проект создан на базе пустого репозитория
`git@github.com:Azizz8618/re-bemsh.git`.

## Цель

Восстановить структуру и исходные тексты:

1. транслятора с языка ассемблера БЕМШ, размещённого на томе 2348;
2. транслятора макроопределений МАКРОБЕМШ (МВЕ60), включая макроредактор
   и макромашину;
3. механизм вызова процедур МС «ДУБНА» из транслятора;
4. перечень и датировку версий транслятора.

## Инструменты

- `disbesm6` — дизассемблер БЭСМ-6 (6 байт/слово);
- `besmtool` — дамп зон с томов SIMH (8 байт/слово → 6 байт/слово);
- `dispak`, `dtran` — эмуляторы и трансляторы для проверки.

Подробный план: [docs/PLAN.md](docs/PLAN.md).

## Структура

| Каталог      | Назначение                                      |
|--------------|-------------------------------------------------|
| `docs/`      | планы, отчёты, таблицы версий и символов        |
| `dumps/`     | бинарные дампы зон (6 байт/слово)               |
| `asm/`       | дизассемблированные `.asm` и аннотации          |
| `sym/`       | таблицы символов                                |
| `tools/`     | вспомогательные скрипты извлечения и сверки     |
| `notes/`     | рабочие заметки по анализу                      |

> Файлы дампов и дисковые образы в репозиторий не коммитятся.
