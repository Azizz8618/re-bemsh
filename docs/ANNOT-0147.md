основная редакция `ВЕР.06/78`, зона `0147₈`.

## 1. Что аннотировано

`bemsh/annotated-MBE-Z0147-L1.asm` — копия
`dis/MBE-Z0147-L1.asm` с комментариями после запятой.
Шапка (18 строк) начинается с `*`. Числовые поля,
мнемоника, адреса и метки не менялись. Добавлено
1259 комментариев, каждый не длиннее 55 символов
(фактический максимум — 54).

В комментариях отмечено:

* границы процедур (начало/конец) и цели ветвлений;
* возвраты `пб (М15)` и `пб (М13)`;
* CALL-сайты `пв Axxxx(Мn)` (макрос `CALL → ВЖМ +
  ПАМ 0`, адрес возврата в М15);
* экстракоды `Э50 '105'`, `Э70 <адрес>`, `Э64`;
* текстовые и числовые `конд`-константы;
* неоднозначность «код или данные» (`* next insn
  used as data`, забелы `пам`);
* ячейки с известной по `analysis/VARIABLES.md`
  ролью (`CNT0..CNT6`, `FLAG0..FLAG3`, `WORKCNT`,
  `SUB04xx`, `SUB05xx`, `SUB0610`, `OUTBUF`).

Все роли и имена ячеек помечены `ГИПОТЕЗА` —
исходного текста транслятора на диске нет.

## 4. Верификация

Скрипт снимает комментарии (всё от первой пары
«пробел + запятая») и вставленную шапку, затем
сравнивает построчно с оригиналом:

```python
SRC = 'dis/MBE-Z0147-L1.asm'
ANN = 'bemsh/annotated-MBE-Z0147-L1.asm'
orig = open(SRC, encoding='utf-8').read().split('\n')
ann  = open(ANN, encoding='utf-8').read().split('\n')
si = next(i for i, l in enumerate(ann)
          if '\tСТАРТ\t' in l
          or l.rstrip().endswith("СТАРТ\t'0'"))
content = []
for i, l in enumerate(ann):
    if i < si and l.startswith('*'):
        continue                 # вставленная шапка
    content.append(l if i < si
                   else l.split(' ,', 1)[0])
diff = [(i + 1, a, b)
        for i, (a, b) in enumerate(zip(orig, content))
        if a != b]
print(len(orig), len(content), len(diff))
```

Результат: `1267 1267 0`, то есть **0 отличий**
(0_CONTENT_DIFFERENCES).
Дополнительно: 1259 комментариев, максимальная длина
комментария 54 символа (лимит 55), макс. длина
строки шапки 59 колонок (лимит 60).

В оригинале нет ни одной запятой, поэтому разделитель
«пробел + запятая» однозначен. Строки `* next insn
used as data` из `disbesm6` сохранены как есть.

## 5. Открытые вопросы

1. Роли процедур неизвестны; слова «утилита», «вывод»,
   «диспетчер» — гипотезы по шаблону вызовов.
2. Конец A00445 (0476) и A00534 (0607) не подтверждён
   `пб (Мn)`; нужна трассировка с `-R<N>=<адрес>`.
3. Области `0561–0607`, `1332–1344`, `1513+` — код
   или таблицы? Помечены как данные, где трассировка
   оборвана; статус гипотетический.
4. `конд п'АРХ..'`, `п'РЕДАК..'` правдоподобно текст
   GOST, но в список 25 надёжных констант
   `docs/TEXT-CONSTANTS.md` не входят.
5. STATIC-анализ не отслеживает значения регистров
   (`docs/REGISTERS.md` §4): `(Мn)` — поле команды,
   а не подтверждённое значение.
6. Имена `SUB04xx/SUB05xx` даны по шаблону
   `пв <адр>(М15)`; привязка к тексту не установлена.

Файлы репозитория, кроме двух указанных в задании,
не изменялись; эталонные образы не трогались.
