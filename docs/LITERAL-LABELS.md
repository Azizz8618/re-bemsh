# ГЛОБАЛЬНАЯ ТАБЛИЦА ЛИТЕРАЛ → МЕТКА

Сгенерировано `python3 tools/literal_labels.py`. Исходники `.be`, `gold/`, `dis/` НЕ изменяются.

> **Статус: аннотация, не ground truth.** Метки — компактные подсказки (≤6 символов, иначе `METKA>6`); роли из `GLOBAL.tab`/`SEMANTIC` — гипотезы без исходника транслятора. См. `docs/LABEL-MAP.md` §0.

## 1. Методика

1. Сканируются все 69 `bemsh/*.be`. Извлекаются кавычные восьмеричные операнды **без буквенного префикса** — `В'...'` (48-битные слова), `П'...'`/`Х'...'` (текст) не трогаются.
2. Строки комментариев (`*`) и хвост после первой запятой отсекаются.
3. Классификация по мнемонике, зоне и значению: `ADDRESS` (операнд — адрес/цель перехода), `CONSTANT` (экстракод `Э50 '105'`, маска `СДА 64-6`, immediate `РЖА '3'`, слово данных, определение `ЭКВ`), `AMBIGUOUS` (контекст не определяет роль).
4. Метка: curated-адрес → `GLOBAL.tab` → `SEMANTIC/Z*.md` → префикс зоны+класс мнемоники + значение. Суффикс — последние цифры восьмеричного адреса; полное значение — в `ALL_LABELS.tab`. Коллизии разрешаются детерминированно.
5. Применение: `<МНЕМ> AM4235(М2)` + строка `AM4235 ЭКВ '4235'`, вставляемая после строки `М`. `ЭКВ` не порождает слово → байтовая идентичность сохраняется.
6. Если подстановка удлиняет строку до 80 символов, транслятор выдаёт `ОПЕРАЦИИ НЕТ` (`docs/RAW-RECOVERY.md`). `--apply-zone` сокращает только комментарий после первой запятой до ≤78 символов; кодовая часть строки не трогается.

## 5. Честные оговорки

1. Метки компактны и нужны только для чтения листинга; они **не** доказательство роли. `ПОДТВЕРЖДЕНО` здесь означает флаг из `GLOBAL.tab`/`ЭКВ`-определения, а не исходник транслятора.
2. `A#####`/`D#####` и адреса `GLOBAL.tab` — zone-local (`LABEL-MAP.md` §0.1): одно и то же число в зонах 0055 и 0147 — разные ячейки. Поэтому role-имя применяется только к глобальным адресам ≥ `02000₈`; для остальных используется context-префикс зоны.
3. Экстракоды (`Э50 '105'`, `Э52 …`, …) и маски помечены `CONSTANT` и **не** переименовываются. `'25252'`/`'72525'` в зонах таблиц ошибок — шахматная заливка, а не адрес (`GLOBAL-XREF.md` §3.1).
4. `AMBIGUOUS` получает метку с confidence `ГИПОТЕЗА`; перед массовым применением такую строку стоит проверить вручную.
5. Обязательная проверка после `--apply-zone`: `bash tools/rebuild-zone.sh <zone> <MODE>` → `1024/1024`, `0 различий`.
