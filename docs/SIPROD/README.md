| файл | содержание |
|---|---|
| `01-obzor.red` | объект, зоны 0055–0060 / 0137–0177 / 0540–0577, версии, штампы, источники |

## Как запускать

Обвязка строит задание Диспака по образцу `SIPROD.md` §1; `run.sh`
берёт на вход только текст после `*EXECUTE`. Поэтому в файлах лежит
только блок `*RED … *E`, а терминатор входного потока `*END` добавляет
обвязка (`run.sh` сам дописывает лишь карту монитора `*end file`):

```sh
cd ~/Yandex.Disk/re-siprod
for f in ~/Yandex.Disk/re-bemsh/docs/SIPROD/*.red; do
  { cat "$f"; echo '*END'; } | tests/siprod/run.sh -
done
```

Один файл:

```sh
{ cat ~/Yandex.Disk/re-bemsh/docs/SIPROD/01-obzor.red; echo '*END'; } \
  | ~/Yandex.Disk/re-siprod/tests/siprod/run.sh -
```

Результат печатается на АЦПУ (128 позиций, две страницы по 64 на
листе). Для полного задания с шапкой и загрузкой библиотеки смотрите
`tests/siprod/run.sh -h` и `SIPROD.md` §1.

## Правила набора

* Значимы позиции 1–72 перфокарты; в файлах не более 60,
  фактический максимум — 52 символа.
* Весь текст прописной; буква с двумя точками и табуляция не
  встречаются. Латинские и
  русские омоглифы (`А/А`, `С/C` и т. п.) имеют в БЭСМ-6 один код,
  поэтому написание омоглиф-безопасно.
* Имена макрокоманд сохранены в OCR-написании (`GВLА`, `SЕТА`, `АIF`,
  `АNОР`, `DК`, `МNОТЕ`) как в `docs/MACRO-COMMANDS.md`.
* `∧` — знак формальных параметров, `↑` — принятый в проекте знак
  возведения в степень (вместо `^` из AGENTS.md, §0.4).
* Ключи командной строки (`--start`, `-e`, `-R3`) оставлены строчными
  намеренно: это буквальный синтаксис вызова; при вводе в СИПРОД
  строчные буквы всё равно превращаются в прописные (`SIPROD.md` §2.1).

## Использованная разметка

Из документированных последовательностей `SIPROD.md` §3–4 применены только:

| последовательность | назначение |
|---|---|
| `*RG` | рамка вокруг страниц (на первой карте блока) |
| `*0STP…` | строка под номером страницы на каждой странице |
| `*T…` | центрированный заголовок + две пустые строки |
| `*MD…` | центрированный подзаголовок |
| `*S…` | новый абзац с отступом |
| `*/…` | принудительный перевод строки (для списков команд и зон) |
| `*E` | конец текста `*RED` |

Таблицы (`*ST`/`*SL`), листинги (`*MF`), макросы `*M=`, форматы
`*STA`/`*MCP`, нумерация `*N` и позиционирование `*G`/`*RF` **не
использованы**: документ набран как обычный текст с заголовками, чтобы
не зависеть от неоднозначных режимов. Режим набора — обычный (56 позиций
в поле), выравнивание по словам — по умолчанию.

  доходят до АЦПУ без искажений.

## Оговорки

* Семантика макрокоманд выведена из *использования* в `macros.be` и из
  синтаксиса листингов, а не из дизассемблированного кода транслятора;
  `macros.be` — не исходник транслятора (`docs/MACRO-COMMANDS.md` §5).
* Принадлежность зон `0154` (макроредактор) и `0170` (макромашина)
  установлена исключительно по текстовым штаммам; исполняемый код в
  этих зонах разрежен. Логические адреса листинга не являются
  физическими якорями (`docs/FINAL-REPORT.md` §5, п. 2–3).
* Экземпляры эталонных образов томов не изменялись: чтение и опыты
  велись через `besmtool`/`dispak` на временных копиях в `/tmp`.
* В репозитории изменены только шесть файлов этого каталога; коммит и
  push не выполнялись (AGENTS.md, §0.6).
