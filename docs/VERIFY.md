# Фаза 5 — побайтовая верификация

## Что проверяем

Эталонный образ `/usr/local/share/besm6/2348` доступен только для чтения.
Верификация строится по принципу re-dispak (`verify.pl`, пары `G`/`S`):
эталон — дамп зоны, полученный **непосредственно** `besmtool dump`, проверка —
сохранённый дамп в `gold/`. Ожидается **ноль отличий** по всем 69 зонам.

Ключевое требование — независимость путей извлечения: `gold/` создаётся
через `tools/disbesm_extract.sh` (восьмеричные номера зон), а проверка —
через прямой `besmtool dump ... --start=<десятичное>` в
`tools/verify-roundtrip.sh`. Это позволяет поймать ошибку номеров зон
(в том числе исторический баг хелпера с `printf '%d' "0${ZONE}"`).

## Команды

```bash
cd /tmp/.private/azizz/re-bemsh
make verify                       # = bash tools/verify-roundtrip.sh
# или вручную для одной зоны:
BESM6_PATH=/usr/local/share/besm6 \
  besmtool dump 2348 --start=95 --length=1 --to-file=/tmp/rt137.bin
bash tools/disbesm_verify.sh /tmp/rt137.bin gold/MBE-Z0137-L1.bin \
  | sed -r 's/\x1B\[[0-9;]*m//g'
```

`disbesm_verify.sh` печатает `✓ Файлы идентичны (2000 слов)` при успехе;
при различии — `зона.слово: эталон → проверка` (восьмеричные) и, с `--disasm`,
дифф дизассемблированных зон. ANSI-цвета срезаются `sed`, иначе в отчёт
попадут escape-последовательности.

## Результат

Полный лог — `verify/report.md` (генерируется скриптом). Критерий успеха —
`=== roundtrip FAIL=0 ===` и 69 записей «Файлы идентичны».

## Ограничение

Побайтовая сверка подтверждает только корректность **извлечения**, а не
правильность аннотирования: комментарии в `.asm` меняются без изменения
байтов. После появления реконструированных `.be` (`bemsh/`) можно будет
добавить обратную сборку: `silver` (собранный модуль) сравнивается с `gold`
(эталон с тома), как в `monitor80-re` (`.orig`/`.dis`/`.diff`).
