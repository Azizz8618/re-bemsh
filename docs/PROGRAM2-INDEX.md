## Ключевые факты

**Тексты** (`PROGRAM2-TEXTS.md`): GOST-8 identity (5/5 штампов), 6-бит TEXT = ASCII−0x20, KOI-7 = таблица мнемоник `0137.0057–0121`. Прямых адресных ссылок на сообщения в xref нет — текст лежит как `конд`, адрес передаётся через OUT_PRINT/регистр; из 86 текстов 20 имеют ссылки, из них только 3 с метками `D#####` (средняя уверенность), остальные 17 — кандидаты по абсолютному адресу.

**Регистры** (`PROGRAM2-REGISTERS.md`): **значения сняты динамически** через `dispak`:
- `-tt` печатает `r[N]=value`; `v` + breakpoint печатает все 15 регистров; `i N -` читает один;
-入口 `02000₈` (макроредактор, 2 попадания): M15=77772/00000, M16=00001, M13=77711/24276;
- print routine `01322₈` (29 попаданий): M15=04000, M16=01221/74002/74003, M17=00001;
- M17 = `77000…77052` (upper memory) и совпадает с `STACKREG=017₈` (`defs.h:61`) — стековость подтверждена;
- M15 link/return, M16 dual link/counter, M13 link/counter — подтверждено статически и динамически;
- ловушка: M5/M12 — псевдо-регистры из fill `AA/55`, не регистры.

**Логика** (`PROGRAM2-LOGIC.md`): макроредактор `0154` → макромашина `0170/0165/0171` → АРАП `0152`; таблица макроопределений +2 ячейки ГС на простой макрос, +4 с `LСLА/SЕТА/АIF`; 46 объектных слов побайтово одинаковы с макросами и без — таблица не попадает в объектный модуль; дескрипторы `0165.0367` (69 слов) и `0170.0003` (53 слова); трассировка `CALL PRINT8 → ВЖМ → ПБ (М15)`.

## Инструменты

- `make check-all` — агрегатная проверка.

## Честно не известное

1. Исходника транслятора на дисках нет (есть только макробиблиотека `macros.be`).
2. Передача управления между проходами не наблюдалась напрямую; карта память↔диск покрывает 12 из 33 зон.
3. Смысл 17 из 20 процедур — гипотезы; только `0176:1354` подтверждено.
4. Биты ячеек ГС не прочитаны; VJM через M13 не проверен.
