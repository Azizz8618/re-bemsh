```

0000.0450:  0144-0144 ГП 'РВС' ДЛЯ Б Е М Ш'А
```

нечитаем; наличие транслятора подтверждается только штампами в самих зонах.

Были дополнительно проверены все 11 копий тома 2048 за пределами
`/usr/local/share/besm6`. Результат: **транслятор есть во всех**, в тех же

Эти же md5 получаются и для зон 2348 — копии 2048/2348 взаимозаменяемы как

## 6. Вывод

1. Третьей версии транслятора на томах 2048/2148/2248 **нет**: везде
   `ВЕР.06/78` (20.06.78 / 1.11.78 / АРАП 04/78); вторая редакция `ВАР.12/77`
   есть только на 2048 в зонах `0537–0577` (данные с 0540).
2. `2148` и `2248` несут только основную версию; на 2248 дополнительно
   сохранён листинг программы, оттранслированной транслятором.
3. Для дизассемблирования достаточно эталона 2348 или 2048 — зоны идентичны.

## 7. Побайтовая сверка 2048 ↔ 2148/2248 (дополнительно)

Склейка ровно 33 зон `0137–0177` (202752 байт) даёт:

```
2048: md5 2f503f5b8f8fb6ad12632fed6f8cf17f
2148: md5 90434226c98df1c40bbb8d76e1560613
2248: md5 90434226c98df1c40bbb8d76e1560613
```

То есть 2148 и 2248 идентичны друг другу, но **не совпадают с 2048**.
Поразовое сравнение:

| Зоны | Отличий | Что это |
|---|---|---|
| `0137–0143` (5 зон) | ~5300 байт/зона | загрузчик/настройка адресов: в 2148/2248 первое слово `070707070720`, в 2048 `000004000000`; `disbesm6` даёт «зп '3407' / Э60 '73407'» против «зп '70000' / сбр» |
| `0144–0146`, `0150`, `0152–0157`, `0160–0175`, `0177` | **0** | код транслятора побайтовно совпадает |
| `0147` | 1977 байт | тексты сообщений: в 2148/2248 префикс `ИПМ` отсутствует |
| `0151` | 3 байт | мелкая правка |
| `0176` | 1 байт | мелкая правка |

**Вывод:** ядро транслятора VER.06/78 одинаково на всех трёх томах; разница
сводится к зонам загрузки `0137–0143` (другая настройка/паспорт тома) и к
нескольким байтам текстовых таблиц. Это **не третья версия**, а другая
установка той же редакции — при сравнении версий учитывать только зоны
`0144–0177`.
