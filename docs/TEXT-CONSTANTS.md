## 2. Механика `п'...'` в disbesm6

Из `/home/azizz/dispak/disbesm6/disbesm6.c`:

```c
int is_good_gost(int s)                 /* ст. 531 */
{
    return (s < 020) || (s >= 040 && s <= 0115);
}
...
if (flags & W_GOST || good_gost) {      /* ст. 553 */
    printf("п'");
    for (i = 0; i < 6; ++i)
        if (bytes[i] < 0140) gost_putc(bytes[i], stdout);
        else printf("'%03o'", bytes[i]);
} else printf("в'%016llo'\n", memory[addr]);
```

`is_good_gost` = байт в `0x00–0x0F` **или** `0x20–0x4D`.
`gost_putc` (таблица `gost10859.h`) отображает:

| Байт | Глиф | Пример |
|---|---|---|
| `0x00–0x09` | `0..9` | `00` → `0` |
| `0x0A–0x0F` | `+ - / , . пробел` | `0F` → пробел |
| `0x20–0x3E` | `А..Я` | `28` → `И` |
| `0x3F–0x4D` | `D F G I J L N Q R S U V W Z ^` | `40` → `F` |
| `0x10–0x1F`, `≥0x4E` | — | слово печатается `в'...'` |

**Отсюда `п'F00900'`** (напр. `0140.0044`, байты
`40 00 00 09 00 00`): `0x40` — это GOST-буква `F`, `0x09` —
цифра `9`, нули — цифры `0`. Это машинное слово
`2000000002200000₈`, а не текст: все 6 байт просто попали в
"хороший" диапазон.

### Правило «текст или число»

1. `п'` **не доказывает** текст — только то, что байты прошли
   `is_good_gost` (или выставлен `W_GOST`).
2. Текст = **ряд из ≥3 соседних слов** с кириллицей, пробелами
   (`0F`) и осмысленными русскими словами, плюс подтверждение
   `besmtool search '<фраза>'` → `зона.слово`.
3. Число = одиночное `п'0xxxx'`, ведущие нули от нулевых байт,
   одиночные латинские `F/N/R/…`, соседство с `пам`/`nop`,
   отсутствие поискового попадания.
4. Байт в `0x10–0x1F` или `≥0x4E` → печать `в'%016llo'`:
   GOST-строкой это слово точно не является (может быть кодом
   или текстом в другой кодировке).

## 6. Структурные таблицы

### 6.1 Таблица мнемоник в KOI-7 (зона `0137` / `0540`)

Из колонки KOI-7 `besmtool view ... --encoding=g,k,t,i`:

Фрагмент колонки KOI-7 (индексы 26:38 строки view, дословно):

```
0137.0060:  ЗПM ``CЧM ``      ~ ЗП, СЧ
0137.0062:  CЛ  ``BЧ  ``      ~ СЛ, ВЧ
0137.0100:  CДA ``PЖA ``      ~ СДА, РЖА
0137.0102:  YИ  ` YИM `!      ~ УИ, УИМ
0137.0110:  Э50 `(MOДA``      ~ Э50, МОДА
0137.0120:  ПB  ``ЦИKЛ``      ~ ПВ, ЦИКЛ
```

`~` = чтение KOI-7 с омоглифами (`C`, `B`, `K`, `Y`, `O`
вместо `С`, `В`, `К`, `У`, `О`) — не все мнемоники проверены
по листингу, поэтому помечены как гипотеза. В GOST-колонке те же
слова — мусор (`  ‾А41`, `J ААe4`, …). Ср. `ANCHORS.md` §2
(`0137.0050–0120`).
B2-копия зоны `0540` содержит ту же таблицу со сдвигом;
её GOST-колонка также нечитаема — признак KOI-7 кодировки.

### 6.2 Числовой пример (НЕ текст)

`0140.0044` = `2000000002200000₈`, байты `40 00 00 09 00 00`
→ `disbesm6` печатает `конд п'F00900'`. Ошибочно принять за
текст; см. §2. Аналоги (`0147.1313` `п'9003Р1'`,
`0170.0165` `п'И00000'`) — тоже данные.

### 6.3 Неопределённые (`НЕОПР`)

Ряды вида `0173.1475 АР009А0Р009АА...`, `0176.0125 К8FV/С/-Х900`,
`0170.1653 2А10+G2А20+I`, `0152.0053 4,Э7ZЦ9007ZШ9007ZЫ` —
смешанные байты (числа + мусорные глифы). Достоверно не
декодируются; в константы не включены. Могут быть таблицами
экстракодов/адресов, но доказательства нет.

## 7. Воспроизведение

```bash
cd /tmp/.private/azizz/re-bemsh

# 1) search — физические якоря (GOST)
besmtool search 2348 'ИПМ МАКРО-БЕМШ'
besmtool search 2348 'АРАП ВАР'
besmtool search 2348 'МАКРОРЕДАКТОР'
besmtool search 2348 'МАКРОМАШИНА'
besmtool search 2348 'ОШ.СПР.НА БЕМШ1'
besmtool search 2348 'ИПМ МАГ-БЕМШ'
besmtool search 2348 'ОШ. СПРАВКИ БЕМШ2'

# 2) 4 кодировки; строка = 2 слова (чётное, нечётное)
besmtool view 2348 --start=0147 --length=1 \
  --encoding=g,k,t,i | grep '^0147.1314:'
besmtool view 2348 --start=0152 --length=1 \
  --encoding=g,k,t,i | grep '^0152.1164:'
besmtool view 2348 --start=0170 --length=1 \
  --encoding=g,k,t,i | grep '^0170.0216:'
besmtool view 2348 --start=0137 --length=1 \
  --encoding=g,k,t,i | grep '^0137.0060:'   # KOI-7 мнемоники

# 3) hex-байты конкретного слова (1315₈ = 717dec, *6 = 4302)
besmtool dump 2348 --start=0147 --length=1 \
  --to-file=/tmp/z0147.bin >/dev/null
xxd -s $((8#1315*6)) -l 6 /tmp/z0147.bin   # 282f 2c0f 2c20

# 4) как то же слово печатает disbesm6
disbesm6 -a0 -e0 gold/MBE-Z0147-L1.bin \
  | grep '^ *1315 '   # конд п'ИПМ МА'

# 5) разбор всех констант (только чтение)
python3 - <<'PY'
import glob,re
p=re.compile(r"^\s*(\d+)\s+([0-7]{16})\s+.*\sконд\s+п'(.*?)'")
c=re.compile('[А-Яа-я]')
for f in sorted(glob.glob('dis/MBE-*.asm')+glob.glob('dis/MBE2-*.asm')):
    for ln in open(f,encoding='utf-8'):
        m=p.match(ln)
        if m and c.search(m.group(3)):
            print(f, m.group(1), m.group(3))
PY
```

Замечание: `besmtool --start` — `strtol(base=0)`, поэтому
`--start=0147` (восьм.) == `--start=103` (дес.). В `-a/-e`
disbesm6 адреса восьмеричные только слитно.
