# Процедуры B2 (0540–0577₈): границы и смысл

Дата: 20.11.2026. Образ 2348 (read-only). Каталог
построен по реальному скану форсированных листингов
всех 32 зон B2. Файлы gold/, dis/, bemsh/,
analysis/, docs/SEMANTIC/* НЕ изменялись.
Выходной файл — только настоящий.

## 1. МЕТОДОЛОГИЯ

1. Для каждой зоны взят форсированный листинг
   Z<zone>-force.asm (disbesm6 -a0 -e0 -n<allcode.tab>):
   все 1024 слова помечены W_CODE, поэтому обрыв на
   первом пб (Мn) устранён и видны CALL/RET за обрывом.
2. Базовый листинг dis/MBE2-Z<zone>-L1.asm даёт метки
   A#####/D##### и забелы конд/пам (границы данных).
3. Вход = цель пв/вжм (CALL) с адресом внутри зоны
   0…1777₈. Внезонные цели 'NNNNN' — внешние CALL,
   в число входов не идут (XREF-METHODOLOGY §3).
4. Выход = первое пб (Мn) не позже забела данных;
   иначе пб <адрес>, стоп/Э74, забел или след. цель.
5. Размер = end-start+1 слов. Адреса локальны для -a0.
   Регистры — счётчик полей (Мn) в диапазоне.
6. Смысл — из SEMANTIC/, LABELS-B2.md, шаблона CALL
   и B↔B2-соответствия. Без исходника бизнес-смысл
   остаётся ГИПОТЕЗОЙ.
7. ПОДТВЕРЖДЕНО — только пара CALL + косвенный RET
   и роль из role-таблицы; остальное — ГИПОТЕЗА.

### Оговорка

disbesm6 не отслеживает регистры; (М15) как link
возврата подтверждён парой пв …(М15) → пб (М15),
но цель косвенного пб (Мn) статически не разрешается.
Часть границ оценочная.

слов не привязываются к адресу), поэтому каталог
построен автономным сканером proc_b2_scan.py.

### 6.1 Процедуры 0147 ↔ 0547

В B после слова 2 вставлены Э50 '105', пе, сч, пб;
в B2 вставки нет. Локальный сдвиг меток −5₈ в начале
зоны и −7₈ к концу (две вставки). Сами адреса:

```

----------  ----------  ------ ----------------

0445-0476   0440-0454   -5    утилита, эпилог
0477-0512   0472-0505   -5    OUT_PRINT, 10 CALL
0513-0520   0506-0513   -5    утилита D707/D714
0521-0526   0514-0521   -5    утилита D714

0615-0625   0606-0616   -7    утилита М16

```

Другие пары: 0151:1322/1345 ↔ 0551:1322/1345
(класс C, s=0); 0145:1322 ↔ 0545:1322 (S, +18);

в B Э74, в B2 Э72 '7657' с кодом 1364-1367

## 7. НЕИЗВЕСТНЫЕ ПРОЦЕДУРЫ

1. Роль 11 блоков 0547 (1426–1735), найденных только
   в force-листинге: CALL/RET есть, смысл нет.
2. ZONE_ENTRY: вход задан -e0, а не найден CALL;
   граница по первому RET — оценочная.
3. 0553, 0574, 0556 — роль неизвестна, код смешан
   с данными/повторами.
4. 0572 — CALL через М4/М6/М11/М17, не М15; ссылки
   link-регистров не доказаны.
5. 0565 — 151 внешний CALL '5013'; где лежит
   подпрограмма, не установлено.
6. FILL-зоны и текстовые таблицы (0573, 0577)
   процедур не содержат; их ZONE_ENTRY не включены.
7. CALL-цели 0552:1322/1345/…, 0571, 0573, 0577
   у входа дают W0000 (нули/таблица) — по образцу
   procedures.md §4.3 это ложные цели — таблицы, а
   не исполняемые процедуры; границы оценочные.
