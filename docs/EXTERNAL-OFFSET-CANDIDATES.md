# Кандидаты на внешние смещения (External Offset Candidates)

Дата: 20.11.2026. Репозиторий: `re-bemsh`. Объект: 32 подозрительные ЭКВ-метки из семейств `AM*`, `B*`, `BR*`.

**Расхождение в задании.** В инструкции сказано «30 меток», но перечислено 32. Проанализированы все 32 перечисленные метки; таблица ниже содержит 32 строки.

Инструмент: `python3 tools/external_offset_scan.py` (`--labels FILE`, `--json`). Тесты: `python3 -m unittest tools.tests.test_external_offset_scan -v` (13 тестов, все проходят).

## 1. Методика

1. Сканируются **все** `bemsh/*.be` (33 зоны: ASM 0055–0060, B 0137–0177, B2 0540–0577). Зона берётся из имени файла (`MBE-Z0137.be` → `0137`).
2. Определение: строка вида `AM10 ЭКВ '10'` даёт (зона, строка, восьмеричное значение). Все 32 метки определены в нескольких зонах с одинаковым значением.
3. Использование: строка кода `МНЕМОНИКА ОПЕРАНД , комментарий`. Имя ищется только в операнде (до запятой), с границами слова, поэтому `B211` не путается с `B2112`.
4. **Критическая проверка.** Значение ЭКВ трактуется как адрес внутри зоны (`'11'` → `0011₈`). По `docs/PROCEDURES-*.md` загружается каталог входов процедур (статусы `ОСН`/`ВЛОЖ` = известный вход, `ДАН` = отвергнутая цель). Если цель ветвления попадает на известный вход **той же зоны** → `LOCAL_ADDR`. Если известного входа нет → `EXTERNAL_OFFSET_CANDIDATE`.
5. target-like = мнемоника из `{ПВ, ПВО, ВЖМ, ПО, ПЕ, ЦИКЛ, ПБ, ПИО, ПИНО, ВЫПР}` **или** комментарий содержит `(переход)` / `(вызов)`. Второе — эвристическая аннотация самого `.be`, она помечена ниже †.
6. Пары: (A) метка в строке N, а в N+1..N+3 — маленькая константа или ветвление; (B) `ПВ`/`ПБ ...(Мn)`, а в предыдущих 1–3 строках регистр `Мn` загружен другой маленькой константой.

**Снимок.** Номера строк ниже соответствуют состоянию `bemsh/*.be`
на момент повторного сканирования 20.11.2026. Другие агенты могут
параллельно править `.be`; для проверки конкретной строки
используйте `--json` и текущий файл.

**Ограничения (важно).** Каталог процедур сам помечен `ГИПОТЕЗА` в `docs/PROCEDURES-*.md`; отсутствие входа — слабое доказательство. Аннотации `(переход)`/`(ячейка)`/`(адрес)` в `.be` порождены эвристикой по имени метки (`BR*` → переход, `B*` → ячейка), а не независимым анализом. `ПБ ... , возврат ... через Мn` может быть возвратом, а не внешним вызовом. Все вердикты — **кандидаты/гипотезы**, не доказанные адреса.

## 6. Наблюдаемые пары

**(A) Последовательная пара «константа + ветвление» (факты; интерпретация как offset — гипотеза).**

- `bemsh/ASM-Z0060.be:1685` `И    B2113(М1)  , И с B2113`
