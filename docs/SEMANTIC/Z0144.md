# СЕМАНТИКА ЗОНЫ 0144₈ (ядро: обработчик + пул диагностики)

Основа: bemsh/MBE-Z0144.be, dis/MBE-Z0144-L1.asm,
gold/MBE-Z0144-L1.bin (1024 слова). Образ read-only
/usr/local/share/besm6/2348. evidence: `144:N` =
dis/MBE-Z0144-L1.asm:N; `F:<a>` = принудительный
дизассембль
`disbesm6 -a0 -e0 -n<allcode.tab> gold/MBE-Z0144-L1.bin`,
`<a>` — физическое слово зоны (восьм.); `TC` =
docs/TEXT-CONSTANTS.md; `XR` = analysis/CROSSREF.md;
`REG` = docs/REGISTERS.md. Адреса восьмеричные.

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: ОБРАБОТЧИК ТАБЛИЦ/СООБЩЕНИЙ ядра МАКРО-БЕМШ:
в младшей части зоны (примерно 0001-0177) — связный
исполняемый цикл, в старшей — пул диагностических
текстов GOST и числовые таблицы. Зона побайтово
идентична 0544 [VER:86; class I].

EVIDENCE:
- принудительное кодирование (`-n`, все 1024 адреса
  W_CODE) вскрыло связную программу: слова 0001-0140
  содержат пары осмысленных команд с регистрами
  М1/М2/М3/М5/М11/М12, ветвлениями `по/пе/пб` и
  вызовами `пв '40130'(М11)`, `пв '40207'(М11)`,
  `пв '40253'(М5)` [F:0001-F:0140];
- исходный `-a0 -e0` листинг остановился на слове 0:
  трасса оборвалась, потому что достижимость `disbesm6`
  не переходит через `пб` (DC §10) — отсюда 962 `конд`
  и ошибочная пометка «одно код-слово» [144:7-9;
  XR:65];
- 7 GOST-якорей `besmtool search` подтверждают тексты
  сообщений [144:197-205,212-217,343-345,631-644,
  777-779,997-1000; TC].

_confidence_: ПОДТВЕРЖДЕНО (по словам: пары команд,
вызовы, GOST-search, идентичность 0544). Бизнес-смысл
программы («обработка таблицы меток/адресов») —
ГИПОТЕЗА по операндам; исходника транслятора нет.

## 7. НЕИЗВЕСТНОЕ

1. Точный конец кодового блока: после F:0140
   forced-листинг переходит в область `пам`/таблиц;
   граница 0177 — оценка, не доказательство.
2. Смысл CALL-целей 40130/40207/40253: это ядро
   (0147)? адреса логические (REG §4); привязка
   без трассировки `-R<N>` не установлена.
3. Что такое «КОР КОМ», «ИКОП», «ПФГП», «ЗОНГП» —
   сокращения паспорта/ОС без исходника не ясны.
4. Природа таблиц 0200-0274 (24000,24200,…) и
   0440-0466 (`20200000…`) — коды/константы.
5. Почему 0144 и 0544 идентичны, а 0143/0543
   различны [VER §6].
6. Все интерпретации «что обрабатывает цикл» —
   ГИПОТЕЗА по мнемоникам, не по тексту программы.
