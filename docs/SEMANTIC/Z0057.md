# СЕМАНТИКА ЗОНЫ 0057₈ (АСМ ИТМ, ИСПОЛНЯЕМЫЙ МОДУЛЬ)

Основа: bemsh/ASM-Z0057.be, dis/ASM-Z0057-L1.asm,
dis/ASM-Z0057-full.asm (принудительный W_CODE),
gold/ASM-Z0057-L1.bin (1024 слова). Образ — read-only
/usr/local/share/besm6/2348. evidence: `057:N` =
dis/ASM-Z0057-L1.asm:N; `F:N` = dis/ASM-Z0057-full.asm:N;
`be:N` = bemsh/ASM-Z0057.be:N; `PLAN:N` = docs/PLAN.md:N;

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: зона `ТРАНСЛЯТОР С А/К И Т М` (автокод ИТМ,
`.75`), каталог `0000.0204` — НЕ БЕМШ [PLAN:18;
FINAL-REPORT:19]. Это ИСПОЛНЯЕМЫЙ МОДУЛЬ, а не
«5 код-слов + 992 табличных `конд`», как требовали
be:5-6 и прежняя версия этого файла.

ИСПРАВЛЕНИЕ ОШИБКИ (главное):
- принудительный W_CODE на все адреса даёт 0 `конд`,
  0 `пам`, ~1990 строк команд [F; ASM-CODE-RECOVERY
  §2.3; GUIDE §1]; 2046/2048 = 99.90% 24-битных
  половин получают имя из `siprod_asm.OPS` [ASM;
  ASM-CODE-RECOVERY §2.4]. Только 2 половины слова
  1341 не имеют opcode [057:748];
- L1-трасса оборвалась после слова 4 (`пб '4012'`
  уводит из зоны) и на индексном поле `(М3)` в CALL;
  слова 5+ были помечены `конд`/`пам` — это дефект
  статической классификации, а не данные [057:16-17;
  GUIDE §3]. Нули 0425/0660/1005/1277/1323 —
  паддинг внутри кода, а не «таблицы»;
- слово 5 при W_CODE — `сч D00722; нтж D00255`
  [F:23-24; 057:17], настоящая команда, а не `конд`.

EVIDENCE программного смысла:
- `сч '4057'; пв '3604'(М3)` — CALL с индексом М3;
  возврат пишется в М15 [057:8-9; F:8-10; GUIDE §5];
- `зп D00172`, `сч D00173` — работа с ячейками,
  которые сами содержат команды [057:11-13; F:12-16];
- `Э64 '3627'` — экстракод ИТМ (ADDREX) [057:14];
- ~250 пар `сч 'NNNN'; пб '3762'` — векторная
  диспетчеризация, выполненная КОДОМ [057:23+; F:22+];
- `пб '4012'` — общий выход зоны [057:13,16].

_confidence_: ПОДТВЕРЖДЕНО (каталог, 99.90% opcode,
0 `конд` при W_CODE, код слова 5, пары CALL/выход);
ГИПОТЕЗА («диспетчеризация» и смысл адресов ИТМ).

другой выборки; здесь 99.9% слов — исполнимый код,
поэтому `(М5)`/`(М12)` [F] — индексы команд, не шум.

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

Блок A — стартовый шлюз 0000-0005. ВХОД: START.
ВЫХОД: D00172 / '4012'.

```
0000 сч '4057'; пв '3604'(М3)
  загрузить адрес 4057₈ и CALL на 3604₈+М3;
  пв запоминает возврат в М15 — обычный вызов
  подпрограммы ИТМ [057:8-9; F:8-10; GUIDE §5].
0001 сч START; зп D00172
  обнулить сумматор и записать в D00172, где
  лежит команда `сч D00720` — установка/правка
  параметра или самой команды [057:10-11; F:12-13].
0002 сч D00173; по '4012'
  прочитать слово-команду `зп D00720` как число;
  по — проверка признака, уход на общий выход
  [057:12-13; F:15-16].
0003 Э64 '3627'; зп START
  экстракод 064 (ADDREX), аргумент 3627₈ —
  системная операция ИТМ (ГИПОТЕЗА); затем сброс
  [057:14; ASM; GUIDE §5].
0004 сч START; пб '4012'
  безусловный уход на ту же цель 4012 — второй
  выход; именно он оборвал трассу L1 [057:15-16].
0005 сч D00722; нтж D00255
  первая команда «за обрывом»: адрес D00722 и
  операция НТЖ над D00255 — начало основной
  программы, НЕ таблица [057:17; F:23-24].
```

Блок B — основная программа 0006-1543. ВХОД: 0005.
ВЫХОДЫ: '4012', '3762', '4267', '4126'.

```
0006-0012 по/пб/мод с D00246, D00255, D00707
  цепочка условных переходов и настройки адреса;
  `мод D00707` готовит индексную базу [057:18-24].
0013-0171 сч '4064'..'4100'; пб '3762'
  ~250 пар «аргумент + переход к общему обработчику»
  — EXECUTABLE vector table; каждая пара — мини-
  процедура, а не константа [057:23-131; F:22+].
0172-0255 зп/сч D00172/173, сдвиг уиа, пб '3564'
  чтение и правка ячеек-команд, работа с индексами
  [057:134-135; 254-255; F:322-325].
1341 2 illegal-половины — единственный не-код
  фрагмент; причина не установлена [057:748].
```
Хвост 1544-1777 декодируется как команды, но
назначение не доказано: оставить ГИПОТЕЗОЙ, не
называть «таблицей».

Дополнение (текстовые константы): Диагностический текст 1335–1346 — данные; точное прочтение
не всех слов требует исходника ИТМ [Z0057 §7].
