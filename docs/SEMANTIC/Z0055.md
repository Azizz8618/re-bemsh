# СЕМАНТИКА ЗОНЫ 0055₈ (АСМ ИТМ, исполнительный модуль)

Основа: gold/ASM-Z0055-L1.bin (1024 слова, read-only),
dis/ASM-Z0055-L1.asm (трасса disbesm6, оборвана),
bemsh/ASM-Z0055.be (реконструкция; разметка КОНД и
шапка «БЕМШ» в ней ошибочны). Полный линейный листинг:
besm6tape.py dis gold/ASM-Z0055-L1.bin --start 0
--count 1024 --bemsh  →  t55:N (временно:
/tmp/.private/azizz/opencode/z55z56/tape-0055.txt).
Тот же текст: disbesm6 -a0 -e0 -n<tab из 1024 записей
типа 2> → 2179 строк, 0 `конд` (проверено; файлы
репозитория не менялись). `055:N` =
dis/ASM-Z0055-L1.asm:N; `t55:NNNN` = слово NNNN
(восьм.) зоны в полном листинге;
`view 0055.N` = besmtool view 2348 --start=0055
--length=1 --encoding=g,k,t,i (read-only; строка N
показывает слова N и N+1). `PLAN` = docs/PLAN.md;
`GUIDE` = docs/DISBESM6-GUIDE.md;
`ASM-CODE-RECOVERY` = docs/SEMANTIC/ASM-CODE-RECOVERY.md.

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: зона `ТРАНСЛЯТОР С А/К И Т М` (автокод ИТМ,
`.75`), каталог `0000.0204`, зоны 0055–0060 [PLAN:18;
inventory.md:32; FINAL-REPORT:19]. НЕ МАКРО-БЕМШ:
шапка `.be` «М/К БЕМШ ВЕР.06/78» — ошибка [be:2-3].

ИСПРАВЛЕНИЕ. Ранее зона описывалась как «1 код-слово
+ таблицы/забелы» (старый Z0055.md §1–2; be:5-6).
ЭТО НЕВЕРНО. disbesm6 обрывает трассу на слове 5
(`nop`) и слове 6 `пб (М3)` при неизвестном М3
[055:12-13; GUIDE §3.2]. При принудительной разметке
всех 1024 адресов как W_CODE: 2179 строк, 0 `конд`;
99.4% половин (2023/2036) в словах 6–1777 дают
именованные команды БЭСМ-6 по siprod_asm.OPS. Прогон
с симтабом 6..1543(dec) [ASM-CODE-RECOVERY §2.3]:
2170 строк, 4 `конд`. `выпр` (IRET) в слове 0 тоже не
даёт преемника [ASM-CODE-RECOVERY §5]. Зона —
ИСПОЛНЯЕМЫЙ МОДУЛЬ с подпрограммами, циклами и
вкраплёнными таблицами констант.

EVIDENCE:
- 36 `пв`, 158 `пб`, 84 `по`, 50 `цикл`; внутренние
  цели CALL: 0220,0221,0300,0301,0302,0321,0322,0402
  [t55:0220,0221,0300-0302,0321,0322,0402];
- слово 6 — пара `пб (М3)` + `зп '6770'` [055:13;
  view 0055.0006]; обрыв трассы — артефакт, не данные;
- 0777/0773/0775 — не «таблица», а операнды-адреса в
  `сч 777`, `зп 773`, `или 775` [t55:0016,0020,0075];
- 169 слов совпадают с зоной 0056 (блоки 0103-0143,
  0200-0351, 0365-0375) — общая библиотека кода.

_confidence_: ПОДТВЕРЖДЕНО (исполняемый модуль, код,
CALL/циклы); НЕИЗВЕСТНО (бизнес-функция без исходника
ИТМ).

  вне зоны; 0003/0004 повторяют его; 0001 — число 7017₈,
  0002 — команда Э20. 0005 — nop [055:7-12].

  `зп '6770'` — пара; 0010 `по 5540`, 0011 `уиа 4154(М1)`,
  `уиа 4235(М2)`, 0012 `пб 4261`; 0013–0016 читают 702,
  проверяют 240, устанавливают 773; 0017 `пб (М7)` —

## 7. НЕИЗВЕСТНОЕ

1. Бизнес-функция модуля и его подпрограмм (нет исходника
   автокода ИТМ); все «роли» в §6 — механические гипотезы.
2. Куда ведёт '70707' и что такое внешние CALL 5132,
   6003, 3604, 4272 (физическая привязка не найдена).
3. Точное назначение рабочих ячеек 0770–0777, 702–727,
   744–770, 46xx–54xx (счётчики? указатели? флаги?).
4. Природа островка 0240–0275 и пула 0700–0777: коды
   литер, маски или адреса — без карты ИТМ не доказано.
5. Почему слова 0003/0004 дублируют шлюз 0000.
6. Почему 156 нулевых слов в 1544–1777 (свободный район
   или неиспользуемый код) — гипотеза zero-fill.
7. Заголовок `.be` ошибочно называет зону БЕМШ [be:2].
