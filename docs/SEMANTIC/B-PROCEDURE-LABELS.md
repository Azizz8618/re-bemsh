# ПРОЦЕДУРНЫЕ МЕТКИ В `.be` ЗОН B (уточнённый критерий)

Дата: 20.11.2026. Объект: 33 зоны B (0137–0177₈),
`ТРАНСЛЯТОР С М/К БЕМШ ВЕР.06/78`.
Изменены только 9 файлов `bemsh/MBE-Z*.be` и этот отчёт.
`gold/`, `dis/`, `dis-forced/`, `sym/`, `tools/`, другие `docs/`
не трогались. Эталонные образы — только чтение.

## 1. УТОЧНЁННЫЙ КРИТЕРИЙ (по указанию оператора)

Процедурной записью считается **только** цель одной из четырёх
команд **перехода с возвратом**:

```
ПБ, ПВ, ПИО, ПИНО (включая пио36)
```

Цели `ПО`, `ПЕ`, `ЦИКЛ`, `ВЫПР` в процедурные записи
**не входят**. Это уточнение отменяет исходную выборку
`PROCEDURES-B.md` (64 записи, где вход мог быть любым
`ВЕТВ×N`). Из 64 кандидатов по уточнённому критерию
подтверждено **36**; 28 исключены.

Источники подтверждения:

1. Разбор `.be` (полный принудительный код всех 33 зон):
   мнемоника ПБ/ПВ/ПИО/ПИНО + операнд, разрешённый через
   таблицу `ЭКВ` зоны. Найдено 31 совпадение.
2. `docs/INTERNAL-CALL-OFFSETS.md` (другой агент,
   абсолютные операнды в `dis-forced/Z0144.asm`,
   `dis-forced/Z0150.asm`): ещё 5 записей каталога,
   у которых места вызова в `.be` записаны как `КОНД В'…'`:
   `0144:1173`, `0144:1175`, `0144:1414`, `0144:1643`,
   `0150:0665`. Все пять — цели `ПБ 'NNNN'(Мn)`.

Расхождение с полным скан-листом второго агента
(5 процедур с ≥2 ссылками) объясняется двумя причинами:
у него порог ≥2 ссылок, а в `dis-forced/` отсутствует
`Z0147.asm` (там 16 подтверждённых целей ПВ/ПБ/ПИО/ПИНО).

## 2. ЧТО СДЕЛАНО

- **36** процедурных шапок `* Процедура: <метка>; <роль>`
  и `* Вх/вых: <регистры, ячейки, RETURN>; <статус>`.
  29 шапок вставлено, 7 существующих общих шапок
  (`* Процедура-утилита, вызов через М15`,
  `* Диспетчер, связь через М13`) заменены на подробные.
- **1** новое определение `P1643 ЭКВ '1643'` после макроса
  `М` в `MBE-Z0144.be` (у остальных 35 метка уже была).
- Роли и входы/выходы взяты из `GUIDE-PROCEDURES-B.md`;
  статус `ГИПОТЕЗА` сохранён, `0176:1354` отмечена
  `ПОДТВЕРЖДЕНО`. Для `0144:1173` и `0173:1636`, где
  смысл не установлен, записано
  `Назначение не установлено; observed: …`.
- Числовые операнды вида `ПВ '477'` не встречаются:
  все места вызовов уже используют символические метки
  (`OUT477`, `UTL521`, `DSP534`, `P605` и т. п.).
  Замен операндов не потребовалось.

Формат: строка `*` ≤59 колонок, комментарии после запятой
не изменились, `↑` не используется, перенос со звёздочкой.

Причина во всех случаях — вход не является целью
ПБ/ПВ/ПИО/ПИНО (только `ПО`/`ПЕ`/`ЦИКЛ`/`ВЫПР`)
либо цель оказалась артефактом данных:

0145: 0000 1322                                 (2)
0147: 0104 0125 1322                            (3)
0150: 0000 0104 0171 0336 0426 0603             (6)
0151: 0000 1322                                 (2)
0152: 0000                                      (1)
0161: 0100 0122 0131 0136 0140                  (5)
0166: 0000                                      (1)

`0145:1322` и `0147:1322` — подставные цели: в `.be`
записаны как `КОНД В'73101322…'`, а не как `ПВ`.
`0150:0426` — область данных (более половины слов
константы/fill). Остальные — короткие ветви без CALL-пары.
