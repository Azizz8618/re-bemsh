## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: ЗАГРУЗОЧНАЯ/УСТАНОВОЧНАЯ зона B2 (`ВАР.12/77`);
B-прообраз — 0142₈. Код-стаб на 5 слов (0-4) с двумя
экстракодами (Э77, Э50), циклом по М17 и прямым return
через М7; остальное — числовые/смешанные таблицы.

EVIDENCE:
- 0542.0000-0004: `зп START; зп D00017` /
  `Э77 '77777'; цикл -1(М17)` / `зп START; Э50 '517'` /
  `уиа '47433'(М7); ржа '3'` / `пб '77337'(М7)` [0542:6-16];
- V:84: 0142↔0542 diff=1023, s=+45, class L [V:120-122];
- XR:95: КМ=0, ДМ=1, BR=2, CALL=0, EX=2;
- экстракоды Э50…Э77 — immed-константы, не адреса [DG §5].

_confidence_: ПОДТВЕРЖДЕНО (стаб, EX=2, class L);
ГИПОТЕЗА (назначение таблиц и immed-констант 517/3).

## 7. НЕИЗВЕСТНОЕ

1. Куда ведёт `пб '77337'(М7)`; роли Э77 '77777', Э50 '517',
   `ржа '3'` как immed — назначение не доказано.
2. Природа таблицы смешанных слов 0755-0773 (НЕОПР, TC
  §6.3).
3. B 0142 — иной код (`или/зп (М13)`, `мода START`,
   `пв '34417'(М16)`, `по/пе '76166'(М7)`) с 2 CALL через
     М16;
   B2 не имеет ни одного CALL — причина по class L не ясна
   [V:84; REG §3M16].
4. Роль зоны «загрузки/установки» — по V:120-122, гипотеза.
