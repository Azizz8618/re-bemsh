## 4. ПЕРЕМЕННЫЕ И ЯЧЕЙКИ

```
ячейка/имя      роль                 кто пишет  кто читает

6214, 6204   маски проверки     —         и (0155:8,:10)

4024         адрес выхода       —         пб (0155:12)

```
`ВХ-счётчик` (XR §4): зона 0155 не входит в топ-20 целей;
`ДМ=0`, т. е. поименованных ячеек с входящими ссылками
нет. «кто пишет/читает» для таблицы — гипотеза по AN:59;
прямого `уиа <база>(Мn)` на 0004+ не найдено.

## 5. РЕГИСТРЫ

В коде слов 0–3 полей `(Мn)` НЕТ: `сч/и/пе/пб` работают
с явными константами (`0155:7-13`). Зона не шахматная
(distinct=734), поэтому псевдо-М5/М12 из Z0146 здесь
не действуют (REG §1.3). Любые `(Мn)` в `конд`-словах —
поле команды, не значение (REG §4).

2. Смысл повторяющейся ячейки `02200000 + R`

3. 734 различных слова: какие из них адреса, какие — коды
   ошибок. 4 кодировки осмысленного текста не дают.
4. Почему обрыв после слова 3: обрыв трассы или
   данные изначально (статический анализ не различает).

   попарное сравнение 0155↔0555 не проводилось.
