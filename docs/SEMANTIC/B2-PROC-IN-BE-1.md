# ПРОЦЕДУРЫ В КОММЕНТАРИЯХ B2 .be

Дата: 21.11.2026. Источник фактов: `docs/PROCEDURES-B2.md`

других `.be` не изменён.

## 1. Что сделано

В 16 B2-модули `bemsh/MBE2-Z0540.be` ... `MBE2-Z0557.be`
добавлены полные описания процедур **только в `*`-комментариях**
перед меткой `*** КОД МОДУЛЯ`, то есть до первой машинной строки.
Машинные строки, `ЭКВ` и операнды не тронуты.

Формат блока на каждую процедуру (4-5 строк):

```
* === ПРОЦЕДУРЫ ЗОНЫ: ПОЛНОЕ ОПИСАНИЕ ===
* Источник: docs/PROCEDURES-B2.md §4, §4.2, §5.
* Границы оценочные где ГИПОТЕЗА; оговорка §1, §7.
* ПРОЦ <имя> <старт>-<конец> size=<N> <вид>
*   ВХ <вход>; ВЫХ <выход>
*   РЕГ <регистры>
*   СМЫСЛ <функция>; ГИПОТЕЗА|ПОДТВЕРЖДЕНО
*     <продолжение со звёздочкой>
* === КОНЕЦ ОПИСАНИЯ ПРОЦЕДУР ===
```

Обозначения (по источнику): `CALL×n` - вид входа по пв и число
CALL-источников; `ВХОД` - вход зоны (ZONE_ENTRY); `Rn` - RET
 (`пб (Мn)`), `R15` - RET (`пб (М15)`), `R` - прямое `пб`,
 `S` - стоп/Э74, `D/END` - забел/конец; `РЕГ` - счётчик полей
 `(Мn)` в диапазоне procedures. Уверенность «ГИПОТЕЗА» или
 «ПОДТВЕРЖДЕНО» перенесена из §4.2 источника без изменений.

Все границы, размеры, входы/выходы, регистры и human-формулировки
взяты из разделов 4, 4.2 и 5 `docs/PROCEDURES-B2.md`. Там, где
источник даёт усечённую формулировку, она сохранена как есть;
новых домыслов сверх текста источника нет. Зона 0546 (FILL, §6)
в §4 каталога записей не имеет, поэтому для неё добавлена только
пометка об отсутствии процедур.
