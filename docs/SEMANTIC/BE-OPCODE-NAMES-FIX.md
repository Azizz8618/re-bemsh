# Исправление ложных имён КОП в комментариях bemsh/*.be

Дата: 20.11.2026. Изменены только 19 файлов bemsh/*.be
и этот отчёт. Эталоны, gold/, dis/, sym/, tools/ не тронуты.

## 1. Основание

AGENTS.md: правила 2, 3, 5. Источник замен:
docs/OPCODES-020-021-047-032.md, разделы 5-6.

Факты (§1, §7 источника):

- КОП 020 = сбр/apx, КОП 021 = рзб/aux (обычные команды).
- КОП 032 = УВВ, привилегированный обмен (PRIV).
- КОП 047 = x47, привилегированная команда (PRIV).
- Настоящие экстракоды пользователя: Э050...Э077.
- Код `02000000`/`02100000` — 2-я структура, не КОП 020/021.
- Слова `2047 70xx` — KOI-7 текст ВЧ/ВЧОБ/ВЧАБ, данные.

Дополнение оператора: КОП 032 именуется только `УВВ`.
Написание `увв32` в комментариях запрещено. Полная глосса
`КОП 032 = УВВ (privileged I/O)` добавлена звёздочкой.

## 2. Правила правки

Правка только после первой запятой строки `КОНД В'...'`.
Поля до запятой, метки, EQU, мнемоники не изменялись.
Длина строки <=60, длина комментария <=55.
Символ `^` не применялся.
Перед правкой сделаны копии в /tmp/.private/azizz/bemsh-opcode-fix-bak.
Перед записью файл перечитан повторно (защита от параллельных
правок); SKIP/ABORT не сработали ни разу.

## 6. Оговорки

- Шесть коротких форм (`левая 020+020, неточно`,
  `020/рег+EXP; LE/RE`) потеряли префикс КОП2 из-за лимита
  60 колонок; смысл сохранён.
- Пометки `неточно`, `EXP-адрес`, `нет мн` сохранены как
  описания исходного листинга, а не как имена команд.
- В zones 0055...0162 параллельно правились другие строки
  теми же файлами. Правка выполнялась по свежему чтению,
  поэтому чужие изменения сохранены.
