## 1. Числа по зонам

Строк в `--fix-list`: 22 + 10 + 9 + 10 = 51.

```
зона   строк  применено  пропущено  из них
0055      22          22           0  21 ПРОЦ + 1 OPERAND
0056      10          10           0   8 ПРОЦ + 2 POINTER
0057       9           9           0   8 ПРОЦ + 1 OPERAND
0060      10           9           1   6 ПРОЦ + 3 POINTER
------------------------------
всего     51          50           1
```

ПРОЦ = PROCEDURE_LABEL, POINTER = POINTER_TO_PROCEDURE
в строке `ЭКВ`, OPERAND = мнемоника экстракода.

## 2. Что делалось

PROCEDURE_LABEL и POINTER в строке `ЭКВ`: переименовано
определение `ЭКВ` и все вхождения имени в том же `.be`
(код и комментарии). Восьмеричное значение не менялось,
поэтому собранные слова остались теми же. Пробелы перед
запятой подправлены так, что колонка запятой сохранена.
Новых одноимённых меток не создавалось
(проверка на дубли: 0 во всех четырёх файлах).

OPERAND (`Э71`, `Э64`): операнд заменён на `PTR`-метку,
после блока `ЭКВ` добавлено определение `PTRnnn ЭКВ`.

## 3. Примеры до -> после

Имя процедуры:

```
- AM220 ЭКВ '220'
+ P220 ЭКВ '220'
- ПО   AM220      , перейти по условию на AM220
+ ПО   P220       , перейти по условию на P220
```

Указатель в `ЭКВ` (0056):

```
- AM301 ЭКВ '301'
+ PTR301 ЭКВ '301'
- УИА  AM301(М3)  , взять адрес ячейки 301 в М3
+ УИА  PTR301(М3) , взять адрес ячейки 301 в М3
```

Экстракод (0055):

```
- Э71  '4244'     , экстракод Э71 4244
+ Э71  PTR424     , адрес процедуры PTR424
+ PTR424 ЭКВ '4244'
```

Экстракод (0057):

```

+ Э64  PTR543     , адрес процедуры PTR543
+ PTR543 ЭКВ '5433'
```

## 4. Пропущенная строка

`0060 | 521 | 0000672707100020 | PTR20` — ПРОПУЩЕНА.

Причина: адрес `00020` — это младшие 5 цифр второго
полуслова `07100020` 16-цифрового слова `В'...'`. Разбить
слово на две символьные половины и доказать побайтовую
идентичность не удалось: способ собрать остальные 11
восьмеричных цифр через метку не проверен. По правилу
«разделять только при доказанной идентичности» слово
оставлено без изменения:

```
КОНД В'0000672707100020'    , код: зп 6727, CALL 020
```

Метка `PTR20` в зоне 0060 всё же определена: она получена
переименованием `MB20 -> PTR20` (значение '20'). Комментарий
`код: зп 6727, CALL 020` уже называет адрес процедуры.
