## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: СТАРТОВАЯ (ЗАГРУЗОЧНАЯ) ЗОНА транслятора
`ТРАНСЛЯТОР С М/К БЕМШ ВЕР.06/78`, том 2348. Она готовит
несколько системных ячеек и содержит таблицу мнемоник,
но почти вся — данные (1019 из 1024 слов).

EVIDENCE:

  2348» [bemsh:3];
- 5 слов кода (0-4): обнуление ячеек, запись `070000₈`
  (SYSCALL), адреса 3 (INITCELL), кода `РЕГ '3554'`
  [bemsh:33-51; 0137:8-18];
- обрыв трассировки `пб (М3)` на слове 4 — после него
  disbesm6 печатает `конд` [0137:18; CROSSREF §5.3;
  AGENTS.md §2];
- таблица мнемоник `0137.0060–0121` в KOI-7 [TC:200-221;
  bemsh:90-134];
- в зоне 0 меток кода, 0 CALL [CROSSREF:60].

_confidence_: ПОДТВЕРЖДЕНО (код загрузки, обрыв трассы,
присутствие KOI-7-таблицы); ГИПОТЕЗА (назначение
отдельных констант, «ячейка загрузчика»).

Физический адрес входа транслятора НЕИЗВЕСТЕН: число
`00000` — нуль/авто-`START`, а не вход [VAL:120].

### Данные 0005-1777

НЕ исполняются. Почему данные: (1) все слова — `конд`
[0137:19+]; (2) 0 меток кода и 0 CALL [CROSSREF:60];
(3) трасса оборвана на 0004. Исключение — таблица
мнемоник `0060–0121` в KOI-7: макрос `Е` использует её
для генерации мнемоник при сборке [LB §3; TC §6.1];
процессором она не исполняется.

## 7. НЕИЗВЕСТНОЕ

1. Физический адрес входа транслятора (00000 — нуль).
2. Природа ~1015 слов 0122-1777: вероятно таблицы
   экстракодов/адресов, но доказательства нет [TC §6.3].
3. Точные роли 00000/00003/070000/003554 — гипотезы по
   частоте обращений; исходника транслятора нет.
4. Штампа версии в зоне 0137 нет; 06/78 — из шапки и
   штампа `0147.1315` (см. Z0147.md §3).
5. `конд п'00000D'`, `п'007000'` (0011, 0021) — числа,
   попавшие в «хороший» GOST-диапазон [TC §2].
6. `РЕГ '3554'` — immed; подстановка символа для immed
   подавляется [VAR §6.3], роль CONST3554 гипотеза.
