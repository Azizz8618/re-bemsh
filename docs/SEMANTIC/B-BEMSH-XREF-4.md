## 2. ПРАВИЛА, ПРИМЕНЁННЫЕ К ВСТАВКЕ

1. Имя метки ≤6 символов, UPPERCASE, определяется через `ЭКВ`
   сразу после директивы `М` (в существующем блоке меток).
   `ЭКВ` не порождает слово, поэтому вставка байтово безопасна.
2. Префиксы: `Pxxx` вход процедуры (цель ПБ/ПВ/ПИО/ПИНО/ПЕ/ПО),
   `Cxxx` ячейка/константа, `Xxxx` внешний адрес (смещение
   другого модуля). Локальные цели ПБ/ПВ/ПИО/ПИНО в этих зонах
   уже помечены `Pxxx` предыдущим КОНД-sweep, новые `Pxxx`
   добавлены только где не было метки.
3. Человекочитаемая `*`шапка даёт роль, `IN` (входящие ветвления),
   `OUT` (выход) и источник xref `PROC:<строка>`/`EXT-OFFSET:<строка>`.
   Для всех этих зон статус `ГИПОТЕЗА`: эталонного исходника
   транслятора на диске нет (PROCEDURES-B.md §1, §5).
4. Каждое новое определение имеет вид
   `МЕТКА ЭКВ 'NNNN' , роль; [источник]`, комментарий после
   запятой ≤55 символов, без тавтологий. Все новые строки
   ≤60 колонок, моноширина, LF, знак `↑` (не `^`), без тире U+2014.
5. Перед каждой правкой создавался `.bak` в
   `/tmp/.private/azizz/BXREF4/`. После КАЖДОЙ зоны выполнялся
   `bash tools/rebuild-zone.sh <Z> B`; при сбое правка отменялась.
