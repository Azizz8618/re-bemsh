# Человеческие комментарии в модулях B2 (0540–0577₈)

Дата: 20.11.2026. Изменены ТОЛКО комментарии в 32 файлах
`bemsh/MBE2-Z0540.be` … `bemsh/MBE2-Z0577.be` и создан этот файл.
Код, числа, метки, ЭКВ-определения, `tools/`, `dis/`, `gold/`,
`analysis/` и другие документы не тронуты.

## Что изменилось

1. **Комментарии после запятой переписаны по-человечески.**
   Вместо механического шума (`,слово 624, лев. часть`,
   `(адр. 726)`, `(было D00626)`, `автометка A00551 -> адр. 552`,
   `0147:69; ГИПОТЕЗА`, голых ролевых тегов `CODE_UTIL_...`)
   теперь короткое объяснение действия команды с именем роли
   из операнда: `, прочитать CNT707`, `, вызвать подпрограмму
   514 через М15`, `, установить BASE14 в М1`.
2. **Заголовки процедур.** В началах всех 71 процедуры из
   `docs/PROCEDURES-B2.md` добавлены короткие `*`-заголовки
   (`* Процедура печати (OUT_PRINT)`, `* Обработка таблицы меток`).
   Строка со степенью уверенности сохранена как `* Вызов и возврат
   подтверждены` (8 процедур) или `* Роль по CALL/RET, гипотеза`
   (63 процедуры). Старые шумные `*`-строки с адресами и
   `ГИПОТЕЗА` убраны; доказательства остались в шапке файла и
   в `*`-строках у определений ЭКВ.
3. **Данные КОНД.** Для известных зон дано человеческое meaning:
   `, текст справки БЕМШ1` (0573), `, текст справки БЕМШ2`
   (0577), `, дескриптор макрокомпилятора` (0565),
   `, таблица символов` (0566, 0571), `, текст сообщения об
   ошибке` (0576), `, текст диагностического сообщения` (0544).
   Нулевые слова — `, забел`, остальные — `, служебное слово`.
4. **Зоны-забелы** 0546/0560/0563/0564/0567 получили короткое
   `,填充 AA/55` (шахматный тестовый узор AA/55).
5. Все ЭКВ-определения сохранены побайтово; длина любого
   комментария ≤55 символов; тавтологий типа `, записать ЗП` нет.

## Проверка

Каждая зона прогнана через `bash tools/rebuild-zone.sh <Z> MBE2`.
Результат **32/32**: везде `WORDS: всего=1024 совпало=1024
различий=0`, `RESULT: PASS`, `✓ Файлы идентичны (2000 слов)`.
Дополнительно проверено:

* множества строк с `ЭКВ` до/после совпадают во всех 32 файлах;
* части строк **до первой запятой** (код) совпадают построчно
  во всех 32 файлах;
* ни один комментарий не длиннее 55 символов.

   ```

   СТАЛО:        ПВ  UTL514(М15) , вызвать подпрограмму 514 через М15
   ```

   * Вызов и возврат подтверждены
