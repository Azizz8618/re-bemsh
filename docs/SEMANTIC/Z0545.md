## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: зона обработки ТАБЛИЦ МЕТОК / ВХОДНЫХ МЕТОК и
компоновки (линковки) B2; B-прообраз — 0145₈. Код (слово 0
и первые ~10 слов) плюс обширный пул диагностики.

EVIDENCE:
- тексты: 0545.0157 «ТАБЛИЦА МЕТОК ЗАПИСАНА НА МЛ»,
  0207-0221 «СВ.ЗАМИН/АМАКС/АСВОБ», 0451 «ДЛИНА …
  ВХОДНАЯ МЕТКА - АБСОЛЮТНАЯ», 0463 «ВХОДНЫХ МЕТОК
  ОТСУТСТВУЕТ ИМЯ ПРОГРАММЫ», 1211 «ЗАДАН НЕДОПУСТИМЫЙ
  НАЗ…» [0545:..; view];

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

ВХОД: управление из ядра. ВЫХОД: CALL A01322 + further code.

```
0000 пв A01322(М16)  CALL: М16 = адрес возврата, передача в
      таблицу меток; рж D00024+2 — immed (fuzz +2)
      [0545:6-7; RAW: слово 0 = КОНД В'7310132200270026']
0001 уиа D01121-3(М1); уиа '70031'(М3)  база таблицы
      меток в М1, константа 70031₈ в М3 [0545:8-9]
0002 счи М3; зп '71507'  счёт в М3, запись адреса
0003 сч D01110; зп '71524'  чтение ячейки, запись адреса
0004 счи М15; зп '71535'  счёт в М15, запись адреса
0017+ ДАННЫЕ/ТЕКСТ    не исполняются: 0 CALL после слова
      0; диагностика и таблицы меток [XR:98].
```
Почему word 0 КОНД в .be: дефект `raw_word_from_halves()`
на префиксе `:` в колонке бит (`0:16 31 01322`); обход
запрещён условиями задачи [RR:88-120]. Байты эталона точны.

## 7. НЕИЗВЕСТНОЕ

1. Роль зоны как «компоновщика» — по текстам, без исходника.
2. Назначение таблиц «СВ.ЗАМИН/АМАКС/АСВОБ».
3. B↔B2-правка: B 0145 word 0 `…; сбр '2027'` → B2 `…; рж
   D00024+2`; константы `зп '3537'/'3554'/'3565'` →
   `'71507'/'71524'/'71535'` (сдвиг в верхнюю память),
   class S diff=820, s=+18 [V:88; 0145:8-15].
4. Fuzz-адреса D01777+1/+2 — не реальные адреса
  [XR:186-190].
5. Точные границы кода (0-775 по .be — завышены).
