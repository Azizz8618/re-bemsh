## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: ГИПОТЕЗА — плотная таблица служебных слов/кодов в
макроредакторном регионе (AN:57–60). Исполняемый код —
только START-слово 0; дальше всё `конд`/`пам`.
Собственного штампа нет; `besmtool search` известных
штампов даёт 0 попаданий.

EVIDENCE:
- XR:75: `Z0156 КМ=0 ДМ=0 BR=1 CALL=0 EX=0` — одно
  ветвление и нуль вызовов;
- `0156:7-8`: `START мод '6613'` + `пб START` — единственное
  код-слово, прямой выход без CALL;
- 5 забелов `пам` на 353/372/422/424/444, последний —
  `пам 732` (`0156:264`) — хвост из 732 нулевых слов;
- 243 разл. слова, 772 нуля; ни одного осмысленного
  GOST-текста (проверено во всех 4 кодировках).

_confidence_: ВЫСОКАЯ (структура и границы); НИЗКАЯ
(смысл таблицы — по соседству с 0154/0155).

## 5. РЕГИСТРЫ

Код слова 0: `мод '6613'`, `пб START` — полей `(Мn)` НЕТ
(`0156:7-8`). Зона не шахматная (distinct=243 ≠ 3),
поэтому псевдо-М5/М12 (Z0146 §3, REG §1.3) здесь не
действуют. `(Мn)` в `конд`-словах — поле команды, не
доказанное значение (REG §4). Гипотетический указатель
таблицы не найден: трассировки `-R<N>=<адрес>` не делалось.

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

```
0000  START мод '6613' ; пб START
  ЧТО: настройка модифицированного адреса (REG §4)
    константой 6613 и немедленный прямой уход на START.
  ВХОД: управление от загрузчика. ВЫХОД: пб START —
    прямой переход, НЕ возврат из CALL (М15 не участвует).
  [0156:7-8; REG §3 M15; XR:75 BR=1].
0001+  данные: исполнение обрывается на слове 0
  (дальше `конд`); забелы `пам` подтверждают «не код»
  (RES §1, STANDARD §2.8). Структура — §3/§4.
```
Процедур, CALL-блоков и ветвлений, кроме START-пб, НЕТ.
