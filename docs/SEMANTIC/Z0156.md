# СЕМАНТИКА ЗОНЫ 0156₈ (обработка битов + таблица)

Основа: bemsh/MBE-Z0156.be, dis/MBE-Z0156-L1.asm,
gold/MBE-Z0156-L1.bin (1024 слова). evidence:
`156:N` = dis/MBE-Z0156-L1.asm:N; `F:<a>` =
принудительная дизассембляция `disbesm6 -a0 -e0
-n<allcode.tab> gold/MBE-Z0156-L1.bin`; `XR` =

`REG` = docs/REGISTERS.md. Адреса восьмеричные.

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: КОРОТКАЯ ПОДПРОГРАММА ОБРАБОТКИ БИТОВЫХ
ПОЛЕЙ (в младшей части зоны) плюс разреженная
таблица констант/связей в остальной части.
Старая формулировка «исполняемый код — только
START-слово 0; дальше всё конд/пам» ОШИБОЧНА.

EVIDENCE:
- forced-листинг вскрыл связную программу в словах
  0002-0062: пары команд с регистрами М1/М2/М14/
  М17, обращения к ячейкам 6272-6274, 6612-6617,
  6445, 6556, ветвления `по '6017'`, `по '6031'`,
  `пб '6023'`, `пб (М2)` и экстракод Э70 [F:0002-
  F:0062];
- слово 0070 содержит `пе '55733'(М15)` и
  `по '40100'(М15)` — переходы через линк М15 [F:0070];
- исходный `-a0 -e0` листинг остановился на слове 0
  (трасса оборвалась), поэтому 251 слово помечено
  `конд` [156:9-265; XR:65]; это артефакт
  достижимости, а не отсутствие кода [DC §10];
- собственного ГОСТ-штампа нет: `besmtool search`
  известных штампов даёт 0 попаданий [AN:57-60].

_confidence_: ПОДТВЕРЖДЕНО (обе половины слов
осмысленны, регистры, ветвления) — наличие кода.
ГИПОТЕЗА — «битовая обработка» (название по opcode).

## 7. НЕИЗВЕСТНОЕ

1. Точная граница кода: блок 0002-0062 доказан,
   0063-0177 — нули/данные; статус 0100-0113
   неопределён.
2. Смысл Э70 как «системного экстракода» и
   CALL-целей 24157/40100/55733 — без исходника
   не установлен (адреса могут быть логическими).
3. Природа ячеек 6272-6274, 6612-6617, 6445,
   6556 — по opcode гипотеза «битовые поля/флаги».
4. Что такое «конк 66154330» (0114) — шаблон
   числа, не расшифрован.
5. Все роли регистров М1/М2/М14/М15/М16/М17 —
   ГИПОТЕЗА до трассировки `-R<N>=<адрес>`.
6. Собственного штампа зоны нет; атрибуция только
   по коду и соседству 0155/0157 [AN:57-60].
