# СТАРТ ПЕРВОЙ НЕКОММЕНТАРНОЙ СТРОКОЙ, B2 0560-0577₈ (MBE2)

## Требование

МАКРО-БЕМШ принимает СТАРТ за шапку модуля только
тогда, когда это первая некомментарная строка. Если
до СТАРТ стоят ЭКВ или другие некомментарные строки,
транслятор игнорирует СТАРТ: слова остаются на базе 1,
а HAM не равен 10000₈. Перенос СТАРТ перед блоком ЭКВ
даёт HAM=10000 и сдвигает адреса в 10000..11777₈.
Значения самих слов при этом не меняются.

## Проверенное состояние

В 16 зонах 0560-0577₈ строка `Z<Z>   СТАРТ '10000'`
уже была первой некомментарной строкой: перед ней
идут только строки шапки, начинающиеся с `*`. Блоков
ЭКВ до СТАРТ нет ни в одной зоне. Перенос строки не
потребовался. Метка модуля и операнд сохранены точно.

## Проверка байтовой безопасности

Для каждой зоны: `make rebuild-zone Z=<Z> MODE=MBE2`.
Автоопределение базы в tools/rebuild-zone.sh выбирает
10000₈: совпадение с gold 1024/1024, различий 0,
RESULT: PASS. Извлечение с базы 1 даёт 0 совпадений,
с базы 10000₈ даёт 1024 совпадений. Адреса сдвинуты,
ни одно из 1024 значений слова не изменилось.

В листинге-пробе HAM=10000, первый адрес кода 10000₈
во всех 16 зонах. Особые зоны проверены так же:
0560, 0563, 0564, 0567 (забелы / FILL) и 0574, 0575
(данные) сравнены на все 1024 слова, расхождений нет.
