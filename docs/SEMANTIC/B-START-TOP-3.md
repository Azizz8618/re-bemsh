## 1. ОБОСНОВАНИЕ БАЗ

Базы -- analysis/RESIDENT-ZONES.md §5:

- 0147 -- 00000 (резидентна, страница 00);
- 0161 -- 24000, 0162 -- 26000 (резидентны, AMBIG);
- 0160, 0163-0167 -- '10000' (нерезидентны, правило
  оператора для диск-оверлеев).

СТАРТ меняет только базу адресов листинга, НЕ значения
слов. Когда СТАРТ распознан как шапка, HAM=<база> и
адреса слов идут <база>..<база>+1777₈; слова те же.

## 4. ОСОБЫЙ СЛУЧАЙ 0147

СТАРТ '0' первой некомментарной строкой даёт ошибку
транслятора `НОЛЬ ЗАПРОШЕН`: ЧИCЛO OШИБOK=0001,
MAKC CEPЬEЗH=4. rebuild-zone требует ровно
`ЧИCЛO OШИБOK=0000` и потому падает до экстрактора.
Проверены написания '0', 0 и '00000' -- все дают
1 ошибку. По правилу «не оставлять падающий файл»
перенос откачен.

С СТАРТ '0' ниже блока ЭКВ шапка не распознаётся:
HAM=00001, адреса 1-based, но ошибок 0 и все 1024
слова равны gold. Операнд '0' сохранён: 0147
резидентна на странице 00, база '10000' была бы
неверной. Побайтовая безопасность подтверждена
отдельно: tools/vneshn_probe.sh probe дал 1024/1024,
different_bytes=0 и при переносе СТАРТ наверх.
