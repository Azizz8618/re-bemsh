# B2-зоны (0540–0577₈): применение глобальной таблицы литерал → метка

Пакетная обработка всех 32 зон старшей копии B2 по `docs/LITERAL-LABELS.md`
и `sym/ALL_LABELS.tab`. Изменены **только** `bemsh/MBE2-Z*.be` (32 файла).

## 1. Методика

1. Для каждой зоны: `python3 tools/literal_labels.py --apply-zone <Z> --mode MBE2`.
2. Обязательная побайтовая проверка: `bash tools/rebuild-zone.sh <Z> MBE2`
   → `RESULT: PASS`, `WORDS: всего=1024 совпало=1024 различий=0`,
   `✓ Файлы идентичны`.
3. Счёт «литералов» — кавычные восьмеричные операнды в кодовой части строки
   (до первой запятой, вне строк `*`), которые сканер `tools/literal_labels.py`
   относит к `ADDRESS`/`AMBIGUOUS` (строки `ЭКВ` исключены). Это и есть
   кандидаты на переименование. Счёт «до» и «после» сделан одним и тем же
   сканером/классификатором, что и в инструменте.
4. Метка вводится строкой `МЕТКА ЭКВ 'NNNN'`, которая не порождает слово,
   поэтому 48-битные слова и байты эталона не меняются.

## 3. Отказы

Отказов нет. Ни одна зона не дала `RESULT: FAIL`, `ОПЕРАЦИИ НЕТ` или
расхождения байтов; откат из `.bak` не потребовался. Зона 0540 была
обработана отдельным пилотным прогоном перед батчем, поэтому в логе батча
она видна как `0 → 0` (к моменту запуска батча литералы в ней уже были
заменены); в таблицу выше вписано её войденное состояние (609 литералов,
276 меток) — это не отказ, а порядок обработки.

## 4. Константы, оставленные без меток

Классификатор намеренно **не** трогал операнды класса `CONSTANT`:
экстракоды (`Э50 '105'`, `Э52 …` и др.), маски, immediate-операнды, слова
данных, шахмальную заливку (`'25252'`/`'72525'`, см. `LITERAL-LABELS.md` §5.3),
а также уже существующие определения `ЭКВ`.

После обработки в 32 зонах осталось **17 981** кавычный операнд класса
`CONSTANT` (включая 7 184 newly вставленные строки `ЭКВ`) — все они
сохранены как есть. Адресных литералов (`ADDRESS`/`AMBIGUOUS`) не осталось
ни в одной зоне (0 по всем 32).

Зоны-«заполнители» B2: 0546, 0560, 0563, 0564, 0567 — по 2047
CONSTANT-операндов в каждой (в основном данные/заливка; в слове 1777
заливка `'66666'` получила метку `CON666` по решению классификатора).
Адресных литералов в них почти нет (по 2 на зону). Константы в метки
**не форсировались**: применено ровно то, что классификатор счёл адресом.

## 5. Оговорки

1. Метки — компактные аннотации для чтения листинга, **не** ground truth
   (`docs/LITERAL-LABELS.md` §0, `docs/LABEL-MAP.md` §0). Роли из
   `GLOBAL.tab`/`SEMANTIC` — гипотезы без исходника транслятора.
2. `ЭКВ` не порождает слово; байтовая идентичность подтверждена для каждой
   зоны отдельным `rebuild-zone.sh` (1024/1024, «Файлы идентичны»).
3. Инструмент укорачивает только хвост комментария после первой запятой,
   чтобы строка не превышала 78 символов (лимит транслятора,
   `docs/RAW-RECOVERY.md`); кодовая часть не изменяется.
4. `.bak.<timestamp>`-файлы, созданные этим агентом для 32 зон B2, удалены
   после успешной проверки.
5. Другие файлы (`bemsh/ASM-Z*`, `bemsh/MBE-Z*`, `tools/`, `sym/`, `gold/`,
   `dis/`, прочие `docs/`) этим агентом не изменялись.
