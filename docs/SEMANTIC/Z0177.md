# ЗОНА 0177₈ — справка ошибок БЕМШ2 + шаблон сообщения

Дата: 19.11.2026. Образ 2348.
Образ: read-only /usr/local/share/besm6/2348.
B2-аналог: 0577₈ (штампы на 44₈ слов раньше: 0353, 1032).

## 1. НАЗНАЧЕНИЕ

Зона содержит два ГОСТ-текстовых объекта:

  0177.0417–0421: ОШ. СПРАВКИ БЕМШ2
  0177.1074–1104: шаблон сообщения
                  «МОДУЛЬ <N> ЗАПИСАН В ЗОНЫ С <N> ПО <N>»

«ОШ. СПРАВКИ БЕМШ2» — заголовок таблицы ошибок справки
этапа БЕМШ2. Шаблон 1074–1104 — формат печати о размещении
модуля по зонам диска (три числовых поля 000000).
Доказательство: `besmtool search 2348 'ОШ. СПРАВКИ БЕМШ2'`
→ 0177.0417 и 0577.0353; поиск `ЗАПИСАН  В  ЗОНЫ`
→ 0177.1076 и 0577.1032. Чтение `view --encoding=g`
даёт осмысленный русский текст; остальные кодировки — мусор.

## 2. СТРУКТУРА

Заголовок: 4 текстовых слова по 6 ГОСТ-символов (24 знака),
затем слово-терминатор 0422 = `7a0000000000`, где 0x7a =
GOST_END_OF_INFORMATION (gost10859.h);
0423 = `0,20,6`.
Хвост 0431–0766 — нули (свободное место таблицы).

Шаблон сообщения: 11 слов, 6 символов на слово, поля чисел
заполнены нулями (0x00), пробелы = 0x0F:

  1074 «МОДУЛЬ» 1075 «  0000» 1076 «00  ЗА»
  1077 «ПИСАН » 1100 « В  ЗО» 1101 «НЫ  С »
  1102 «000000» 1103 «  ПО  » 1104 «000000»
  1105 разделитель 0x99.

Далее 1110–1114 — числа 777777, ffffff, 7fff, 1;
1115–1777 — нули.

## 4. ИСПОЛЬЗОВАНИЕ

analysis/CROSSREF.md §3: Z0177 КМ=1, ДМ=0, BR=4, CALL=3.
analysis/procedures.md §4.3: A01322 — ложная цель CALL:
`dis/MBE-Z0177-L1.asm:379` — `зп START`, то есть нули.
analysis/VARIABLES-VALIDATION.md: 02006 = ERRWORK,
Прямых ссылок на штамп 0417 нет: он —
метка таблицы, а не процедура.
Индекс записей не найден: явного `уиа <база>(Мn)` для
таблицы ошибок в зоне 0177 не обнаружено. ГИПОТЕЗА:
обращение через базу 04000 (TAB1, 0147:44) или 02000.

## 5. НЕИЗВЕСТНОЕ

  0177.0000–0416 и 0424–1073: плотный код/данные,
 разбросаны по `конд в'…'`; часть —
  нули, часть не расшифрована.
  0177.0423 «0,20,6», 1110–1114 — назначение не доказано.
  Точное значение 0x99 (разделитель) неизвестно;
  besmtool GOST-колонка показывает пробелы.
  B2 0577 отличается от B не только сдвигом −44₈
  (0573/0173 по analysis/versions.md).
