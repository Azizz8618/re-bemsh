## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: ЗАГРУЗОЧНАЯ/УСТАНОВОЧНАЯ зона B2 (`ВАР.12/77`);
B-прообраз — 0141₈. Одно код-слово (прямой переход через М7)
и 1023 слова числовых таблиц. Штампа в зоне нет.

EVIDENCE:
- 0541.0000: `пб '77136'(М7)` — единственная исполняемая
  команда [0541:6]; слово 1 = `конд в'0220000073121660'`
  [0541:7];
- V:83: 0141↔0541 diff=1024, s=+34, class L — полная
  замена загрузочных слов [V:120-122];
- XR:94: КМ=0, ДМ=0, BR=1, CALL=0;
- 0 текстовых штампов [0541:7+].

_confidence_: ПОДТВЕРЖДЕНО (одно код-слово, class L);
ГИПОТЕЗА (смысл таблиц, цель перехода 77136).

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

ВХОД: управление загрузчиком. ВЫХОД: прямой `пб '77136'`.

```
0000 пб '77136'(М7)  передать управление по адресу 77136₈
      с индексом М7. Возврат НЕ через (М15): это прямой
      переход, канонической пары пв/пб здесь нет [0541:6].
0001+ ДАННЫЕ          не исполняются: 0 CALL, 0 меток кода;
      трасса обрывается на слове 0 [XR:94].
```
Почему данные: все слова `конд`, повторяющиеся машинные
константы без меток; ни одного входа/возврата [0541:7+].

## 7. НЕИЗВЕСТНОЕ

1. Куда ведёт `пб '77136'(М7)` (адрес в ОП).
2. Природа таблиц 0001-1777 и роль М7 в них.
3. B 0141 имел 2 код-слова с CALL через М16
   (`пв '14342'(М16)`, `пв '40540'(М16)`, `пб '77260'(М7)`),
   B2 — одно слово; причина по class L не установлена
     [V:83].
4. Точная роль зоны как «загрузки/установки» — по V:120-122;
   исходника загрузчика нет.
