# ЗОНА 0566 — МАКРОКОМПИЛЯТОР B2. ГЛУБОКАЯ СЕМАНТИКА

Статус: ФАКТ = адреса/слова/байты; ГИПОТЕЗА = роль.
B2 = старшая копия 0540–0577₈ (ВАР.12/77).
Адреса восьмеричные. Зона = 1024 слова (6144 байт).

## 1. РОЛЬ ЗОНЫ

Штамп 0566.1221–1225 (GOST-10859):
  «МАКРОКОМПИЛЯТОР ОТ 12.2.76»
  (1221 «МАКРОК», 1222 «ОМПИЛЯ», 1223 «ТОР ОТ»,
   1224 « 12.2.», 1225 «76    »).
B-штамп 0165.0043–0047 — «…2.8.78». B2 на 2 года
  старше и сдвинут внутри зоны на ~+1136 слов.

ГИПОТЕЗА (по сообщениям): пул диагностики компилятора
  макроопределений:
  0566.1246 «NНАЧ», 1247 «NКОН», 1250 «ОШИБКА»,
  1251 «НАЧАЛО», 1252 «КОНЕЦ» — проверка пар
  «начало/конец» (типа МАСRО…МЕND);
  1254 «ПП КП», 1256 «ЗОНА», 1257 «ДЫРА»,
  1320–1321 «ЧИСЛО ОШИБОК», 1322–1325
  «КОМПИЛЯЦИЯ ЗАКОНЧЕНА», 1326–1327 «ИМЕЕТ ОШИБКИ».
НЮАНС: 69-словная таблица дескрипторов B 0165.0367+
  лежит в B2 НЕ здесь, а в 0565 (versions.md:
  0165↔0565). Зона 0566 — ПАРА ПО ТЕКСТУ/ШТАМПУ.
Физическая привязка B2 к ОП не снималась.

## 2. ЧТО РЕАЛЬНО ИСПОЛНЯЕТСЯ

Начало зоны — настоящий КОД (10 слов, 3 CALL):
  0566.0  START сч '4462' ; или '5445'
     +1         мода START ; пв '4363'(М16)
  0566.2        сч '4470' ; зп 5(М17)
  0566.3        сч 1(М7)  ; пв '4147'(М16)
  0566.4        сч -5(М17); пе '4047'
  0566.5        сч '4465' ; пв '4363'(М16)
  0566.6        сч -4(М17); нтж '5233'
  0566.7        зп -4(М17)

Действие: инициализация констант 4462/4470/4465,
  работа с ячейками 5(М17)/-5(М17)/-4(М17),
  М7 как индекс, вызовы через М16 (связь),
  ветвления пе/нтж. Регистры: М7, М16, М17.
Вход: константы 4462/4470/4465; выход: пв '4363',
  пв '4147', ячейки 4–5(М17).
CROSSREF.md: BR=5, CALL=3, КМ=0, ДМ=0.
В B-паре 0165: BR=1, CALL=0 — код ЗНАЧИТЕЛЬНО
  отличается (гипотеза: B2 сохранил больше логики).

## 3. КОНСТАНТЫ И ТАБЛИЦЫ

GOST-10859, 6 символов/слово. 64 текстовые константы.
- 0566.1245 байты `2c 20 31 47 2e 0f` = «МАСRО » —
  ИДЕНТИЧНО B 0165.0107 (проверено xxd). 0x47 =
  GOST `R` (омоглиф Р).
- 0566.1221 штамп «МАКРОКОМПИЛЯТОР ОТ 12.2.76»;
  слово 1221 = `1302005214027052` — то же, что
  B 0165.0043.
- 0566.1246 «NНАЧ», 1247 «NКОН», 1250 «ОШИБКА»,
  1251 «НАЧАЛО», 1252 «КОНЕЦ», 1254 «ПП  КП»,
  1256 «ЗОНА», 1257 «ДЫРА», 1320 «ЧИСЛО»,
  1321 «ОШИБОК», 1322–1325 «КОМПИЛЯЦИЯ ЗАКОНЧЕНА».
Мусорные байты 0566.0001 «/8К900», 1006 «1+U-+Р»
  текстом НЕ считать (TEXT-CONSTANTS.md §6.3).
Дескрипторной таблицы `0220 0000 0300` здесь НЕТ
  (в B2 она в 0565 — 69 слов).
Уверенность: ВЫСОКАЯ (штамп, МАСRО, сообщения),
  НИЗКАЯ (интерпретация кода 0566.0–7).

## 4. СВЯЗЬ С МАКРОКОМАНДАМИ

НАЙДЕНО КАК ТЕКСТ (ФАКТ): `МАСRО` (macros.be:1) —
  слово 0566.1245. Имя команды в диагностике,
  НЕ доказательство «реализации» её кодом.
ПО ФУНКЦИИ (НЕ найдено как константы):
- `МЕND` (macros.be:6) — по «НАЧАЛО/КОНЕЦ» (1251–
  1252) гипотетически проверяется закрытие блока.
- `∧`-параметры (macros.be:2) — отдельная проверка
  байта 0x4D в 0547–0577 не проводилась.
- `GВLА`/`GВLВ`/`LСLА` (macros.be:17/123/70) —
  объявления, разбираемые при компиляции.
- `ЭКВ`/`ЭКВИВ` (macros.be:63/62) — косвенно.
Важное правило: словарь команд взят из macros.be,
  а НЕ выведен из текстов зоны.

## 5. ВЕРСИОННЫЕ ОТЛИЧИЯ B ↔ B2 (подробно)

По заданию 0165 ↔ 0566; versions.md даёт иную
  побайтовую пару: 0165↔0565 (s=−4), 0166↔0566
  (diff=754, s=−12, class S). Обе пары — гипотезы
  о сдвиге. Фактическое содержимое:
- штамп 0165.0043 «…2.8.78» → 0566.1221 «…12.2.76»;
  первое слово ИДЕНТИЧНО, дата изменена.
- `МАСRО` 0165.0107 → 0566.1245 — байты идентичны.
- сообщения 0165.0110–0126 → 0566.1246–1257.
- ТАБЛИЦА `0220 0000 0300` (69 слов): B 0165.0367+,
  B2 — 0565 (69 слов, тот же префикс), НЕ 0566.
- код: B 0165.0 `ржа '3'` (1 слово, 0 CALL) →
  B2 0566.0–7 (10 слов, 3 CALL) — существенное
  расширение/сохранение исполняемой логики.
- 52 текста → 64.
