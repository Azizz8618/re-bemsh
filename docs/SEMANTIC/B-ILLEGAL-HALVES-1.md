## 1. ЗАДАЧА И РЕЗУЛЬТАТ

Пройти по ВСЕМ оставшимся сырым словам `КОНД` в зонах B 0137 и
0140–0147₈, разобрать обе 24-битные половины, для половины с
`name=None` (`siprod_asm.decode()`) сверить поля с `disbesm6.c` и
`simh/besm6_cpu.c`, проверить EXP-бит и экстракоды, вынести вердикт
COMMAND / DATA / EXP-ADDRESS / UNRESOLVED и записать честную роль
в комментарии после запятой. Символической командой заменять только
то, что побайтово воспроизводится; failures откатывать.

**Результат:** 390 слов `КОНД` разобраны. Ни одно 48-битное слово не
изменено. Все 9 зон дают `RESULT: PASS`, `1024/1024`. Три пары
ложных команд (`Э66`/`ЗПМ` внутри KOI-7 таблицы) сведены обратно
в `КОНД` с ролью `KOI7: …; данные`.

## 2. ЧТО ТАКОЕ `None` И КАКИЕ КОДЫ ЗА ЭТИМ СТОЯТ

`siprod_asm.lookup()` (`re-siprod/tools/siprod_asm.py:92-97`) возвращает
`None`, если `half & mask` не совпадает ни с одной записью `OPS`.
В `disbesm6.c:83-89` четыре таких кода **есть, но закомментированы**:

```
/*  { "Э46", 0x026000, 0x0bf000, OPCODE_STR2,  BASIC },
    { "Э47", 0x027000, 0x0bf000, OPCODE_STR2,  BASIC },*/
/*  { "э20", 0x080000, 0x0f8000, OPCODE_STR2,  BASIC },
    { "э21", 0x088000, 0x0f8000, OPCODE_STR2,  BASIC },*/
```

Имена в кавычках выше - дословная цитата исходника
`disbesm6.c`; это НЕ пользовательские экстракоды (ЭК - только
050..077₈). `э20`/`э21` здесь - коды 2-й структуры.

`УВВ` (КОП 032, `0x01a000`) закомментирован в `disbesm6.c:71`. Все эти коды
реальны в ЦП: `simh/BESM6/besm6_cpu.c:1477,1485,1499-1500`
(`э46`, `э47`, `э20`, `э21` - имена в simh, не ЭК), `optab.c:61` содержит `x47`.
`э20`/`э21` (коды 0200₈/0210₈ 2-й структуры,
системные ловушки, не ЭК), векторы `0560`/`0561`
(алиас `э60`/`э61`,
`simh/BESM6/README/Memory_Mapping.md:539-540`).

| слот | код | маска | структура | где живёт | вердикт |
|---|---|---|---|---|---|
| КОП2 020 | `0x080000` | `0x0f8000` | 1-я | `disbesm6.c:109` (коммент.), simh | COMMAND (резерв таблицы 06/78) |
| КОП2 021 | `0x088000` | `0x0f8000` | 1-я | `disbesm6.c:110` (коммент.), simh | COMMAND (резерв таблицы 06/78) |
| Э46 | `0x026000` | `0x0bf000` | 2-я | `disbesm6.c:83` (коммент.), simh | COMMAND (резерв таблицы 06/78) |
| x47 (КОП 047) | `0x027000` | `0x0bf000` | 2-я | `disbesm6.c:84` (коммент.), optab.c:61 | COMMAND / EXP-ADDRESS |
| УВВ (КОП 032) | `0x01a000` | `0x0bf000` | 2-я | `disbesm6.c:68` (коммент.) | COMMAND (резерв таблицы 06/78) |

**Важно (факт).** `None` само по себе НЕ доказывает, что слово — данные,
и НЕ доказывает EXP-адрес. EXP-бит — бит 18 (`0x40000`); для 2-й структуры
`siprod_asm.py:115` прибавляет `0o700000` к младшим 12 битам. Только когда
у **неразбираемой** половины `exp=1` и адрес `≥ 0o700000`,
можно говорить об EXP-адресе. Таких слов два:
`0140:1423` (R `x47 (КОП 047)`, `'704246'`) и `0147:0576` (R `x47 (КОП 047)`, `'707174'`).

KOI-7 таблица мнемоник (`0137:0060–0120`, копии в `0141`, `0142`, `0143`)
даёт второй источник `None`: 6 байт слова читаются как 4 знака KOI-7
имени + 2 байта атрибута. Код `047` в `2047xxxx` — совпадение битов
текста с битами КОП 047 (x47), а не экстракод. Подробно:
`docs/ILLEGAL-HALVES-ANALYSIS.md:34-158`. Ложные пары `Э66`/`ЗПМ`
в этой таблице сведены в `КОНД` (как в `MBE2-Z0540.be:1000`).

## 6. ГИПОТЕЗЫ И ОГРАНИЧЕНИЯ

1. **ГИПОТЕЗА.** Слова со слотами КОП2 020/021, КОП 046, x47, УВВ (КОП 032) в линейном
   коде являются командами с зарезервированным в таблице 06/78
   opcode. Факты: коды есть в `disbesm6.c` (закомментированы) и в
   `simh`. Гипотеза: именно COMMAND, а не данные, в конкретных адресах.
2. **ГИПОТЕЗА.** Принадлежность слов `0140:1202–1464`, `0141:0676–0747`,
   `0142:1710–1765`, `0143:1202–1347` к линейным процедурам
   (по соседним командам и комментариям); альтернатива — таблица
   адресов, где `'34526'`, `'46131'` и др. — данные.
3. **ГИПОТЕЗА.** EXP-адреса в `0140:1423` и `0147:0576` — именно адреса,
   а не случайный EXP-бит: факт только exp=1 и 15-битный адрес `≥ 0o700000`.
4. **ФАКТ.** KOI-7 таблица и её копии: байты читаются в KOI-7,
   в GOST — мусор; `dis/MBE-Z0137-L1.asm` печатает `конд`.
5. Символическая замена для слотов КОП2 020/021, КОП 046, x47, УВВ (КОП 032)
   **невозможна**: мнемоники нет в таблице транслятора 06/78,
   подмена Э60/Э61/СТОП меняет биты. Поэтому все такие слова
   оставлены `КОНД` (байты сохранены).
