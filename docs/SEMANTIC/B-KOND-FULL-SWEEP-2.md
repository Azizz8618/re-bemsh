## 2. МЕТОД

1. Адрес слова = индекс в `gold/MBE-Z<зона>-L1.bin`. Перед
   каждой правкой сырое слово из `.be` сверялось с эталоном:
   расхождений 0 (проверено для всех 2527 слов).
2. Слово делится на две половины, каждая разбирается
   `siprod_asm.decode()`: мнемоника, `kind`, регистр, адрес,
   DMS/EXP/структура.
3. reg печатается восьмеричным `(Мn)`; для reg ≥ 8 номер
   увеличивается на 2 (`reg 9` → `(М11)`, `reg 15` → `(М17)`),
   что точно воспроизводит биты 23..20 включая DMS.
   Для `reg1` первый операнд - регистр (`Мn`), второй -
   `(Мk)`; EXP печатается 5-значной формой `'7abcd'`.
   Адреса ≤ `0o777` пишутся числом `'n'`, большие -
   `P`-меткой (цели) или `C`-меткой (ячейки).
4. Метки `ЭКВ` не порождают слово. Формат строк 0137
   сохранён: `        МНЕМ   'арг'(Мn), из КОНД, левая
   (гипотеза)`; комментарии только после запятой, ≤55
   символов, строка ≤60 колонок.

### 2.1. Причины, по которым замена НЕ производится

Экспериментально (через `rebuild-zone.sh`) установлено:

| причина | поведение транслятора | решение |
|---|---|---|
| левая `call`/`addrex`/`stop`/`imm2` | авто-вставка `мода`, сдвиг слова | `КОНД` |
| левая immex, кроме `Э66` | авто-вставка `мода`, +1 слово | `КОНД` |
| `EXP`-бит в любой половине | дополнительное слово адреса | `КОНД` |
| `пио36` | мнемоники в 06/78 нет | `КОНД` |
| `illegal` в любой половине | нет символической формы | `КОНД` |
| `reg1` с аргументом > 0o17 | поле не кодируется | `КОНД` |

`Э66` слева принят (14/14 OK в зоне 0137), поэтому его
разрешено переводить. RIGHT-половина `call`/`addrex`/`immex`
обычно принимается (в 0137 переведены `ПВ`, `Э50` и др.).

## 7. ОГРАНИЧЕНИЯ И ИСТОЧНИКИ

- Вердикт «переведено» означает только НАЛИЧИЕ команд и
  побайтовую идентичность. Бизнес-роль пар - ГИПОТЕЗА
  (как и в `Z0137-KOND-FULL-SWEEP.md` §6).
- Метки `P`/`C` дают адрес, но не доказывают, что `P` - точка
  входа или что `C` - именно ячейка данных; это гипотеза
  по контексту.
- Опытным путём установлено, что переход на `ЭКВ`-метки не
  меняет байты (в отличие от EXP/immex слева); поэтому
  метки использованы для целей ветвлений/вызовов и ячеек,
  а малые адреса оставлены числами по образцу 0137.
