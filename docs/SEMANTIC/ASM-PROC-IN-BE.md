## 1. Что сделано

В четыре ASM-модуля (`bemsh/ASM-Z0055.be`, `ASM-Z0056.be`,
`ASM-Z0057.be`, `ASM-Z0060.be`) добавлены полные описания
процедур **только в `*`-комментариях** перед меткой
`*** КОД МОДУЛЯ`, то есть до первой машинной строки.

Формат блока на каждую процедуру (3-5 строк):

```
* ПРОЦ <старт>-<конец> size=<N> <вид>
*   ВХ <вход>; ВЫХ <выход>
*   РЕГ <регистры>
*   СМЫСЛ: ГИП: <механическая роль / гипотеза о функции>
*     <продолжение со звёздочкой>
```

Обозначения (приведены в легенде каждого файла): `C<n>` -
входов по CALL (пв), `B<n>` - входов по ветвлению, `Rnnn` -
RET (`пб Мn`) в слове `nnn`, `Xnnn` - уход из зоны,
`ГИП` - гипотеза по коду (исходника автокода ИТМ нет).

Все границы, размеры, регистры, входы/выходы и формулировки
функций взяты из разделов 5.1-5.2, 6.1-6.2, 7.1-7.2, 8.1-8.2
`docs/PROCEDURES-ASM.md`. Там, где источник не даёт функции,
записана механическая роль и пометка "смысл ИТМ неизвестен":
не делалось ни одного домысла сверх текста источника.

комментарии не попадают. Независимая проверка: после
