## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: ИСПОЛНЯЕМЫЙ КОД МАКРОКОМПИЛЯТОРА — основной
  цикл с частыми CALL `пв '5013'(М16)` и ветвлениями,
  работающий с ячейками 52xx/54xx. 4 кластера (53+4+6+6)
  бинарных дескрипторов [36-битный тег | 12-бит адрес],
  не 69 подряд (`analysis/DESCRIPTORS-69-53.md`,
  `analysis/Z0565-ROLE.md`); `022000000300 | указатель`:
  ДАННЫЕ-дескрипторы внутри кода, не содержимое зоны.
  0565 = код B2-макрокомпилятора, 151 CALL в page 02,
  вход 0000→02040, флаг D01167=0 выбирает 0570.

EVIDENCE:
- `D` даёт только 3 код-слова, дальше `конд` (обрыв на
  `пб 2040`) [D:7-10];
- `F`: 998 «сильных» слов в 13 блоках, 151 CALL
  `пв '5013'(М16)` (31 из них с адресом '5013'), 159 `пб`,
  61 `пе`, 50 `по`, 31 `пино` [F];
- siprod_asm.decode: 99.9% валидных половин
  (1022/1024 слева, 1024/1024 справа);
- `grep -c '022000000300' D` = 69 (то же в 0165) —
  дескрипторы перенесены, но не являются телом зоны;
- B-аналог 0165 — «МАКРОКОМПИЛЯТОР. ГЛУБОКАЯ СЕМАНТИКА»
  [docs/SEMANTIC/Z0165.md], class S [versions.md:103].

_confidence_: ПОДТВЕРЖДЕНО (код, CALL/RET, дескрипторы,
  search); ГИПОТЕЗА («программа печати/проверки»).

### 6.5 Почему прежняя классификация неверна
`D` обрывается на `пб 02040`, объявляя всё остальное
  `конд`. В `F` тот же участок — связная программа с
  151 CALL, ветвлениями и 17 регистрами. Дескрипторы —
  вставка (4 кластера), а не содержание зоны.

## 7. НЕИЗВЕСТНОЕ

1. Семантика CALL '5013' (печать? проверка?) — нет
   исходника; 31 вхождение это подтверждает только
   шаблон вызова.
2. Где физически лежит подпрограмма '5013' (в 0566?).
3. Смысл 69 указателей 03135–04017 и тега
   022000000300.
4. Роль базы 5450 и перехода 02040.
5. Почему class S с s=−4: границы 0565/0566 при
   сдвиге 0165 не совпадают [versions.md:103].
6. Трассировка `-R16=<адрес>` не делалась; адреса
   CALL через (М16) — поле, не значение регистра [REG §4].
7. Точные границы блоков 0767–1561 оценены по `F`,
   не по инструкциям возврата.
