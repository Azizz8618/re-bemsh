# ЗОНА 0554 — МАКРОРЕДАКТОР B2. ГЛУБОКАЯ СЕМАНТИКА

Статус: ФАКТ = адреса/слова/байты; ГИПОТЕЗА = роль.
B2 = старшая копия 0540–0577₈ (ВАР.12/77).
Адреса восьмеричные. Зона = 1024 слова (6144 байт).

## 1. РОЛЬ ЗОНЫ

Первый проход конвейера B2. Роль доказана штампом
0554.0751–0755:
  «МАКРОРЕДАКТОР ОТ 10.04.76» (GOST-10859).
Дата 10.04.76 — на 2 года 2 мес. старше B-штампа
  (0154: 20.06.78). B2 не содержит даты 1978 г.

Счётчик таблицы ГС: 0554.1236–1237
  «-КОЛИЧ ЯЧ ГС» (в B — 0154.1450).
Факт из B-эксперимента (MACRO-TABLE-FORMAT-VERIFIED):
  одно простое макроопределение = 2 ячейки ГС;
  для B2 эксперимент НЕ проводился (открытый вопрос).

Свидетельство кода (ФАКТ): 0554 загружена в ОП?
  B2-карта не снималась; для B (0154) доказан запуск
  по 02000₈ (MEMORY-MAP.md). Перенос на B2 —
  ГИПОТЕЗА по аналогии.

## 2. ЧТО РЕАЛЬНО ИСПОЛНЯЕТСЯ

`-a0 -e0`, два код-слова:
  0554.0  START сч '5617'
    +1           Э50 '103'
  0554.1         пб '2757'
Действие: загрузка константы 5617, экстракод 50,
  прямой переход на 2757 (тот же, что в B).
Регистры: полей (Мn) НЕТ. Вход/выход не прослежены.
Возврат прямой, НЕ (М15).
CROSSREF.md: BR=1, CALL=0, EX=1, КМ=0, ДМ=0.
Забелы `пам`: 5. Остальное — `конд`: 21 текст
  и числовые таблицы. Процедур НЕТ.

ОТЛИЧИЕ от B: константа `сч '6065'` → `сч '5617'`
  (изменена на 0250₈); Э50 '103' и пб '2757' те же.

## 4. СВЯЗЬ С МАКРОКОМАНДАМИ
