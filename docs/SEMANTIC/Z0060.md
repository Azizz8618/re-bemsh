dis/ASM-Z0060-L1.asm:N; `be:N` = bemsh/ASM-Z0060.be:N;
`PLAN:N` = docs/PLAN.md:N; `REG` = docs/REGISTERS.md;

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: зона `ТРАНСЛЯТОР С А/К И Т М` (автокод ИТМ,
`.75`), НЕ БЕМШ [PLAN:18; FINAL-REPORT:19]. 8 код-слов
+ островок `пб (М1)` в слове 20. Код готовит таблицу
D00721 через индекс М13, извлекает поле `сда 64-29`,
пишет D00777 и вызывает подпрограмму '6727' через М1.
Данные слов 10-17 — таблица дескрипторов 07200-07250.

EVIDENCE:
- 8 полупар в 0000-0007 [060:7-21; be:15-30];
- `A00020 пб (М1)` — код-островок в массиве `конд`
  [060:30; CROSSREF §5.2: next insn used as data];
- слово 0 = `уи М17; нтж D00721` — инициализация
  таблицы [060:7-8].

_confidence_: ПОДТВЕРЖДЕНО (каталог, 8+1 слов кода,
таблица 072xx); ГИПОТЕЗА («табличная утилита», смысл
D00721/D00777).

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

Блок 0000-0007 + островок 0020. ВХОД: START.
ВЫХОД: D00777, переход '6017'.

```
0000 уи М17; нтж D00721
  обнулить М17 и подготовить адрес таблицы D00721
  [060:7-8].
0001 нтж D00721-9(М13); по '6017'
  адрес таблицы с базой М13; если флаг — сразу выход
  на 6017 [060:9-10].
0002 нтж ...; зп D00721-9(М13)
  прочитать и тут же записать ячейку таблицы —
  типичная модификация дескриптора [060:11-12].
0003 сда 64-29; слц (М13)
  выделить поле 64-29 (число 35₁₀) и счесть/сложить
  с индексом М13 [GUIDE §5; 060:13-14].
0004 зп D00777; счи М1
  результат в D00777; инкремент М1 — подготовка
  к вызову [060:15-16].
0005-6 зп '6727'; пв 16(М1); мод '6727'; уиа 0(М1)
  CALL на 6727 с адресом возврата в М1, затем
  перенастройка адресации на ту же базу [060:17-20].
0007 пб '6017'
  уход на общую цель 6017 в конце таблицы [060:21].
0020 пб (М1)
  косвенный выход через М1 — объект CROSSREF §5.2
  «next insn used as data» [060:30].
```
Слова 10-1777 — данные: 23 `пам`, 873 `конд`
(856 числовых); трасса оборвана на 0007.
`пб (М1)` в 20 — не CALL.

## 7. НЕИЗВЕСТНОЕ

1. Природа D00721 и D00777 (таблица/результат ИТМ).
2. Смысл поля `сда 64-29` (35₁₀) без исходника ИТМ.
3. ('6727') — CALL-цель; ('6017') — общий выход;
   физическая привязка не установлена.
4. Что такое 6 дескрипторов 07200..07250.
5. Почему `пб (М1)` в слове 20 попал в массив данных.
6. Заголовок `.be` называет зону БЕМШ (ошибка шапки).
