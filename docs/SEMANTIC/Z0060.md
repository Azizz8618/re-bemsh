# СЕМАНТИКА ЗОНЫ 0060₈ (АСМ ИТМ, ИСПОЛНЯЕМЫЙ МОДУЛЬ)

Основа: bemsh/ASM-Z0060.be, dis/ASM-Z0060-L1.asm,
dis/ASM-Z0060-full.asm (принудительный W_CODE),
gold/ASM-Z0060-L1.bin (1024 слова). Образ — read-only
/usr/local/share/besm6/2348. evidence: `060:N` =
dis/ASM-Z0060-L1.asm:N; `F:N` = dis/ASM-Z0060-full.asm:N;
`be:N` = bemsh/ASM-Z0060.be:N; `PLAN:N` = docs/PLAN.md:N;
`GUIDE` = docs/DISBESM6-GUIDE.md; `TC` =
docs/TEXT-DECODING-INVESTIGATION.md; `ASM` = siprod_asm.OPS.

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: зона `ТРАНСЛЯТОР С А/К И Т М` (автокод ИТМ,
`.75`), каталог `0000.0204` — НЕ БЕМШ [PLAN:18;
FINAL-REPORT:19]. Это ИСПОЛНЯЕМЫЙ МОДУЛЬ, а не
«8 код-слов + таблица дескрипторов 07200-07250»,
как утверждали be:5-6 и прежняя версия файла.

ИСПРАВЛЕНИЕ ОШИБКИ (главное):
- принудительный W_CODE на все адреса даёт 0 `конд`,
  0 `пам`, ~1951 строк команд [F; ASM-CODE-RECOVERY
  §2.3; GUIDE §1]; 2038/2048 = 99.51% половин
  получают имя из `siprod_asm.OPS`; не декодируются
  лишь 10 половин [ASM; ASM-CODE-RECOVERY §2.4].
  «Дескрипторы» 0010-0016 —
  исполняемые `зп (М10); зп '77200'` и т.п. [F:38-50];
- L1-трасса оборвалась после слова 7 (`пб '6017'`)
  и на косвенном `пб (М1)` в слове 20; всё остальное
  попало в `конд`/`пам` — дефект классификации
  [060:21,30; GUIDE §3], а не данные;
- три старых чтения неверны:
  (а) `D00721-9(М13)` — артефакт окна fuzz=64:
      реальный адрес `0710₈(М13)` [060:9-12; F:10-13;
      GUIDE §2];
  (б) CALL идёт не на '6727': `зп '6727'` — запись
      в ячейку, а `пв 16(М1)` — CALL по `020₈+(М1)`
      (16 — десятичное представление 020₈) [060:17-18;
      F:23-24]; 020₈ и есть «островок» `пб (М1)`;
  (в) `сда 64-29` — это ASN/сдвиг влево на 29,
      а не «поле 64-29 = число 35» [ASM; re-forex
      docs/lib21/04-extract-codes.md:72].

EVIDENCE программного смысла:
- `уи М17; нтж D00721` — инициализация таблицы
  [060:7-8]; `сда 64-29; слц (М13)` — выделение
  поля индекса [060:13-14];
- `зп D00777` — запись в ячейку-вектор, которая
  содержит `выпр '70707'(М17)` — общий шлюз ИТМ
  [060:15; 060:494; 055:7; 056:7];
- `пв 16(М1)` + `пб (М1)` в 020 — CALL и косвенный
  переход: настоящая dispatching-пара [060:18,30].

_confidence_: ПОДТВЕРЖДЕНО (каталог, 99.51% opcode,
0 `конд` при W_CODE, CALL→020, сдвиг ASN, шлюз 70707);
ГИПОТЕЗА (смысл таблиц 0710/0721 и ячеек 0772xx).

`(Мn)` — поле команды, не доказанное значение;
disbesm6 не трассирует регистры [REG §4; GUIDE §3].

[REG §3M15]. Читать М5/М12 как «шум таблиц» из
Z0146 здесь нельзя: 99.51% слов — исполняемый код.

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

Блок A — шлюз 0000-0007. ВХОД: START. ВЫХОД: '6017'.

```
0000 уи М17; нтж D00721
  сбросить индекс М17 и взять ячейку D00721 —
  подготовка таблицы/указателя [060:7-8].
0001 нтж 0710(М13); по '6017'
  прочитать ячейку таблицы 0710 с индексом М13;
  по — досрочный выход на 6017 (общая цель с 0007)
  [060:9-10; F:9-10]. `-9(М13)` в L1 — fuzz, не
  смещение [GUIDE §2].
0002 нтж 0710(М13); зп 0710(М13)
  чтение и запись той же ячейки — модификация
  дескриптора/указателя, а не «пустая таблица»
  [060:11-12; F:11-12].
0003 сда 64-29; слц (М13)
  ASN: сдвиг влево на 29 разрядов (N=64−29=35₁₀
  из поля 0043₈), затем сдвиг/выборка по М13 —
  выделение номера ячейки (ГИПОТЕЗА) [060:13-14;
  ASM; re-forex 04-extract-codes.md:72].
0004 зп D00777; счи М1
  записать результат в ячейку-вектор 0777, где
  лежит `выпр '70707'(М17)` — шлюз ИТМ; увеличить
  индекс М1 [060:15-16; 060:494].
0005 зп '6727'; пв 16(М1)
  записать слово в ячейку 6727₈ и CALL на 020₈
  с индексом М1 (16₁₀ = 020₈); возврат в М15.
  Это НЕ «CALL '6727'» [060:17-18; F:23-24].
0006 мод '6727'; уиа 0(М1)
  настроить адресацию на 6727 и зафиксировать М1
  перед косвенным переходом [060:19-20].
0007 пб '6017'
  безусловный общий выход; оборвал трассу L1
  [060:21].
```

Блок B — инициализация 0772xx, 0010-0016. ВХОД: 0010.
```
0010-0016 зп (М10)/(М11); зп '77200'..'77250'
  исполняемые команды записи в ячейки 077200..
  077250 с индексами М10/М11 — настройка блока,
  а не «таблица из 6 дескрипторов» [060:22-28].
```

Блок C — CALL-островок и продолжение 0020-0716.
```
0020 пб (М1)
  косвенный переход через М1 — настоящая цель
  CALL из 0005; «одинокий код в массиве данных»
  на самом деле dispatching-вектор [060:30; F:49].
0021-0027 счи/уи М1, нтж '6726', сда 64-63(М1),
  нтж/зп '7210'(М17) — сдвиг влево на 63 и работа
  с таблицей 07210 [060:33-36; F:50-62].
```
Хвост 0717-1777: D00721/D00777 и повтор
`выпр '70707'(М17)` в 0770-0777 — векторное
заполнение шлюза; считать данные, не «бессмысленный
мусор» [060:487-494; view].

## 7. НЕИЗВЕСТНОЕ

1. Содержание и роль ячеек 0710/0721/0777 и
   077200-077250 без карты памяти ИТМ.
2. Точный смысл сдвигов `сда 64-29`, `64-63` —
   гипотеза «выделение поля адреса/индекса».
3. Адреса '6017', '6727', '6726', '77200..' —
   физическая привязка не установлена.
4. Роль М13: индекс таблицы или fuzz-артефакт
   `-9(М13)` (последнее доказано для L1).
5. Механизм CALL 020→`пб (М1)` и что именно
   попадает в М1 перед островком.
6. `.be` ошибочно называет зону БЕМШ [be:2-6];
   каталог даёт АСМ ИТМ `.75` [PLAN:18].
