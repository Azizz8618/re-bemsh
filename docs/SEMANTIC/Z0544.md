## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

ВХОД: управление из 0547/0545 (ядро). ВЫХОД: `пб '605'(М2)`.

```
0000 уиа '40000'(М2)  загрузить базу 40000₈ в М2 —
      настройка адресации [REG §4]
0000 пб '605'(М2)     переход по адресу 605₈ с индексом М2;
      возврат прямой, НЕ (М15) [0544:7]
0001+ ДАННЫЕ/ТЕКСТ    не исполняются: 0 CALL, 0 меток кода;
      трасса обрывается на слове 0 [XR:97].
```
Почему 0001+ данные: сообщения — GOST-текст, `конд`,
`пам`-разделители, повторяющиеся машинные слова; ни одной
  цели
вызова [0544:8+; V:115].

Дополнение (текстовые константы): Пул сообщений 0275+ — GOST-текст, `конд`; выполнение обрывается
на слове 0 (`пб '605'(М2)`), текст не исполняется [Z0544 §6].

## 7. НЕИЗВЕСТНОЕ

1. Сокращения «КОР КОМ», «ИКОП», «ОШ.ПК Р В С», «ОШ НОМ СП».
2. Куда ведёт `пб '605'(М2)`; роль базы 40000₈.
3. Наиболее сильная B↔B2-находка: зона ИДЕНТИЧНА (diff=0),

   [V:87,115-116].
