# Применение глобальной таблицы литерал → метка к зонам АСМ ИТМ (0055–0060₈)

Источник таблицы: `sym/ALL_LABELS.tab`, методология и оговорки — `docs/LITERAL-LABELS.md`.
Инструмент: `python3 tools/literal_labels.py --apply-zone <Z> --mode ASM`.
Побайтовая проверка: `bash tools/rebuild-zone.sh <Z> ASM` → `1024/1024`, `0 различий`, «Файлы идентичны».

## 1. Результат по зонам

| зона | адресных литералов до→после | меток добавлено | rebuild result |
|---|---|---|---|
| 0055 | 936 → 0 | 474 | PASS 1024/1024, «Файлы идентичны» |
| 0056 | 1169 → 0 | 544 | PASS 1024/1024, «Файлы идентичны» |
| 0057 | 1362 → 0 | 614 | PASS 1024/1024, «Файлы идентичны» |
| 0060 | 905 → 0 | 436 | PASS 1024/1024, «Файлы идентичны» |

Итого: 4372 адресных операнда заменены, 2068 определений `ЭКВ` добавлено, 4/4 зон побайтово идентичны эталону.

Подробности подсчёта (все кавычные операнды кодовой части, без `ЭКВ`-определений):

| зона | всего литералов до→после | CONSTANT осталось | `ЭКВ` до→после |
|---|---|---|---|
| 0055 | 957 → 21 | 21 | 22 → 496 |
| 0056 | 1188 → 19 | 19 | 22 → 566 |
| 0057 | 1378 → 16 | 16 | 22 → 636 |
| 0060 | 929 → 24 | 24 | 22 → 458 |

«До» взято из `.bak.<timestamp>` (сохранён инструментом перед записью); «после» — из текущего `bemsh/ASM-Z<Z>.be`.
Счётчик использует ту же функцию `classify()`, что и `--apply-zone`: `ADDRESS`/`AMBIGUOUS` — заменяемые, `CONSTANT` — нет.

их числовое поле не является адресом ячейки (`docs/LITERAL-LABELS.md` §1, §5.3).

| 0056 | 19 | 7 | 9 | 3 |

## 3. Оговорки

1. **0055 не перекладывался повторно.** Родитель-агент применил `--apply-zone 0055` сам до начала
   моей работы; мной выполнена только проверка `rebuild-zone.sh 0055 ASM` → PASS. Двойного
   применения не было: число `ЭКВ` выросло ровно с 22 до 496 (= 474 вставки), замен — ровно 936,
   что совпадает с «до» по `.bak`. `.bak` зоны 0055 оставлен нетронутым (создан не мной).
2. Метки — **аннотация, не ground truth** (`docs/LABEL-MAP.md` §0, `docs/LITERAL-LABELS.md` §5).
   Роли выведены из `GLOBAL.tab`/`SEMANTIC`, а не из исходника транслятора; одинаковое восьмеричное
   число в зонах 0055 и 0147 — разные ячейки (адреса zone-local).
3. В 0056 один операнд попал в класс `AMBIGUOUS` (confidence `ГИПОТЕЗА`): `СД '4516'` (слово 672)
   → `СД AM4516`. Это единственная замена с неопределённой контекстом ролью; остальные 4371 — `ADDRESS`.
4. Вставленные строки `ЭКВ` не порождают слово, поэтому 48-битные слова не меняются; все четыре
   зоны дают `RESULT: PASS` и «Файлы идентичны» (2000 слов / 6144 байт каждая).
5. Длина строк: инструмент укорачивает только хвост комментария после первой запятой до ≤78 символов;
   кодовая часть не трогается. Проверено: `maxlen=78`, строк длиной >78 и >80 — **0** во всех четырёх файлах.
6. Блок `ЭКВ` вставлен сразу после строки `М` (строка 14), до первой кодовой строки:
   0055 — строки 19–549, 0056 — 19–618, 0057 — 19–686, 0060 — 19–514; `ЭКВ` после кода — 0.
7. `.bak.<timestamp>` для зон 0056/0057/0060 удалены после успешной проверки. Файлы других семейств
   (`MBE-*`, `MBE2-*`) и прочие каталоги (`tools/`, `sym/`, `gold/`, `dis/`) в рамках этой задачи не изменялись.
