### 6.4 Почему прежняя классификация неверна
`D` останавливается на `пб` в слове 1 и печатает
  806 `конд`; `F` с W_CODE на всех 1024 словах даёт
  788 осмысленных команд, 40 CALL, 150 возвратов и
  19 циклов. Это код, а не таблица: нули занимают
  только первые 255 слов.

   гипотеза по CALL-шаблону; исходника нет).
2. Куда ведут CALL '2277', '3162', '4550', '3300',
   '2443', '2367'.
3. Причина 255 нулевых слов в начале (резерв?

4. Почему CALL идут через М4/М6/М11/М17, а не М15 —
   трассировка `-R<N>=<адрес>` не проводилась.
5. Точные границы блоков 0554–1503 оценены по `F`,
   не по возвратам.
6. B-копия 0172 классифицирована так же ошибочно;
   class C diff=316 — правка констант в коде.
