# ЗОНА 0175₈ — почти пустая зона с двумя STOP (ГИПОТЕЗА)

Дата: 20.11.2026. Образ 2348 (read-only).
Источники: `dis/MBE-Z0175-L1.asm` (`0175:N`),
`bemsh/MBE-Z0175.be` (`be:N`), `gold/MBE-Z0175-L1.bin`,
`analysis/CROSSREF.md` (`XR`), `docs/ANCHORS.md` (`AN`).
Адреса восьмеричные.

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: ГИПОТЕЗА — резервная/почти пустая зона: 1020 из
1024 слов — нули; 4 ненулевых слова образуют ДВЕ пары
«ячейка адреса + STOP» (242/243 и 250/251).
Собственного штампа нет; `besmtool search` известных
штампов — 0 попаданий. В регионе таблиц справок
(AN:57–60) — сосед 0174/0176.

EVIDENCE:
- XR:90: `Z0175 КМ=0 ДМ=0 BR=0 CALL=0 EX=0 FZ=0` —
  абсолютный минимум активности (наравне с 0153/0172);
- distinct word = 5: 1020 нулей + 4 уникальных;
- `0175:332-347`: слова 242/250 — `зп START` + `зп
  '2035'/'2032'`; слова 243/251 — `стоп` + `зпм`
  (`.be:339-354`);
- забелов `пам` НЕТ: весь хвост — нули `зп START`;
- все 4 кодировки `besmtool view` не дают текста.

_confidence_: ВЫСОКАЯ (структура, STOP-слова); НИЗКАЯ
(назначение — «точки останова/резерв» по шаблону).

```

### 3.2 Вторая пара (ДАННЫЕ/КОД)

```
0250  0000000000002032₈ → 00 00 00 00 04 1a
  L=зп START, R=зп '2032'.
  view `0175.0250:` GOST «00004‘, 00×0» — мусор.
0251  0330000000012000₈ → 0d 80 00 00 14 00
  L=стоп, R=зпм '2000'. [0175:346-347; be:353-354].
```
`0x0d8000` (octal `0330000`) в левой половине — opcode
`стоп` (disbesm6), в правой — `0x001000`/`0x001400`,
что .be читает как `зпм`. Точная семантика пары
«2035/2032 + стоп» не установлена (§7).

## 4. ПЕРЕМЕННЫЕ И ЯЧЕЙКИ

```
ячейка/имя    роль            кто пишет   кто читает
'2035'        адрес STOP-1    — (конст.)  зп (0175:333)
'2032'        адрес STOP-2    — (конст.)  зп (0175:345)
'2000'        параметр STOP-2 — (конст.)  зпм (0175:354)
0233/243      STOP-точки      —           стоп (:334,:346)
```
`ВХ-счётчик` (XR §4): зона 0175 отсутствует в топ-20;
`ДМ=0`, поименованных ячеек с входящими ссылками нет.
Ссылок на STOP-точки из других зон не найдено: они не
являются целями `пв/пе/пб` (BR=0).

## 5. РЕГИСТРЫ

Полей `(Мn)` в ненулевых словах НЕТ: все команды
безадресные (`зп '2035'`, `стоп`, `зпм '2000'`).
Зона не шахматная (distinct=5, но 1020 нулей, а не
чередование AA/55), поэтому псевдо-М5/М12 из Z0146
здесь не действуют (REG §1.3). `(Мn)` в `зп START` —
поле команды, не значение (REG §4).

Процедур, CALL-блоков и ветвлений НЕТ (XR:90: BR=0,
CALL=0). `стоп` не считается ветвлением в XR.

## 7. НЕИЗВЕСТНОЕ

1. Назначение зоны: резерв, тестовые STOP-точки или
   хвост таблицы справок — гипотеза.
2. Смысл пар '2035'/'2032' и '2000' (логические
   адреса? AN §1 запрещает подставлять их как зоны).
3. Почему STOP-точки ДВЕ и ни одна не является целью
   ветвления из других зон.
4. Точная семантика `зпм` как правой половины STOP-слова
   (REG/DISBESM6-GUIDE не описывают эту пару).
5. B2-аналог 0575: BR=0/CALL=0 (XR:122) — также пуст;
   побайтовое сравнение 0175↔0575 не проводилось.
