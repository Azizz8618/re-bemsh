# BEMSH-МЕТКИ И ПЕРЕКРЁСТНЫЕ ССЫЛКИ В ASM-МОДУЛЯХ (0055-0060₈)

Дата: 20.11.2026. Образ 2348 (том Д-2048/2348, МГУ; read-only).
Изменены ТОЛЬКО четыре `bemsh/ASM-Z*.be` и этот отчёт. `gold/`,
`dis/`, `sym/`, `tools/`, другие `docs/` и эталонные образы не
трогались. Ни одно машинное слово не изменено: все новые строки —
`*`комментарии и `ЭКВ`-определения (ЭКВ не порождает слово).

## 1. ПРИМЕНЁННЫЕ ПРАВИЛА BEMSH

1. Имя метки ≤6 символов, ВЕРХНИЙ РЕГИСТР, роль задана префиксом:
   `Pnnnn` — локальная цель ПБ/ПВ/ПИО/ПИНО, `Xnnnn` — внешняя
   или межмодульная цель, `Cxxx`/`CELxxx` — ячейка (уже были).
2. Определения стоят **после** макроса `М` и **до** `СТАРТ`.
3. Каждая локальная цель перехода с возвратом (адрес ≤01777₈)
   получила `P`-метку. Всего 93 новых определения.
4. Внешние адреса (>01777₈) получили компактные `X`-метки с
   комментарием, называющим цель: `CALL 3604`, `диспетчер 3762`,
   `общий выход 4012/6017`. Уже существующие `ITMGT7`, `CAL604`,
   `JMP762` сохранены как якоря; `X`-метки — дополнительные
   роль-имена для тех же чисел.
5. Над каждой процедурой добавлена `*`строка перекрёстной ссылки:
   кто вызывает вход, в формате `зона:слово`. Источник —
   `docs/PROCEDURES-ASM.md` §5-§8 (списки «вызывающие») и
   `docs/ASM-ZONE-LINKS.md`. 87 шапок дополнено.
6. Длина `*`строки ≤59, комментария ≤55, перенос со `*`,
   символ `^` не используется.

ВАЖНО: одинаковые адреса в 0057/0060 — **другие** процедуры, не
версии 0055/0056 [PROCEDURES-ASM.md §10.9]. Поэтому перекрёстные
ссылки из других зон добавлены только для подтверждённой пары
0055/0056 (общие 0220/0221/0301, 169 общих слов).

## 3. ПРИМЕРЫ

### 3.1 Общая утилита 0055/0056, вход 0221

```
* Процедура 0221: утилита, CALL A0302, выход 5620
* Вызывают P221: 0055:0377,0436,0443,0467,0653; 0056:0377
*   1012,1025,1243,1250,1270,1362,1514,1723,1745
        СЧ   (М2)       , взять через М2
```

До вставки шапка содержала только роль; вызывающие не были
указаны. Источник — PROCEDURES-ASM.md §5.1 и §6.1.

### 3.2 Локальная цель без CALL-вызовов

```
* P33: локальная цель CALL, вызывающие не найдены
P33 ЭКВ '33'
```

Метка определена после `М`; слово не порождается. Отсутствие
вызывающих — честный результат скана, а не пропуск.

### 3.3 Внешние `X`-метки

```
* --- X-МЕТКИ внешних/межмодульных целей ---
* X3604: CALL 3604: общая цель 4 зон
X3604 ЭКВ '3604'
* X3762: диспетчер 3762: 34 пары в зоне 0057
X3762 ЭКВ '3762'
* X4012: общий выход зоны 0057
X4012 ЭКВ '4012'
```

`70707` (шлюз ИТМ) в зоне 0057 отсутствует; его роль там
выполняют `4012` и `3762` [ASM-ZONE-LINKS.md §4]. В 0055/0056/
0060 шлюз остаётся под устоявшимся именем `ITMGT7`.

После **каждой** зоны выполнялся обязательный прогон:

```

bash tools/rebuild-zone.sh 0056 ASM   -> 1024/1024, PASS
bash tools/rebuild-zone.sh 0057 ASM   -> 1024/1024, PASS
```

Каждый прогон печатал `WORDS: всего=1024 совпало=1024
различий=0`, `RESULT: PASS` и `✓ Файлы идентичны (2000 слов)`.
Дополнительно проверено пословно: все строки, не являющиеся
комментариями и не содержащие `ЭКВ`, побайтово совпадают с
копиями до правки (`/tmp/.private/azizz/asm-be-bak/`).
Перед правкой созданы `.bak`-копии; откат не потребовался.

## 5. ОГОВОРКИ

1. Исходника автокода ИТМ на диске нет. Роли процедур —
   механические гипотезы по коду; факты — адреса, мнемоники,
   регистры, номера строк и списки вызывающих из каталога.
2. `A#####`/`D#####` — артефакт принудительного симтаба;
   физическая привязка адресов 70707/3604/3762/4012 не
   доказана [AGENTS.md §3, ASM-ZONE-LINKS.md §1].
3. CALL через `(Мn)` статически не разрешается; такие
   переходы в списки вызывающих не попадали.
4. Число `034 пары / 35 ссылок` на 3762 в 0057 подтверждено
   полным листингом; «~250 пар» из Z0057.md не подтверждается.
