## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: ЗОНА ЗАГРУЗЧИКА (класс L). 3 код-слова:
записать константу 11 со смещением М17, вызвать
'14342' через М16, инкрементировать М11, вызвать
'40540' через М16, выйти на '77260' через М7.
Слова 3-17 — таблица дескрипторов с повторяющимся
префиксом `7400000X`, задающим номера ячеек.

EVIDENCE:
- класс L: 0141↔0541 differ 1024/1024 words, сдвиг
  +34 не помогает [VER:83, §6 L; reloc §3];
- 3 слова кода [141:7-11; be:15-20]; CALL=2 [XR:62];
- оба вызова идут через М16 — «модифицированный
  адрес вызывающего» [REG §3M16; VER §6].

_confidence_: ПОДТВЕРЖДЕНО (класс L, 2 CALL,
префикс таблицы); ГИПОТЕЗА («таблица CALL»).

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

Блок 0000-0002. ВХОД: START. ВЫХОД: '77260'.

```
0000 зп 11(М17); пв '14342'(М16)
  записать малую константу 11 по базе М17 (номер
  варианта/ячейки), затем CALL '14342'. [141:7-8]
0001 счи М11; пв '40540'(М16)
  инкремент М11 (счётчик прохода) и второй CALL
  на '40540' — та же пара link М16. [141:9-10;
  REG §3M16]
0002 пб '77260'(М7)
  прямой уход на '77260', завершающий зону
  [141:11].
```
Слова 3-1777 НЕ исполняются: трасса обрывается на
`пам` 560 и 1563 [141:377,892]; BR=3, CALL=2
[XR:62]. Префикс `7400000X` — данные (номера
ячеек), а не команды: 0xf0 ≥ 0x4e, GOST-мусор
[view].

## 7. НЕИЗВЕСТНОЕ

1. Смысл константы 11(М17) и счётчика М11.
2. CALL-цели '14342', '40540' (нет меток в зоне).
3. Куда уходит '77260'.
4. Природа таблицы 0003-0559 (7400000X): адреса
   ячеек паспорта тома — гипотеза без исходника.
5. Почему зона полностью отличается от 0541
   (другая установка загрузчика) [VER §6 L].
