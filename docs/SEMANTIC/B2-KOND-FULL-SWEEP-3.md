## 1. ЗАДАЧА И РЕЗУЛЬТАТ

Требуется полный проход по оставшимся `КОНД` в зонах 0560–0567₈
методом `Z0137-KOND-FULL-SWEEP.md`: посчитать `КОНД`, разобрать обе
24-битные половины через `siprod_asm.decode()`, сверить слово с
эталоном и перевести байтово безопасные слова в символические
командные пары.

Результат: из 476 оставшихся `КОНД` переведено 252 слова; 224 слова
оставлены `КОНД` с честной ролью. Все 8 зон дают `RESULT: PASS`,
`1024/1024`. Fill-зоны 0560/0563/0564/0567 не изменялись: в них
изначально 0 `КОНД`, это подтверждённая шахматка AA/55, а не код.

## 2. МЕТОД

1. Перед правкой созданы `.bak` всех 8 файлов с меткой
   `20261120_sweep3`; эталонные дампы не изменялись.
2. Для каждой строки `КОНД В'................'` восьмеричное слово
   делилось на две половины; каждая разбиралась `siprod_asm.decode()`:
   мнемоника, `kind`, регистр, адрес, DMS/EXP, признак структуры.
3. Сырое значение слова сверялось с `gold/MBE2-Z<zone>-L1.bin`
   по адресу (индекс слова). Расхождений 0.
4. Регистр и адрес печатаются восьмеричными; DMS кодируется самим
   номером регистра (бит 21), поэтому `(Мn)` задаёт и регистр, и DMS.
   EXP пишется 5-значной формой `'7abcd'`.
5. Если обе половины имели мнемонику транслятора и не входили в
   список пропусков, слово заменялось двумя строками команд с
   комментариями `из КОНД, левая/правая (гипотеза)`.
6. Комментарии только после запятой, строки ≤60 колонок. Для
   пропущенных слов добавлена строка-продолжение `*` с разбором
   половин и причиной.
7. Обязательная проверка после КАЖДОЙ зоны:
   `bash tools/rebuild-zone.sh <Z> MBE2`, ожидается `1024/1024`.

### 2.1. Список пропусков (остаются КОНД)

- `illegal` в любой половине;
- `ПИО36` в любой половине (нет мнемоники транслятора);
- EXP-бит в любой половине;
- левая `пв` (CALL) - авто-вставка `мода` со сдвигом кода;
- `addrex` (`Э60`, `Э64`, `Э70`, `Э72`, `Э73`) и `stop` (`Э74`);
- **дополнительно, по результатам эксперимента:** `immex`
  (`Э50`, `Э52`, `Э54`,
  `Э62`) в любой половине. Эксперимент показал, что любая пара с
  `immex` вызывает авто-вставку `мода`: при попытке перевести 28
  слов с `Э50` зона 0566 дала 283 расхождения байтов. Поэтому
  `immex` оставлен сырым, хотя в `Z0137` одиночный `Э66` проходил.

### 2.2. Найденные и исправленные ловушки синтаксиса

- reg1 с большим аргументом: `М4512` воспринимается как НЕопределённая
  метка (5 ошибок транслятора). Для аргумента >`17₈` пишется
  `'4512'` (кавычки).
- `(М0)` тоже НЕопределённая метка: при регистре 0 суффикс
  опускается (`УИА '6413'`).

## 5. ПРИМЕРЫ ПЕРЕВОДА (байтово безопасно)

```
КОНД В'0300317102200000'  ->  ПБ   '3171' / МОДА
КОНД В'6300011702200000'  ->  ПБ   '117'(М14) / МОДА
КОНД В'7300000002200000'  ->  ПБ   (М16) / МОДА
КОНД В'0300204002200000'  ->  ПБ   '2040' / МОДА
КОНД В'6640402100740000'  ->  УИА  '4021' / КОНД (Э74 справа)
```

Примеры оставшихся КОНД с ролью:

```
КОНД В'1360000000000000'    , L:ПИО36 нет мнем.  (гипотеза)
КОНД В'7310501300060053'    , L:CALL авто-мода   (гипотеза)
КОНД В'1462744400001001'    , L:immex авто-мода  (гипотеза)
КОНД В'0360541711020051'    , L:ПИО36 R:EXP      (гипотеза)
```

Адреса записаны числами, как в методе `Z0137-KOND-FULL-SWEEP.md`
(новых меток 0). Попытка заменить их на `Pxxx`/`Cxxx` (`ЭКВ` с тем же
значением) оказалась НЕ байтово безопасной: 0561 дал 20 расхождений,
0562 - 29, 0566 - 12 (0565 прошел). Причина - иная ширина поля
адреса при сборке с меткой. Все метки откачены. Существующие
`CAxxxx`/`CELxxx` тоже не переиспользованы: значения их `ЭКВ`
часто включают DMS-бит (`BR6261 = 76264`), что делает подстановку
неэквивалентной числовому адресу.

  транслятора и сдвиг кода.
