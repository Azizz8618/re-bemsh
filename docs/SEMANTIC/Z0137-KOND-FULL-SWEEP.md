# ПОЛНЫЙ ПРОХОД ПО КОНД ЗОНЫ 0137₈: 103 СЛОВА

Дата: 20.11.2026. Образ `2348` (том Д-2048/2348 МГУ), только чтение.
Изменён только `bemsh/MBE-Z0137.be` и этот документ. `gold/`, `dis/`,
`dis-forced/`, `sym/`, `tools/` и чужие `.be` не трогались.

---

## 1. ЗАДАЧА И РЕЗУЛЬТАТ

Пользователь процитировал строки с `КОНД В'1600000000000007',
КОНД В'3707562102200000', КОНД В'2204751424450650' и спросил:
«зона 137 не почищена? пройдись по ВСЕЙ зоне!»

Все 103 оставшихся слова КОНД разобраны `siprod_asm.decode()` по
обеим 24-битным половинам. 88 слов переведено в символические
командные пары, 15 оставлено КОНД с человеческим комментарием
вместо шаблонного `, служебное слово`.

---

## 2. МЕТОД

1. Адрес слова = индекс в `gold/MBE-Z0137-L1.bin` (проверено:
   103/103 сырых слов совпали с эталоном, расхождений 0).
2. Каждое слово делится на две 24-битные половины; каждая
   разбирается `siprod_asm.decode()`: мнемоника, `kind`, регистр,
   адрес, DMS/EXP.
3. Если обе половины имеют мнемонику и левая НЕ относится к
   `{addrex, stop, call}`, слово заменяется двумя строками команд.
   Операнд берётся из полей `decode()`, а не из листинга.
   Регистр печатается восьмеричным `(Мn)`, DMS ставится битом
   регистра, EXP пишется 5-значной формой `'7abcd'`
   (`EXTRACT-74-66-DECODE-FIX.md §2`).
4. Авто-`мода` транслятора при левой ADDREX/STOP/CALL сдвигает код:
   такие слова оставлены КОНД (доказано в `B-KOND-DECODE-1.md`).
5. Проверка после каждой партии: `bash tools/rebuild-zone.sh 0137 B`.

### Применённые правила для «трудных» мнемоник

- `И`, `ИЛИ` в правой половине принимаются транслятором: DMS-бит
  ставится самим регистром `(М7)` (`Z0137-KOND-LINEAR.md`).
- `Э66` (IMMEX) в левой половине принят: 14/14 OK
  (`EXTRACT-74-66-DECODE-FIX.md`).
- `СДА` (imm64) и EXP-адрес `'77774'(М17)` приняты: 3/3 OK.
- `ПИО36` не имеет мнемоники транслятора: оставлено КОНД.
