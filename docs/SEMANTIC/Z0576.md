# ЗОНА 0576₈ — диагностика листинга (B2)

Дата: 20.11.2026. Образ 2348 (read-only, besm6).
B2 = старшая копия 0540–0577₈ (ВАР.12/77).
B-аналог: 0176₈ (REGISTERS.md §3; procedures-RESOLVED.md).
Адреса восьмеричные. Зона = 1024 слова (6144 байт).
Сдвиг штампа B→B2 = −32₈ (0176.1732 → 0576.1700).

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Зона содержит код обработки ошибок + пул сообщений
и шапку листинга транслятора. Штамп — СТАРЫЙ
(1971 г.), отличается от Basic-штампа 0547.

  0576.1700–1703: ИПМ МАГ-БЕМШ ВАР.А(12/71
  0576.1711–1731: ОШИБКИ НПК СВОБ ПЕРЕМ АДРЕС
                  КОМАНДА А ИСП N ГЕН N ИСХ МЕТКА
                  ОПЕРАЦИЯ ОПЕРАНД КОММЕНТАРИЙ

EVIDENCE:
- `besmtool search 2348 'ИПМ МАГ-БЕМШ'` →
  0176.1732 и 0576.1700 (GOST).
- Код 0576.1363 при `-n 01363=W_CODE` даёт
  `Э72 '7657'(М2)`, а не B `Э74 '4653'(М14)`
  (procedures-RESOLVED.md:120–122) — правка кода.
- CROSSREF.md §3: Z0576 КМ=3, ДМ=7, BR=11, CALL=4,
  EX=2, FZ=1.
- versions.md §5: 0176↔0576 diff=1013, s=+26, класс S.

Confidence: ПОДТВЕРЖДЕНО (штамп, bytes, search);
смысл сообщений — ГИПОТЕЗА (по контексту текста).
