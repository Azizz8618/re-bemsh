## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

ВХОД: управление загрузчиком. ВЫХОД: `пб 7(М17)`.

```
0000 пб 7(М17)       переход по сумме 7 + (М17); возврат
      прямой, НЕ через (М15) [0543:6]
0000 цикл -1(М17)    повтор с границей -1 в М17
      (типичный повтор/ожидание) [0543:7; REG §2]
0001+ ДАННЫЕ         не исполняются: 0 CALL, 0 меток кода;
      трасса обрывается на слове 0 [XR:96].
```
Почему данные: все `конд`, повторяющиеся машинные слова без
меток, ни одного входа/возврата [0543:8+].

## 7. НЕИЗВЕСТНОЕ

1. Куда ведёт `пб 7(М17)`; назначение `цикл -1(М17)`.
2. Природа таблиц 0001-1777, включая смешанный ряд
  0254-0273.
3. B 0143 — иной код (`мод D00036`, `пв '4231'(М16)`,
   `уиа '44022'(М3)` и др., 4 код-слова), B2 — одно; причина
   по class L (s=-41) не установлена [V:85].
4. Роль «загрузки/установки» — по V:120-122, гипотеза.
