# ЗОНА 0571₈ — «движок» обработки символов (B2)

Дата: 20.11.2026. Образ 2348 (read-only, besm6).
B2 = старшая копия 0540–0577₈ (ВАР.12/77).
B-аналог: 0171₈ (docs/SEMANTIC/Z0171.md).
Адреса восьмеричные. Зона = 1024 слова (6144 байт).
Собственного штампа НЕТ — атрибуция только по коду
и по таблице алфавита.

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

ГИПОТЕЗА (средняя): исполняемое ядро обработки
символов/выражений макромашины — сканнер имён по
таблице алфавита, работа со «стэком» и условиями
«АВ ИФ / АВ ВФ». Код B2 сохранился, но резко
деградировал по сравнению с B.

EVIDENCE:
- CROSSREF.md §3: Z0571 КМ=0, ДМ=1, BR=7, CALL=0;
  B-пара Z0171: КМ=2, ДМ=2, BR=47, CALL=13 —
  абсолютный пик активности в B, спад в 6 раз.
- таблица алфавита 1357–1371: «ВСDЕFG», «НIJКLМ»,
  «NОРQRS», «ТUVWХУ», «ЬЫЗШЭЩ» (GOST+латиница).
- 1561–1564: «АВ ИФ», «КОН ИФ», «АВ ВФ», «КОН ВФ».
- versions.md §5: 0171↔0571 diff=896, s=+13, класс S.

Confidence: ГИПОТЕЗА (как и Z0171.md §1): нет штампа,
динамическая карта B2 не снималась. Факт деградации
кода — ПОДТВЕРЖДЕНО (CROSSREF).

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

Базовый блок 0000–0015 (start = 0571.0):

  0: пе '3660'; по '2300' — два прямых перехода
     (ветвление по признаку, цель вне зоны).
  1: вчаб START; сч D00012 — запись и чтение флага.
  2: зп 5(М17); слиа 6(М17) — инициализация счётчиков.
  3: счи М16; зп (М17) — подготовка link и контекста.
  4–6: мода '23700'/'7776'(М7); уи М7; пио '4014' —
     настройка указателя кадра и запись в стек.
  7: нтж -2(М17); по '4014' — проверка и повтор.
  10–11: мода (М7); сч (М1); сда 64+25; и '5523'.
  12: D00012 `уи М7`; пино '4006'(М7) — вызов
     «next insn used as data» (CROSSREF §5.2).
  13–15: пио '4014'; мода START; сч (М17); уи М16;
     слиа -6(М17); пб (М16) — возврат через М16.

  Вход: D00012, ячейки 5/6(М17).
  Выход: стек '4014'/'4006'; пб (М16).
  Evidence: `dis/MBE2-Z0571-L1.asm:8–36`.

Далее 0016–1776 — данные: таблица алфавита 1356–
1371 для разбора идентификаторов (ГИПОТЕЗА),
условия 1561–1564, хвост нулей. CALL и меток кода
НЕТ: гипотеза «код макромашины перенесён в 0570»
(Z0570.md §1) здесь подтверждения не находит.

## 7. НЕИЗВЕСТНОЕ

2. Назначение D00012 и ячеек 5/6(М17).
3. Роль таблицы алфавита 1356–1371 (5 строк +
   продолжение 1364–1371) — гипотеза разбора имён.
4. Связь «АВ ИФ» (1561) с директивой `АIF` —
   написание не совпадает.
