# ПРАВКА МАРКИРОВКИ РЕГ В ЗОНАХ B2 0540-0577

Дата: 20.11.2026. Образ тома 2348 читался только.
Изменены только `bemsh/MBE2-Z*.be` (17 зон) и этот файл.
`gold/`, `dis/`, `sym/`, `tools/` и чужие `.be` не трогались.

## 1. ПРАВИЛО КЛАССИФИКАЦИИ

Валидный селектор по `docs/REG-INSTRUCTION.md` и заданию:

    Aex & 0377 в 000-007, 020-033, 036-037,
                0100-0137, 0200-0207, 0237

Всё остальное (дыры 010-017, 034-035, 040-077, 0210-0236,
0240-0377, watchdog 0140-0177) есть данные, прочитанные
как opcode 002. Наличие `(Мn)` статус не меняет.

Важное уточнение второго прохода: листинг МАКРО-БЕМШ печатает
поле opcode со знаком адреса, например `03 102 2460` вместо
`03 002 2460` для слова `15022460`. Настоящий opcode есть
`поле & 0077`. Без этой маски 11 строк с аргументами
`'72460'`, `'75417'`, `'77060'`, `'70062'`, `'70017'`
остались бы неопознанными. Селектор берётся из младших 9 бит
адресного поля, знаковый бит на него не влияет.

Отличие от `docs/REG-OPERAND-AUDIT.md`: аудит считал
подозрительным любой аргумент > 0377₈, даже при валидном
селекторе. Здесь применено
явное правило задания (только `Aex & 0377`), поэтому 38 строк
типа `'6000'` (селектор 000), `'4000'` (000), `'3433'` (033)
и `'400'` (000) оставлены без изменения.

## 2. МЕТОД

1. Для каждой зоны: `.bak` в `/tmp/.private/azizz/b2reg/bak/`,
   затем `bash tools/rebuild-zone.sh <Z> MBE2` с Private
   `REBUILD_ALL_IMAGES`, контроль `1024/1024`, копия листинга.
2. Из листинга извлекались все строки с мнемоникой `РЕГ`
   (только до первой запятой, чтобы не ловить комментарии
   «установить регистр»). Адрес = печатный минус 1.
   Каждая половина сверялась с 6 байтами из
   `gold/MBE2-Z<Z>-L1.bin` по формуле из rebuild-zone.sh.
3. Если подозрительны обе половины слова, две команды заменялись
   одной `КОНД В'<16 восьм. цифр>'` со словом из эталона.
   Если подозрительна одна половина, она заменялась сырой
   `КОНК В'<8 восьм. цифр>'`, вторая строка не трогалась.
   Для уже готовых `КОНД` с ложным комментарием менялся только
   комментарий: `, НЕ РЕГ: данные`.
4. Комментарии только после запятой, не более 55 символов,
   строка не более 60 колонок. Метки и числа не удалялись.
5. Обязательная сборка после КАЖДОЙ правки зоны. При FAIL
   предусмотрен возврат из `.bak`; сбоев не было, возвратов 0.
