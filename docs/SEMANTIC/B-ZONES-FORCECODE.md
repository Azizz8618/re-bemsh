   пары команд с регистрами, обращения к ячейкам зоны,
   ветвления/CALL — против тривиальных шаблонов
   (`зп C0000`, `сч C0000`+значение), текст GOST/KOI-7
   и шахматного заполнения.
5. ВАЖНОЕ ОГРАНИЧЕНИЕ: valid% >90% получен для ВСЕХ
   33 зон. Это слабый дискриминатор: таблица OPS
   покрывает большую часть 24-битных комбинаций
   (opcode `зп`/`сч` = 0, `мода` и др.), поэтому почти
   любое слово декодируется. Решающим был разбор
   forced-листинга, а не процент.
6. Ошибка парсера: первая версия скрипта принимала
   строки продолжения полуслова за новые адреса;
   исправлено по колонке метки `Cnnnn` (метка есть
   только в строке адреса). Выводы ниже — по
   исправленному разбору.

   1024 слов)». forced-листинг вскрыл связный блок
   0040-0117 (`уиа`, `ржа`, `пб`, `Э66/Э67`, `выпр`,

   7 разделам; интерпретация кода помечена ГИПОТЕЗА
   (нет CALL/RET-пар, нужна трассировка).
2. **Z0144.md** — было «Одно код-слово 0 ... пул
   диагностики». forced-листинг вскрыл программу
   0001-0140 с регистрами М1/М2/М3/М5/М11/М12,
   ветвлениями и CALL `пв '40130/40207/40253'`.
   GOST-тексты сохранены как данные; документ
   переписан по 7 разделам.
3. **Z0156.md** — было «Исполняемый код — только
   START-слово 0; дальше всё конд/пам». forced-
   листинг вскрыл подпрограмму 0002-0062 (битовые
