# ЗОНА 0574₈ — цикл экстракодов (B2); роль не доказана

Дата: 20.11.2026. Образ 2348 (read-only, besm6).
B2 = старшая копия 0540–0577₈ (ВАР.12/77).
B-аналог: 0174₈ (versions.md §5).
Адреса восьмеричные. Зона = 1024 слова (6144 байт).
Штампа НЕТ — атрибуция только по коду.

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

ГИПОТЕЗА (низкая): небольшой цикл обработки ячейки
через экстракоды Э72/Э52/Э55 и счётчики; возможная
подпрограмма копирования/преобразования таблиц.

EVIDENCE:
- CROSSREF.md §3: Z0574 КМ=0, ДМ=3, BR=7, CALL=0,
  EX=3, FZ=1 — три экстракода и три метки данных.
- код слов 0000–0021, забелы `пам` 36/191/767/2;
  метки D00100, D00377, D01776; `ФИНИШ`.
- versions.md §5: 0174↔0574 diff=61, s=−28, класс C.
- `besmtool search` текстов в зоне не даёт попаданий.

Confidence: ФАКТы (байты/листинг) — ВЫСОКАЯ;
роль подпрограммы — ГИПОТЕЗА.

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

Базовый блок 0000–0021 (start = 0574.0):

  0–1: зп D01776+2 (fuzz); слц START — подготовка.
  2–7: цикл '76000'(М7); зп D00100; цикл -8(М7);
     зп (М4); цикл (М7); зп D00377 — инициализация
     счётчика M7 и четырёх ячеек-указателей.
  10–14: цикл -1(М17); уи; сч '70000'(М2);
     зп D01776; зп '3770' — вторая настройка,
     М17 как граница цикла.
  15: цикл '27100'(М12); сл D00100(М4) — вход в
     цикл по ячейке D00100.
  16–20: Э72 '72656'(М12); Э52 '5714'(М12);
     цикл '23246'(М12); Э55 '4653'(М12);
     сл D00100(М4) — три экстракода над содержимым
     D00100. Экстракоды — извлечение битовых полей
     (ГИПОТЕЗА разбить на atomic-операции).
  21: пб '40100'(М14) — прямой возврат (НЕ (М15)).
  Вход: D00100, D00377, D01776.
  Выход: D00100 (перезапись); возврат на 040100.
  Evidence: `dis/MBE2-Z0574-L1.asm:9–43`.

Далее 0022–1777 — данные и забелы; процедур нет.

## 7. НЕИЗВЕСТНОЕ

1. Роль подпрограммы: что именно делают Э72/Э52/Э55.
2. Куда ведут пб '40100' и D01776 (+2 fuzz).
3. Назначение ячеек D00100, D00377, 02035/02032.
4. Причина локального сдвига блока: B 0174.0061 →
   B2 0574.0000, тогда как versions.md даёт s=−28.
5. Почему RETURN через М14, а не М15.
