## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: САМАЯ АКТИВНАЯ ЗОНА ЗАГРУЗЧИКА (класс L):

дескрипторов через М7 (9,11,12,13), правит ячейки
по базе М16/'36436', выделяет поле `сда 64+23`,
вызывает '34417' и '34562', возвращается по М16.
Данные 0024+ — дескрипторы с префиксом `00430016`.

EVIDENCE:
- класс L: 0142↔0542 1023/1024 words differ [VER:84,
  §6 L; reloc §3];
- 18 код-слов 0000-0021 [142:7-42], BR=5, CALL=2
  [XR:63: Z0142 КМ=0, ДМ=0, BR=5, CALL=2];
- `мода START; пв '34562'(М16)` [142:33-34;
  REG §3M16], возврат `пб (М16)` [142:42];
- `мода '36436'` повторяется 3 раза (слова 5,6,12)
  — база переадресации [142:18,20,28; be:23-28].

_confidence_: ПОДТВЕРЖДЕНО (18 слов, CALL/RET,
класс L); ГИПОТЕЗА (смысл полей 9/11/12/13).

## 7. НЕИЗВЕСТНОЕ

1. Что такое база '36436' и поля 9/11/12/13(М7).
2. CALL-цели '34417', '34562' без паспорта тома.
3. Смысл `сда 64+23` (87₁₀) при переадресации.
4. RETURN по М16 показан в листинге, но трасса
   обрывается — проверить -R16.
5. Природа ~996 числовых слов 0024-1777.
6. Почему 0142 и 0542 почти целиком различны
   (разная установка загрузчика) [VER §6 L].
