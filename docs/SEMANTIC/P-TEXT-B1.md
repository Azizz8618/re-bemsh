# P-тексты в модулях БЕМШ B: КОНД В → КОНД П'

Дата: 21.11.2026. Образ 2348 (Д-2048/2348 МГУ), копия B ВЕР.06/78.
Зоны: `0137`, `0140`–`0147` (9 модулей). Эталонные дампы не изменялись.

## 1. Методика

1. Для каждого слова зоны брались 6 байт из `gold/MBE-Z<зона>-L1.bin`
   (только чтение) и побайтово декодировались по таблице GOST-8
   (`dtran.cc:167`, `0…96`).
2. К переписке допускались только слова осмысленного сообщения или
   штампа: кириллица, пробелы `0F`, знаки `+ - / , . : ( ) '`, цифры
   в датах. Кандидат должен входить во фразу из docs/TEXT-CONSTANTS.md
   §5 или docs/TEXT-CONSTANTS-ALL.md §5 (B2-копии зон `0544`/`0545`
   соответствуют B-зонам `0144`/`0145` со сдвигом `+0400₈`).
3. В `.be` слово могло быть записано как одно `КОНД В'<16 цифр>'`
   либо парой строк `… , из КОНД, левая` / `… , из КОНД, правая`.
   В обоих случаях представление заменялось на одну строку
   `КОНД П'<ровно 6 GOST-символов>'`; комментарий сохранялся или
   заменялся описанием текста.
4. Байтовая безопасность: после каждой группы правок
   `make rebuild-zone Z=<зона> MODE=B` → `RESULT: PASS`, 1024/1024.
   Отдельно проверено, что каждый P-текст побайтово равен слову эталона
   по адресу (97/97 совпадений).
5. Рецепт из задания подтверждён: `КОНД П'ИПМ МА'` ↔ `КОНД В'1202745403626040'`
   (байты `28 2f 2c 0f 2c 20`). Символов больше шести → `ПЕРЕПОЛНЕНИЕ`.
