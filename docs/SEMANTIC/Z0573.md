# ЗОНА 0573₈ — справка/таблица ошибок БЕМШ1 (B2)

Дата: 20.11.2026. Образ 2348 (read-only, besm6).
B2 = старшая копия 0540–0577₈ (ВАР.12/77).
B-аналог: 0173₈ (docs/SEMANTIC/Z0173.md).
Адреса восьмеричные. Зона = 1024 слова (6144 байт).
Сдвиг штампов B→B2 = −44₈ слов (0655→0611, 0661→0615).

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Зона содержит два ГОСТ-штампа внутренних таблиц
диагностики этапа БЕМШ1:

  0573.0611–0613: ОШ.СПР.НА БЕМШ1
  0573.0615–0617: ЛИМ.СТРЕЛ.НА БЕМШ1

«ОШ.СПР.» = ошибки справки; «ЛИМ.СТРЕЛ.» = лимиты
стрелок (указателей). Это НЕ сообщения пользователю,
а заголовки таблиц ограничений/диагностики.

EVIDENCE:
- `besmtool search 2348 'ОШ.СПР.НА БЕМШ1'` →
  0173.0655 и 0573.0611 (сдвиг ровно 44₈).
- `besmtool view --start=0573 --length=1 \
    --encoding=g,k,t,i`: GOST-колонка читается как
  осмысленный русский текст; KOI7/TEXT/ITM — мусор.
- CROSSREF.md §3: Z0573 КМ=1, ДМ=5, BR=7, CALL=1,
  EX=1 — зона почти не ссылается на код: данные.
- versions.md §5: 0173↔0573 diff=943, s=−1, класс S.

Confidence: ПОДТВЕРЖДЕНО (штампы, search, bytes).
Смысл записей таблицы — ГИПОТЕЗА (как и в Z0173.md).

## 2. КАРТА ПАМЯТИ

  0000–0015    код: настройка индексов, CALL, переходы
  0016–0610    плотные данные (контроль/таблицы)
  0611–0617    два штампа + разделитель 99 (0614)
  0620         разделитель 99
  0621–0626    числа-указатели/лимиты (0621=02241…)
  0627–1331    плотные данные с байтами 0xA1–0xDE
  1334–1609    записи таблицы: [код | адрес приёмника]
  1610–1776    нули (хвост)
  1777         ff ff ff ff ff 00 — нестандартный хвост

Шаг записи в 1334–1609 — одно слово (левая половина
код, правая — адрес). B2-сдвиг структур −44₈.

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

Базовый блок 0000–0015 (start = 0573.0):

  0–4: сч D01177/01173/01200; зп 2243/2251/2253,
       или 2244 — загрузка трёх баз таблиц и
       констант в ячейки. Вход: D01177/01173/01200.
  5:   мода START; Э50 '103' — экстракод 50
       (маркер/переключение режима, REGISTERS.md §2).
  6:   уиа '2241'(М1); пв A01522(М2) — CALL:
       М1 = база 02241, М2 = адрес возврата.
  7–10: уиа 1(М1), уиа '5573'(М2), сч '4626'(М1) —
       сдвиг индекса и подготовка второго прохода.
  11–15: сбр/сда/зп/мод/по '4016'/пб '4012' —
       работа с ячейкой 02006 и прямой возврат.
  Выход: ячейки 0224x; A01522 `рег '710'; зп '4232'`.

Далее 0016–1776 — ДАННЫЕ (не procedure): штампы,
числа, 173-записная таблица ошибок. Пример записи
1334: `[020660 | 04235]`; 1522: `[0710 | 04232]`.
Значение пары — ГИПОТЕЗА: «код ошибки → ячейка».

  Evidence: `dis/MBE2-Z0573-L1.asm:8–36, 873–876,
  1212–1220`; Z0173.md §2–§4 (B-структура).

Дополнение (текстовые константы): Штампы 0611–0617 и TEXT-имена 0677+ — данные таблиц;
в §6 они не меняют порядок выполнения (КМ=1, ДМ=5).

## 7. НЕИЗВЕСТНОЕ

1. 0573.0016–0610 и 0627–1331 — байты 0xA1–0xDE;
   GOST/KOI7/TEXT/ITM не дают текста (как в Z0173.md §5).
2. Механизм индексации записей 1334–1609: явного
   `уиа <база>(Мn)`+`счи` не найдено; базы 02241/02254
   из 0621 — ГИПОТЕЗА.
3. Смысл 0x99 (разделитель) и кодов 0710/04232.
4. Почему хвост 1777 = ff…00 в B2, а в B 0173 нули.
5. CALL через М2 вместо М15 — причина правки.
