# ЗОНА 0577₈ — справка ошибок БЕМШ2 (B2)

Дата: 20.11.2026. Образ 2348 (read-only, besm6).
B2 = старшая копия 0540–0577₈ (ВАР.12/77).
B-аналог: 0177₈ (docs/SEMANTIC/Z0177.md).
Адреса восьмеричные. Зона = 1024 слова (6144 байт).
Сдвиг B→B2 = −44₈ слов (0417→0353, 1076→1032).

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Зона содержит два ГОСТ-текстовых объекта:

  0577.0353–0355: ОШ. СПРАВКИ БЕМШ2
  0577.1030–1040: шаблон сообщения
    «МОДУЛЬ <N> ЗАПИСАН В ЗОНЫ С <N> ПО <N>»

«ОШ. СПРАВКИ БЕМШ2» — заголовок таблицы ошибок
справки этапа БЕМШ2. Шаблон 1030–1040 — формат
печати о размещении модуля по зонам диска.

EVIDENCE:
- `besmtool search 2348 'ОШ. СПРАВКИ БЕМШ2'` →
  0177.0417 и 0577.0353.
- `besmtool search 2348 'ЗАПИСАН  В  ЗОНЫ'` →
  0177.1076 и 0577.1032.
- `besmtool view --start=0577 --length=1 \
    --encoding=g,k,t,i`: GOST — осмысленный текст,
  KOI7/TEXT/ITM — мусор (diagnostic GOST, TC §3).
- CROSSREF.md §3: Z0577 КМ=0, ДМ=1, BR=3, CALL=0.
- versions.md §5: 0177↔0577 diff=391, s=+36, класс S.

Confidence: ПОДТВЕРЖДЕНО (search, bytes, GOST).
Назначение чисел 0357 и масок — ГИПОТЕЗА.

`(М4)` в `пб (М4)` — поле команды; REGISTERS.md §2
отводит М4 роль «индекс/указатель (литеральный)»,
а ПОДТВЕРЖДЕНО — только М15/M16/M13.
Возврат здесь НЕ (М15): ГИПОТЕЗА о link-регистре
этапа БЕМШ2. Регистры М1–М17 больше не встречаются;
остальные слова зоны — данные/забелы `пам` (13).

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

Базовый блок 0000–0003 (start = 0577.0):

  0: сч D01111; пе '6003' — загрузка базы и печать
     по прямому адресу 06003.
  1: сч '2064'; и '6272' — константа + маска
     (проверка признака перед переходом).
  2: пе '6004'; мода START — второй вывод, сброс
     адресации.
  3: сч '6172'; пб (М4) — подготовка и возврат
     через М4.
  Вход: D01111. Выход: печать на 06003/06004;
  ячейки 06172. Evidence: `dis/MBE2-Z0577-L1.asm:8–14`.

Далее 0004–1776 — ДАННЫЕ: штамп, EOI, число, шаблон
сообщения, разделитель 99, маски. Процедур нет;
`пб (Мn)` — только слово 3. Забелы `пам`: 13
(0005, 100, 377, 1776 и др. — как labels в B-паре).
