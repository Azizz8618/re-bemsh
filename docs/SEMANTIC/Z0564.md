# ЗОНА 0564₈ — шахматный fill B2, НЕ таблица ошибок

Дата: 20.11.2026. Образ 2348 (B2 = ВАР.12/77, зоны
  0540–0577₈).
Только read-only: `besmtool dump/view`, `cmp` с `gold/`.
B-аналог: 0164₈ — байтово идентична (cmp ниже).

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: РЕЗЕРВНАЯ/ЗАПОЛНЕННАЯ зона B2. Ни текста, ни
таблиц ошибок, ни исполняемой логики здесь НЕТ.
Все 1024 слова (6144 байт) заняты шахматным шаблоном:

  слова 0000,0002,…,1776 (512) = AA AA AA AA AA AA
  слова 0001,0003,…,1775 (511) = 55 55 55 55 55 55
  слово 1777 (последнее)       = DB 6D B6 DB 6D B6

EVIDENCE:
- дамп `besmtool dump 2348 --start=0564 --length=1`
  побайтово совпадает с эталоном (cmp с gold); md5 = md5
  эталона в manifest.sha256 (одна и та же для 0146/0160/
  0163/0164/0167 и B2-аналогов).
- distinct word = 3 (Python по 6-байтовым словам):
  `aaaaaaaaaaaa`, `555555555555`, `db6db6db6db6`.
- `cmp gold/MBE2-Z0564-L1.bin gold/MBE-Z0164-L1.bin` —
  IDENTICAL (класс I, versions.md §5: 0164↔0564, diff=0,
    s=0).
- CROSSREF: Z0564 КМ=0, ДМ=0, BR=2, CALL=0 — переходов нет
  (BR=2 дают авто-START и последнее «по»).

_confidence_: ПОДТВЕРЖДЕНО (байты, cnt=3, тождество B);
ГИПОТЕЗА («резервная зона» — назначение, исходника нет).

 disbesm6 читает шаблон как код (`disbesm6.c`: вчп ст.66,
слиа ст.114, prreg ст.321):

```
0564.0000 aaaaaaaaaaaa → слиа '25252'(М12)
0564.0001 555555555555 → вчп '72525'(М5)
0564.1777 db6db6db6db6 → по '66666'(М15)
```
Байтовая причина: 0xAA=0o252, половина 0o02525252 →
reg=0o12 (М12), opcode «слиа», арг '25252';
0x55=0o525 → reg=0o5 (М5), opcode «вчп», арг '72525';
0xDB6DB6 → reg=0o15 (М15), opcode «по», арг '66666'.

## 4. ПЕРЕМЕННЫЕ И ЯЧЕЙКИ

Переменных нет. `D`-меток, обращений сч/зп к зоне 0564
извне нет (CROSSREF §4: цели D00656 и др. lie в 0547).
Слово 0564.1777 «по (М15)» — НЕ вызов:
analysis/VARIABLES-VALIDATION называет 0o66666 «RETM15»
(20 вхождений в 10 зонах), но это один и тот же
заполнитель, а не CALL.

## 5. РЕГИСТРЫ

М5 / М12 / М15 здесь — ПСЕВДО-РЕГИСТРЫ:
артефакт совпадения байтов fill с полями opcode/reg
(docs/REGISTERS.md §1.3, §3, §5 «М5/М12 — данные»).
Реально исполняемого регистра в зоне НЕТ: трасса
`disbesm6 -a0 -e0` обрывается на слове 0 (START),
дальше — `конд`. `пб (М15)` здесь не встречается.

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

Нет процедур. Единственная «команда» — стартовая
0564.0 `слиа '25252'(М12)` (артефакт decoding AA):
НЕ исполняется — это данные. Аналогично 0564.1
«вчп '72525'(М5)» и 0564.1777 «по '66666'(М15)».
ВХОДОВ/ВЫХОДОВ нет. Забел (`пам`) в зоне 0.
