# ПОЛНАЯ РЕКОНСТРУКЦИЯ B2-ЗОН ИЗ ПРИНУДИТЕЛЬНЫХ ЛИСТИНГОВ

Дата: 20.11.2026. Объект: старшая копия B2 (ТРАНСЛЯТОР С М/К БЕМШ
ВАР.12/77), зоны 0540–0577₈ (32 зоны, `bemsh/MBE2-Z<зона>.be`).
Эталоны `gold/MBE2-Z<зона>-L1.bin` и внешние образы только читались;
`tools/`, `dis/`, `dis-forced/`, `gold/`, B- и ASM-`.be` не изменялись.

## 1. ПРОБЛЕМА

Большинство B2 `.be` было получено из обычного листинга
`disbesm6 -a0 -e0`, где статическая трасса обрывалась на первом же
`пб (Мn)` / `пб <адрес>` (`docs/FORCED-CODE-SCAN.md §5.2`).
В 22 зонах это давало ~820–1025 `КОНД`-строк вместо команд.
Сканер сохранил для них полные принудительные листинги
`dis-forced/Z<зона>.asm` (0 строк `конд`, ~1700–2050 командных строк).
Остальные 10 зон полного листинга в `dis-forced/` НЕ имеют и потому
переписаны не были (см. §4).

## 2. МЕТОД

1. Вход для зоны `z`: `dis-forced/Z<z>.asm`, если он есть, иначе
   `dis/MBE2-Z<z>-L1.asm`. Генерация:
   `python3 tools/dis2be.py --input <вход> --output <temp>.be`.
2. Временный листинг имеет имя `MBE2-Z<z>-L1.asm`: `dis2be.py` выводит
   путь к gold из basename входа, и только при таком имени он находит
   `gold/MBE2-Z<z>-L1.bin`. Без gold подавленная правая половина и
   слова `конк`/`пио36`/`э72`/`э74` были бы восстановлены неверно.
3. Перед генерацией изforced-листинга сливается артефакт адреса 0:
   строка вида `0:10 044 0013  ноп` (в 0551 без двоеточия) и следующая
   за ней строка с настоящей мнемоникой (`START уии М13(М10)`) склеиваются
   в одну обычную строку листинга. Иначе `НОП` попадал в левую половину
   и транслятор вставлял слово `00 22`, сдвигая весь модуль.
4. Из старого `.be` переносятся все комментарии шапки и определения
   `ЭКВ` (вставляются сразу после `М`), включая поясняющие `*`-строки.
   В шапку добавлена честная строка
   `*   Листинг: dis-forced/Z<z>.asm (0 конд).`
5. Подстановки меток в операндах сохранены только там, где они
   побайтово безопасны: числовой `'NNN'` заменяется на имя `ЭКВ`
   при точном совпадении со значением определения (зона 0573:
   278 подстановок, все 32 `ЭКВ` на месте).
6. Постобработка после первой сборки (все правила проверены транслятором):
   * `Мnn` с `nn >= 18` (например `УИ М24`) даёт `НЕОП МЕТ ВЫР`:
     такое слово выводится сырым `КОНД` из gold;
   * ведущий `+` в операнде (`сч +1`) транслятором не принимается —
     снимается (0570, 5 строк);
   * если оставались побайтовые расхождения, соответствующие слова
     заменялись сырым `КОНД` из gold, после чего сборка повторялась.
   Это гарантирует 1024/1024 при сохранении максимума семантических строк.
7. Обязательная проверка каждой зоны:
   `bash tools/rebuild-zone.sh <z> MBE2` → `RESULT: PASS`,
   `WORDS: всего=1024 совпало=1024 различий=0`.
   Перед изменениями все 32 файла скопированы в `/tmp/b2-be-orig/`.

## 4. НЕ ПЕРЕПИСАННЫЕ ЗОНЫ

* **FILL AA/55:** 0546, 0560, 0563, 0564, 0567. Шахматка
  `слиа/вчп` из трёх уникальных слов, не код (`B2-ZONES-FORCECODE.md §4`).
  Оставлены в точности как были; их 2048 «кодовых» строк — это
  закодированные данные, а не программа.
* **0547** (ядро, `ALREADY-CODE`): полного листинга в `dis-forced/` нет,
  а существующий `.be` уже содержит 1370 семантических строк и 65 `ЭКВ`.
  Перегенерация из усечённого `dis/` потеряла бы уже восстановленный код
  и метки, поэтому файл не трогался.
* **0556, 0574, 0575, 0577** (`DATA`): полного листинга нет; это
  нули/таблицы, где forced-листинг дал бы лишь псевдо-команды. Оставлены
  без изменения.

## 7. ЧЕСТНЫЕ ОГОВОРКИ

1. Принудительная разметка делает кодом ВСЕ 1024 адреса,
   включая таблицы и константы внутри CODE-зон. Байты при этом точны,
   но семантика «инструкция» для слова из таблицы не доказана
   (`FORCED-CODE-SCAN.md §5.1`).
2. Метки `A#####`/`D#####`, `* next insn used as data`, `nop` на нулевом
   адресе и ведущий `+` — артефакты принудительной достижимости,
   а не реальные имена исходника.
3. `КОНД` в готовых файлах — не обязательно данные: это слова, которые
   транслятор 06/78 не может поставить в левую половину, а также слова,
   где принудительная дизассембляция дала расхождение с gold.
4. Число «код. строк» в таблице — это число строк с мнемоникой, а не
   число уникальных процедур; каждая пара строк — половины одного слова.
5. Зоны без `dis-forced/Z<z>.asm` оставлены прежними: их `.be` уже
   проходили 1024/1024 до этой работы, и переписывать их из усечённого
   листинга было бы шагом назад.
