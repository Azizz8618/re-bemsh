# Полные описания процедур в комментариях .be зон B 0150-0167₈

Дата: 21.11.2026. Задача: перенести ПОЛНЫЕ описания процедур
(границы, функция, вход/выход, регистры) в область комментариев
модулей `bemsh/MBE-Z<зона>.be` зон 0150-0167₈.

## 1. Источник и объём

Источник: `docs/PROCEDURES-B.md` §4 «ПОЛНАЯ ТАБЛИЦА КАНДИДАТОВ».
Каждая запись содержит:
`зона:начало-конец size=N <вид> <класс>`,
`вход: ... выход: ...`, `ВХ=n рег: ...`, `текст: ...`, `СМЫСЛ: ...`,
`ув: ГИПОТЕЗА`.

Диапазон 0150-0167₈ содержит **16 зон**
(0150-0157₈ и 0160-0167₈). В исходном задании указано
«18 файлов», что соответствует десятичному счёту 150..167;
в восьмеричной записи это 16 модулей. Обработаны все 16
существующих файлов `MBE-Z0150.be` .. `MBE-Z0167.be`.

Всего перенесено 53 записи: 21 ОСН, 4 ВЛОЖ, 28 ДАН.
Добавлено 540 строк комментариев.

## 2. Формат добавленного блока

Блок вставляется перед меткой `*** КОД МОДУЛЯ` и имеет вид:

```
* === ПОЛНЫЕ ОПИСАНИЯ ПРОЦЕДУР (PROCEDURES-B.md §4) ===
* ЗОНА <zone>: всего=N осн=A влож=B дан=C (ГИПОТЕЗА).
* ПРОЦ PROC-<start> <start>-<end> size=<N> <вид> <класс>
*   ВХ <вход>; ВЫХ <выход>
*   РЕГ <регистры>
*   ТЕКСТ <текст>          (только если есть в источнике)
*   СМЫСЛ <функция>
*   ув ГИПОТЕЗА
* === КОНЕЦ ОПИСАНИЙ ПРОЦЕДУР ===
```

Для зон без кандидатов добавляется блок с нулевыми счётчиками
и пометкой «Кандидатов в PROCEDURES-B.md §4 не найдено».

Правила, соблюдённые при переносе:

* добавлены ТОЛЬКО строки, начинающиеся с `*`;
* машинные строки, ЭКВ и операнды не изменены (проверено
  побайтово: удаление `*` строк из до/после даёт идентичный
  текст для всех 16 файлов);
* длина любой добавленной строки не более 60 символов;
* символ `↑` вместо `^`, тире не используется (заменено на `-`);
* пометка `ув ГИПОТЕЗА` сохранена для каждой записи, так как
  источник помечает все записи как ГИПОТЕЗА (STATIC-анализ без
  эталонного исходника).
