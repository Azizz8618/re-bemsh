## 4. СЛУЧАЙ `0141:449` И УВВ

Первоначально строка была отложена по указанию оператора
(гипотеза «УВВ = СТОП» проверялась исследовательским агентом).
Гипотеза **опровергнута** документом
`docs/UVV-STOP-ANALYSIS.md`:

- УВВ: КОП `033`, `0x01b000`, `OPCODE_IMM`, `PRIV`;
  `besm6_cpu.c:1372-1376` (`case 033: /* увв, ext */`),
  `cmd_033()` управляет барабанами, дисками, лентами, АЦПУ.
- СТОП: КОП `0330`, `0x0d8000`, `OPCODE_IMM2`, другая
  структура; `besm6_cpu.c:1673-1685` (`case 0330`).
- Половины слова: L = УВВ `'72100'(М12)` (КОП 033, EXP=1),
  R = Э72 `'1731'(М12)` (КОП 072).

Пересборка зоны 0141 после замены: `RESULT: PASS`,
`1024/1024`, «Файлы идентичны (2000 слов)».
Отложенных строк больше нет.

## 5. ЕДИНСТВЕННЫЙ ПРОПУСК: `0145:230`

```
КОНД В'5473466350727655' , Э73 команда Э72 команда
```

Левая половина `Э73 '4663'(М13)` относится к ADDREX.
Транслятор МАКРО-БЕМШ 06/78 вставляет авто-`мода`
`00 22 00000` перед ADDREX/STOP в левой половине и
сдвигает код: `ДЛИHA ПPOГ=02001`, 572 различия с первого
слова. Замена **не байтово безопасна**, строка оставлена
сырой `КОНД` (как и в `EXTRACT-74-66-DECODE-FIX.md` §5).
