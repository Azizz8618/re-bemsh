# ЗОНА 0153₈ — таблица макроредактора (ГИПОТЕЗА)

Дата: 20.11.2026. Образ 2348 (read-only).
Источники: `dis/MBE-Z0153-L1.asm` (`0153:N`),
`bemsh/MBE-Z0153.be` (`be:N`), `gold/MBE-Z0153-L1.bin`,
`analysis/CROSSREF.md` (`XR`), `docs/ANCHORS.md` (`AN`),
`docs/TEXT-CONSTANTS.md` (`TC`).
Адреса восьмеричные; зона = 1024 слова (6144 байт).

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: служебная таблица прохода макроредактора, НЕ
исполняемый код. Штампа зоны и GOST-сообщения нет
(`besmtool search` всех известных штампов: 0 попаданий).

EVIDENCE:
- XR:72: `Z0153 КМ=0 ДМ=0 BR=0 CALL=0 EX=0 FZ=0` — нуль
  ветвлений/вызовов во всей зоне;
- `0153:8-9`: дизассемблируется только слово 0;
  правая половина — `конк в'02000000'`
  (illegal opcode → данные, RES §1);
- `0153:10+`: все последующие слова — `конд`/`пам`,
  пары `пв …(М15)`/`пб (М15)` нет (REG §3 M15);
- AN:57-60: регион `0154–0165` — конвейер макроредактора;
  0153 — его безымянный сосед.

_confidence_: ВЫСОКАЯ (структура, нуль ветвлений); НИЗКАЯ
(бизнес-роль — «таблица макроопределений» гипотеза по
размещению; исходника транслятора на диске нет).

## 4. ПЕРЕМЕННЫЕ И ЯЧЕЙКИ

Именованных переменных нет: `BR=0`, `ДМ=0` (XR:72), ни одной
`зп`/`сч` на адрес зоны в статическом листинге.

```
ячейка/имя      роль              кто пишет   кто читает
0000            START-слово       —           загрузчик
0001-0051       таблица 25 пар    — (константа) ГИПОТЕЗА:
                                              ред. по базе
0052-1102       заполнитель/теги  —           НЕИЗВЕСТНО
1103-1777       забел (нули)      —           —
```
`ВХ-счётчик` (XR §4) для зоны 0153 отсутствует:
цели с меткой не встречаются. «кто читает» —
гипотеза по AN:59
(0154–0165 = макроредактор); прямого `уиа <база>(Мn)`
сюда не найдено.

## 5. РЕГИСТРЫ

В трассируемом слове 0 полей `(Мn)` НЕТ:
`START сч START` (0153:8) — безадресная загрузка константы.
Зона НЕ шахматная (`distinct word = 321`, не 3, как в 0146/
0160), поэтому псевдо-регистры М5/М12 из Z0146 здесь
НЕ действуют (REG §1.3, Z0146 §3).
Регистры, гипотетически индексирующие таблицу — НЕ
наблюдались; любые `(Мn)` в `конд`-словах — поле команды,
не доказанное значение (REG §4, STANDARD §2.7).

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

```
0000  START сч START ; конк 02000000
  ЧТО: загрузка константы в счётчик без индекса; правая
    половина — служебная ячейка связи (02200000).
  ВХОД: управление от загрузчика. ВЫХОД: нет пб/пв;
   продолжения нет: слово 1 — `конд`.
  [0153:8-10; REG §3 M15 (пары вызова НЕТ)].
```
Процедур, CALL-блоков и ветвлений в зоне НЕТ (XR:72).
Все слова 0001-1777 — данные: обрыв трассы после слова 0,
забелы `пам`, `конк` (RES §1) — прямое свидетельство
«не код» (STANDARD §2.8). Назначение данных — §3/§4.

## 7. НЕИЗВЕСТНОЕ

1. Бизнес-роль: гипотеза «таблица макроредактора/ГС» по
   соседству с 0154; штампа и текста нет.
2. Смысл типов `0x08/0x10/0x20/0x28/0x60` в байте 2 R.
3. Константа-заполнитель `0x538000000000` (220 слов) и
   редкие `0x51800000…`, `0x67800000…`, `0x7f8000…`.
4. Почему каждая запись продублирована дважды (ср. 0154:
   «2 ячейки ГС на макрос», MACRO-TABLE-FORMAT-VERIFIED §4).
5. Кто и с какой базой читает таблицу: косвенных ссылок
   не найдено (BR=0).
6. B2-аналог 0553 также без текста (XR:104); попарное
   сравнение 0153↔0553 не проводилось.
