# П'-константы B2 (0540-0577, MBE2): побайтовая замена

Дата: 21.11.2026. Образ 2348 (Д-2048/2348 МГУ).

ВНИМАНИЕ: это отчёт по зонам B2 0540-0577
(MBE2, ВАР.12/77). Не путать с отчётом по B
0150-0177: docs/SEMANTIC/P-TEXT-B2.md.

Все прочтения GOST-10859 помечены ГИПОТЕЗА,
кроме identity-штампов, подтверждённых
besmtool search/view. Эталонные образы не
изменялись; сборка только в /tmp/.private/azizz/.

## 1. Проверенный рецепт

`КОНД П'ИПМ МА'` (ровно 6 символов) -> байты
28 2f 2c 0f 2c 20, идентично
`КОНД В'1202745403626040'` (0147.1315).
7 символов дают ПЕРЕПОЛНЕНИЕ. 0147 не трогалась.

## 2. Методика

1. Адрес фразы из docs/SEMANTIC/Z05*.md §3.Д/§3.Е,
   docs/TEXT-CONSTANTS.md, docs/TEXT-CONSTANTS-ALL.md;
   hex-байт сверен с gold/.
2. 6 байт -> 6 GOST-символов (таблица dtran.cc,
   0..0x5f; см. §7).
3. Замена в .be: целое `КОНД В'...'` -> `КОНД П'...'`
   (комментарий сохранён) либо пара половин
   `из КОНД` -> одно `КОНД П'...'` (из gold).
4. `make rebuild-zone Z=<Z> MODE=MBE2`: 1024/1024 PASS.
   При FAIL откат.

## 5. Проверка побайтовой безопасности

Все 14 зон: `make rebuild-zone Z=<Z> MODE=MBE2`
-> RESULT PASS, 1024/1024 слов. gold sha256
до/после не изменился (manifest.sha256,
verify/report.md). Эталонные образы не
изменялись; рабочие копии только в
/tmp/.private/azizz/.

## 6. Не переводились (не текст / шум)

Отброшено как шум:

- ЦБАЮ/ГФЕД/СРЯП/ВЖУТ/ШЗЫЬ (0542/0543);
- ВСDЕFG/ЬЫЗШЭЩ;
- КНЦ$$$;
- числовые фрагменты;
- таблицы KOI-7 / 6-bit TEXT.

## 7. Примечание о таблице GOST

Таблица GOST в dtran.cc:167 имеет сдвиг на
1 позицию в латинской части (фактически
63:'D', а не 64:'D'). Кириллица не затронута.
Все преобразованные слова лежат в диапазоне
0..95, поэтому сдвиг на результат не влияет.
