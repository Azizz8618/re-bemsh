только чтение. Изменены 5 файлов:
bemsh/MBE-Z0165.be, Z0166, Z0170, Z0176, Z0177
и этот документ. gold/, dis/, sym/, tools/, чужие .be
и чужие docs не трогались.

> КОРРЕКЦИЯ (20.11.2026): ложные имена Э20/Э21/Э47/Э32
> заменены: КОП2 020/021 (системные), x47 (КОП 047,
> priv), УВВ (КОП 032, обмен). Экстракоды - 050..077₈.
> См. docs/OPCODES-020-021-047-032.md.

## 1. ЗАДАЧА И РЕЗУЛЬТАТ

Разобрать оставшиеся слова КОНД в зонах B 0165-0177,
особенно половины с `name=None` (illegal). Для каждой
такой половины сверить поле КОП с disbesm6.c и simh,
проверить бит EXP и байты. Символическая замена
допускалась только при `rebuild-zone.sh <Z> B` -> PASS
1024/1024; неудачные опыты отменялись.

Переведено в команды 18 слов (36 командных строк).
Все 11 зон дают RESULT: PASS, 1024/1024.

## 2. МЕТОД

1. Слово читалось из gold/MBE-Z<Z>-L1.bin, адрес -
   индекс слова (восьмеричный). Эталон не менялся.
2. Обе 24-битные половины разбирались
   siprod_asm.decode(): мнемоника, kind, reg, адрес, EXP.
3. Для `None` проверялось значение `half & mask`:
   все 154 случая попали в opcode, ЗАКОММЕНТИРОВАННЫЕ
   в disbesm6.c:76-84 (УВВ/КОП 032, Э46, x47, КОП2 020/021).
4. Классы: COMMAND (байтовая замена прошла), DATA
   (illegal/KOI-7/константа), EXP (префикс 7xxxxx
   у данных), UNRESOLVED (нет доказательств).
5. После каждой зоны: bash tools/rebuild-zone.sh <Z> B.

## 4. ПОЧЕМУ illegal - ЭТО ДАННЫЕ

Все 154 `None`-половины разбиваются по commented-out
кодам disbesm6.c (проверено по полю `half & mask`):

| код | комментарий в disbesm6.c | число половин | EXP=1 |
|---|---|---:|---:|
| Э46 (КОП 046) | строка в op[] закомментирована | 1 | 1 |
| УВВ (КОП 032, priv) | строка в op[] закомментирована | 43 | 19 |
| КОП2 020 (системный код) | строка в op[] закомментирована | 47 | 0 |
| КОП2 021 (системный код) | строка в op[] закомментирована | 63 | 0 |

Факты из смежного анализа (docs/ILLEGAL-HALVES-ANALYSIS.md):
- код 047 (x47, привилегированная команда) реален в optab.c:61 и besm6_cpu.c:1485,
  но в наших словах его байты читаются как KOI-7
  ("ВЧ", "ВЧОБ", "ВЧАБ") плюс атрибуты;
- префикс `7` в `70xx` принадлежит байтам текста,
  а не EXP-адресу (бит 18 сброшен у текстовых слов);
- мнемоники УВВ/КОП2 020/021/Э46/x47 НЕТ в таблице
  МАКРО-БЕМШ 06/78, поэтому символическая запись
  этих половин невозможна в принципе.

Вердикт по всем 154: DATA/UNRESOLVED как код.
EXP=1 у 20 половин - НЕ доказательство EXP-адреса:
это биты данных (см. ту же работу, §4).
