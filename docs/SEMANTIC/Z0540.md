## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: ЗАГРУЗОЧНАЯ/УСТАНОВОЧНАЯ зона старшей редакции
`ВАР.12/77`; B-прообраз — 0140₈. Содержит короткий код-стаб
на 4 словах (2 машинных слова) и обширные числовые таблицы.
Самой зоны штампа нет (штамп B2 — в 0547.1315).

_confidence_: ПОДТВЕРЖДЕНО (код-стаб, class L, LINK М16);

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

ВХОД: управление загрузчиком тома. ВЫХОД: `пб (М16)`.

```

       (М13↔М10) перед вызовами; точный эффект уии —
         ГИПОТЕЗА.
0000 П пв '21277'(М16) CALL: в М16 записан адрес возврата,
       управление → 21277. [REG §3M16]
0001 Л уиа '40771'(М3) загрузить базу 40771₈ в индекс М3
       (адресация таблиц). [REG §4]
0001 П пв '21462'(М16) второй CALL через тот же link М16.
0002 Л сч (М17)       прочитать счётчик/границу в М17.
0002 П уи М16         сбросить индекс М16 после возврата.
0003 Л слиа -5(М17)   шаг -5 по М17 (проход по таблице).
0003 П пб (М16)       возврат по link М16 — конец стаба.
0004+ ДАННЫЕ          не исполняются: 0 меток кода и 0 CALL
       после слова 3 [XR:93]; трасса обрывается на пб (М16).
```

Почему слова 0004+ данные: все `конд`, повторяющиеся
  машинные
слова без меток, нет ни одной цели вызова [0540:14+; XR:93].

## 7. НЕИЗВЕСТНОЕ

1. Куда ведут CALL 21277 и 21462 (физические адреса в ОП).
2. Природа таблиц 0004-1777 (адреса/длины/паспорт тома).
3. Причина радикальной правки кода B 0140 (`сч '132'(М7)`,
   `сда 64-23`, `пв '34562'(М16)` …) → B2 0540 (М10/М13/М3):
   class L, побайтово не объяснено [V:82,120-122].
4. Точная семантика `уии` и `слиа -5` без трассировки
  `-R<N>`.
5. Штампа версии в зоне нет; 12/77 — из 0547.1315
  [ANCHORS:49].
