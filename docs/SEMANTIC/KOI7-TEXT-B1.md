## 1. ЗАДАЧА И ПРОВЕРЕННЫЕ ФАКТЫ

Нужно было просмотреть массивы KOI-7 (таблица мнемоник)
и 6-бит TEXT в зонах 0137-0157. В `КОНД П'<6 симв.'`
переводим только те слова, у которых все 6 байт лежат
в GOST 0..96 и читаются осмысленно. Остальные оставляем
`КОНД В'` и добавляем честный комментарий: тип массива,
чтение, причину не-П и ссылку файл:строка.

Факты, проверенные до правки:

1. `КОНД П'ИПМ МА'` = `в'1202745403626040'` =
   байты `28 2f 2c 0f 2c 20` (identity GOST, dtran.cc:167).
2. KOI-7: 0x20-0x5F - ASCII, 0x60-0x7F - кириллица.
   В словах таблицы есть байты 0x6C/0x7E, то есть >096.
   Диапазон GOST 0..96 их не покрывает, колонка GOST - мусор.
3. Восемь символов 6-бит TEXT (dtran.cc:182) для слов
   таблицы дают шум: `0137:0060` -> `'+G.Я( 0.'`,
   `0137:0061` -> `'0WYЯ( 0Ц'`. Осмысленной фразы нет.
4. Проба директивы `текст п'` в /tmp (0 ошибок транслятора):
   `текст п'LZFN    '` даёт ДВА слова
   `2104610021207417 0360741703607417`, а не исходное
   `5472465600000000`. Раскладка иная, байты не совпадают.
   Для шести символов `текст п'ИПМ МА'` даёт одно слово
   `1202745403626040`, совпадающее с `КОНД В'`.
5. GOST П'...' вмещает 6 символов на слово, 6-бит TEXT - 8.

Вывод: **переводов в П' нет**. Все пригодные GOST-штампы
в этих зонах уже записаны как `КОНД П'` (см. §3). Добавлены
только комментарии; машинные строки не изменялись.
