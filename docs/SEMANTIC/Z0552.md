## 2. ЧТО РЕАЛЬНО ИСПОЛНЯЕТСЯ

Первые два слова — КОД, отличающийся от B:
  0552.0  START чед '76462'(М2)
    +1           Э60 '7447'(М3)
  0552.1         рег '5056'(М2)
    +2           выпр '33450'(М2)
Действие: работа с индексным регистром М2 и М3,
  экстракод 60, затем косвенная передача управления
  (выпр) через М2.
Регистры: М2, М3 (ПОЛЯ ЕСТЬ — в отличие от B!).
Вход: параметры в М2/М3; выход: выпр '33450'(М2).
Слова 0552.2+ — `конд` (данные; 0552.2 «ЛАСЬ» —
  хвост сообщения «ЗАПИСЬ … ЗАКОНЧИЛАСЬ»).
Забелы `пам`: 15. Процедур с `пб (Мn)` НЕТ.

## 5. ВЕРСИОННЫЕ ОТЛИЧИЯ B ↔ B2 (подробно)

Согласно versions.md §5: 0152 ↔ 0552, diff=562,
  class S, внутризоновый сдвиг s=+7 слов.
- штамп 0152.1164 → 0552.1154 (−10 слов в зоне);
  дата 04/78 → 10/75 (разница 2 года 6 мес.).
- сообщения: 0152.0151 → 0552.0142 (сдвиг −9);
  0152.0157 → 0552.0150; 0152.0172 → 0552.0163.
- 100 текстов → 96 (B2 короче на 4).
- КОД слово 0 РАЗЛИЧЕН (не просто сдвиг):
  B 0152.0 `мод D01211; пб START` (без М-полей);
  B2 0552.0 `чед '76462'(М2); Э60 '7447'(М3)`,
  0552.1 `рег '5056'(М2); выпр '33450'(М2)`.
  ГИПОТЕЗА: в 1975 г. АРАП имел иную схему
  вызова/настройки (М2/М3 как регистры связи).
- возврат `пб START` (B) заменён на `выпр (М2)` (B2).
