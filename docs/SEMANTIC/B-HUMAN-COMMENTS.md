# Человеческие комментарии в модулях зон B (0137–0177₈)

Дата: 20.11.2026. Охват: все **33** файла `bemsh/MBE-Z*.be`
редакции B (`ТРАНСЛЯТОР С М/К БЕМШ ВЕР.06/78`).

## Что изменилось

Переписаны **только комментарии после первой запятой** — 60 046 строк.
Код, числа, метки, операнды, `(Мn)`, определения `ЭКВ` и директивы
(`СТАРТ`, `Е`, `М`) не тронуты. Шапки и `*`‑строки с доказательствами
сохранены; построчные «хвосты» вида `вход; 0147:20; ГИПОТЕЗА`
удалены (41 строка, все — в зоне 0147) — статус остался в шапке и в
12 новых `*`‑строках на началах процедур.

Механический шум убран полностью: `,слово N, лев. часть`,
`слово N, прав. часть (адр. N)`, `,сырое слово`, `CODE_CNT` как
комментарий, `(было …)`, `0147:69; ГИПОТЕЗА`. Вместо него — короткая
человеческая фраза «что делает команда здесь и зачем», построенная по
шаблону **мнёмокод + роль из операнда** (например, мнемокод `СЧ` +
роль `CNT717` → `, считать CNT717 (счётчик)`).

Особые случаи:

* **Зоны Fill** `0146/0160/0163/0164/0167`: повторяющиеся слова
  `'25252'(М12)` / `'72525'(М5)` получили честную метку `,填充 AA/55`
  (шахматный тестовый шаблон).
* **КОНД‑данные**: известные слова подписаны
  `, таблица мнемоник KOI-7` (0137, слова 0050–0120),
  `, текст справки БЕМШ (АРХ67Z)` / `, текст справки (РЕДАКZ)` /
  `, текст справки (АРХ42Z)` / `, штамп версии 06/78` (0147),
  нули — `, забел`, остальное — `, служебное слово`.
* **Начала процедур** (0147, по `analysis/procedures*.md`) получили
  короткие `*`‑строки: `* Процедура вывода и печати сообщений`,
  `* Диспетчер, связь через М13`, `* Процедура-утилита, вызов через М15`.
* Каждая зона получила одну `*`‑строку с человеческой ролью в шапке
  (например, `* Установочно-перемещающий загрузчик зон`).

Все комментарии ≤55 символов; длина строки ≤60 колонок (кроме
одной предсуществовавшей строки заголовка 0137).

## Ограничения

Роли процедур («утилита», «вывод», «диспетчер») остаются гипотезой
по шаблону вызовов — исходника транслятора на диске нет
(`docs/SEMANTIC/Z0147.md` §7, `docs/COMMENTING-STANDARD.md` §1).
Комментарии фиксируют **действие команды и роль операнда**, а не
доказанный бизнес-смысл.
