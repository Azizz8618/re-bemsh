# П'-константы в модулях B (0150-0177): побайтовая замена

Дата: 21.11.2026. Образ 2348 (Д-2048/2348 МГУ).
Все прочтения GOST-10859 помечены ГИПОТЕЗА (кроме identity-штампов).
Эталонные образы не изменялись; сборка только в /tmp/.private/azizz/.

## 1. Проверенный рецепт

`КОНД П'ИПМ МА'` (РОВНО 6 символов) -> байты 28 2f 2c 0f 2c 20,
идентично `КОНД В'1202745403626040'` (0147.1315). 7 символов дают
ПЕРЕПОЛНЕНИЕ. 0147 не трогалась.

## 2. Методика

1. Адрес фразы из docs/TEXT-CONSTANTS-ALL.md, docs/TEXT-CONSTANTS.md
   §4-6 и docs/SEMANTIC/Z0150,Z0151,Z0152,Z0154,Z0161,Z0162,Z0165,
   Z0166,Z0170,Z0171,Z0173,Z0176,Z0177.md; hex-байт сверен с gold/.
2. 6 байт -> 6 GOST-символов (таблица dtran.cc, 0..0x5f).
3. Замена в .be: целое `КОНД В'...'` -> `КОНД П'...'` (комментарий
   сохранён) либо пара половин `из КОНД` -> одно `КОНД П'...'`.
4. `make rebuild-zone Z=<z> MODE=B`: 1024/1024, PASS. При FAIL откат.
