# ЗОНА 0170 — МАКРОМАШИНА. ГЛУБОКАЯ СЕМАНТИКА

Статус: ФАКТ = адреса/слова/байты; ГИПОТЕЗА = роль кода.
Адреса восьмеричные. Зона = 1024 слова (6144 байт).

## 1. РОЛЬ ЗОНЫ

Второй проход конвейера (MACRO-COMMANDS.md §2):
  МАКРОРЕДАКТОР → МАКРОМАШИНА → АРАП.
Роль «МАКРОМАШИНА» доказана штампом 0170.0216–0221:
  «МАКРОМАШИНА ОТ 1.11.78» (GOST-10859).
Семантика по macros.be: подстановка ∧-параметров,
  исполнение SЕТА/АIF/.МЕТКА/ЭКВ, ветвления по ∧ВS.

НОВОЕ СВИДЕТЕЛЬСТВО (analysis/MEMORY-MAP.md §5–6):
- ИСПРАВЛЕНО (22.11, `analysis/PASSES-CODE-LOCATION.md`):
  зона 0170 ЗАГРУЖАЕТСЯ по базе `02000₈` как оверлей page 01,
  page 01 = 1024/1024 слова gold; старый вывод «не в ОП»
  был из-за неверной страницы 0o72000.
  Штамп 0170.0216 найден в RAM по `02216`,;
  читается как данные, не исполняется. Код до/после:
  `02000: ntr 3`, `02214: uj`, `02222: utc`.
Косвенно: в 0171 — 47 BR / 13 CALL (пик среди зон
  конвейера, CROSSREF.md), там же «ТЕКСТ», «СТЭК»,
  таблица алфавита. ФАКТ: интерпретатор макромашины из
  трассы использует адреса 03460/03462/03465 в зоне 0170
  (см. выше: база `02000₈`, штамп в RAM по `02216`);
  гипотеза «код в 0171, а 0170 - пул сообщений» ОТОЗВАНА.
Сам штамп — ФАКТ; привязка роли коду — ГИПОТЕЗА.

## 2. ЧТО РЕАЛЬНО ИСПОЛНЯЕТСЯ

`-a0 -e0`: одно код-слово, 0 целей вызовов:
  0170.0  START ржа '3'
   +1            пб '2214'   ; прямой переход
Действие: стартовая инструкция (операнд 3),
  затем прямой уход на 2214. Регистров НЕТ.
Вход/выход не прослежены; возврат НЕ (М15).
Статистика CROSSREF.md: КМ=0, ДМ=0, BR=1, CALL=0.

Состав: 1021 `конд`, 1 `пам`. Код разрежен.
Линейная развёртка (sweep.asm) на 0170.1522 даёт
  осмысленный фрагмент «мода | пв '4276'(М16)», но
  базовый листинг его НЕ трассирует — ГИПОТЕЗА
  (ANNOT-MACRO.md §3, procedures.md §3).
Процедур с `пб (Мn)` НЕТ.

## 4. СВЯЗЬ С МАКРОКОМАНДАМИ

НАЙДЕНО КАК ТЕКСТ в 0170: НИ ОДНА из 37 команд.
  (только «В КОМПИЛЯЦИЮ» и штамп — не команды).
ПО ФУНКЦИИ (реализация гипотетическая):
- `∧`-параметры (macros.be:2) — позиционная подстановка
  (16 букв А…Р, ∧М = имя макроса).
- `SЕТА`/`SЕТВ` (macros.be:71/125), `АIF` (macros.be:4),
  `.МЕТКА` (macros.be:4) — единственный механизм циклов
  и условной генерации; пример — macros.be:101–108.
- `ЭКВ`/`ЭКВИВ` (macros.be:63/62) — связывание имён.
- `GВLА`/`GВLВ`/`LСLА` (macros.be:17/123/70) —
  области видимости переменных.
- ключевой флаг `∧ВS` → `ВНЕШБ/ВНЕШС`, `ВХОДБ/ВХОДС`,
  `КОНДБ/КОНДС` (macros.be:32/40/24/16/48/55).
macros.be — внешний набор макросов, НЕ исходник
  транслятора; команды — директивы времени трансляции.
