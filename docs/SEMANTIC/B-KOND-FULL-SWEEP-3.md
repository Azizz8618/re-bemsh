## 2. МЕТОД

1. Адрес слова = индекс в `gold/MBE-Z<зона>-L1.bin` (6144 байт).
2. Слово делится на две 24-битные половины; каждая разбирается
   `siprod_asm.decode()`: мнемоника, `kind`, регистр, адрес, DMS/EXP.
3. Если обе половины имеют мнемонику И левая НЕ относится к
   `{addrex, stop, call, illegal, imm, immex}`, слово заменяется двумя
   командными строками. Операнд строится ПО ПОЛЯМ decode.
4. Левая половина CALL/ADDREX/STOP вызывает авто-вставку `мода`
   и сдвиг слов (доказано в `B-KOND-DECODE-1.md`, `Z0137-KOND-FULL-SWEEP.md`):
   такие слова оставлены КОНД. Расширение адреса EXP кодируется
   5-значной формой `'7xxxx'`; большие reg2-адреса — метками `Cxxx`.
5. Метки `Pxxx` для целей ПБ/ПВ/ПИО/ПИНО/ПО/ПЕ/ЦИКЛ и `Cxxx` для
   ячеек добавляются как `ЭКВ` (слова не порождают). Имена ≤6 символов,
   коллизии с существующими метками разрешаются префиксами `Q`/`K`.
6. Комментарий только после запятой, ≤55 символов; строка ≤60 колонок;
   перенос комментария со звёздочкой (здесь не потребовался).
7. Обязательная проверка после КАЖДОЙ зоны:
   `bash tools/rebuild-zone.sh <Z> B` → `ЧИCЛO OШИБOK=0000`,
   `WORDS: всего=1024 совпало=1024 различий=0`, `RESULT: PASS`,
   «Файлы идентичны (2000 слов)». Перед правкой создавался `.bak`.
