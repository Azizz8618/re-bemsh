# KOI7 и 6-битный TEXT в модулях АСМ ИТМ (0055,0056,0057,0060₈)

Дата: 21.11.2026. Образ `2348` (том Д-2048/2348 МГУ).
Эталонные дампы `gold/` только читались. Правки внесены
только в 4 `.be` и этот документ. Коммит/push
не выполнялись.

## 1. Вопрос

Проверить гипотезу: содержат ли зоны АСМ ИТМ массивы,
которые следует читать как KOI-7-таблицу мнемоник
(по образцу `0137:0057-0121`) или как 6-битный TEXT
(8 символов на слово, `dtran.cc:182 text_to_utf`).
Если слово байтово безопасно как GOST-8 и даёт связный
текст, переписать его как `КОНД П'<6 символов>'`.
Иначе оставить `КОНД В'` и дать честный комментарий.

## 2. Метод и калибровка

1. Для каждого адреса из `docs/TEXT-CONSTANTS-ALL.md`
   (разделы «АСМ ИТМ» для 0055/0056/0057/0060) и для
   каждого кластера `КОНД В'` из
   `analysis/INLINE-CONSTS-ASM.md` взяты 6 байт из
   `gold/ASM-Z<зона>-L1.bin` (только чтение).
2. Каждое слово декодировано тремя таблицами:
   GOST-8 (`dtran.cc:167`), KOI-7 (`encoding.cpp:681`),
   6-бит TEXT (`dtran.cc:182`, 8 групп по 6 бит).
3. Дополнительно воспроизведено чтение TCA из
   `tools/text_decode_all.py` (6 бит как ASCII−0x20):
   именно оно даёт строки вроде `EM8VAF8F`, `1QQ50RD4`.
  Это НЕ таблица `dtran.cc:182`; выводы по ним
  не строились.
4. Директива `текст п'...'` проверена экспериментально
   (прогон `dispak` в `/tmp/.private/azizz/koi7text/`,
   0 ошибок, `ДЛИHA ПPOГ=00006`):

   | исходник | слова (восьм.) | байты |
   |---|---|---|
   | `текст п'ИПМ МА'` | `1202745403626040` | 28 2f 2c 0f 2c 20 |
   | `КОНД В'1202745403626040'` | `1202745403626040` | 28 2f 2c 0f 2c 20 |
   | `текст п'12345678'` | `0020100301002406`, `0160401703607417` | 01 02 03 04 05 06 / 07 08 0f 0f 0f 0f |
   | `текст п'АБВГДЕЖЗИ'` | `1002044210622045`, `1142345003607417` | 20 21 22 23 24 25 / 26 27 28 0f 0f 0f |

   Вывод: `текст п'` и `КОНД П'` на 6 символов дают
   один и тот же GOST-8 байтовый ряд; длинная строка
   добирается словами по 6 символов с заполнением
   хвоста `0f` (пробел).
   Каноническая форма DISPAK для длинных строк -
   `текст п'...'`, но это GOST-8, а не 6-битный TEXT
   из `dtran.cc:182`. Для одного слова избран `КОНД П'`
   (единообразие с уже переведёнными словами).

## 4. Итог по действиям

| зона | слов examined | переведено в П' | оставлено В' + коммент. |
|---|---:|---:|---:|
| 0055 | 13 | 0 | 13 (1 общий коммент. на кластер) |
| 0056 | 12 | 0 (5 ранее) | 7 (2 коммент.) |
| 0057 | 7 | 0 (2 ранее) | 5 (1 коммент.) |
| 0060 | 9 | 0 | 9 (2 коммент. на дубль) |

**Новых переводов: 0.** Причина: все слова с байтами
`0..96` и связным GOST-чтением были переведены ранее
(`P-TEXT-ASM.md`, 8 слов). У всех прочих есть байты
`>0x80`, либо GOST-чтение - мусор; `П'...'` изменила бы
байты эталона. Ни одно 8-символьное чтение `dtran.cc:182`
не дало осмысленной фразы (ср. ожидаемое `ВРЕМЯ СЧЕТА`),
поэтому `текст п'<8 символов>'` нигде не применён.

Наличие KOI7-таблицы мнемоник в ASM-зонах ранее
опровергнуто: `analysis/SIMILAR-BLOCKS-ASM.md` §3 даёт
0 блоков по сигнатуре `2 буквы + пробел + атрибут`.
Кластеры `КОНД` в ASM - вкраплённые константы/шум,
не KOI7 и не 6-битный TEXT.
