## 2. ЧТО РЕАЛЬНО ИСПОЛНЯЕТСЯ

Одно исполняемое слово в `-a0 -e0`:
  0152.0  START мод D01211 ; пб START
  Действие: настроить адресацию на данные D01211 и уйти
  по прямому адресу 0 (START). Возврат — прямой, НЕ (М15).
  Регистры: нет полей (Мn) в этих двух словах.
  Вход: управление от предыдущего прохода; выход: пб 0.
  D01211 — метка данных в той же зоне.
Далее слово 1 = `пам 1` (забел), слова 2–1023 — `конд`
  (данные/текст). Процедур с `пб (Мn)` НЕТ (0 целей вызова).
