## 1. МЕТОДИКА

1. Кандидат - строка `.be` вида `КОНД В'................'`, у которой хотя
   бы одно соседнее слово (предыдущее или следующее) является командой
   (`cmd2`), то есть слово лежит внутри линейной процедуры, а не в таблице
   данных/забела. Адрес слова = его индекс в `.be` = адрес в `gold/` и
   в листинге `dis`/`dis-forced` (проверено побайтово: 0 несовпадений).
2. 16 восьмеричных цифр делятся на две 24-битные половины. Каждая
   половина разбирается `siprod_asm.decode()`: мнемоника, адрес, регистр,
   DMS/EXP, признак структуры. Регистр печатается восьмеричным `(Мn)`.
3. Обе половины заменяют одно слово КОНД ДВУМЯ строками команд.
   Число слов не меняется, сборка остаётся побайтовой.
4. Операнд выводится из полей `decode()`, а НЕ из текста принудительного
   листинга: `disbesm6` искажает операнды типов `reg1`/`imm` (например,
   адрес `3514` печатается как `М14`) и не различает EXP. Для EXP
   адрес пишется 5-значной формой `'7abcd'` (так его кодирует
   МАКРО-БЕМШ 06/78). Нулевая половина пишется голой `ЗП`, подавленная
   правая (`02200000`) - голой `МОДА`.
5. Пропуск: `illegal`/`конк`, мнемоника отсутствует в таблице
   транслятора (`ПИО36`, `Э66`, `И`, `ИЛИ`, `Э72`, `Э74`), либо левая
   половина относится к типам `call`/`addrex`/`immex`/`stop` и вызвала бы
   авто-вставку `мода` со сдвигом кода.
6. Для целей `ПБ`/`ПВ`/`ПИО`/`ПИНО` заведены компактные метки `Pxxx`
   (≤6 символов, `ЭКВ` не порождает слово); где была подходящая
   существующая `ЭКВ`, использована она. Комментарии только после запятой,
   помечены `гипотеза`.
7. Обязательная проверка после каждой зоны: `rebuild-zone.sh <Z> B`,
   ожидается `RESULT: PASS`, `1024/1024`, «Файлы идентичны».
