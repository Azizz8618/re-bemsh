# ЗОНА 0575₈ — почти пустая зона B2 (копия 0175₈)

Дата: 20.11.2026. Образ 2348 (read-only, besm6).
B2 = старшая копия 0540–0577₈ (ВАР.12/77).
Адреса восьмеричные. Зона = 1024 слова (6144 байт).

## 1. НАЗНАЧЕНИЕ МОДУЛЯ

Роль: свободная зона; 1020 слов нулевых, 4 слова
ненулевых (две пары «запись + стоп»). Ни штампа,
ни кода, ни таблиц.

EVIDENCE:
- `cmp gold/MBE2-Z0575-L1.bin gold/MBE-Z0175-L1.bin`
  → идентичны; versions.md §5: 0175↔0575 diff=0, s=0,
  класс I.
- подсчёт байт: distinct word = 5, из них 1020×
  `00 00 00 00 00 00`; ненулевые tylko 0242, 0243,
  0250, 0251.
- CROSSREF.md §3: Z0575 КМ=0, ДМ=0, BR=0, CALL=0 —
  полное отсутствие переходов.
- `besmtool search` текстов в зоне не даёт попаданий.

Confidence: ПОДТВЕРЖДЕНО (байты, cmp, CROSSREF).
Назначение двух пар — ГИПОТЕЗА (см. §6).

  0000–0241    `00 00 00 00 00 00`    нули (162 слова)

## 3. ЗНАЧЕНИЯ КОНСТАНТ

Все 4 ненулевых слова. Команда (read-only):
`besmtool view 2348 --start=0575 --length=1 \
  --encoding=g,k,t,i`

  слово | bytes           | oct             | decoding
  ------+-----------------+-----------------+-----------
  0242  | 00 00 00 00 04 1d|0000000000002035| GOST
        |                 |                 | `00004<,`
        |                 |                 | KOI7 `,
        |                 |                 | TEXT 0-Ц8
  0243  | 0d 80 00 00 10 00|0330000000010000| GOST мусор,
        |                 |                 | KOI7 `,
        |                 |                 | TEXT 0-Ц8
  0250  | 00 00 00 00 04 1a|0000000000002032| GOST
        |                 |                 | `00004‘,`
  0251  | 0d 80 00 00 14 00|0330000000012000| GOST мусор

GOST-колонка слов 0242/0250 — `00004<,` / `00004‘,`:
это ЧИСЛА (0x1d/0x1a на конце), а не сообщения
(TEXT-CONSTANTS.md §2, правило «п' не доказывает текст»).
KOI7/TEXT/ITM — мусор (признак не-GOST кодировки).
Confidence: ВЫСОКАЯ (байты); смысл — ГИПОТЕЗА.

## 5. РЕГИСТРЫ

Полей `(Мn)` в ненулевых словах НЕТ:
- слово 0242: 00 000 2035 → opcode `зп`, адрес 02035;
- слово 0243: 00 33 00000 → `стоп` + `зпм START`;
- слово 0250: `зп '2032'`, 0251: `стоп` + `зпм '2000'`.

Регистры М1–М17 зоной НЕ используются. Роль М-полей
в соседних зонах (REGISTERS.md §2) сюда не переносится:
COMMENTING-STANDARD.md запрещает домысливать.
Confidence: ПОДТВЕРЖДЕНО (разбор байт).

## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

Осмысленной трассы НЕТ: BR=0, CALL=0 (CROSSREF.md §3).

  0242: зп '2035' — записать? НЕТ: слово данных.
  0243: стоп ; зпм START — стоп + запись в START.
  0250: зп '2032' ; 0251: стоп ; зпм '2000'.

ГИПОТЕЗА (низкая): две пары — остатки отладочных
точек/заглушек («записать константу, остановиться»),
сохранённые при переносе B→B2 без изменений.
Вход/выход не прослежены. Процедур и `пб (Мn)` нет.
Evidence: `dis/MBE2-Z0575-L1.asm` строки 332–345;
`dis/MBE-Z0175-L1.asm` (та же разметка).

## 7. НЕИЗВЕСТНОЕ

1. Назначение ячеек 02035 и 02032 и константы 02000.
2. Почему пары расположены именно на 0242 и 0250.
3. Идентичность B и B2 объяснима только копированием;
   причина сохранения заглушек неизвестна.
