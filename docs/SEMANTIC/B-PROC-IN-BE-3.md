## 1. ОБЛАСТЬ И МЕТОД

Обработаны 8 модулей: bemsh/MBE-Z0170.be ... MBE-Z0177.be.
В каждый модуль вставлен блок комментариев над
строкой "*** КОД МОДУЛЯ".
Формат блока на каждую запись источника:

```
* ПРОЦ P<start> <start>-<end>
*   size=<N> <kind> <status> <conf>
*   ВХ <entry>; ВЫХ <exit>
*   РЕГ <registers>
*   СМЫСЛ <function>
```

Дополнительно одна строка заголовка блока. Для зон без
записей добавляется пометка "осн=0, влож=0, ДАН=0"
со ссылкой на §3, §8.

Правила, соблюдённые при вставке:

* добавлены только строки, начинающиеся с `*`;
* машины, ЭКВ и операнды не изменялись
  (проверка strip-comment);
* длина любой добавленной строки <= 60 символов;
* тире в тексте заменено на `-`, применён знак ↑;
* урезанные в источнике поля РЕГ сохранены как есть
  (многоточие), пометка ГИПОТЕЗА выставлена по источнику;
* для зон 0174, 0175 записей в источнике нет.
