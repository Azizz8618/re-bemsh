## 2. ФОРМАТ БЛОКА

```
* ПРОЦ P<start> <s>-<e> size=<N> <вид> <класс> PROC:<n> ...
*   ВХ <вход>; ВЫХ <выход>
*   РЕГ <регистры>
*   СМЫСЛ <функция>
*       <продолжение СМЫСЛ>
```

Пример:

```
* ПРОЦ P0310 0310-0323 size=014 CALL ОСН PROC:502 ГИПОТЕЗА
*   ВХ ПВ@0147:0446; ВЫХ RET@0323
*   РЕГ М3:счётчик цикла/длины, М5:индекс, М15:адрес
*       возврата, М16:модифицированный адре…
*   СМЫСЛ Процедура: пробегает по элементам таблицы с
*       индексом, наращивая счётчик. Ячейки: D0734, D0747,
*       D0746. Вызов из 0446. В зоне «ЯДРО ИСПОЛНЯЕМОГО КОДА
*       транслятора». Использует М3(счётчик цикла/длины),
*       М5(индекс), М15(адрес возврата).
```

Соблюденные правила:

* границы, `size`, вид, класс, ВХ/ВЫХ, РЕГ и СМЫСЛ взяты
  дословно из источника, без домысливания;
* урезанные в источнике поля РЕГ сохранены с многоточием
  (`адре…`, `буфе…`), `М11:-` вместо прочерка-тире;
* тире заменено на `-`, знак возведения
  в степень не применён;
* все добавленные строки начинаются с `*` и имеют длину
  не более 60 символов (максимум замерен: 60);
* машинные строки, ЭКВ и операнды не менялись.
