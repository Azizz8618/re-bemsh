# B-BEMSH-XREF-1: метки и кросс-ссылки в `.be` зон 0137, 0140–0147₈

Дата: 20.11.2026. Объект: восемь реконструированных исходников
`bemsh/MBE-Z<зона>.be` (B, версия 06/78, том 2348):

```
0137  0140  0141  0142  0143  0144  0145  0146  0147
```

Задача: для всех операндов ПВ/ПБ/ПИО/ПИНО (= CALL/return) зоны
дать осмысленную метку, для локальных процедур — человеческую
шапку с ролью, входами/выходами и ссылкой на источник, для
внешних адресов — компактную метку с именем цели. **Ни одно
машинное слово не изменено**: все правки — это `*`строки,
`ЭКВ`-определения и замена литерала на его символический
эквивалент (то же восьмеричное значение).

---

## 1. Правила (по заданию и `AGENTS.md`)

| Тип метки | Форма | Назначение |
|---|---|---|
| `Pxxx` | `P` + восьмеричный адрес входа | локальная процедура (цель ПБ/ПВ/ПИО/ПИНО) |
| `Cxxx` | `C` + адрес ячейки | локальная ячейка/цель внутри зоны, не процедура |
| `Xnnnnn` | `X` + литерал адреса | внешняя цель (адрес за пределами зоны) |

Дополнительно:

* имя ≤6 символов, ВЕРХНИЙ регистр, определяется через `ЭКВ`
  сразу после `М` (в блоке меток);
* над каждой локальной процедурой — `*`шапка: роль, `ВХ`/`ВЫХ`
  (регистры), `PROC:<строка>` из `docs/PROCEDURES-B.md`;
* у каждой `X`-метки в комментарии названа цель: страница ОП
  и зона по `CALL-OUT-OF-MODULE.md` §2, §6 или пометка
  «стр.N не привязана» (по `CALL-TRACE-RUNTIME.md` §1.3);
* комментарий после запятой ≤55 символов, `*`строка ≤59 колонок,
  `↑` вместо `^`, без тавтологий («переход», «константа» и т.п.).
* зона `0146` — FILL: метки не выдумываются (см. §4).

Источники кросс-ссылок: `docs/PROCEDURES-B.md` (каталог процедур
B, §3–4), `docs/CALL-OUT-OF-MODULE.md` (§4, §6 — адреса и страницы),
`analysis/CALL-TRACE-RUNTIME.md` (§1.3, §4 — привязка страниц
к зонам; операнды `34562`, `51670`, `07417` не исполнялись).

Пояснения к таблице:

* «Процедур в PROC» — число кандидатов каталога для зоны;
  статус `ДАН` (ложная цель: базовый листинг печатает `конд`)
  осознанно не получает метки `P` и человеческой шапки.
* `P` в 0144/0147 частично переиспользуют уже существовавшие
  метки (`P603`, `P605`, `P110`, `P1310`, `P1173`, `P734`,
  `P301`, `P125`, …) — они дополнены ролями и `PROC:<строка>`.
* `X`-метки даны для **каждого** внешнего адреса, даже если он
  встречается один раз; повторы в задании не теряются.
* «Замен операндов» — число литералов `'NNNNN'`, заменённых на
  эквивалентную символическую метку в строках ПВ/ПБ/ПИО/ПИНО.

## 3. Примеры (фактический текст файлов)

### 3.1 Локальная процедура (0144, `PROC:191`)

```
* P110 0144:0110 ВЕТВ: Утилита диагностики: вызывает ядро
*   ВХ ВЕТВ×5@0144:0106; ВЫХ RET@0127; PROC:191; ГИПОТЕЗА
...
P110 ЭКВ '110' ,Утилита диагностики: вызывает; PROC:191
...
* P110 (0144:0110) Утилита диагностики: вызывает ядро
        УИА  '40000'(М2), из КОНД, левая (гипотеза)
        ПБ   '605'(М2)  , из КОНД, правая (гипотеза)
```

### 3.2 Внешняя цель (0137, `CALL-OUT §6`)

```
* X75523: '75523' -> зона 0153 (стр.36); 0137:0043
...
X75523 ЭКВ '75523' ,зона 0153 (стр.36); CALL-OUT §6
...
        ПБ   X75523(М7), из КОНД, левая (гипотеза)
```

Адрес `75523₈` лежит на странице `36₈`, которая по
`CALL-OUT-OF-MODULE.md` §2 соответствует зоне `0153`; значит
`X75523` — это ПБ в зону 0153, а не «шум» и не константа.

### 3.3 Неподтверждённая страница (0144)

```
* X41471: '41471' -> стр.20 не привязана; 0144:0546
X41471 ЭКВ '41471' ,стр.20 не привязана; CALL-OUT §6
        ПВ   X41471(М11), из КОНД, правая (гипотеза)
```

Динамическая трасса (`CALL-TRACE-RUNTIME.md` §4) показала, что
"`34562`", "`51670`" и "`07417`" как CALL-цели не исполнялись;
поэтому для них в комментарии стоит нейтральная пометка
«стр.N не привязана», а не выдуманное имя подпрограммы.

### 3.4 Ячейка (0137)

```
* C770: '770' цель ПБ; 0137:0114; ГИПОТЕЗА
C770 ЭКВ '770' ,лок. цель; 0137:0114
        ПБ   C770(М6) , переход с возвратом 770 через М6
```

## 4. Зона 0146 (FILL)

`0146` намеренно **не** получила меток `P`/`X`/`C` и шапок:
по `PROCEDURES-B.md` §3 в ней 0 кандидатов, 0 `CALL`, 0 `RET`,
0 `STOP`; все 1024 слова — регулярный повтор
`СЛИА '25252'(М12)` / `ВЧП '72525'(М5)` (шахматный FILL).
Вместо выдуманных целей в шапку добавлено честное пояснение:

```
* Зона 0146 — FILL: регулярный повтор слов по всем 1024
*   словам; команд ПВ/ПБ/ПИО/ПИНО в зоне нет.
*   PROC §3: 0 кандидатов, 0 CALL, 0 RET, 0 STOP;
*   PROCEDURES-B: зона не содержит программы.
*   Метки П/Х/С не вводятся: несуществующие цели не
*   выдумываются (AGENTS.md §0.2, «не домысливай»).
```

## 6. Оговорки

1. Роли процедур — `ГИПОТЕЗА`: эталонного исходника транслятора
   на диске нет, STATIC-анализ не отслеживает значения регистров
   (`PROCEDURES-B.md` §1, `COMMENTING-STANDARD.md` §2.4).
2. `ВХ`/`ВЫХ` в шапках взяты из каталога `PROCEDURES-B.md` и
   описывают **статистику входящих ссылок/выход RET**, а не
   доказанную сигнатуру.
3. Привязка `X`-метки к зоне — по странице ОП из 8 снимков
   (`CALL-TRACE-RUNTIME.md` §1.3); возможны оверлеи между
   снимками, поэтому «зона 0157/0152» означает «на этой
   странице в снимках лежит эта зона».
4. Число `П` в таблице §2 для 0147 (27) меньше числа кандидатов
   (39): 12 ложных целей (`ДАН`) осознанно не получили меток.
