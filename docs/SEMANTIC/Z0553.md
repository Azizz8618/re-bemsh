## 6. ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ

Процедур НЕТ:
- 0553.0: дизассемблер показывает START, но вторая
  половина — `конк` (illegal opcode) — это данные,
  попавшие в код (SEMANTIC-STANDARD §1.8);
- 0553.1-50: 25 пар дескрипторов `[Tag|TT|N]`;
  N растёт 1..23, TT меняется (02/10/12/60),
  пары идентичны → гипотетически «дублирование
  левой/правой половины»;
- 0553.51+: массив повторов `2470000000000000`
  (216 слов `538000…`), затем числа 0x50–0x63;
- 0553.1066: `пам 458` — забел до конца зоны.
ВХОДОВ/ВЫХОДОВ НЕТ.

Дополнение (текстовые константы): TEXT-имена 0554+ лежат в числовой таблице; зона по-прежнему
не имеет CALL/BR — текст здесь не исполняется.

2. Для чего 216 повторов `538000…` и хвост 1040+.
