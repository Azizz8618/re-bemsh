# ПОЛНЫЕ ОПИСАНИЯ ПРОЦЕДУР В КОММЕНТАРИЯХ B-МОДУЛЕЙ, ЧАСТЬ 1

Дата: 21.11.2026. Образ тома 2348 только читался.
Объект: 8 модулей `bemsh/MBE-Z<зона>.be` зон
`0137, 0140–0146₈` (B, ВЕР.06/78).
Источник записей: `docs/PROCEDURES-B.md` §4
(142 записи всего; в этих 8 зонах 28).

## 1. ЧТО СДЕЛАНО

В верхнем комментарии каждого модуля, в секции
`* === ФАЗА E: ПРОЦЕДУРЫ И КРОСС-ССЫЛКИ ===`,
добавлен или обогащён блок
```
* === ПОЛНЫЕ ОПИСАНИЯ ПРОЦЕДУР (PROCEDURES-B; ГИПОТЕЗА) ===
```
Формат каждой записи:

```
* ПРОЦ P110 0144:0110-0127 size=020 BRANCH ОСН PROC:191
*   ВХ ВЕТВ×5@0144:0106; ВЫХ RET@0127; ГИПОТЕЗА
*   РЕГ М2:счётчик цикла, М5:индекс
*   СМЫСЛ Утилита диагностики: вызывает ядро ...
```

Поля: границы `зона:start-end`, `size=<N>` (восьм. слова),
вид (`BRANCH`/`CALL`/`-`), статус (`ОСН`/`ВЛОЖ`/`ДАН`),
номер записи `PROC:nnn` (= номер строки в PROCEDURES-B.md),
вход, выход, регистры и полный текст `СМЫСЛ` из документа.
Если рядом зафиксирован текст (`ВНЕШ. МЕТКА`, `НЕТ МДЛ`),
он сохранён строкой `*   ТЕКСТ ...`.
Все записи помечены `ГИПОТЕЗА` по источнику: эталонного
исходника транслятора на диске нет, STATIC-анализ не
отслеживает значения регистров [PROCEDURES-B.md, §1].

В зонах 0144 и 0145 существующие двухстрочные заголовки
`* Pnnn ...` / `*   ВХ ...; PROC:nnn` заменены на полные
блоки на том же месте; номер `PROC:nnn` использован как
ключ сопоставления с записью документа (22/22 и 2/2).
В зонах без существующих заголовков блоки вставлены
сразу после заголовка ФАЗЫ E. В зонах без записей
добавлена одна строка с явным нулём.

## 4. БАЙТОВАЯ БЕЗОПАСНОСТЬ

1. Изменены только строки, начинающиеся с `*`.
   Дифф против резервных копий проверен программно:
   строк, не являющихся комментариями, среди
   удалённых/добавленных: 0 во всех 8 файлах.
   Строки `ЭКВ`, операнды, метки и машинные строки
   не тронуты.
2. Длина всех добавленных/заменённых строк <=60
   символов (проверено программно, 0 нарушений).
3. В добавленных строках нет тире U+2014 и знака `^`;
   где в источнике стояло тире, подставлен ASCII `-`.
   Продолжение СМЫСЛ/РЕГ делается со звездочкой `*`
   в начале строки, как требует AGENTS.md §0.
4. Перед изменением созданы копии в каталоге
   `/tmp/.private/azizz/b-proc-backups/` с именами
   `MBE-Z<зона>.be.bak.20261121_003459`.
   Генератор проверял длину и символы до записи.
5. Эталонные образы `gold/` и каталоги `dis/` не
   изменялись; сборка использует только копии в `/tmp`
   через `tools/rebuild-zone.sh`.
