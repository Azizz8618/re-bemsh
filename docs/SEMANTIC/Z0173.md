# ЗОНА 0173₈ — справка/таблица ошибок БЕМШ1

Дата: 19.11.2026. Образ 2348.
Образ: read-only /usr/local/share/besm6/2348.
B2-аналог: 0573₈ (штампы на 44₈ слов раньше:
0611, 0615).

## 1. НАЗНАЧЕНИЕ

Зона содержит два ГОСТ-штампа отладочных таблиц:

  0173.0655–0657: ОШ.СПР.НА БЕМШ1
  0173.0661–0663: ЛИМ.СТРЕЛ.НА БЕМШ1

«ОШ.СПР.» = ошибки справки; «ЛИМ.СТРЕЛ.» = лимиты стрелок
(указателей). Это НЕ сообщения пользователю, а заголовки
внутренних таблиц диагностики/ограничений этапа БЕМШ1.
Доказательство: `besmtool search 2348 'ОШ.СПР.НА БЕМШ1'`
даёт 0173.0655 и 0573.0611; `besmtool view --encoding=g`
читает те же слова как осмысленный русский текст.
В B2-копии 0573.0611 тот же штамп (сдвиг −44₈ слов).

## 2. СТРУКТУРА

Штамп = 3 слова по 6 ГОСТ-символов (18 знаков, с хвостовыми
пробелами 0x0F). За каждым штампом идёт слово-разделитель
0173.0660 / 0173.0664 = `990000000000`.
Шаг между штампами: 0661−0655 = 4₈ слова.
Запись-заголовок: 3 текстовых слова +
1 разделитель = 4 слова.

Далее —

  0173.0665–0672: 6 чисел-указателей/лимитов (две половины
                  по 24 бит; octal 02241,
                  02254, 07057 …);
  0173.0673–1377: плотные данные с байтами 0xA1–0xDE;
  0173.1400–1654: 173 записи по одному слову:
                  левая половина = код,
                  правая = зп адр;
  0173.1655–1777: нули (хвост зоны).

Пример записи 0173.1522: левая половина 020060
(`рег '60'`), правая 004154 (`зп '4154'`).

## 4. ИСПОЛЬЗОВАНИЕ

analysis/CROSSREF.md §3: Z0173 КМ=1, ДМ=4, BR=3, CALL=1 —
зона почти не ссылается на код, это данные/таблица.
analysis/procedures.md §4.3: A01522 — ложная цель CALL,
при чтении `рег '60'` (таблица), не процедура.
analysis/VARIABLES-VALIDATION.md: ERRCELL1 04154 — 36 точных
вхождений `зп ERRCELL1`, рядом штамп 0173.0655.
Как индекс выбирает запись — НЕ установлено: явного
`уиа <база>(Мn)` + `счи` для 0173.0665+ не найдено;
базы 02241/02254 (слово 0665) — ГИПОТЕЗА индекса.

## 5. НЕИЗВЕСТНОЕ

  0173.0673–1377: байты 0xA1–0xDE. Пробованы GOST, KOI-7,
  TEXT, ITM (`view --encoding=g,k,t,i`), кодировки koi8-r,
  cp1251, iso8859-5, сдвиги и константы —
  осмысленного текста нет. Возможно, компактные
  внутренние коды/адреса.
  0173.1475–1500: повтор `АР009А0…`
  (docs/TEXT-CONSTANTS.md §6.3).
  Точное назначение 0x99 и кодов 04154/04231 — ГИПОТЕЗА.
  B2 0573 отличается не только сдвигом −44₈ (versions.md).
