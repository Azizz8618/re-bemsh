# Аудит и исправление комментариев B2 (0540–0577₈)

Дата: 20.11.2026. Исправлены ТОЛЬКО комментарии после запятой в 32 файлах
`bemsh/MBE2-Z0540.be` … `bemsh/MBE2-Z0577.be` и создан этот документ.
Код, числа, метки, ЭКВ-определения, `tools/`, `dis/`, `gold/`, другие
документы не тронуты. Резервные копии до правки — вне репозитория:
`/tmp/.private/azizz/b2-comment-backup/`.

## 1. Методика

Источник ошибки — предыдущая сессия, записавшая «человеческие» комментарии
(`docs/SEMANTIC/B2-HUMAN-COMMENTS.md`). Проверка шла по тексту .be и
побайтовому эталону `gold/MBE2-Z<зона>-L1.bin`.

Классы найденных ошибок:

1. **Команда с пустым операндом + выдуманное действие.** В .be строка
   вида `ЗП             , записать результат` не содержит адреса/модификатора:
   между мнемоникой и запятой — только пробелы. В эталоне такие половинки
   слов — нулевые/пустые (`0547:0 = 0000000000000000`). Комментарий
   «записать результат», «установить режим», «прочитать значение» и т.п.
   приписывает команде несуществующий операнд.
   Исправление: `, нулевое слово (забел)`.
2. **Комментарий называет регистр/метку, отсутствующую в операнде.**
   Проверка по всем 32 файлам: токены `М\d+`, метки вида `[A-Z]+\d+`
   и 3–5-значные адреса из комментария сверены с текстом операнда.
   Отдельных нарушений не найдено: все такие упоминания совпадают с
   операндом (например `ПВ UTL514(М15) , вызвать подпрограмму 514 через М15`).
   Единственные случаи — пустой операнд из п. 1 — исправлены там же.
3. **Повторяющийся комментарий-карта узора (>20 на файл).** В зонах-забелах
   0546/0560/0563/0564/0567 к каждой строке был приклеен один и тот же
   шаблон `,填充 AA/55` (2048 раз на файл, 10240 всего), причём часто
   поверх команды с ненулевым операндом
   (`СЛИА '25252'(М12),填充 AA/55`, `ВЧП '72525'(М5),填充 AA/55`).
   Это контекстно-свободная подпись байтового узора, а не действие команды.
   Исправление: нейтральное `, данные`.

## 4. Проверка

1. Для каждой из 32 зон выполнено
   `bash tools/rebuild-zone.sh <Z> MBE2`.
   **32/32 PASS**: везде `WORDS: всего=1024 совпало=1024 различий=0`,
   `RESULT: PASS`, `✓ Файлы идентичны (2000 слов)`.
2. Построчная сверка с резервными копиями: часть строки **до первой
   запятой** (код) и все `*`-строки совпадают во всех 32 файлах.
3. Длина любого комментария ≤40 символов (лимит 55), ширина строк
   сохранена, форматирование до запятой не менялось.
4. Прогон `python3 tools/comment_audit.py --all --json` (только чтение):
   по всем 32 зонам B2 **0** флагов `EMPTY-OPERAND-SEMANTIC` и **0** флагов
   `CONTRADICTION`. Оставшиеся `REPETITION`/`TAUTOLOGY` — канонические
   маркеры (`нулевое слово (забел)`, `забел`) и известные ложные
   срабатывания по `COMMENT-AUDIT.md` §5 (см. п. 1.2–1.3 того документа).
5. Затронуто 32 файла `bemsh/MBE2-Z*.be` и этот документ. Другие файлы
   репозитория не изменялись.
