# ЗОНА 0154 — МАКРОРЕДАКТОР. ГЛУБОКАЯ СЕМАНТИКА

Статус: ФАКТ = адреса/слова/байты/дамп ОП; ГИПОТЕЗА = роль.
Адреса восьмеричные. Зона = 1024 слова (6144 байт).

## 1. РОЛЬ ЗОНЫ

Первый проход конвейера (MACRO-COMMANDS.md §2):
  МАКРОРЕДАКТОР (20.06.78) → МАКРОМАШИНА → АРАП.
Роль доказана штампом 0154.0751–0755:
  «МАКРОРЕДАКТОР ОТ 20.06.78» (GOST-10859).

КЛЮЧЕВОЕ СВИДЕТЕЛЬСТВО (analysis/MEMORY-MAP.md §5–6):
- зона 0154 загружена в ОП по 02000₈ (страница 01),
  1024/1024 точных слов — полное совпадение;
- breakpoint `02000` сработал и показал `xta 6065`
  = первая команда зоны `сч '6065'`.
Гипотеза «код прохода лежит вне 0154» ОПРОВЕРГНУТА.
Это ЕДИНСТВЕННАЯ зона конвейера с доказанным
  исполняемым кодом в ОП.

Счётчик таблицы ГС: 0154.1450–1451 «-КОЛИЧ ЯЧ ГС».
Эксперимент (MACRO-TABLE-FORMAT-VERIFIED.md §4.1):
  E0=001332, E1=+2, E2=+4, E3=+4 ячейки;
  одно простое определение = 2 ячейки ГС (ФАКТ),
  но биты самих ячеек не наблюдались.

## 2. ЧТО РЕАЛЬНО ИСПОЛНЯЕТСЯ

Базовый листинг `-a0 -e0` трассирует только 2 слова:
  0154.0  START сч '6065'   ; загрузка константы 6065
     +1     Э50 '103'   ; экстракод 50, арг. 103
  0154.1         пб '2757'  ; прямой переход на 2757

Действие: инициализация (сч '6065'), экстракод 50,
  передача управления по ПРЯМОМУ адресу 2757.
Регистры: полей (Мn) в этих словах НЕТ.
Вход: управление от загрузчика; выход: пб '2757'.
Возврат НЕ через (М15) — каноническая пара CALL
  здесь не наблюдается (ANNOT-MACRO.md §3).

Статистика analysis/CROSSREF.md: КМ=0, ДМ=0, BR=1,
  CALL=0, EX=1 (экстракод Э50) — код разрежен.
Забелы `пам`: 0154.477(1), 550(121), 1334(3),
  1447(1). Остальное — `конд`: сообщения/таблицы.
Процедур с `пб (Мn)` и целей вызовов НЕТ.

## 4. СВЯЗЬ С МАКРОКОМАНДАМИ

НАЙДЕНО КАК ТЕКСТ: НИ ОДНА из 37 команд.
Связь только ПО ФУНКЦИИ (фазе 1 — чтение определений):
- `МАСRО` (macros.be:1) — начало определения; редактор
  читает тело до МЕND и заносит в таблицу ГС.
- `МЕND` (macros.be:6) — конец определения.
- `ФИНИШ` (macros.be:234) — метка конца файла macros.be.
- `GВLА`/`GВLВ` (macros.be:17/123), `LСLА`
  (macros.be:70) — объявления переменных, разбираемые
  при регистрации макроса.
ВАЖНО: байт `∧` = 0x4D в зонах 0147–0177 НЕ
  встречается (MACRO-TABLE-FORMAT.md §3): ∧-параметры
  не хранятся здесь GOST-текстом.
