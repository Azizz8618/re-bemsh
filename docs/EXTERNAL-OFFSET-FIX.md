# Исправление кандидатов на внешние смещения (mnemonic-evidenced)

Дата: 20.11.2026. Репозиторий: `re-bemsh`.

Выполнено переименование только тех кандидатов, у которых основанием
external-вердикта является **мнемоника ветвления/вызова**
(`ПВ/ПВО/ВЖМ/ПО/ПЕ/ЦИКЛ/ПБ/ПИО/ПИНО/ВЫПР`), а не комментарий
`(переход)`. По данным `tools/external_offset_scan.py --json` до правки:
`external_basis = {mnemonic: 65, comment_role: 266}`. После правки:
`external_basis = {comment_role: 266}`, то есть все 65 mnemonic-кандидатов
сняты.

## 1. Правило компактных имён

Метки БЭСМ-6 ограничены **6 символами**, поэтому длинные имена вида
`EXT_BR122_122_Z0055` из `docs/EXTERNAL-OFFSET-CANDIDATES.md` §7 не могут
быть идентификаторами БЕМШ. Принято имя длиной 5 символов:

```
X + 3 цифры отличительной части старой метки + буква семейства
A = ASM (0055-0060), B = БЕМШ (0137-0177), C = B2 (0540-0577)
```

Например: `BR122 -> X122A`, `BR122 -> X122C`, `BR016 -> X016C`,
`B2120 -> X120B`, `AM63 -> X063A`. Все 30 введённых имён имеют
длину 5 символов (≤ 6), внутри каждого файла они уникальны.
Восьмеричное значение `ЭКВ` не изменялось.

## 4. Применённые изменения

| показатель | значение |
|---|---:|
| отобранных меток (с mnemonic-доказательством) | 17 |
| пар «файл + метка» -> 49 определений `ЭКВ` переименовано | 49 |
| изменённых `.be` файлов | 24 |
| переименованных ссылок в операндах всего | 93 |
| из них отобранных mnemonic-использований | 65 |
| из них попутных ссылок той же метки в том же файле | 28 |
| введено компактных имён (уникальных) | 30 |

Попутные ссылки переименованы обязательно: определение `ЭКВ` действует
внутри файла, поэтому все обращения к той же метке в этом файле должны
иметь новое имя. Три ссылки с вердиктом `LOCAL_ADDR` и комментарий-
обоснованные usage не служили основанием выбора; в незатронутых файлах
метки оставлены без изменения.

Строка определения получила комментарий вида:

```
X122A ЭКВ '122' , возможное смещение во внешнем модуле
* (ГИПОТЕЗА) [EXTERNAL-OFFSET-CANDIDATES.md:241]
```

Длина строки ≤60, длина комментария ≤55, перенос со звёздочкой `*`.
Комментарии в строках использования сохранены как историческое
описание; менялся только идентификатор в операнде.

- Все вердикты остаются гипотезами: каталог процедур в
  `docs/PROCEDURES-*.md` сам помечен `ГИПОТЕЗА`.
- Номера строк `EOC:N` относятся к снимку
  `docs/EXTERNAL-OFFSET-CANDIDATES.md` на момент правки; документ
  редактировался параллельно, поэтому 40 ссылок были приведены к
  актуальным номерам после его изменения.
- Повторное сканирование после правки: `mnemonic = 0`,
  `comment_role = 266` (только непереименованные метки).
