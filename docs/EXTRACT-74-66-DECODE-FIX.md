## 2. РАЗКЛАДКА ПОЛЕЙ И ПРИЧИНЫ ПРОПУСКА

24-битная команда (схема `docs/SIPROD/04-mashinnaya-model.red`):

```
биты 23-20 регистр | бит 19 1-я структура | бит 18 EXP
биты 17-12 КОП (2-я структура) | биты 11-0 адрес
```

- Э66 = `0x036000` (КОП 066, 2-я структура, **IMMEX**);
  Э74 = `0x03c000` (КОП 074, **STOP**, уникальный тип);
  Э72 = `0x03a000` (КОП 072, **ADDREX**).
- EXP (бит 18) превращает 12-битный адрес в `070000+младшие 12`.
  `disbesm6` печатает 5 цифр (`'73447'`), `siprod_asm` - 6
  (`'703447'`); в `.be` используется 5-значная форма `'7abcd'`.
  Все 20 целевых половин имеют **EXP=0**; EXP есть только у левой
  `УВВ` в 0141:449 (`'72100'`).
- `disbesm6` печатает STOP через `%08o` без разбиения полей
  (`disbesm6.c:393-414` → `default`), поэтому `00 074 0000`
  выглядит как сплошное `00740000`.

**Корень пропуска.** В отчётах указано «нет мнемоники в трансляторе
(Э66/Э72/Э74)». Это **неверно**: мнемоники есть и в `siprod_asm.OPS`,
и в таблице `disbesm6.c`, и, что важно, **принимаются реальным
транслятором МАКРО-БЕМШ 06/78**. Эксперимент с минимальным заданием
без директив `Е`/`М` дал `ОПЕРАЦИИ НET` для всех Эxx, включая Э70;
с директивами `Е`/`М` даёт `ЧИCЛO OШИБOK=0000` и корректные слова
`12 064 6704`, `14 074 4653`, `04 066 6143`, `12 072 1731`.
Причиной пропуска была ошибка в методике проверки предыдущих агентов,
а не отсутствие мнемоники.

**Реальное ограничение: авто-`мода`.** Транслятор вставляет слово
`00 22 00000` перед командой типа ADDREX/STOP, оказавшейся в ЛЕВОЙ
половине, и сдвигает все последующие слова. IMMEX (Э66) в левой
половине сдвига **не вызывает** (проверено на 14 случаях). Правило:

```
левая половина kind ∈ {addrex, stop, call} → НЕ байтово безопасно
иначе (immex, str1, reg2, addrmod, ...)     → байтово безопасно
```

Единственный случай из 20, попадающий под запрет: **0145:230**
(L `Э73 '4663'(М13)` = ADDREX, R `Э72 '7655'(М12)`). Пересборка дала
`ДЛИHA ПPOГ=02001` и 572 различия с первого же слова. Он **должен
остаться `КОНД`**.

## 3. СЕМАНТИКА ПО ТЮРИНУ (согласована с экспериментом)

- **Э74** (`00 074 0000`): конец задачи / передача управления по
  заранее установленному АИСП (ЭК 072 с константой
  `22642531 21233462В`); вторая зафиксированная функция: запрос
  номера терминала. `BASIC`, не привилегированная команда.
  `СТОП` (`0x0d8000`, 1-я структура, PRIV) **не является заменой**.
- **Э66** (`К 00 066 Аплли р`): обращение к стандартной программе;
  M15 задаёт адрес размещения СП, операнд это адрес информации.
  Портит M16. `ADDREX`-экстракод (Э64/Э70) **не является заменой**.

Это подтверждает, что замена возможна только «точка в точку» по
тем же битам, через те же мнемоники Э74/Э66/Э72, а не через
семантически близкие команды.
