# Реконструкция зоны 0137: `bemsh/MBE-Z0137.be`

Дата: **19.11.2026**. Результат: **PASS — 1024/1024 слов, 0 байт отличий**.

## 1. Что сделано

Реализована **реальная сборка** зоны 0137 штатным транслятором
ИПМ МАКРО-БЕМШ ВЕР.06/78 (dispak) из исходника
`bemsh/MBE-Z0137.be`. Объектные слова, полученные из листинга
транслятора, построены в `silver.bin` и пословно/побайтово
сверены с эталоном `gold/MBE-Z0137-L1.bin`.

| Параметр | Значение |
|---|---|
| Эталон | `gold/MBE-Z0137-L1.bin`, 6144 байт = 1024 слова |
| Исходник | `bemsh/MBE-Z0137.be`, 1044 строки |
| Команд в исходнике | 10 (слова 0–4) + 1019 `КОНД` + `ФИНИШ` |
| Длина программы | `ДЛИHA ПPOГ=02000`₈ = 1024 слова |
| Ошибки транслятора | `ЧИCЛO OШИБOK=0000` |
| Совпало слов | **1024 из 1024** |
| Отличий | **0 байт** (`disbesm_verify.sh`: ✓ Файлы идентичны) |

Воспроизведён **весь диапазон** слов 0000–1777₈ (0–1023).

## 2. Точные команды

```bash

# копии образов ( originals НЕ трогаются ) уже в /tmp:
#   /tmp/.private/azizz/rebuild-0137/{2048,2053,2099,2248}
# полный воспроизводимый цикл:

```

Скрипт сам:
1. отказывается работать, если `WORK` не под `/tmp` или совпадает
   с настоящим каталогом образов (`/usr/local/share/besm6`, `~/.besm6`,
   `simh/BESM6/MD/EC5061`);
2. копирует недостающие образы (2048, 2053, 2099, 2248) в `WORK`;
3. собирает задание с `0-0` (только листинг — образы не пишутся);
4. гонит `dispak -l` с `BESM6_PATH=$WORK` (только копии);
5. разбирает листинг в 48-битные слова (колонка адреса [25:30],
   поле команды/слова [31:]), пишет `silver.bin`;
6. печатает пословный счётчик и зовёт `tools/disbesm_verify.sh`.

## 3. Как кодировались слова

Правила из `re-siprod` (`siprod_asm.py`, `siprod_bemsh.py`):

* 48-битное слово = две 24-битные половины (левая, правая).
*-half: `reg 23..20`, код операции, адрес; ` EXP` (бит 18)
  даёт запись `'70000'`; нулевой адрес опускается; `сч 0` → `СЧ`.
* Первые 5 слов — **настоящие команды** (проверены по `disbesm6`):

```
слово 0:  ЗП          / ЗП   '70000'
слово 1:  ЗП          / СБР
слово 2:  ЗП          / ЗП   '3'      (адрес 3 = D00003)
слово 3:  ЗП          / РЕГ  '3554'
слово 4:  ЗП          / ПБ   (М3)
```

* Слова 5–1023 объявлены как `КОНД В'<16 окт. цифр>'` —
  восьмеричная константа на все 48 бит. `В'...'` в этом
  трансляторе — **восьмеричная** запись (проверено: шестнадцати-
  ричные цифры `8`, `9`, `A`–`F` дают `ЧУЖОЙ CИMBOЛ`).

Разбор листинга (`0-0`) вместо записи модуля (`1-1`) выбран
намеренно: в режиме `1-1` транслятор вставляет записи перемещений
(например, после `конд 6400000000000000` вставляются 2 слова
`00000fffff00 004000000001`), поэтому дамп записанной зоны
**не** идёт побайтово с эталоном. Листинг даёт «чистые» слова
до применения перемещений.

## 4. Честный список blockers (что НЕ восстановлено семантически)

Побайтовая идентичность достигнута, но **полная семантическая
реконструкция исходника не выполнена**. Остальное (кроме слов 0–4):

1. **Код/данные неразличимы после `пб (М3)`** (слово 4). `disbesm6`
   без таблицы точек входа печатает слова 5–1023 как `конд`, поэтому
   они выведены сырыми `В'...'`, а не командами. Это данные,
   таблицы мнемоник (0137.0050–0120 в KOI-7), маски и забелы.
2. **Зона 0137 — образ загруженного транслятора, а не DMS-модуль.**
   В ней есть абсолютные адреса и слова с битами перемещения;
   транслятор не порождает их из «красивого» исходника напрямую.
3. **Макрорасширенный код.** Макросы (`CALL → ВЖМ + ПАМ 0`, экстракоды `Э50`–`Э77`) разворачиваются транслятором; по бинарнику
   без текста макроопределений восстановить вызовы макросов
   невозможно — только результат их раскрытия.
4. **Перемещаемые слова.** В режиме записи (`1-1`) часть констант
   снабжается relocation-записями; для побайтовой сверки используется
   режим листинга (`0-0`), что корректно, но не даёт модуль для загрузки.
5. **Поддержка only мнемоник `disbesm6`.** Команды слов 0–4 покрыты
   таблицей `OPS` (`siprod_asm.py`); остальные слова командами не
   expressed, поэтому вопрос «unsupported mnemonics» для них не стоит.

Итог: **побайтовая (объектная) реконструкция всей зоны — PASS**;
семантическая реконструкция — только первые 5 слов (слова 0–4),
остальное — верифицированные константы.
