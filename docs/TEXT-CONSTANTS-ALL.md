# Текстовые константы БЭСМ-6 во всех кодировках: полный каталог

Дата: 20.11.2026. Образ: 2348 (Д-2048/2348 МГУ). Источник: `gold/*.bin`, 69 зон по 1024 слова (6 байт/слово).
Инструмент: `python3 tools/text_decode_all.py --all`. Эталонные образы не изменялись (только чтение).

## 1. Методика

Каждое слово разбирается в 4 кодировках сразу: **GOST-8** (побайтово, `gost_to_unicode_cyr`), **KOI-7** (`koi7_to_unicode`), **6-бит TEXT** (8 групп по 6 бит, код = ASCII−0x20), **ITM** (`itm_to_gost` → GOST).
Биасов, поворотов и обменов половин нет: калибровка даёт identity 5/5. disbesm6 печатает п'…' только для GOST-8; в'…' может быть корректным 6-битным TEXT или KOI-7.

**Отбор.** Кириллический score сам по себе ничего не доказывает: почти любой байт 0x20…0x4D GOST даёт букву. Поэтому GOST-кандидат принимается только при словарном слове (ИПМ, МАКРО, БЕМШ, ВЕР, ВАР, ОШ, СПР, …) или частом диграфе (≥0.35), плюс отсутствие ведущих нулей и латиницы. TEXT — ≥5 печатных позиций из 8, только «уверенные» коды (dtran `is_likely_text`), ≥4 уверенных символа, анти-маска повтора >50%. KOI-7/ITM — только связная фраза целиком.

Соседние правдоподобные слова объединяются в фразы; дубликаты по содержимому удаляются. `·` = нет глифа.

## 2. Таблицы кодировок

| Кодировка | Бит/симв. | Симв./слово | Источник таблицы |
|---|---:|---:|---|
| GOST-8 | 8 | 6 | encoding.cpp:36, gost10859.h |
| KOI-7 | 8 | 6 | encoding.cpp:681 (KOI-7 Н2) |
| TEXT | 6 | 8 | ASCII−0x20, re-forex docs 19/20 |
| ITM | 8 | 6 | encoding.cpp:463 (автокод Чайковского) |

GOST-8 (кириллица): 0x00…0x09 → `0…9`, 0x0A…0x0F → `+ - / , . пробел`, 0x20…0x3E → `А…Я`, 0x3F…0x4D → латинские омоглифы. Байт ≥0x80 — глифа нет (`·`).
KOI-7: 0x20…0x5F — ASCII, 0x60…0x7F — кириллица (ЮАБЦДЕФГ…), 0x05…0x1F — служебные глифы. Именно KOI-7 записана таблица мнемоник в `0137.0050–0120`.
TEXT (6 бит): коды 0, 10, 15, 16–25, 29, 30, 33–58 — уверенные; остальные — управляющие. Код 0 — пробел/паддинг.
ITM: таблица разрежена; большинство байт не имеют глифа.

## 6. Честный список неразобранных фрагментов

Следующие адреса из docs/TEXT-CONSTANTS.md §6.3 остаются недешифруемыми ни одной из четырёх таблиц: это смешанные числа/коды, а не текст. Гипотеза о неправильной таблице здесь не работает (docs/TEXT-DECODING-INVESTIGATION.md §6.1).

|---|---|---|
| `0173.1475` | АР009А0Р009АА | смешанные байты (числа + глифы) |
| `0176.0125` | К8FV/С/-Х900 | смешанные байты (числа + глифы) |
| `0170.1653` | 2А10+G2А20+I | смешанные байты (числа + глифы) |
| `0152.0053` | 4,Э7ZЦ9007ZШ9007ZЫ | смешанные байты (числа + глифы) |

Оговорка: disbesm6 печатает п'…' и для чисел, если все 6 байт попали в «хороший» диапазон. Пример `0140.0044` (`40 00 00 09 00 00` → `F00900`) — машинное слово, не текст.
