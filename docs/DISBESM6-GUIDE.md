# Практическое руководство по `disbesm6` (для аннотирования МВЕ60)

Источник — `/home/azizz/dispak/disbesm6/disbesm6.c` (1011 строка); бинарник
`/usr/local/bin/disbesm6` (md5 `f40ca3e302c45a5d650d849eb5db2882`).
Все примеры получены на зоне `0137₈` (`/tmp/.private/azizz/mbe137.bin`, 6144 байт).

## 1. CLI — что реально работает

| Ключ | Реальное поведение |
|---|---|
| `-aN` | Адрес загрузки, **восьмеричный, только слитно** (`-a10000`). `-a 10000` → loadaddr=0, а `10000` — отдельный файл. Цифры 8/9 → `Usage:`. |
| `-eN` | Entry point, восьмеричный, та же форма. **Обязателен** — без него весь код печатается как `конд`. |
| `-RN=x` | Начальное значение регистра N (1…017), восьм., маскируется 17 бит. Ключ для трассировки `пб (М3)`. |
| `-nfile` | Таблица символов; имя файла — остаток аргумента. Формат `fscanf("%o %d %63s")`: адрес восьм., **тип: `1 = W_DATA`, `2 = W_CODE`**, имя ≤63. `-` вместо имени — только пометить тип/достижимость. |
| `-r` | **Инертен**: `prrel()` (ст. 297–315) внутри `#if 0`. Вывод с/без `-r` идентичен; `crc` не печатается. |
| `-b` | **Инертен**: `bflag` нигде не читается. |
| файл | Обрабатывается **немедленно**; флаги глобальны и действуют на последующие файлы. |

Имя символа `START` добавляется автоматически как `W_CODE` на `entryaddr`
(ст. 778). В конце всегда добавляются символы на 32768 и 0 (ст. 880–881).

**Расхождение исходник/бинарник:** в `make_syms()` ст. 892 исходник пишет
`G%05o`, установленный бинарник — `A%05o`. Фиксируем в отчётах, каким
бинарником получен листинг.

## 2. Формат вывода

```
         File: mbe137.bin
         Type: Binary
         Code: 6144 (02000) words        /* байт; слов = size/6 */
      Address: 0
                                СТАРТ	'0'     /* печатает loadaddr, НЕ entry */
...
                                ФИНИШ            /* всегда */
```

- Первый байт потока — **UTF-8 BOM** (`EF BB BF`) — учитывать при `diff`/`head`.
- Код печатается **двумя строками на слово**: левая половина `memory>>24`,
  правая `memory & 0xffffff`. Правая подавляется при `W_NORIGHT` и нуле/`02200000`.
- Адрес `%5o`, `:` вместо пробела = `W_STARTBB` (начало базового блока).
- Короткие формы (`STR1/ADDREX/IMM/REG1`): `%02o %03o %04o` = `R | KKK | AAAA`.
  Длинные (`JUMP/CALL/REG2/…`): `%02o %02o %05o` = `R | NN | AAAAA`.
- Адреса операндов (`praddr`, ст. 326–379): точное совпадение → имя символа;
  `name±<дец>` при попадании в окно **fuzz=64**; `< 0100` → десятичное;
  `>= 077700` → отрицательное смещение (`слиа -5(М17)`); иначе `'<восьм>'`.
  Отсюда артефакт `сч D00003+34` — не осмысленная ссылка.
- `* next insn used as data` (ст. 830–831) — ячейка одновременно `W_CODE|W_DATA`
  (например, адрес 0 и 3 в зоне 0137). Это не ошибка, а адресное слово/метка.
- `конд` + `п'<ГОСТ>'` или `в'%016llo'` — данные; `nop/пам <N>` — нули.

## 3. Подводные камни

1. **Забытый `-e`:** `disbesm6 -a10000 mbe137.bin` → `конд п'000400'` и т.п.
   С `-e10000` — `зп`, `сбр`, `пб (М3)`.
2. **Обрыв трассировки:** `пб (М3)` (адрес 4 зоны 0137) обрывает анализ —
   дальше `конд`. Лечение: `-R3=100` и/или `-n` с `01000 2 MBE60`
   (тип 2 = `W_CODE` добавляет точку входа). Проверено: `-R3=100` добавил
   осмысленный код `Э66 '2101'(М4)`; `-n` добавил 64 строки кода.
3. **Статический анализ:** `мод` помещает цель как `W_DATA`, но не отслеживает
   содержимое регистра; `уи` обнуляет `regval`. Самомодифицирующийся код
   будет потерян или помечен как данные.
4. **Предел:** `memory[32768]`, `mflags[32768]`; файл >32768 слов молча
   обрезается; `-a` должен быть `< 0100000`.
5. **Склейка зон:** `disbin()` вызывается один раз на весь файл: одна шапка,
   одна пара `СТАРТ/ФИНИШ`, границы зон **не видны**. Дизассемблировать по одной
   зоне (6144 байт).
6. **Бракованная строка `-n`:** `dis: error reading symbol table`, файл
   символов закрывается, вывод усекается. Тип 32 (`W_UNSET`) не печатается.
7. **Неполное слово:** `codelen = size/6`; хвост не печатается, но проверяйте
   кратность 6.

## 4. Рабочий процесс аннотирования

```bash
# 1) эталон (зона задаётся ВОСЬМЕРИЧНО; tools/ версия хелпера исправлена)
tools/disbesm_extract.sh 2348 137 1 -o gold/MBE-Z0137-L1.bin

# 2) первый проход
disbesm6 -a0 -e0 gold/MBE-Z0137-L1.bin > dis/MBE-Z0137-L1.asm

# 3) подобрать базу (из листинга: вход 01000₈), задать входы и регистр
cat > sym/MBE.tab <<'EOF'
01000 2 MBE60
01205 2 PRINT8
00050 0 ALIAS
EOF
disbesm6 -a10000 -e10000 -nsym/MBE.tab gold/MBE-Z0137-L1.bin > dis/MBE-Z0137-named.asm
disbesm6 -a0 -e0 -R3=100 gold/MBE-Z0137-L1.bin > dis/MBE-Z0137-R3.asm
```

**Сохранять в `.asm`:** адрес, обе половины слова, мнемонику, операнд, `(Мn)`,
метки `A/D#####`, `ноп`, `экв`, `пам`, `конд/п'…'/в'…'`.

**Исправлять вручную (только в комментариях и именах):**
- внешние процедуры по `*EXECUTE` (`PRINT8`, `MON*ITOR`, `PLREG`, …);
- макроразвёртки `CALL → ВЖМ + ПАМ 0` (адрес возврата в M15);
- `Э74/Э70 → КК '74'/'70'` в исходной нотации;
- для таблиц ошибок зон `0173/0177` явно писать `; ТАБЛИЦА ДАННЫХ (ОШ.СПР.НА БЕМШ1)`
  и не пытаться дизассемблировать как код.

**Неопределённость:** помечать `; НЕИЗВ: код/данные?` и вести
`analysis/uncertain.md` (адрес — гипотеза — доказательство).

**Верификация:** `disbesm_verify.sh … --disasm`; ожидаемо `✓ Файлы идентичны`.
Аннотация меняет только комментарии — **ноль байтовых отличий** должен сохраняться.

## 5. Шпаргалка: мнемоника → opcode → операнд

| Мнемоника | opcode | Тип | Чтение операнда |
|---|---|---|---|
| `зп`/`зпм` | 000000/001000 | STR1 | `KKK AAAA`; `'70000'` = адрес 0o70000; `(Мn)` — индекс |
| `пб` | 0b0000 | JUMP | `arg2 = opcode&077777` + `(Мn)`; `пб (М3)` — обрыв трассировки |
| `пв` | 0c8000 | CALL | `arg2` + `(Мn)`; возврат в M15 |
| `по`/`пе`/`цикл` | 0b8000…0f8000 | BRANCH | `arg2` + `(Мn)` |
| `э74` | 03c000 | STOP | `'<oct>'(Мn)`; в исходнике `КК '74',…`; обрывает трассировку |
| `э70`/`э64`/`э67` | 038000/034000/… | ADDREX | `'<oct>'(Мn)`, цель помечается `W_DATA` |
| `э50…э77` | 028000…03f000 | IMMEX | `'<oct>'(Мn)` — константа, не адрес |
| `рег` | 002000 | IMM | `'<oct>'(Мn)` |
| `сда`/`счмр` | 01e000/019000 | IMM64 | база 64 + десятичная дельта: `сда 64-23` |
| `уи`/`счи`/`сли` | 020000…025000 | REG1 | `М<opcode&037>` и `(М<reg>>20)` |
| `уиа`/`слиа` | 0a0000/0a8000 | REG2 | `arg2` + `(Мn)`, ноль печатается явно |
| `конд`/`пам` | — | данные | `в'%016llo'`, `п'<ГОСТ>'`, `пам <N>` |
| `вжм` (макрос CALL) | — | VJM | `ВЖМ <sym>, М15`; следующее слово — `ПАМ 0` |
